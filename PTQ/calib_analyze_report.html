校正 pattern 挑選報告

結論

    這份報告只看 graph 的輸入 tensor。挑選對 graph 內部各層是否合適，要用量化後模型的輸出來判斷。

    建議挑選

    「被夾的值」＝落在 range 外、上板後會被夾到邊界的值佔全部的比例；「有值被夾的 frame」＝至少有一個值被夾的 frame 比例，兩者都是精確計數。SQNR 是在每個 tensor 最多 個抽樣值上實際量化再反量化算出來的；「含被夾」把被夾的值算進誤差，「不含被夾」只看 range 內的值（也就是解析度）。三種格式共用同一份資料：8x8 看 8-bit 欄，16x8 和 16x16 看 16-bit 欄。range 一律包含 0（min/max 量化讓 0 可以被精確表示）。
    「隨機」和「丟極端值」兩組對照是用整池本身評分的：整池的極值就在評分資料裡，所以會高估丟掉極值的代價；不偏的數字請用 coverage 子命令對另一份沒看過的錄音評估。

    graph 內部的 tensor

    每個 frame 各自帶著錄下來的 state，逐一用 FP32 graph 重跑，記錄每個 ONNX tensor 的最小值和最大值（只重排資料的 op 不列）。「保留」＝挑出的 frame 涵蓋基準 range 的比例；「超出的 frame」＝基準裡有值落在挑出的 range 之外的 frame 比例，上板後這些值會被夾。基準是套用 clip 預算後剩下的 frame。range 變窄的列排在前面。

    互動挑選

    點選單位：
    tail ratio＝絕對值最大值 ÷ 第 99.9 百分位的絕對值，越大代表少數值把 range 撐開。「中間 99.8% 佔 range」越小，代表大部分的值擠在 range 的一小段裡。「固定位置」表示極端值總是落在同一個 channel 或位置：那是特徵縮放的問題，刪 frame 解決不了。

    每個 frame 的絕對值最大值（點擊可丟掉或放回）

    保留目前決定最小值或最大值的 frame已丟掉

    SQNR 與丟掉的 frame 數

    依「最極端的先丟」的順序，每丟一些就用剩下的 frame 重算 range，再對整份校正檔評分（被丟的 frame 的值會被夾）。紅線是上方滑桿的位置。

    來源

    range 收斂情形 依隨機順序一個一個加入來源，最不穩定的 tensor 的 range 達到最終寬度的幾 %（實線：中位數；虛線：第 10 百分位）。曲線越早到 100%，代表再多錄資料越不容易出現新的極值。
    「拿掉後 range 縮小」：只拿掉這一個來源時，range 縮小最多的 tensor 縮了多少。數字大的來源獨自撐起 range，值得去聽，確認是真實會遇到的情境還是壞資料。勾選「丟掉」可整個來源一起丟。

    名詞說明

    min/max 校正
    converter 用每個 tensor 在校正資料裡的最小值和最大值決定 range。多一個極端 frame，range 就變寬、step 變粗；少一個，上板遇到那種值就會被夾。
    為什麼數量本身不重要
    只要挑出的 frame 包含每個 tensor 的最小值和最大值，輸入的 range 就和整池相同。數量影響的是 graph 內部各層；不加 --onnx 時這份報告看不到。音訊相鄰 frame 幾乎一樣，所以重點是從多少錄音、多少情境裡挑，而不是挑幾個。
    8-bit 和 16-bit 的取捨
    16-bit 比 8-bit 多約 48 dB 的解析度，range 寬一點幾乎無感，被夾掉的代價比較大；8-bit 剛好相反。三種格式共用同一份資料時，要同時看兩欄。
    grid
    這份報告的輸入 grid：。非對稱＝range 包含 0、整數 zero point；對稱＝±絕對值最大；2 的冪次＝對稱、上限取到 2 的冪次（定點格式輸入的 scale）。第一個 frame 全為 0 的 tensor 視為 recurrent state：板端 state port 的 zero point 必須是 0，所以非對稱時 state 改用對稱 grid 評分。
    graph 內部的 tensor
    輸入看起來普通的 frame，也可能讓 graph 裡某一層出現最大值；只看輸入來挑，這種 frame 可能被丟掉，那一層的 range 就會變窄。加上 --onnx（預設用校正時一起匯出的 graph）會把每個 frame 用 FP32 graph 重跑一次，連內部 tensor 的極值 frame 一起保留，並在上面列出比較。互動挑選區仍然只依輸入計算。
    限制
    不加 --onnx 時只看輸入 tensor；SQNR 是抽樣估計；「丟掉的 frame」是依輸入的極端程度排序，不代表它在 graph 內部也最極端。
