校正 pattern 挑選報告

結論

    建議挑選

    「有值被夾的 frame」＝至少有一個值落在 range 外、上板後會被夾到邊界的 frame 比例（逐 frame 精確計數）。SQNR 是在每個 tensor 最多 個值上實際量化再反量化算出來的（值太多時，從 個 frame 裡抽）；「含被夾」把被夾的值算進誤差，「不含被夾」只看 range 內的值（也就是解析度）。三種格式共用同一份資料：8x8 看 8-bit 欄，16x8 和 16x16 看 16-bit 欄。range 一律包含 0（min/max 量化讓 0 可以被精確表示）。「隨機」對照用整池本身評分，會高估丟掉極值的代價；不偏的數字請用 coverage 對另一份沒看過的錄音評估。

    資料夠不夠：輪流拿掉一組來源

    來源分成幾組，每次拿掉一組，用其餘各組的 frame 定出 grid，再看被拿掉那一組的值超出多少（超出的量 ÷ grid 寬度）。輸入照報告的 grid（state 用對稱），graph 內部用含 0 的非對稱 grid。「超出的 frame」是超出最多的那一組裡有值超出的 frame 比例。標「softmax 前」的 tensor 走到 softmax 之前沒經過任何 activation：這類值被夾平時，最大的幾個會變成一樣大，softmax 就選不出原本最大的那一個。這些數字沒有驗證過的門檻。

    graph 內部的 tensor

    每個 frame 各自帶著錄下來的 state，逐一用 FP32 graph 重跑，記錄每個 ONNX tensor 的最小值和最大值（只重排資料的 op 不列）。「保留」＝挑出的 frame 定出的 grid 佔整池 grid 的比例；「超出的 frame」＝整池裡有值落在挑出的 grid 之外的 frame 比例，上板後這些值會被夾。grid 是含 0 的非對稱 min/max。range 變窄的列排在前面。

    輸入 tensor

    tail ratio＝絕對值最大值 ÷ 第 99.9 百分位的絕對值，越大代表少數值把 range 撐開。「中間 99.8% 佔 range」越小，代表大部分的值擠在 range 的一小段裡。「channel 集中」「位置集中」＝峰值最大的 channel（或位置）÷ 中位數，括號內是一般 frame 裡的同一個比值，@ 後面是從 0 數的位置。「固定」＝一般 frame 裡也很大、而且多數 frame 是同一個位置；「輪流」＝幾個位置輪流最大；這兩種都是特徵縮放的問題，刪 frame 解決不了。「少數 frame」＝只有少數 frame 撐出來的。

    每個 frame 的絕對值最大值

    frame 的峰值（frame 太多時，每根柱子是一段 frame 裡最大的）決定最小值或最大值的 frame來源分界

    來源

    range 收斂情形 依隨機順序一個一個加入來源，最不穩定的 tensor 的 range 達到最終寬度的幾 %（實線：中位數；虛線：第 10 百分位）。曲線越早到 100%，代表再多錄資料越不容易出現新的極值。
    「拿掉後 grid 縮小」：只拿掉這一個來源時，grid 縮小最多的輸入縮了多少，也就是 step 變細多少；後面是 16-bit 的 step 變化，和這個來源裡撐出極值的 frame（從 0 數）。數字大的來源獨自撐起 range，值得去聽，確認是真實會遇到的情境還是壞資料。

    名詞說明

    min/max 校正
    converter 用每個 tensor 在校正資料裡的最小值和最大值決定 range。多一個極端 frame，range 就變寬、step 變粗；少一個，上板遇到那種值就會被夾。
    為什麼數量本身不重要
    只要挑出的 frame 包含每個 tensor（輸入和 graph 內部）的最小值和最大值，range 就和整池相同；之後再加落在這些範圍內的 frame，step 也不會變。音訊相鄰 frame 幾乎一樣，所以重點是從多少錄音、多少情境裡挑，而不是挑幾個。
    8-bit 和 16-bit 的取捨
    16-bit 比 8-bit 多約 48 dB 的解析度，range 寬一點幾乎無感，被夾掉的代價比較大；8-bit 剛好相反。三種格式共用同一份資料時，要同時看兩欄。
    grid
    這份報告的輸入 grid：。非對稱＝range 包含 0、整數 zero point；對稱＝±絕對值最大；2 的冪次＝對稱、上限取到 2 的冪次（定點格式輸入的 scale）。recurrent state（報告記錄的，或第一個 frame 全為 0 的 tensor）在板端 state port 的 zero point 必須是 0，所以非對稱時 state 改用對稱 grid 評分。
    限制
    內部 range 是 FP32 graph 的值；converter 之後的調整（合併 op、查表類函數夾範圍、多個 tensor 共用 scale）和遞迴 op 內部的 gate 都不在裡面。SQNR 是抽樣估計。量化後的精度要用量化後模型的輸出判斷。
