6.4 AEC Preset — 單一 Pareto 旋鈕

preset 改動的欄位為 min_gain_floor_far_active_db（far-active 殘響 gain 地板，權衡回音消除 ↔ 近端保留）、min_gain_floor_dt_db（double-talk 地板）與 min_gain_split_floor_enabled（aec_config_from_preset() 實測）：

Presetfar-active floorDT floorsplit floor特性 / 場景
mild−20 dB−20 dB開近端優先 — 保留更多近端、回音漏更多
balanced ★−28 dB−20 dB開預設、通用
aggressive−38 dB−30 dB開回音優先 — 壓更深、近端損失較多，高 echo 環境
no_floor—（惰性）—（惰性）關移除地板機制，這條軸最深的操作點，近端損失最大

執行期用 aec_set_preset(aec, preset, ramp_ms) 改（ramp 範圍 [0, 60000] ms；DT floor 與 split floor 一律立即階躍）。完整 ours / AEC3 / Speex 三方對照見 AEC/README.md。

6.5 NR 降噪等級

NR 的強度 preset 只改 g_min_db（最大抑制量，amplitude dB）、q（語音先驗機率）、xi_min_db 與 noise_over_subtraction；時域平滑 alpha_attack／alpha_decay 各等級相同（alpha_g 在增益路徑上不被讀取）：

等級g_min_dbq推薦場景
Mild−20 dB0.58高 SNR (>10 dB)、近端品質優先、保留細節
Moderate−23 dB0.54介於 mild 與 balanced
Balanced−25 dB0.52預設、一般場景
Aggressive−28 dB0.45低 SNR (<5 dB)、需要安靜背景
等級選擇 trade-off：
  • Mild：語音失真最小，但靜音段仍聽得到底噪
  • Balanced：echo/quality 平衡，適合通用語音場景
  • Aggressive：背景幾乎靜音，但低 SNR 下語音可能有 musical noise / 鈍化

詳細參數調整指南見 NR/docs/parameter_tuning.md。

7. 已知限制

類別限制
輸入 單通道、8 / 16 / 48 kHz，無 spatial filtering
AEC 線性模型 非線性 echo（speaker 飽和）靠 RES 壓制，無獨立非線性模型
AEC 穩態 far-end 弱信號段 linear AEC 仍可能在弱信號段把語音吸收
AEC delay estimation matched-filter delay estimator 在低 SNR 或強非線性場景可能鎖到錯的 delay
NR 突發噪音 impulse / crackle / 敲擊 — MCRA TC 跟不上
NR 噪音突升 / 突降 minimum tracking 需收斂（視窗 L 約 512 ms 的 wall-clock），期間噪音可能漏抑制
NR 音樂背景 SPP 二元假設（語音 vs 噪音），音樂被誤判為語音保留
NR 強迴響 reverb tail 與穩態噪音相近，可能被誤抑制
RES musical noise 低 SNR 下仍可能殘留
