3. AEC — PBFDKF + Shadow Filter

核心是 PBFDKF (Partitioned Block Frequency-Domain Kalman Filter)，搭配 shadow filter 做雙濾波器策略。

3.1 PBFDKF 架構

圖 3：PBFDKF 結構 — 頻域 partition 卷積 + Kalman 權重更新
為什麼用 PBFDKF？
  • 頻域處理：FFT 加速卷積，降低複雜度
  • Partition：把長 filter 切成多個短 partition，減少 latency
  • Kalman：動態調整 step size（Q/R），比固定 mu 的 NLMS 收斂更快、追蹤更穩
項目值
block_size256 samples (= 2 × hop，16 kHz 預設 256/128)
fft_size256 (= frame size)
n_partitionsceil(filter_length ÷ hop) = 7（16 kHz 預設 FL=832）
Kalman Q (model uncertainty)1e−3 (kalman_q_high，未收斂), 1e−6 (kalman_q_low，收斂後)
main filter step size mu0.3

3.2 Shadow Filter 雙濾波器策略

圖 4：Shadow Filter 雙濾波器策略 — main 穩定輸出, shadow 快速追蹤
為什麼要兩個 filter？

單一 filter 必須在「快速追蹤 echo path 變化」和「DT 段抗污染」之間取捨。雙 filter 各司其職，再用 bidirectional copy 自動把較好的權重複製過去，兩全其美。

3.3 Echo Path Change (EPC) 偵測

當 main + shadow 兩者誤差同時上升、且差距變小時，視為 echo path 變化（移動、新的反射路徑等）：

errors_rising = (total_err > prev_total_err × 1.5)  &  delta_ratio < 0.3

此判定即 epc_update_shadow_rise()（epc_total_rise=1.5、epc_delta_threshold=0.3）；far-end 穩態時事件被丟棄。EPC 另有兩個來源：delay 改變（epc_force_delay()）與 EPV 偵測。觸發後 epc.active 維持 epc_hangover 個 hop（authored 20 hops @10 ms，建立時 retime），期間：

  • 收斂穩定旗標要求 !epc.active，不會被判為已穩定
  • double-talk 指標被抑制（raw_dt 歸零、is_stationary_dt 清除、shadow_dt ×0.08）
  • epc_active 隨 AecResContext 交給後級

3.4 Stationary far-end DT 保護

問題場景：白噪音、風扇、冷氣等穩態 far-end + 近端有人講話 → 傳統 DT 偵測全部失效（dt_indicator → 0, coh² → 1），RES 把語音當 echo 壓掉。

AEC3 post chain 以 StationarityEstimator 與 is_stationary_dt 旗標處理這個場景，演算法見 lib/aec/docs/aec_methods.md §3.1。
