Audio_ALG

底層函式庫

Audio_ALG 透過 lib/deps.mk 和三個 pin 解析相依庫。以下連結適用於四個 repo 位於同一層目錄的完整 checkout。獨立閱讀 Audio_ALG 時，本庫的模型與 pipeline 手冊都可離線開啟。

AEC

線性回音消除、delay estimator、殘留回音抑制，以及交給後級使用的誤差信號。 AEC 離線文件

NR

頻域噪音估計、降噪增益與參數調整。 NR 離線文件

audiolib

FFT／STFT、視窗、HPF、resampling，以及 VAD、DOA 和 beamforming。 audiolib 離線文件
