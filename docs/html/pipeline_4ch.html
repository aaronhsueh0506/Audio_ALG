audio_pipeline_4ch — 4 mic 共用 delay + 4 條線性 AEC + SRP/BF(唯一包起來的單元)

概要

兩層結構(pipelines/4ch_aec_bf_nr_res/),只有「多聲道線性 AEC + BF」被包成一個單元:

  • 前端 4aec_nr_res(FourAecNrRes):1 個共用 far aligner(delay_mode=MATCHED 時是 1 個 DelayAec matcher + 1 條共用 aligned render delay line;FIXED/EXTERNAL_ALIGNED 時 matcher count = 0,兩者都不 carve)→ 4 條獨立線性 AEC lane → 外部 beamformer 權重投影。每 hop 兩個呼叫:four_aec_front_process()(delay + 四條 lane,交出借用的 FourAecFront)與 four_aec_fuse()(用外部權重投影,填 SeSpecFrame)。RES、NR、CNG 與 iFFT 不在前端內:它們是獨立的函式庫物件,各有 mem_size／init,由應用初始化並明寫串接 se_res_stage_gain → se_anr_stage_gain → sk_min_f32 → sk_capply_gain_f32 → aec_cng_fill → ac_istft_push(範例:pipelines/samples/se_sample_chain.h),不複製 NR/RES 到每條 lane,也沒有函式指標表。
  • 單元 audio_pipeline_4ch(AudioPipeline4Ch):把 SRP-PHAT DOA + BF(audiolib/doa、audiolib/bf)接進 four_aec_front_process() 與 four_aec_fuse() 之間,擁有它們的生命週期,並提供保守 energy-VAD fallback。輸出是 BF 後誤差頻譜與有效權重(AudioPipeline4ChBeam);audio_pipeline_4ch_fuse() 是獨立的可選步驟,填 SeSpecFrame 給後級。單元內沒有 RES／NR／CNG／合成,也沒有神經後濾波:那些由整合者各自初始化並串接。

結構稽核值(*_count()):matched_filter 依 cfg.delay_mode 而定——MATCHED 時 1,FIXED/EXTERNAL_ALIGNED 時 0(無 estimator 可數);linear_aec 恆 4;前端提供 four_aec_nr_res_matched_filter_count()／_linear_aec_count(),單元提供同名的 audio_pipeline_4ch_matched_filter_count()／_linear_aec_count()。後級 stage 是否存在由你的鏈設定決定(例如 se_sample_chain_res()／se_sample_chain_nr() 是否為 NULL),單元沒有 nr／post_res 計數。Lane 0 每 hop 跑真 far-FFT,lane 1–3 經 aec_process_context_shared_far() 借用 lane 0 的 far 頻譜(4 次 far-FFT → 1 次,測試以 four_aec_nr_res_far_fft_real_compute_count() 證明)。支援 16 kHz(fft 256 預設 / 512 明示)與 48 kHz(fft 1024)。

共用 estimator 的 duty-cycle(MATCHED):與 mono lib 同一套機器,delay_est_period_s 預設 0.0(全速);為正值時,估計 solid 且 delay_est_init_s(0.3 s,固定)不變後,matched-filter 分析降為 1-in-K(K=round(delay_est_period_s/hop)÷5,最小 1);estimator 每 hop 照餵(decimation 只作用於分析,不作用於音訊)。回全速的時機不是「立刻」:被略過的 hop 不會發佈新估計,所以 delay 改變/信心流失只能在下一個排定的分析被看見,全速從看見的那個 hop 起恢復——最壞多等一個 duty 週期。windowed-ERLE 自洩漏峰值崩 6 dB 的看門狗可以提早喚醒它,但它必須先讓峰值超過同一個 6 dB 才會武裝。census:four_aec_nr_res_duty_hops_run()(實跑分析的 hop)對 four_aec_nr_res_duty_hops_total()(=estimator_calls 的別名,分母)。已知邊界(已由 test_4aec_nr_res.c 的低 ERLE A/B 場景釘住):lane ERLE 壓在 6 dB 之下時看門狗永遠不會武裝,delay change 的 re-lock 完全由 1-in-K 取樣承擔(mono 同款行為)。

API 用法

/* 單元(含 SRP/BF) */
AudioPipeline4ChConfig cfg = audio_pipeline_4ch_default_config(16000);
AudioPipeline4ChMemReq req;
audio_pipeline_4ch_get_mem_requirements(&cfg, &req);
void* pool = platform_alloc(req.bytes, req.alignment);
AudioPipeline4Ch* p = audio_pipeline_4ch_init_ex(pool, req.bytes, &cfg, &req);

/* 後級是各自的函式庫: RES / NR / CNG / 合成 放進範例鏈的一塊 pool(自己的 mem_size 與 init) */
SeSampleChainConfig sc = se_sample_chain_default_config(16000, audio_pipeline_4ch_fft_size(p));
SeSampleChain* chain = se_sample_chain_init(chain_pool, se_sample_chain_mem_size(&sc), &sc);

AudioPipeline4ChBeam beam;  AudioPipeline4ChFrameInfo info;  SeSpecFrame frame;
audio_pipeline_4ch_process(p, mics_interleaved, ref, &beam, &info);       /* 內建 auto-VAD */
/* 產品有 VAD 時: audio_pipeline_4ch_process_with_activity(p, mics, ref,
 *                    vad_raw, vad_out, frequency_mask, &beam, &info);
 * 要由 lane 頻譜算 mask/VAD 時: process_front(p, mics, ref, &front) → 算 mask → process_beam(p, &front, ...) */
audio_pipeline_4ch_fuse(p, &frame);                       /* 可選: core.enable_post=1 */
P = se_sample_chain_form(chain, &frame);                  /* RES 增益 → NR 增益 → min → apply → CNG */
se_sample_chain_synthesize(chain, P, out);                /* 一次 iFFT/OLA */
/* 任一呼叫被拒或輸出非有限: audio_pipeline_4ch_reset(p) + se_sample_chain_reset(chain) 一起 */
se_sample_chain_destroy(chain);  audio_pipeline_4ch_destroy(p);   /* 不釋放 caller pool */

/* 只用前端 + 自備 beamformer 與後級(4aec_nr_res_static.c 與 tests/conv_chain_4ch.h 是完整範例) */
FourAecFront front;
SeSpecFrame  frame;
four_aec_front_process(core, mics_interleaved, ref, &front);
/* ... 用 front.linear_spectra / front.aligned_ref 算 weights(與可選的 beamformed error) ... */
four_aec_fuse(core, weights, beamformed_error /* 或 NULL */, &frame);
/* 後級由應用串接;frame 為借用視圖,有效至下一次 front_process／reset */
res_gain = se_res_stage_gain(res, &frame);
nr_gain  = se_anr_stage_gain(nr, &frame, extra_noise, 1);
sk_min_f32(total_gain, nr_gain, res_gain, frame.n_freqs);
sk_capply_gain_f32(spec, frame.e, total_gain, frame.n_freqs);
aec_cng_fill(&rng, spec, frame.cn, res_gain, nr_gain, SE_CNG_NR_GAIN_FLOOR, frame.n_freqs);
ac_istft_push(istft, spec, out);
/* 外部 NN 後級(如 ULCNet)只用前端/單元(core.enable_post=0):不呼叫 fuse,下一個 front_process 直接接手。 */

換用別的後級(例如 DFN2)。前端只交出 SeSpecFrame;frame.e 是 RES 與降噪據以估計的 pre-RES beamformed 誤差頻譜,frame.cn／frame.r2 是同一次投影的舒適噪音與殘餘回音 PSD。想插入神經後濾波的應用,在 se_res_stage_gain() 之後自己組 P = E · G_res (+ comfort noise)(範例鏈的 enable_nr = 0、with_synthesis = 0),處理完交給自己的 ac_istft_push()——整條鏈沒有函式指標表,每個應用把自己的幾行寫出來。目前的消費者是 pipeline_dfn_4ch(核心加範例鏈的 RES 增益加 samples/dfn_hop.h)。前端 FOUR_AEC_NR_RES_LAYOUT_VERSION 為 23。

Descriptor 慣例(32-byte 固定 ABI、init_ex 8 點閘)只存在於核心、單元(以及 DFN stage／bridge);範例鏈沒有 descriptor。核心 FOUR_AEC_NR_RES_LAYOUT_VERSION=23、單元 AUDIO_PIPELINE_4CH_LAYOUT_VERSION=18,兩者 descriptor_version 皆 1;單元的 build_flags_hash 摺入核心的 hash(核心 layout bump 會連帶作廢外層 descriptor)。核心 config:delay_mode(AEC_DELAY_MATCHED|FIXED|EXTERNAL_ALIGNED,四條 lane 共用同一個決策)、delay_num_filters(僅 MATCHED,[1,5])、fixed_delay_samples(僅 FIXED,原生取樣點數;其餘須 −1)、capture_proxy_channel(matcher 輸入,[0,3])、max_delay_ms(僅 MATCHED 用於 sizing delay ring,預設 1024,delay ring = ceil(ms×sr/1000)+2×hop+1)、filter_length(0=rate default)、delay_backward_quarantine_enabled(bool,預設 0;開啟後只隔離比現行 delay 更早的新估計,且僅在 capture_proxy_channel 那一條 lane 仍在消除回音時;往後跳與首次取得對齊都不受影響)、delay_backward_quarantine_s(float,預設 1.0;隔離窗長,init 時換算成 hop 數,到期即採用——延後一個窗,不是治癒;不是 pre-echo 誤鎖的解藥;estimator 的 aggregator 回報 dominant matched-filter peak)。產品組態維持預設 OFF。enable_post 決定 lane 是否保留頻域 post context 並 carve fuse 緩衝(0 時 four_aec_fuse()／audio_pipeline_4ch_fuse() 回 INVALID_ARGUMENT)。核心 config 沒有 RES／NR／CNG／preset 欄位(aec_preset、nr_mode、enable_res、enable_nr、enable_cng、legacy_amin 已移除):lane 一律以 AEC_PRESET_BALANCED 導出並只算線性殘留,這些設定屬於你的後級鏈(SeSampleChainConfig)。

執行期強度控制與逐階段耗時

強度屬於擁有 RES 與 NR 的那一層,單元與前端都沒有 preset／mode setter:aec_res_set_preset(se_sample_chain_res(chain), preset, ramp_ms)(ramp_ms 以 dB 線性走到新地板)、anr_set_mode(se_sample_chain_nr(chain), mode)、唯讀的 aec_res_split_floor(res, &live, &target)(線性功率)只作用在鏈裡那一個共用 post 級抑制器與降噪器;對四條 lane 重新指定 preset 是無效操作(lane 以 spatial_linear_context 建立,不走自己的殘留抑制器)。診斷用的 four_aec_nr_res_get_last_timing()(FourAecNrResLastTiming,單元用 audio_pipeline_4ch_last_core_timing())回報前端各階段的 wall-clock 微秒。兩者的呼叫表、回 −1 條件、ramp 與 A/B 量測注意事項、時鐘替換方式收在 pipeline_4ch_detail。

前端輸出契約(FourAecFront 與 SeSpecFrame)

欄位內容擁有者/壽命
FourAecFront.delaydelay_samples/confidence/solid/changed;changed 非零時外部 STFT/OLA 歷史須清除值複製
FourAecFront.formed_hop[4]各 lane [hop] formed 線性 hop(選定/crossfaded 後的 WOLA 合成輸出;候選為 refined／coarse／capture,見下方 formed capture 註)借用 lane buffer;有效至下一次 four_aec_front_process()／reset／destroy
FourAecFront.linear_spectra[4]各 lane formed 頻譜 [n_freqs](與時域 hop 同一次選擇,別名 lane 自己的 buffer,非 copy)同上;reset 不清除,呼叫端必須在 reset 後停讀
FourAecFront.aligned_ref[hop] 本 hop 實際餵給四條 lane 的 delay-aligned 時域 far(ring 未滿時前導為 0)。給外部 NN post(Align-ULCNet far branch)用借用;同上
SeSpecFrame(four_aec_fuse() 填)e=beamformed 誤差、y=投影近端、x=lane 0 的 far 頻譜、r2/cn=投影後的殘餘回音／舒適噪音 PSD、far_hop、max_dt/max_sat/all_converged(對權重有非零響應的 lane 取)、clock_drift、delay 旗標;g_res_ctx 恆為 NULL(lane 不算自己的增益)借用;e 在傳入 beamformed_error 時別名呼叫端的陣列,否則別名實例內 buffer;有效至下一次 front_process／reset／destroy;任何階段都不得寫入

formed seam 的第三個候選是 capture。四條 lane 都以 enable_res=0 / return_res_context=1 建立,而 lib/aec 的 formed 選擇器只在這個 context-only 模式多開一個候選:上一個 hop 的濾波品質判定尚未認可線性估計、且被選中的殘差(refined 或 coarse)在這個 hop 的能量大於同一 hop 的 mic capture 時,該 lane 的時域 hop 與其頻譜一起改送 capture,既有的 30-sample crossfade 承接邊界(不丟 OLA 歷史、不歸零任何 hop)。外部 beamformer 因此可能在這些 hop 上拿到 mic 原樣而不是誤差——那正是「濾波器在加訊號」時該有的行為。enable_res=1 的路徑不走這條,仍由 AEC3 post 自己的頻域 over-output 保護處理。

序列規則:four_aec_fuse() 要求自建構或上次 reset 之後至少處理過一個 front frame(否則 FOUR_AEC_NR_RES_SEQUENCE_ERROR);沒有 token 要歸還。權重無效(全零、非有限)回 INVALID_ARGUMENT 且 front frame 保持可用,呼叫端可修正後重試。從不呼叫 fuse 的應用(例如 ULCNet,enable_post=0)不需要任何「放棄」呼叫:下一個 four_aec_front_process() 直接接手。

停用的增益來源(鏈的 res = SE_SAMPLE_RES_OFF 或 enable_nr = 0)讀 unity 全 1 向量,所以同一個 sk_min_f32 涵蓋所有組合;CNG 只在有 RES 且 enable_cng 時執行。換用別的後級(例如 DFN2、ULCNet)就是換掉最後一個方塊裡的幾行,單元與前端不變。

延遲與 warm-up

  • 演算法延遲:1 hop(WOLA;實測 argmax 127 samples @hop=128 → 8 ms @16k 預設)。
  • delay acquisition:估計值要 solid 且 n_updates≥3 才被接受;開始新的可用 alignment generation 的那個 hop 回報 delay.changed=1——首次 acquisition、unlock 後同值重鎖、鎖定中值改變皆屬之(不只值改變;見 4aec_nr_res.h 的 FourAecNrResDelayState 契約),核心對四條 lane 做 aec_apply_external_realign()(濾波器依 delay 差位移,不重置、不清合成 OLA);外部 beamformer 若自帶 STFT/OLA 狀態,應照 changed 清除。ring 未累積到 delay 樣本前 aligned_ref 前導為 0。
  • SRP/BF warm-up:DOA smoother 需 doa_switch_consecutive=3 次一致觀測才切換;BF RLS 由 vad_out 凍結(vad_out=1 → 凍結適應)。
  • NR 噪聲底的最小值追蹤視窗是函式庫預設的 wall-clock 約 512 ms(L 依 hop 換算)。
