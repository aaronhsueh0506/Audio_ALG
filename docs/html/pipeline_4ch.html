mcab + mcab_sample_beam — 4 mic 共用 delay + 4 條線性 AEC(flow 層)與 SRP/BF(sample helper);RES 由應用用 libaec 自備

概要

四聲道線性 AEC 的 flow 層加一個 sample 層 helper(pipelines/4ch_aec_bf_nr_res/):

  • flow 層 mcab(Mcab;mcab.h／mcab.c;libaudio_pipeline_mcab.a 只含 mcab.o):不是 lib 外殼,lib 物件由應用用各 lib 自己的 get_mem_size／init 建立,以指標注入——4 條 libaec Aec lane(config 由 mcab_lane_config(),或 aec_config_from_level() 加 mcab_apply_lane_contract() 取得)與 delay_mode=MATCHED 時 1 個共用 DelayAec(FIXED／EXTERNAL_ALIGNED 不需要,matcher count = 0)。mcab 不配置、不釋放它們,只持有自己小 pool 的 flow 狀態(delay admission、對齊環、aligned far、per-lane view、fuse 緩衝)。每 hop 兩個呼叫:mcab_process_front()(共用 delay → 4 條 lane,交出借用的 McabFront)與 mcab_fuse(p, W, E, frame)(以呼叫端 beamformer 的權重 W[4][n_freqs]與可選的 beamformed 頻譜 E 投影,填 McabFrame)。mcab 內沒有 beamformer,也沒有 RES、NR、CNG 與 iFFT(McabFrame.g_res_ctx 恆為 NULL)。
  • sample helper mcab_sample_beam(mcab_sample_beam.{h,c};範例碼,不在 archive):擁有 SRP-PHAT DOA 與 BF(audiolib/doa、audiolib/bf)及保守 energy-VAD fallback,把 doa_step() + bf_process_with_weights() 接在 mcab_process_front() 與 mcab_fuse() 之間,輸出 BF 後誤差頻譜與有效權重(McabSampleBeamResult);mcab_sample_beam_fuse() 是獨立的可選步驟。builder mcab_sample_flow.{h,c} 把應用端 init 順序(4 條 lane、DelayAec、mcab)寫在一處。有自己 beamformer 的產品直接用 mcab,不需要 helper。mcab 與 helper 內都沒有 RES、NR、CNG、合成與神經後濾波。RES 由 libaec 管理:要做 RES 的應用在自己的 init 用 aec_res_get_mem_size()／aec_res_init() 建 AecRes(config 取 aec_config_from_level(level, sample_rate),fft_size 設成 mcab_fft_size()),每 hop 以 mcab_sample_res_input(&frame, &in) 填 AecResInput、aec_res_process(res, &in) 取增益,強度 aec_res_set_level(),重設 aec_res_reset()(沒有 destroy)。NR(AnrDenoiser)與合成(AcIstft)同為獨立函式庫物件,由應用初始化並明寫逐 hop 串接。mono 是例外:RES 增益在 aec_process_context() 內算(見 pipeline_mono)。

結構稽核值:mcab_matched_filter_count() 在 MATCHED 時 1、其餘 delay_mode 為 0;mcab_linear_aec_count() 恆 4。Lane 0 每 hop 跑真 far-FFT,lane 1–3 經 aec_process_context_shared_far_from() 借用 lane 0 的 far 頻譜(4 次 far-FFT → 1 次,測試以 mcab_far_fft_real_compute_count() 證明)。支援 16 kHz(fft 256 預設 / 512 明示)與 48 kHz(fft 1024)。

Descriptor 慣例(32-byte 固定 ABI、init_ex 8 點閘)只存在於 mcab 與 DFN stage／bridge;Aec、AnrDenoiser、AcIstft 與 sample helper 只提供大小查詢。4ch flow MCAB_LAYOUT_VERSION=25,descriptor_version 1,只描述 mcab 自己的 pool(lane 與 estimator 由應用建立後注入,SRP/BF 在 sample helper)。欄位分級、固定常數、函式清單、狀態碼與輸出契約收在 pipeline_4ch_params。

如何呼叫使用

呼叫順序(括號為失敗訊號):mcab_default_config(sr) 與 mcab_sample_beam_default_params() → 視需要改欄位 → 查大小(mcab_sample_flow_get_mem_size() 合計 4 條 lane、estimator 與 mcab,mcab_sample_beam_get_mem_size() 查 helper;−1 = 無效)→ 配置 16-byte 對齊的 pool → mcab_sample_flow_init()(內部依序 aec_init ×4、MATCHED 時 delay_aec_init、mcab_init_ex();−1 = config 無效、pool 過小／未對齊、任一物件 init 失敗,靜默無診斷)→ mcab_sample_beam_init(mem, bytes, &cfg, &bp, flow)(NULL = 拒絕)→ 應用自己為 RES、NR、合成查大小並 init(另一塊 post pool)→ 每 hop process_front() → process_beam() → fuse() → aec_res_process() → NR 增益 → 後級 → 任一步非 OK、增益為 NULL 或輸出非有限時 mcab_sample_beam_reset() 加上自己的 aec_res_reset()、anr_reset()、ac_istft_reset()、rng 一起重設 → 拆除 helper → mcab_destroy() → aec_destroy() ×4(mcab_sample_flow_destroy() 含後兩步;都不釋放 caller 記憶體)。descriptor 與大小不可跨 build 快取。範例已在 -Wall -Wextra -Werror 下做過語法檢查(platform_alloc()、stream_next4()、product_vad() 是平台／I/O 佔位)。

flow + helper(含 SRP/BF)+ 自備 RES + NR + 合成

McabConfig cfg = mcab_default_config(16000);                  /* 建立前可改 cfg 欄位(見 pipeline_4ch_params) */
McabSampleBeamParams bp = mcab_sample_beam_default_params();   /* 陣列幾何、SRP/BF 參數 */
size_t flow_b, beam_b;
if (mcab_sample_flow_get_mem_size(&cfg, &flow_b) != 0 ||        /* -1 = 無效 */
    mcab_sample_beam_get_mem_size(&cfg, &bp, &beam_b) != 0) return -1;
void* flow_mem = platform_alloc(flow_b, 16);
void* beam_mem = platform_alloc(beam_b, 16);
McabSampleFlow flow;                                           /* 4 條 lane + 共用 DelayAec + mcab */
if (mcab_sample_flow_init(&flow, flow_mem, flow_b, &cfg) != 0) return -1;   /* -1 = 拒絕, 無診斷輸出 */
McabSampleBeam* b = mcab_sample_beam_init(beam_mem, beam_b, &cfg, &bp, flow.flow);
if (!b) return -1;

/* RES(libaec)、NR、合成: 應用自己的 init, 另一塊 post pool, 格點取 flow 的值 */
int fft = mcab_fft_size(flow.flow), nf = mcab_n_freqs(flow.flow), hop = mcab_hop_size(flow.flow);
AecConfig res_cfg;  aec_config_from_level(&res_cfg, AEC_LEVEL_BALANCED, cfg.sample_rate);
res_cfg.fft_size = fft;
AnrConfig nr_cfg = anr_config_for_level_grid(cfg.sample_rate, fft, ANR_LEVEL_BALANCED);
AcStftConfig syn_cfg;  ac_stft_config_default(&syn_cfg, fft);
size_t res_b = aec_res_get_mem_size(&res_cfg), nr_b = anr_get_mem_size(&nr_cfg), syn_b = ac_istft_get_mem_size(&syn_cfg);
if (!res_b || !nr_b || !syn_b) return -1;                   /* 0 = 無效 */
size_t vec = ALIGN16(nf * sizeof(float)), cvec = ALIGN16(nf * sizeof(Complex));
uint8_t* post = (uint8_t*)platform_alloc(ALIGN16(res_b) + ALIGN16(nr_b) + ALIGN16(syn_b) + 2 * vec + cvec, 16);
AecRes* res = aec_res_init(post, res_b, &res_cfg);
AnrDenoiser* nr = anr_init(post + ALIGN16(res_b), nr_b, &nr_cfg);
AcIstft* istft = ac_istft_init(post + ALIGN16(res_b) + ALIGN16(nr_b), syn_b, &syn_cfg);
if (!res || !nr || !istft) return -1;
float* total_gain = (float*)(post + ALIGN16(res_b) + ALIGN16(nr_b) + ALIGN16(syn_b));
float* extra_noise = total_gain + vec / sizeof(float);
Complex* spec = (Complex*)(extra_noise + vec / sizeof(float));
uint32_t rng = MCAB_SAMPLE_CNG_RNG_SEED;

const float *mics, *ref;  float out[512];
while (stream_next4(&mics, &ref, out)) {
    McabSampleBeamResult beam;  McabSampleBeamInfo info;  McabFrame frame;
    int vad = product_vad(mics);                            /* 沒有產品 VAD 時改呼叫 mcab_sample_beam_process() (內建 energy VAD) */
    int rc = mcab_sample_beam_process_with_activity(b, mics, ref, vad, vad, NULL, &beam, &info);
    if (rc == MCAB_OK) rc = mcab_sample_beam_fuse(b, &frame);   /* 需要 enable_post=1; frame.g_res_ctx 為 NULL */
    if (rc == MCAB_OK) {
        AecResInput rin;  mcab_sample_res_input(&frame, &rin);
        const float* g_res = aec_res_process(res, &rin);                      /* RES 在 mcab 之外, 由應用呼叫; 被拒回 NULL */
        const float* g_nr = g_res ? mcab_sample_anr_gain(nr, &frame, extra_noise, 1) : NULL;
        if (!g_nr) rc = MCAB_DSP_ERROR;
        else {
            sk_min_f32(total_gain, g_nr, g_res, frame.n_freqs);
            sk_capply_gain_f32(spec, frame.e, total_gain, frame.n_freqs);
            if (frame.cn) aec_cng_fill(&rng, spec, frame.cn, g_res, g_nr, MCAB_SAMPLE_CNG_NR_GAIN_FLOOR, frame.n_freqs);
            ac_istft_push(istft, spec, out);                                  /* 一次 iFFT/OLA */
            if (!skn_all_finite_f32(out, (size_t)hop)) rc = MCAB_DSP_ERROR;
        }
    }
    if (rc != MCAB_OK) {                                    /* 任一步被拒或輸出非有限: helper(含 flow)與後級一起 reset */
        mcab_sample_beam_reset(b);  aec_res_reset(res);  anr_reset(nr);  ac_istft_reset(istft);  rng = MCAB_SAMPLE_CNG_RNG_SEED;
        memset(out, 0, (size_t)hop * sizeof(float));
    }
}
anr_destroy(nr);                                            /* AecRes 沒有 destroy */
mcab_sample_beam_destroy(b);  mcab_sample_flow_destroy(&flow);   /* 先 helper, 再 mcab 與 lane; 都不釋放 caller 記憶體 */
platform_free(post);  platform_free(beam_mem);  platform_free(flow_mem);

產品有 VAD 時用 process_with_activity()(如上);沒有則 mcab_sample_beam_process()(內建 energy VAD)。要由 lane 頻譜算 mask／VAD 時拆成 mcab_sample_beam_process_front(b, mics, ref, &front) → 在 front.linear_spectra 上算 mask → mcab_sample_beam_process_beam(b, &front, vad_raw, vad_out, mask, &beam, &info)。外部 NN 後級(如 ULCNet)用 enable_post=0 的 flow:不呼叫 fuse,下一個 process_front() 直接接手。

只用 mcab + 自備 beamformer 與 RES

產品的波束器在別處時不需要 helper:mcab_process_front() → 自己的 beamformer → mcab_fuse(p, weights, NULL, &frame) → 自備 AecRes 的 aec_res_process() → 同樣的後級。完整、已語法檢查的範例(含 lane／estimator 的顯式 init)在 pipeline_4ch_detail;可執行範例是 mcab_external_static.c。

換用別的後級(例如 DFN2)。mcab 只交出 McabFrame(frame.e 是 pre-RES 誤差頻譜,cn／r2 是同一次投影的 PSD);神經後濾波用自備 AecRes 的增益自己組 P = E · G_res (+ comfort noise),現成消費者是 pipeline_dfn_4ch。

強度屬於擁有 RES 與 NR 的那一層(aec_res_set_level()、anr_set_level());mcab 與 helper 沒有 setter,對四條 lane 重新指定 level 是無效操作。呼叫表、ramp 與逐階段耗時診斷(mcab_get_last_timing())見 pipeline_4ch_detail。

延遲與 warm-up

  • 演算法延遲:1 hop(WOLA;實測 argmax 127 samples @hop=128 → 8 ms @16k 預設)。
  • delay acquisition:估計值要 solid 且 n_updates≥3 才被接受;開始新的可用 alignment generation 的那個 hop 回報 delay.changed=1——MATCHED 的首次 acquisition(init 或 reset 之後)與鎖定中值改變(移動 > 32 樣本且 16 樣本內再次被提出)才會;FIXED／EXTERNAL_ALIGNED 不設(見 mcab.h 的 McabDelayState 契約),mcab 對四條 lane 做 aec_apply_external_realign()(濾波器依 delay 差位移,不重置、不清合成 OLA);外部 beamformer 若自帶 STFT/OLA 狀態,應照 changed 清除。ring 未累積到 delay 樣本前 aligned_ref 為 raw ref。
  • SRP/BF warm-up:DOA 平滑值為 NaN(尚無可用 DOA)時 BF 旁路取 mic 0 且不適應;DOA smoother 需 doa_switch_consecutive=3 次一致觀測才切換;BF RLS 由 vad_out 凍結(vad_out=1 → 凍結適應)。
  • NR 噪聲底的最小值追蹤視窗是函式庫預設的 wall-clock 約 512 ms。
