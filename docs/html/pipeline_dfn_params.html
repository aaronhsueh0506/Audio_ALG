DFN2 pipeline 的參數表(外部／內部)

概要

分類準則:外部 = 第三方整合者可以調的(部署資訊、模式開關、level／強度、模型接口);整合者專用 = 串接拓樸,不是調參;內部 = 程式碼裡存在且可以改、但不建議開放的(時間常數、門檻、尺度、容量、版面計數器),附位置與不開放的理由。範圍涵蓋 mono 與 4ch 兩個範例使用的設定面;AEC 與 NR 函式庫本身的欄位表見各自元件頁。每一列的出處是 Audio_ALG 內的檔案路徑加符號名稱(不標行號,行號會隨原始碼移動)。4ch 的 McabConfig 只含 flow 參數,陣列幾何與 DOA／BF／VAD 在 sample helper 的 McabSampleBeamParams,lane 的 AecConfig(level、濾波長度)由應用組。

沒有包裝層的 setter:mono 直接對 Aec 呼叫 aec_set_level(),4ch 對範例自建的 AecRes(libaec;mcab 不含 RES)呼叫 aec_res_set_level(res, …);本鏈沒有降噪器實例,所以沒有 NR 強度參數。
