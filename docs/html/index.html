Audio_ALG 演算法文件站

概要

本站是 Audio_ALG 整合 repo 的演算法/移植文件：每個模組一頁， 純 HTML + 行內 CSS、零外部資源，可離線瀏覽。模組頁固定章節順序為： 概要 / API 用法 / Block diagram / 訊號泳道圖 / I-O 表 / State 表 / 延遲與 warm-up / 相關檔案與測試路徑。全站數字皆對照當前程式碼與測試， 與程式碼衝突時以程式碼為準。

元件頁（AEC/NR/audio_common）位於各自 repo 的 docs/html/，本站以連結方式指向；連結假設 SE 樹 sibling 佈局 （SE/{AEC,NR,audio_common,Audio_ALG} 同層)。

C API 使用說明（整合者視角）

頁面一行描述
aec_c_api AEC 的 init/process C API：grid 與 hop 選擇、三態 delay mode、五個 per-hop 入口、 逐欄位參數效果、前端 HPF、搭配 NN 後級的 context-only 用法、狀態查詢與建置旗標。
aec_c_api_params AEC 逐欄位參數的可調範圍與「調了會怎樣」（自 aec_c_api 拆出的參考頁）。
nr_c_api NR 的頻域 C API：五組合法 grid、process vs process_gain、 逐欄位參數效果與四級 mode、stationary 疊加層的覆寫陷阱、執行期 reconfigure 契約。
audio_common_c_api 八個 header 哪些該碰：FFT（scaling 與 aliasing 規則）、HPF 設定、pre-gain／FixGain 兩套 gain 的差異、resampler、共用 sk_* 核心與建置旗標。
integration_example 怎麼把三個 lib 接起來：四條 pipeline 的逐 hop 呼叫序列、誰做 FFT／誰擁有 window／ WOLA 在哪的三種答案、4ch pre/post 協定、接 NN 的做法、以及 release build 還剩什麼可 DEBUG。

核心程式庫

頁面一行描述
aec lib/aec/c_impl：PBFDKF main/shadow 線性濾波 + AEC3 matched-filter delay estimator + AEC3 post（RES/CNG/suppression）；grid 8k/256、16k/256|512、48k/1024。
nr lib/nr/c_impl：OM-LSA 核心（MCRA 噪聲估計 + SPP + LSA gain）， 4 檔強度 preset + stationary content mode；呼叫端持有 FFT/窗/OLA。
audio_common 共用基礎層：fft_wrapper.h（kiss/ne10 後端）、SIMD kernels、 fast_math、WAV I/O、HPF、resampler；三個上層 repo 的唯一 FFT 來源。

Pipelines（C 整合層）

頁面一行描述
pipeline_mono pipelines/mono_aec_nr_res/audio_pipeline.c：AEC(linear) → echo-aware NR → RES， pool-first 零 heap；grid 8k/256、16k/256|512、48k/1024。
pipeline_ulcnet_mono pipelines/mono_alignulcnet/audio_pipeline_ulcnet.c：AEC 線性誤差 + Align-ULCNet NN post-filter（per-frame callback）；一個 build 一個編譯期格點（16k/512/256 或 48k/1024/512），演算法延遲 1 hop = 16 ms（48 k 為 10.67 ms）。
pipeline_4ch pipelines/4ch_aec_bf_nr_res/：4×AEC lanes + 共享 delay + SRP-PHAT DOA + GSC beamforming + post RES/NR（4aec_nr_res.c 核心）。
pipeline_ulcnet_4ch pipelines/4ch_alignulcnet/audio_pipeline_4ch_ulcnet.c：GSC 的 beamformed 誤差頻譜直送 Align-ULCNet NN post stage（不重建、不再分析）；新增演算法延遲 1 hop = 16 ms（48 k 為 10.67 ms）。

AINR（NN 降噪模型）

頁面一行描述
ainr_dfn2 DeepFilterNet2：48k、1024/512（非上游 960/480）；stateless ONNX exporter + C 前後處理 dfn2_process.c（STFT/ERB+complex 特徵/EMA 正規化/compose/ISTFT）， graph 只含 heads。
ainr_gtcrn GTCRN：16k、512/256；C 端 gtcrn_process.c 只做 STFT/ISTFT， 頻譜之間全部在網路；stateless ONNX 以三組 cache 作顯式 I/O。
ainr_rnnoise_erb RNNoise-ERB：16k、512/256、22 ERB bands + 0–4 kHz complex 特徵； export_onnx.py 以 GRU h1–h3 顯式進出，host 檢查 next state finite 後回寫。

AIAEC（NN AEC/RES 四候選）

頁面一行描述
aiaec_align_ulcnet Align-ULCNet：16k/512/256；具有完整產品 pipeline 的候選 （ulcnet_process.c，centered STFT 與 center=False 的 ulcnet_analysis_push_frame()（一 hop 一幀）兩種分析並存 + WOLA + NPU callback 邊界；每幀交易封在 ulcnet_prepost.c class）。
aiaec_align_cruse Align-CRUSE：16k/512/256；cumsum 無衰減積分器與 paper_global 非因果 mode 是 streaming 語意風險。
aiaec_deepvqe_s DeepVQE-S：16k/512/256；時間軸最乾淨的候選（純 causal conv + 每幀獨立 attention），輸出 3×3 complex convolving mask。
aiaec_cagcrn CAGCRN：16k/512/256；參數最少（54,963），但 NPU op 面最重 （CATA broadcast、動態 ConvTranspose2d）。
