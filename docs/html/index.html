Audio_ALG 演算法文件站

概要

本站是 Audio_ALG 整合 repo 的演算法/移植文件：每個模組一頁， 純 HTML + 行內 CSS、零外部資源，可離線瀏覽。模組頁固定章節順序為： 概要 / 如何呼叫使用（API 用法）/ 流程時序圖（含 block diagram）/ 訊號泳道圖 / 參數表（外部／內部）/ I-O 表 / State 表 / 延遲與 warm-up / 相關檔案與測試路徑。全站數字皆對照當前程式碼與測試， 與程式碼衝突時以程式碼為準。內容多的元件與 pipeline 拆成 *_usage（呼叫順序與最小範例）、 *_sequence（時序圖）、*_params（外部／內部參數）與 *_detail 幾頁，下方索引逐頁列出。

元件頁（AEC／NR／audiolib）位於各自 repo 的 docs/html/：AEC/docs/html/、NR/docs/html/、 audiolib/common/docs/html/（common：FFT／STFT／HPF／resampler）與 audiolib/docs/html/（空間鏈：VAD／DOA／BF）。本站以連結方式指向；連結假設 SE 樹 sibling 佈局 （SE/{AEC,NR,audiolib,Audio_ALG} 同層)。

RES 的歸屬：mono 的 RES 增益在 aec_process_context() 內算出，經 aec_get_res_context() 以 AecResContext.res_gain 交出，強度用 aec_set_preset()（mono 是明確例外， 範例的 mono_form() 只決定套不套用）。4ch flow Mcab（mcab.h）只做到 mcab_fuse()（g_res_ctx 為 NULL）， 不含 RES；要 RES 的應用在自己的 init 用 libaec 的 aec_res_get_mem_size()／aec_res_init() 建立 AecRes，每 hop 呼叫 aec_res_process()（輸入由 mcab_sample_res_input() 自 McabFrame 填入），強度用 aec_res_set_preset()。

版號（出處為 header，pipelines/tests/test_doc_layout_versions.py 逐頁核對）： 4ch flow MCAB_LAYOUT_VERSION = 25； 全表見 conventions。

Pipelines（C 整合層）

頁面一行描述
pipeline_mono pipelines/mono_aec_nr_res/main.c：沒有 mono 單元層，Aec（linear，自帶 RES 增益）＋ main 內的 mono_nr_gain()（echo-aware NR 增益）； NR 與合成（AnrDenoiser、AcIstft）由 main 自己初始化並明寫逐 hop 串接（min、套 gain、CNG、合成）； 各函式庫各自 mem_size／init，pool-first 零 heap；grid 8k/256、16k/256|512、48k/1024。頁內含呼叫順序、已編譯檢查的範例與時序圖。
pipeline_mono_params mono 的參數與入口分級：外部（命令列旗標、AnrMode、執行期 setter、組成開關、進階 AecConfig 欄位）vs 內部（時間常數、門檻、seam、編譯期常數），公開 vs 內部函式清單。
pipeline_mono_detail mono 的執行期強度控制（aec_set_preset()／anr_set_mode()）與逐階段耗時診斷。
pipeline_ulcnet_mono pipelines/ulcnet/mono_alignulcnet/main.c：Aec 線性誤差 + 範例 stage ulcnet/ulcnet_nn_stage.c（Align-ULCNet NN post-filter，per-frame callback）；一個 build 一個編譯期格點（16k/512/256 或 48k/1024/512），演算法延遲 1 hop = 16 ms（48 k 為 10.67 ms）。
pipeline_4ch pipelines/4ch_aec_bf_nr_res/：mcab，4ch 的 flow 層而不是函式庫——應用自己建立四條 Aec lane（mcab_lane_config() 或 mcab_apply_lane_contract()）與（MATCHED）一個共享 DelayAec，以指標交給 mcab_init_ex()； mcab 只擁有共享 delay 的 admission、對齊環與 fuse 緩衝。每 hop：mcab_process_front() → 呼叫端的 beamformer 權重 → mcab_fuse()（把 E、R²、comfort noise 投影成 McabFrame，g_res_ctx 為 NULL）。 mcab 不含 RES、不含 beamformer；SRP-PHAT／BF 的 sample 層 helper 是 mcab_sample_beam.{h,c}（不在 archive 內）。 RES（libaec 的 AecRes）、NR、CNG、合成由各 main 自己建立並串接： aec_res_process() → NR gain（mcab_sample_anr_gain()）→ min → CNG → synthesis。頁內含呼叫順序、已編譯檢查的範例與時序圖。版號：MCAB_LAYOUT_VERSION = 25。
pipeline_4ch_params 4ch mcab 的設定欄位分級（McabConfig、lane 契約欄位、sample helper 參數）、每 hop 輸入、固定常數、公開／內部函式清單、狀態碼與輸出契約。
pipeline_4ch_detail mcab＋呼叫端 beamformer＋自備 AecRes 的呼叫範例、4ch 應用後級的執行期強度控制（aec_res_set_preset()／anr_set_mode()）與逐階段耗時診斷。
pipeline_ulcnet_4ch pipelines/ulcnet/4ch_alignulcnet/main.c：mcab（enable_post=0，不建 RES）加 sample beam helper 的 BF 誤差頻譜直送 Align-ULCNet NN post stage（不重建、不再分析）；新增演算法延遲 1 hop = 16 ms（48 k 為 10.67 ms）。
pipeline_ulcnet_detail 兩條 ULCNet 範例共用的細節：參考 accelerator adapter（state 留在 CPU 端、每幀 prepare → run → commit）與 alignment 邊界的 identity reprime 推導。
pipeline_ulcnet_usage／pipeline_ulcnet_sequence／pipeline_ulcnet_params 兩條 ULCNet 範例的呼叫方式、時序圖與參數表。
pipeline_dfn_mono pipelines/dfn/mono_aec_dfn_res/main.c：Aec ＋ main 自寫的 P 形成（只取 AEC 自己的 RES 增益，不建 NR，取自 aec_get_res_context()）＋ dfn/dfn_hop.h， 以 DeepFilterNet2 取代 MMSE-LSA——估計用 pre-RES 頻譜 E、套用在 post-RES 頻譜 P。host 跑產品自己的取樣率 （8/16/48 k，預設 16 k），只有 DFN2 stage 在 48 k，由 dfn/dfn_rate_bridge.c 來回；演算法延遲（lookahead 1/1） 16 k/256 為 800 samples = 50 ms、48 k 為 3 hop = 32 ms。
pipeline_dfn_4ch pipelines/dfn/4ch_aec_bf_dfn_res/main.c：同一個 DFN2 stage 接在四聲道 mcab 之後（enable_post=1，mcab 只到 mcab_fuse()，SRP-PHAT／BF 經 sample beam helper），RES 增益由 main 自建的 libaec AecRes 經 aec_res_process() 算出，P 的形成與合成由應用自己串；前端跑 16 k（預設）或 48 k，16 k 經同一支 rate bridge； 演算法延遲（lookahead 1/1）16 k/256 為 800 samples = 50 ms、48 k 為 3 hop = 32 ms。
pipeline_dfn_detail 兩支 DFN2 範例共用的細節：dfn_hop 呼叫語意與 reject-first 清單、DfnRateBridge pool 逐項、各測試檔檢查的內容。
pipeline_dfn_usage／pipeline_dfn_sequence／pipeline_dfn_params 兩支 DFN2 範例的呼叫方式、時序圖與參數表。

兩支 DFN2 變體共用 pipelines/dfn/dfn_res_stage.{h,c} 與 dfn/dfn_rate_bridge.{h,c}； 沒有模型或模型失敗時輸出即「降噪器關的傳統鏈延後」（fail-open）：48 k 是逐位元等值、 延後兩個 hop，原生格點是經 resampler 往返、延後 added delay 的通帶容差等值。

AINR（NN 降噪模型）

頁面一行描述
ainr_dfn2 DeepFilterNet2：48k、1024/512（非上游 960/480）；stateless ONNX exporter + C 前後處理 dfn2_process.c（STFT/ERB+complex 特徵/EMA 正規化/compose/ISTFT）， graph 只含 heads。
ainr_dfn2_detail DFN2 prepost 類別的 pool 大小與所有權、DFN2Model callback 與 descriptor、libainr_prepost.a 建置、skip identity 的 partition-of-unity 檢查。
ainr_dfn3 48 kHz DFN3 raw-low DF / masked-high split；兩個 heads、layout 9、TIME/FREQ 靜態 pool API，lookahead pair 預設 1/1（15 組合法 pair，建置期選定），1/1 的 identity 音訊位移 2 hops。
ainr_gtcrn GTCRN：16k、512/256；C 端 gtcrn_process.c 只做 STFT/ISTFT， 頻譜之間全部在網路；stateless ONNX 以三組 cache 作顯式 I/O。
ainr_rnnoise_erb RNNoise-ERB：16k、512/256、22 ERB bands + 0–4 kHz complex 特徵； export_onnx.py 以 GRU h1–h3 顯式進出，host 檢查 next state finite 後回寫。

AIAEC（NN AEC/RES 四候選）

頁面一行描述
aiaec_align_ulcnet Align-ULCNet：16k/512/256；具有完整產品 pipeline 的候選 （ulcnet_process.c：ulcnet_framing_config() 描述 audiolib 的 AcStft／AcIstft， centered（center 1）與一 hop 一幀（center 0）兩種分析並存 + WOLA + NPU callback 邊界；每幀交易封在 ulcnet_prepost.c class）。
