AINR RNNoise-ERB：如何呼叫、流程時序圖、外部／內部參數

概要

RNNoise-ERB 的 C 端是 RNNoise-ERB/process.h 的一組函式與呼叫端 pool 內的 RNNoiseState：grid 由應用端以 RNNoiseGridSpec 在執行期給定，記憶體由呼叫端配置（rnnoise_get_mem_size() → 記憶體 → rnnoise_init_ex()，沒有 create／destroy），只做頻域。framing（AcStft／AcIstft）、ERB 矩陣與 GRU state 都歸應用端。它與 DFN／GTCRN 有兩處不同，整合時最容易寫錯：(1) lookahead_frames=1：新特徵窗 [t-2,t-1,t] 的 gain 屬於 spectrum t-1，應用端必須保存並延遲對應的頻譜，再用 rnnoise_apply_gains() 套 gain（就地改寫頻譜，內含 × stft_unscale，所以 AcIstft 的 ispec_scale 必須維持 1.0f）；(2) 模型輸入是前 3 框特徵（oldest → newest），前 2 框無模型輸出。模型內容見 ainr_rnnoise_erb。

如何呼叫使用

  1. grid：RNNoiseGridSpec 取 config.ini 的 [signal]／[feature] 值（出貨：16000、512、22 bands、min_bins_per_band 2、lookahead_frames 1、spec_max_hz 4000，加上兩組 EMA 設定）→ rnnoise_grid_make(&grid, &spec)（非 RNNOISE_GRID_OK 就是被拒，rnnoise_grid_status_text() 給文字）。推導出 hop 256、n_bins 257、spec_bins 129、conv_delay 1、兩個 α 0.984、stft_scale 1/√512。
  2. framing（audiolib）：ac_stft_config_default(&sc, grid.n_fft)，只改 sc.spec_scale = grid.stft_scale，其餘維持預設（sqrt-Hann、center 0、AC_OLA_ACCUMULATE、ispec_scale = 1.0f）；每個 hop 餵 hop 個新樣本，ac_stft_push_planar() 內部保留前一個 hop，零歷史起算。函式庫不持有 framing 物件，縮放設錯偵測不到。
  3. ERB 矩陣：兩個借用指標，由應用端載入並持有（函式庫不讀檔、不複製，矩陣須比所有借用它的物件活得久）：erb_fwd 是 bin-major [n_bins][n_bands]（train.py mode 0），erb_inv 是 band-major [n_bands][n_bins]（mode 1），各 n_bins × n_bands 個 float32（16000/512/22 為 257 × 22 × 4 = 22,616 bytes）。來源見下方說明。
  4. 建立：rnnoise_config_defaults(&cfg, &grid) → 填 erb_fwd／erb_inv（float host 再填 h1／h2／h3 與各自的 _elements，元素個數不是 bytes；三組都設或都不設）→ rnnoise_get_mem_size(&cfg, &req) → 16-byte 對齊的記憶體 → rnnoise_init_ex(pool, req.bytes, &cfg, &req)。init 把已註冊的 state 歸零，generation 從 1 開始。回 NULL ＝ config 或 pool 被拒（錯位、太小、別的 grid 或 build 做的 pool）。
  5. 每個 hop：ac_stft_push_planar → rnnoise_compute_features（前 2 框回 0、沒有模型輸出：gain 用 unit gain，已存在的延遲頻譜（t - grid.lookahead_frames ≥ 0）照樣合成，否則第一個輸出會少一份重疊項，還沒有頻譜時才輸出補零；回 1 時 out_erb 與 out_spec 是平的陣列，長度為 rnnoise_erb_window_elements() 與 rnnoise_spec_window_elements()）→ 加速器（h1_in/h1_out 等綁同一塊 buffer，先讀完所有 state 輸入才寫輸出）→ rnnoise_frame_finish（非有限就改用 unit gain）→ rnnoise_apply_atten_lim（可選）→ rnnoise_expand_gains → 對延遲 grid.lookahead_frames 框的頻譜 rnnoise_apply_gains → ac_istft_push_planar。
  6. generation：rnnoise_state_generation() init 後為 1，reset 與被拒的 rnnoise_frame_finish 各加 1。float host 註冊的 buffer 已由函式庫歸零；板端若在加速器另存定點 hidden，須在起始填成量化後的 0，並在每次數值與上次看到的不同時重填。
  7. 重新開始一段串流：rnnoise_reset(st)（清特徵 ring、正規化 EMA 回起始值、歸零已註冊的 state）加應用端自己的 ac_stft_reset／ac_istft_reset，並清掉應用端保存的延遲頻譜。同一段 stream 分 chunk 時須保留 EMA、GRU、framing／OLA 與對應的 spectrum 延遲；不同 WAV 之間必須重置。

ERB 矩陣的來源：export_erb_matrix.py --format bin（預設）寫 erb_matrix.bin，little-endian：int32 n_bins、int32 n_bands、float32 W_fwd [n_bins][n_bands]（mode 0）、float32 W_inv [n_bins][n_bands]（mode 1）、int32 nfftborder[n_bands]；--format npy 與 c 的兩個矩陣也都是 [n_bins][n_bands]。正向矩陣的版面等於函式庫要的；反向矩陣在檔內是 bin-major，函式庫要 band-major，band-major 的反向矩陣樹內沒有 exporter 輸出，應用端載入後自行轉置。

#include <math.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "audio_stft.h"
#include "RNNoise-ERB/process.h"

enum { GRU_HIDDEN = 128 };    /* 匯出圖的 h1、h2、h3 各 [1,1,128]：應用端的形狀 */

static void *alloc16(size_t bytes) { return aligned_alloc(16, (bytes + 15) & ~(size_t)15); }

/* 加速器：erb[3][n_bands]、spec[3][2][spec_bins]、h1..h3 -> band_gains[n_bands]；hidden 輸出寫回輸入的同一組 buffer。 */
typedef int (*RunModel)(const float *erb, const float *spec, float *h1, float *h2, float *h3,
                        float *band_gains);

/* erb_fwd（bin-major）／erb_inv（band-major）：應用端載入並持有，函式庫只借用。 */
int run_rnnoise(const float *erb_fwd, const float *erb_inv, RunModel run_model,
                const float *in, float *out, long hops)
{
    const RNNoiseGridSpec spec = {            /* 出貨模型：config.ini [signal] [feature] */
        .sample_rate = 16000, .n_fft = 512, .n_bands = 22, .min_bins_per_band = 2,
        .lookahead_frames = 1, .spec_max_hz = 4000,
        .erb_norm_tau_sec = 1.0, .erb_norm_init_lo_db = -20.0f, .erb_norm_init_hi_db = -45.0f,
        .erb_norm_scale_db = 40.0f, .spec_norm_tau_sec = 1.0,
        .spec_norm_init_lo = 0.04f, .spec_norm_init_hi = 0.008f, .spec_norm_eps = 1e-12f,
    };
    RNNoiseGrid grid;
    int status = rnnoise_grid_make(&grid, &spec);
    if (status != RNNOISE_GRID_OK) {
        fprintf(stderr, "grid refused: %s\n", rnnoise_grid_status_text(status));
        return -1;
    }

    int rc = -1;
    const size_t nb = (size_t)grid.n_bins, erb_n = rnnoise_erb_window_elements(&grid);
    float *h = calloc(3 * GRU_HIDDEN, sizeof *h);                          /* h1、h2、h3 */
    float *buf = malloc(sizeof *buf * (9 * nb + grid.n_bands + erb_n + rnnoise_spec_window_elements(&grid)));
    float *hist_re = buf, *hist_im = hist_re + 3 * nb;                     /* 最近三個頻譜 */
    float *cur_re = hist_im + 3 * nb, *cur_im = cur_re + nb, *bin_gains = cur_im + nb;
    float *band_gains = bin_gains + nb, *erb = band_gains + grid.n_bands, *spec_win = erb + erb_n;
    void *stft_mem = NULL, *istft_mem = NULL, *pool = NULL;
    AcStft *stft = NULL;
    AcIstft *istft = NULL;
    RNNoiseState *st = NULL;
    if (!h || !buf) goto done;

    AcStftConfig sc;                          /* framing 是 audiolib 的 */
    ac_stft_config_default(&sc, grid.n_fft);
    sc.spec_scale = grid.stft_scale;          /* ispec_scale 維持 1.0f：rnnoise_apply_gains() 已乘 stft_unscale */
    size_t stft_bytes = ac_stft_get_mem_size(&sc), istft_bytes = ac_istft_get_mem_size(&sc);
    stft_mem = alloc16(stft_bytes);
    istft_mem = alloc16(istft_bytes);
    if (!stft_mem || !istft_mem) goto done;
    stft = ac_stft_init(stft_mem, stft_bytes, &sc);
    istft = ac_istft_init(istft_mem, istft_bytes, &sc);
    if (!stft || !istft) goto done;

    RNNoiseConfig cfg;
    RNNoiseMemReq req;
    if (rnnoise_config_defaults(&cfg, &grid) != 0) goto done;
    cfg.erb_fwd = erb_fwd;
    cfg.erb_inv = erb_inv;
    cfg.h1 = h;                  cfg.h1_elements = GRU_HIDDEN;    /* float host：三組都註冊， */
    cfg.h2 = h + GRU_HIDDEN;     cfg.h2_elements = GRU_HIDDEN;    /* 板端都不註冊 */
    cfg.h3 = h + 2 * GRU_HIDDEN; cfg.h3_elements = GRU_HIDDEN;
    if (rnnoise_get_mem_size(&cfg, &req) != 0) goto done;
    pool = alloc16((size_t)req.bytes);
    st = pool ? rnnoise_init_ex(pool, (size_t)req.bytes, &cfg, &req) : NULL;
    if (!st) goto done;

    rc = 0;
    for (long t = 0; t < hops; ++t) {
        float *slot_re = hist_re + (size_t)(t % 3) * nb, *slot_im = hist_im + (size_t)(t % 3) * nb;
        float *hop_out = out + t * grid.hop;
        ac_stft_push_planar(stft, in + t * grid.hop, slot_re, slot_im);
        int ready = rnnoise_compute_features(st, slot_re, slot_im, erb, spec_win);
        if (ready < 0) { rc = -1; break; }
        for (int b = 0; b < grid.n_bands; ++b) band_gains[b] = 1.0f;          /* 還沒有 3 框：unit gain */
        if (ready) {
            for (int b = 0; b < grid.n_bands; ++b) band_gains[b] = NAN;       /* 沒被寫的輸出會被拒 */
            int run_rc = run_model(erb, spec_win, h, h + GRU_HIDDEN, h + 2 * GRU_HIDDEN, band_gains);
            /* rnnoise_frame_finish() 一律都呼叫，即使 run_model() 本身回報失敗：NaN 填的
             * band_gains 仍會觸發它自己的有限值檢查，把已註冊的 state 歸零、generation +1
             * （feature ring 與 OLA 時序不動）—— 短路跳過的話，失敗呼叫寫了一半、但仍有限
             * 的 state 會原封不動帶進下一個 hop。 */
            int finish_rc = rnnoise_frame_finish(st, band_gains);
            if (run_rc != 0 || finish_rc != 0)
                for (int b = 0; b < grid.n_bands; ++b) band_gains[b] = 1.0f;   /* 被拒：unit gain */
            rnnoise_apply_atten_lim(st, band_gains, 0.0f);                     /* 可選；<= 0 不作用 */
        }
        rnnoise_expand_gains(st, band_gains, bin_gains);
        /* 窗 [t-2, t-1, t] 的 gain 屬於 spectrum t - lookahead_frames；第一個窗之前的 spectrum 也要合成
         * （unit gain），否則第一個輸出會少一份重疊項 */
        long s = t - grid.lookahead_frames;
        if (s < 0) { memset(hop_out, 0, sizeof *hop_out * (size_t)grid.hop); continue; }   /* 還沒有可輸出的 spectrum */
        memcpy(cur_re, hist_re + (size_t)(s % 3) * nb, sizeof *cur_re * nb);
        memcpy(cur_im, hist_im + (size_t)(s % 3) * nb, sizeof *cur_im * nb);
        rnnoise_apply_gains(st, cur_re, cur_im, bin_gains);                    /* 內含 x stft_unscale */
        ac_istft_push_planar(istft, cur_re, cur_im, hop_out);
    }
done:
    free(pool); free(istft_mem); free(stft_mem); free(buf); free(h);
    return rc;
}

範例（float host）已在暫存副本以 -std=c11 -Wall -Wextra -Wpedantic -Werror 編譯通過，並以單位 gain 的假加速器實跑：輸出等於輸入延遲 2 hops（512 samples）；實際的加速器 runtime 由目標平台提供。rnnoise_apply_gains 就地修改傳入頻譜（× grid.stft_unscale），所以要先複製延遲的那一框；它與 rnnoise_apply_atten_lim、rnnoise_expand_gains 對 NULL 參數回 -1 且不寫輸出。

流程時序圖

caller (AcStft/AcIstft)        rnnoise (process.c)                 NPU graph
  |                                  |                                  |
  |== init ==========================|==================================|
  | rnnoise_grid_make / config_defaults / get_mem_size / init_ex        |
  |                                  | generation = 1, EMA 起始值       |
  |                                  |                                  |
  |== hop 0, 1 (暖機) ================|==================================|
  | ac_stft_push_planar(hop) -> spec |                                  |
  | rnnoise_compute_features ------->| 推入 3-frame ring                |
  | <-------- 0 ----------------------|  (無模型輸出：gain = 1)          |
  | save spec 到延遲佇列 ------------|                                  |
  | t - lookahead >= 0 時以 unit gain 合成該 spectrum，否則輸出補零      |
  |                                  |                                  |
  |== hop t >= 2 =====================|==================================|
  | ac_stft_push_planar(hop) -> spec(t)                                 |
  | rnnoise_compute_features ------->| erb3[3][22], spec3[3][2][129]    |
  | <-------- 1 ----------------------|                                  |
  | ----------------------- run(erb3, spec3, h1..h3) ----------------->| 輸出 band_gains[22] (屬 t-1)
  | <----------------------- gains, h*_out ---------------------------|
  | rnnoise_frame_finish(gains) ---->| 非有限: -1 (state 歸零, generation+1)
  | apply_atten_lim(gains, dB) ----->| 22 帶線性混合, dB <= 0 不作用     |
  | expand_gains(22 -> 257) -------->| erb_inv, partition of unity      |
  | rnnoise_apply_gains(delayed spec, bins) -> x gain, x N^+0.5 (就地)  |
  | ac_istft_push_planar(spec) ----> out256 (IFFT, OLA)                 |
  | save spec(t) -------------------|                                  |
