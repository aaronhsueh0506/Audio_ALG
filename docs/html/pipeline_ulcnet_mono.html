audio_pipeline_ulcnet — mono AEC(linear) → Align-ULCNet NN 後級

概要

pipelines/mono_alignulcnet/audio_pipeline_ulcnet.{h,c}:與 audio_pipeline 同一套 pool-first 建構紀律,但後級換成 Align-ULCNet 神經後濾波,經 ulcnet_process.h 的 UlcnetModel 每幀 callback 驅動外部 NPU runtime。此 pipeline 只擁有已驗證的 C 前後處理(centered sqrt-Hann STFT、0/2/1 幀發射、WOLA)+ 線性 AEC + 模型周邊的 delay-state policy。格點編譯期固定:16 kHz / fft 512 / hop 256 / 257 bins(ULCNET_SR/N_FFT/HOP/BINS);其他 sample rate 與 fft(0→512 以外)一律 reject。

ONNX / NPU graph 邊界

位置內容
graph 內(已由 export_streaming_onnx.py 匯出)(error_ri, far_ri, 顯式 states) → enhanced_ri:signed |x|^0.3 壓縮(ULCNET_COMPRESSION_EXP=0.3f)、attention、GRU、解壓縮全部在 graph 內。若目標 runtime 不支援 pow 類算子而把壓縮/解壓縮移出 graph,C 端有 ulcnet_compress_frame()/ulcnet_expand_frame(),但邊界移動必須連 export graph 一起改、兩邊一致。
graph 外(C 前處理)線性 AEC(aec_process_context)、centered sqrt-Hann STFT(ulcnet_analysis_push,重現 torch.stft center=True + reflect 前綴)、delay-state policy。
graph 外(C 後處理)enhanced_ri → centered WOLA(sqrt-Hann、包絡正規化、半窗 trim;ulcnet_synthesis_push)。
runtime 跨呼叫保存的 NN statesfar attention K/V ring、attention-logit 史、GRU hidden h — pipeline 只透過 model.reset 要求全部清除；參考 adapter 的 ulcnet_model_io_reset() 會將 K/V、logit 與兩組 GRU hidden 一併歸零。

accelerator adapter(CPU 擁有 state,加速器本身無狀態)

AIAEC/Align_ULCNet/ulcnet_accelerator_adapter.{h,c} + ulcnet_model_io.{h,c} 是「graph 內」那格的參考實作,把上面模糊的「runtime 保存」變成具體的 C 結構:accelerator 的單次呼叫是無狀態的(UlcnetAcceleratorRun run(user, inputs, outputs),一次一幀),K/V ring、attention-logit 史、GRU hidden 全部由 CPU 端 UlcnetModelIoState 在呼叫之間保存並於每次呼叫前後 pack/unpack——這是刻意選的邊界(export_streaming_onnx.py 稱其 boundary 為 stateless_one_frame_delta_state):ONNX graph 本身只吃「當前幀 + 顯式 state 輸入」、只吐「當前幀 enhanced 輸出 + state 的 delta」,不在 graph 內部遞迴。

state 張量shape(ONNX 慣例,省略 batch/time)排列
key/value history[1,32,D−1,26]newest-first(index 0 = 最近一幀)
logit history[1,32,4,D]oldest-first(index 0 = 最舊一幀——與 K/V 相反,commit() 內分別用不同方向的 shift)
GRU hidden(2 層)[2,1,128]—(逐層 next 直接整組替換,無 ring)

ulcnet_model_io_prepare() 在每次 infer 前把目前的 err/far RI 與上述三組 state 包成 UlcnetModelIoInputs(唯讀視圖)並把 UlcnetModelIoOutputs(accelerator 要寫的 key_now/value_now/logit_now/gru*_hidden_next/enhanced_ri)全部預填 NaN;ulcnet_model_io_commit() 驗證 accelerator 確實寫滿每個輸出欄位(NaN 未被覆蓋 = 判定失敗,持久 state 完全不動、視同該幀被丟棄——與 pipeline 自己的 fail-open 全有限值檢查是兩層獨立保護)後才推進三組 ring/hidden 並解包 enhanced_re/im。far_input_mode 記在 UlcnetModelIoDescriptor 裡,由 ulcnet_accelerator_adapter_model() 回傳的 UlcnetModel.io_descriptor 一併發布給 pipeline(見下方三方一致性)。

model.infer(user, err_ri, far_ri, out_ri)                 ← pipeline 每個發射幀呼叫一次
 │  (adapter 內部,對 pipeline 不可見)
 ├─ ulcnet_model_io_prepare(state, err_ri, far_ri, &inputs, &outputs)
 │      inputs.key_history/value_history  ← state 的 K/V ring(newest-first 視圖)
 │      inputs.logit_history              ← state 的 logit 史(oldest-first 視圖)
 │      inputs.gru0/1_hidden              ← state 目前的 GRU hidden
 │      outputs.*_now / *_hidden_next / enhanced_ri  ← 全部先填 NaN
 ├─ run(user, &inputs, &outputs)          ← 呼叫端(板端)一次無狀態 tensor invocation
 └─ ulcnet_model_io_commit(state, enhanced_re, enhanced_im)
        全欄位非 NaN?
          是 → K/V ring 前移一格塞入 key_now/value_now(newest-first)
               logit 史後移一格塞入 logit_now(oldest-first)
               gru0/1_hidden ← gru0/1_hidden_next(整組替換)
               回 0,enhanced_re/im 解包給呼叫端
          否 → persistent state 不動,回 -1(該幀視同失敗,pipeline fail-open)

D(delay_depth)決定 ring 深度,依 checkpoint 而定;主機參考範例(pipelines/mono_alignulcnet/main.c)用 D=8 呼叫 ulcnet_accelerator_adapter_get_mem_size(8, ...),實測(host, kiss)bytes=68,912(其中 ulcnet_model_io state 本體 68,880 B + adapter 控制塊 32 B),ULCNET_MODEL_IO_LAYOUT_VERSION=2。此記憶體不在上方 audio_pipeline_ulcnet 的 558,768 B pool 內——它是呼叫端額外配置、傳給 adapter 的獨立 pool(見下方 API 用法)。

API 用法

AudioPipelineUlcnetConfig cfg = audio_pipeline_ulcnet_default_config(16000);
/* fft_size=0→512, aec_preset=BALANCED, model=all-zero(identity),
 * far_input_mode=ULCNET_FAR_RAW(checkpoint 相容預設) */

/* 推薦路徑:用 accelerator adapter 包一個無狀態 run() callback(main.c 範例) */
size_t adapter_bytes, adapter_align;
ulcnet_accelerator_adapter_get_mem_size(8 /* delay_depth D */, &adapter_bytes, &adapter_align);
void* adapter_pool = platform_alloc(adapter_bytes, adapter_align);
UlcnetAcceleratorAdapter* adapter = ulcnet_accelerator_adapter_init(
    adapter_pool, adapter_bytes, 8, checkpoint_far_input_mode /* 讀自 ONNX metadata */,
    board_run_stateless_tensor_invocation, NULL);
cfg.model = ulcnet_accelerator_adapter_model(adapter);   /* 帶 io_descriptor,見下方三方一致性 */

AudioPipelineUlcnetMemReq req;
audio_pipeline_ulcnet_get_mem_requirements(&cfg, &req);  /* far_input_mode 不合會在這裡就 reject */
void* pool = platform_alloc(req.bytes, req.alignment);
AudioPipelineUlcnet* p = audio_pipeline_ulcnet_init_ex(pool, req.bytes, &cfg, &req);
while (stream) {
    audio_pipeline_ulcnet_process(p, mic, ref, out);   /* 各 256 floats */
}
audio_pipeline_ulcnet_reset(p);   /* 也呼叫 model->reset */
audio_pipeline_ulcnet_destroy(p); /* 不釋放 caller pool */

far_input_mode 部署契約 + 三方一致性鎖

模式far 來源套用閘控權重/export
ULCNET_FAR_RAW(預設=0)caller 的 raw ref hop(與 error tap 同 hop)不以 delay lock 閘控;只有 infer 失敗/非有限輸出才 fail-open現行權重以 RAW far 訓練;現行 export 皆記錄 raw_far
ULCNET_FAR_ALIGNED(=1)AecLinearContext.aligned_far_hop(本 hop 線性濾波器實際吃到的 aligned far)UNLOCKED 時模型輸出 bypass(仍照步進)本專案已接受既有權重的 aligned-far 部署；export descriptor 與 pipeline 接線仍須同為 ALIGNED

far mode 是 export/init profile,不可逐 hop 熱切換。既有權重可依本專案已接受的部署 sweep 明確 export 成 RAW 或 ALIGNED；未定義值在 ulcnet_derive_dims_and_config() reject。三方一致性由同一個 inline 函式 ulcnet_far_input_mode_agrees()(ulcnet_model_io.h)把關,三個地方共用一份定義:(1) ONNX/JSON metadata 的 far_input_mode 字串(export_streaming_onnx.py 寫入,ulcnet_far_input_mode_name() 雙向映射);(2) 由 (1) 灌進 ulcnet_accelerator_adapter_init() 的 far_input_mode 參數,編譯成 UlcnetModelIoDescriptor.far_input_mode,經 UlcnetModel.io_descriptor 一路帶到 pipeline;(3) pipeline 自己的 cfg.far_input_mode(呼叫端從 far branch 接線決定)。(2)(3) 不合在 audio_pipeline_ulcnet_get_mem_requirements()/_init()/_init_ex()/_create() 全部 reject(mono 的 model 是 init-time config 欄位,不匹配即整個 init 失敗)。io_descriptor==NULL(all-zero identity model 或未發布 contract 的 runtime)不受閘控。回歸測試:AIAEC/tests/test_ulcnet_model_io_c.py、pipelines/mono_alignulcnet/tests/test_audio_pipeline_ulcnet.c 的「far-input contract gate」測試群組(10 個斷言,含 RAW/ALIGNED 互換皆拒、matched pair 仍可 init)。

UlcnetModel callback 契約(step-always / apply-gated)

  • Fail-open identity:infer==NULL(all-zero model)、infer() 回非 0、或輸出幀含任何非有限值(ulcnet_frame_is_finite() 逐 bin isfinite)→ 該幀改走誤差頻譜原樣;NaN/Inf 永不進 WOLA。STFT/WOLA 時序不因模型存在與否改變。
  • Step-always:只要裝了 infer callback,每個發射幀都呼叫 infer(per-hop 計算量恆定、runtime recurrent state 連續);閘控只決定「輸出是否套用」。
  • Delay 事件(每 hop 讀一次 AecLinearContext.delay_state):AEC_LINEAR_DELAY_CHANGED → 先呼叫 model->reset 再 infer(兩種 far 模式都做——error branch 在此邊界不連續重對齊);UNLOCKED → 僅 ALIGNED 模式 bypass 套用;LOCKED → 正常套用。首次 acquisition 本身就是一次 CHANGED,ALIGNED 模式下 UNLOCKED 期間累積的 raw-far 狀態在該邊界被 flush。C 端 STFT/WOLA 狀態跨 delay change 連續(接受 1–2 幀暫態;crossfade 是後續 phase)。

延遲與 warm-up

  • 端到端演算法延遲 = 1 hop = 256 samples = 16 ms(centered 分析半窗 lookahead 本身;WOLA 收尾被半窗 trim 吸收)。測試佐證:far-timestamp 測試 far[2085] 的脈衝準確落在 out[2341](+256, offset +0)。
  • warm-up:hop#0 不發射任何幀,輸出全零;hop#1 一次補發 2 幀。identity E2E 測試:out[hop p] ≈ formed_history[p-1](2e-4 內),hop 0 精確為零。
  • AEC delay acquisition(bulk-delay 測試訊號實測 ~hop 15)前 ALIGNED 模式恆 fail-open;RAW 模式從第一個發射幀就套用模型。
  • reset:audio_pipeline_ulcnet_reset() 重置 AEC/兩路 analysis/synthesis 並呼叫 model->reset;timing 前導(hop#0 零輸出)重新開始。

短延遲部署注意(僅 ALIGNED 模式;pipeline 實測發現):echo path 的 bulk delay 落在線性濾波器 832-tap 涵蓋範圍內時,濾波器未對齊即可收斂(ERLE>2.5 dB)→ Path-A already-cancelling 保護(delay_acquire_protect_converged)會永久擋下 first acquisition → delay_state 恆為 UNLOCKED → ALIGNED 模式的 NN 永遠 fail-open(輸出=線性殘差,音質安全但 NN 從未生效)。RAW 模式不受影響(不以 lock 閘控)。產品狀態機需要「filter 已收斂且無 delay 需求 → 視同 LOCKED」的路徑(見 docs/align_ulcnet_embedded_streaming_design_zh_TW.md §8)。
