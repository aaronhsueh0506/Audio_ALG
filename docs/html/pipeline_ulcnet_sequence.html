Align-ULCNet pipeline 流程時序圖(mono / 4ch)

概要

本頁是 pipeline_ulcnet_usage 的時序圖:初始化、穩態 hop(mono 與 4ch,含 adapter 與 NPU)、拆開的 front／beam 形式、失敗與 reset。箭頭標的是實際函式名,順序就是呼叫順序;「|」是生命線,箭頭太短放不下的標籤寫在箭頭上一行。端到端延遲是 1 個編譯期格點 hop(16 kHz 為 256 samples = 16 ms,48 kHz 為 512 samples = 10.67 ms),來源是 synthesis 的半窗 trim;hop #0 輸出全零,hop p 輸出對應輸入 hop p-1(各頁的 hop 泳道圖見 mono、4ch)。

1. 初始化(mono;4ch 把 Aec 換成 mcab_sample_flow_init() 加 mcab_sample_beam_init(),stage 用 ulcnet_nn_stage_mem_size(0))

  | ulcnet_model_io_descriptor_default(D, &desc)        D 必須等於匯出時的 delay depth                        |
  |-- ulcnet_accelerator_adapter_get_mem_size(&desc, &bytes, &align) ------------->|                          |
  |-- ulcnet_accelerator_adapter_init(pool, bytes, &desc, run, user) ------------->|                          |
  |                          |                          |                          | ulcnet_prepost_init_ex(FREQ 模式)-> 四個 state tensor 在 caller pool;NULL = 未對齊／太小／descriptor 被拒
  | aec_get_mem_size(&aec_cfg)                          |                          |                          |
  |------------------------->|                          |                          |                          |
  | ulcnet_nn_stage_mem_size(1)           mono:1 = 另帶時域 error 分析用的 STFT;4ch:0                         |
  |---------------------------------------------------->|                          |                          |
  | aec_init(pool, aec_b, &aec_cfg)                     |                          |                          |
  |------------------------->|                          |                          |                          |
  |-- ulcnet_nn_stage_init(mem, stage_b, 1) ----------->|                          |                          |

  |-- ulcnet_accelerator_adapter_model(adapter) ---------------------------------->|                          |
  |<- UlcnetModel{user = adapter, infer, reset, io_descriptor} --------------------|                          |
  |-- ulcnet_nn_stage_set_model(stage, &model) -------->|                          |                          |
  | 0 | -1(infer 沒有 descriptor、或 descriptor 不是 raw-far／格點不符;原本裝的模型保留)                      |

2. 穩態 hop:mono

App(main.c)                 Aec                   UlcnetNnStage          Adapter(model.infer)             NPU run()
  |                          |                          |                          |                          |
-- 每個 hop(mic / ref / out 各 ULCNET_HOP 個 float) ----------------------------------------------------------------------
  | aec_process_context(aec, mic, ref)                  |                          |                          |
  |------------------------->|                          |                          |                          |
  | aec_get_res_context(aec, &rctx);  aec_get_linear_context(aec, &lctx)           |                          |
  |------------------------->|                          |                          |                          |
  | delay.changed = (delay_state == CHANGED);  delay.solid = (delay_state != UNLOCKED)                        |
  | ulcnet_nn_stage_begin_time(stage, rctx.formed_hop, ref, delay)                 |                          |
  |---------------------------------------------------->|                          |                          |
  |                          |                          | delay.changed 或 首次 solid:model.reset(user)(-> ulcnet_prepost_reset)並武裝 reprime_frames = 1
  |                          |                          | ac_stft_push_planar(err = formed_hop);ac_stft_push_planar(far = 原始 ref);每 hop 各恰 1 幀
  |                          |                          | reprime_frames > 0 ? 遞減,本幀 identity(不 step 模型)  :  nn_wanted = 1
-- 路徑 A:ulcnet_nn_stage_process(stage, out) = nn_begin + model.infer + nn_end + end ------------------------------------
  |-- ulcnet_nn_stage_process(stage, out) ------------->|                          |                          |
  |                          |                          | model.infer(user, err_re, err_im, far_re, far_im, out_re, out_im)
  |                          |                          |------------------------->|                          |
  |                          |                          |                          | ulcnet_prepost_pre_process_freq -> frame_inputs(K/V、logit、h_gru 視圖;output 預填 NaN)
  |                          |                          |                          | run(run_user, &inputs, &outputs)
  |                          |                          |                          |------------------------->|
  |                          |                          |                          | 0 = output 與四個 *_out 寫入原位址 | 非 0
  |                          |                          |                          |<-------------------------|
  |                          |                          |                          | rc != 0 -> frame_skip,回 -1;commit 驗證有限(失敗:四個 state 歸零、generation +1、frame_skip、回 -1);成功 -> post_process_freq
  |                          |                          |<- 0 | -1 ----------------|                          |
-- 路徑 B:phased,呼叫端自己跑加速器(可以呼叫 adapter 的 model.infer,或自己的 NPU 程式) -----------------------------------
  | ulcnet_nn_stage_nn_begin(stage, &job)  ->  1 | 0(reprime 幀)| < 0              |                          |
  |---------------------------------------------------->|                          |                          |
  |-- job.err_* / job.far_* -> 加速器 -> job.out_*(預填 NaN,每個 bin 都要寫) -------------------------------->|
  |-- ulcnet_nn_stage_nn_end(stage, rc) --------------->|                          |                          |
  |                          |                          | rc == 0 且 ulcnet_frame_is_finite(out) 才採用,否則 identity(不是錯誤)
-- 收尾(兩條路徑相同) ----------------------------------------------------------------------------------------------------
  | ulcnet_nn_stage_end(stage, out)       沒取走的幀 = identity                    |                          |
  |---------------------------------------------------->|                          |                          |
  |                          |                          | ac_istft_push_planar(synthesis, 採用的頻譜, out);hop #0 回 0 樣本 -> out 補零
  | 0 | ULCNET_NN_STAGE_DSP_ERROR(-3,非整 hop)| SEQUENCE_ERROR(-2)| INVALID_ARGUMENT(-1)                      |
  |<----------------------------------------------------|                          |                          |

4. 失敗與 reset

App(main.c)             Aec | helper+flow          UlcnetNnStage                 Adapter                      NPU
  |                          |                          |                          |                          |
-- 任何一步回負值(process_hop 回 -1) -------------------------------------------------------------------------------------
  | aec_reset(aec)  |  mcab_sample_beam_reset(unit)(連帶 flow、lane、estimator、SRP/BF)   |                          |
  |------------------------->|                          |                          |                          |
  |-- ulcnet_nn_stage_reset(stage) -------------------->|                          |                          |
  |                          |                          | ac_stft_reset(far[, err]);ac_istft_reset;last_delay、frame_index、phase、reprime_frames 清零;安裝的模型保留
  |                          |                          |-- model.reset(user) ---->|                          |
  |                          |                          |                          | ulcnet_prepost_reset:四個 state tensor 歸零,ulcnet_accelerator_adapter_state_generation() +1
  |                          |                          |                          | 定點加速器自己的 state 緩衝:generation 變了就填量化後的 0(板端 run() 內做)
  |                          |                          |                          |------------------------->|
-- 不是錯誤、不要 reset --------------------------------------------------------------------------------------------------
  | nn_end(rc != 0)或輸出有非有限 bin:該幀 identity;adapter 的 commit 拒絕則自己把 state 歸零                 |
  | alignment 邊界(CHANGED／首次 solid):stage 在 begin 內自己 model.reset + reprime,不需要 App 動作           |

alignment 邊界(CHANGED，或 FIXED 首次 UNLOCKED → LOCKED)之後有 ULCNET_NN_STAGE_REPRIME_FRAMES(= 1)個發射幀走 identity 且不呼叫模型;推導與兩個 grid 的實測見 pipeline_ulcnet_detail。
