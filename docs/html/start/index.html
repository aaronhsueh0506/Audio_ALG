Audio_ALG

建置與第一次執行

在 Audio_ALG/ 根目錄執行。預設從同層的 AEC/、NR/ 和 audiolib/ 讀取 C 原始碼，版本由 lib/*.pin 指定。

建置 mono 範例

make -f lib/deps.mk bootstrap-deps
make -C pipelines check-pins
make -C pipelines
BIN="$(make -s -C pipelines print-bin-dir)"
"$BIN/aec_nr_pipeline" mic.wav far.wav enhanced.wav balanced

準備取樣率相同、時間對齊的單聲道 16 kHz PCM WAV。mic.wav 是收音，far.wav 是播放參考，第三個路徑是輸出。要跑 Python pipeline 或 WAV parity，先執行 git submodule update --init --recursive，讓 Python 匯入和測資可從 lib/aec、lib/nr 取得。
