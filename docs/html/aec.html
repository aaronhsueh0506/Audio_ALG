AEC C library(單聲道)— lib/aec/c_impl

概要

單聲道 PBFDKF 回音消除器的 float32 C 實作(Python aec.py 為演算法規格)。一個 hop 的處理鏈:mic 端 HPF → 飽和偵測 → AEC3 matched-filter 延遲估計 + 參考訊號 ring buffer 對齊 → PBFDAF shadow / PBFDKF main 線性濾波 → AEC3 post(殘留回音抑制 RES + CNG)。全部 state 收在單一 Aec struct(caller pool 或單一 heap arena),process 熱路徑零 malloc(make test-zero-heap 實測 50 個 init/process/reset/destroy 週期 allocator 呼叫為 0)。heap 與 caller-pool 兩條建構路徑輸出逐位元相同(test_static_aec:669,824 樣本 byte-equal)。

沒有任何 NN/NPU 成分:本函式庫是純 DSP,跨 hop 的 state 全部由 C struct 保存,host 不需另存任何 state。AecResContext / AecLinearContext 兩個 seam 是外接 NN 後級(RES/NR)時的接點,見 lib/aec/docs/nn_integration_interface.md。

API 用法

#include "aec.h"

AecConfig cfg;
aec_config_from_preset(&cfg, AEC_PRESET_BALANCED, 16000);
/* 可選:cfg.fft_size = 512;  10ms-authored 常數在建構時(aec_carve)
 * 才對最終 hop 重定時,所以覆寫 fft_size 是安全的 */

/* A. caller pool(嵌入式建議;零 heap) */
size_t bytes = aec_get_mem_size(&cfg);          /* 回 0 = config 無效 */
Aec* a = aec_init(pool, bytes, &cfg);            /* pool 需 16-byte 對齊 */

/* B. heap(單一 malloc arena) */
Aec aec;                                          /* struct 由呼叫端持有 */
if (aec_create(&aec, &cfg) != 0) { /* 失敗 */ }

int hop = aec_hop_size(a);
for (每個 hop) {
    aec_process(a, mic, ref, out);   /* 各恰好 hop 個 float32 樣本 */
}
aec_destroy(a);   /* aec_init 實例為 no-op;pool 由呼叫端釋放 */

四個 process 進入點推進完全相同的內部 state(都經 aec_process_core()),只差結果怎麼交付,可在同一實例上自由交錯、不需 reset:

進入點用途
aec_process(a, mic, ref, out)lockstep(離線/同執行緒)。與 Python 規格對齊的標準路徑;結果 memcpy 進 out。
aec_process_context(a, mic, ref)context-only:跑完整線性 + AEC3 post,但不寫 out(省一次 O(hop) memcpy)。給只讀 aec_get_res_context() 的呼叫端(mono pipeline 即此模式)。
aec_process_context_shared_far(a, mic, ref, far_spec)多實例共用遠端 FFT:borrow 別的 lane 已算好的 far spectrum(必須是同一 hop、同一 far 訊號的頻譜;ref 仍必填)。傳 NULL 退回自算。儀表:aec_far_fft_real_compute_count()。
aec_analyze_render(a, ref) + aec_process_capture(a, mic, out)串流(render/capture 非同步)。SPSC:恰一個 render 執行緒 + 恰一個 capture 執行緒可無鎖並行。單執行緒 lockstep 呼叫時與 aec_process() 逐位元相同。underrun → 以全零 hop 處理並回 AEC_BUF_RENDER_UNDERRUN;overrun → drop-new / consumer catch-up,回 AEC_BUF_RENDER_OVERRUN。aec_reset()/aec_destroy() 前必須先靜止兩側執行緒。

Preset(唯一差異軸):mild / balanced / aggressive 只差 min_gain_floor_far_active_db = −20 / −28 / −38 dB(SuppressionGain far-active 最低增益地板)。其餘所有欄位相同。

AecResContext seam(aec_get_res_context(),頻域,外接 NR/RES 用):error_spec = formed 線性輸出的 50%-overlap periodic-sqrt-Hann STFT E(f)(音訊尺度);echo_spec 為對應回音估計、near_spec = error_spec + echo_spec;res_gain = AEC3 SuppressionGain G_res(f) ∈ [0,1];r2(殘留回音 PSD)與 comfort_noise(CNG N²)為 int16² 尺度(除以 32768² 得 |E|² 音訊功率尺度)。頻域欄位僅在 enable_res=1 或 return_res_context=1 時非 NULL;spatial_linear_context=1 時 res_gain 恆為 NULL(該 lane 的 G_res 根本沒算,NULL 表示「未計算」而非「全抑制」)。所有指標都 alias AEC 內部 per-hop buffer——下一次任何 process 呼叫前必須讀完。

AecLinearContext seam(aec_get_linear_context(),時域,外接 NN 後級用):formed_linear_hop(post 鏈有跑時為 e_form,否則 raw 線性輸出)、aligned_far_hop(本 hop PBFDKF 實際吃到的時域 far,alias a->far_hop)。delay_state 誠實語意:

  • AEC_LINEAR_DELAY_UNLOCKED — 內容是未補償的 raw far:延遲尚未擷取、ring 未填滿、或 enable_delay_est=0。另外超出可擷取上限的 bulk delay 永遠停在 UNLOCKED(估計器不會擷取也不會報錯),fail-open 策略歸整合端。
  • AEC_LINEAR_DELAY_LOCKED — 已用穩定 offset 補償。
  • AEC_LINEAR_DELAY_CHANGED — 恰在 offset 於本 hop 移動的那個 hop 回報(下一 hop 回到 LOCKED);下游應 flush far 特徵快取。

generation 在每次 ring 讀取 offset 改變時 +1(首次擷取、確認位移——含不設任何旗標的 soft-recovery realign——以及 aec_reset()),飽和於 0xFFFFFFFF 不回繞。請輪詢 generation 而不是對 delay_samples 做差分(瞬時 A→B→A 位移對差分不可見)。

Debug:aec_debug_status()(唯讀、零熱路徑成本)回 delay_samples(−1=未擷取)、delay_confidence(0/0.5/1.0)、delay_updates、erle_windowed_db、usable_linear、filter_converged、near_power/out_power(EMA α=0.95)。

延遲為脈衝實測(lib/aec/docs/c_user_manual_zh_TW.md §3「演算法延遲(實測)」),無 look-ahead。可擷取上限是編譯期常數(matched filter 搜尋長度 × 4 倍降取樣),調 max_delay_ms 不會提高;48 kHz 內部先降到 16 kHz 估計再 ×3 回傳。另注意 aec.h 寫的 ~509 ms 是「可靠峰值」定義、608 ms 是幾何全跨度——兩種定義,非矛盾(見 nn_integration_interface.md)。

Warm-up:warmup_frames=100(10 ms 基準著作 ≈1000 ms;於 aec_carve() 對實際 hop 重定時,例如 16k/256 內部變 125 hop)期間濾波器以較積極方式收斂。延遲估計需 delay_aec3_n_updates() ≥ 3 且 solid 才擷取;估計穩定 delay_est_init_s=0.3 秒後 duty-cycle 把 matched-filter 分析降到 1-in-K(ERLE 看門狗回退)。delay_acquire_warm_transfer=1(預設)在首次擷取時平移已學到的 IR 而非歸零,避免開場「垂直線」回音。
