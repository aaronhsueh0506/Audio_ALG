DeepFilterNet2

單路 int16 PCM，輸出同樣長度的一個 hop。SDK 封裝 HPF（選用）、STFT、DFN2 頻域前後處理與 ISTFT。frames_per_call 可以是 1..64（grid 欄位，執行期給）：N=1 每拍都推論；N>1 每 N 拍才推論一次，DFN2HopIO.job_ready 標示哪一拍要跑加速器，但 pre_process／post_process 兩支函式每拍都要照常呼叫。輸入與輸出時序以 checkpoint 的 grid 為準。

建置與初始化

make -C stream/ainr/dfn2 lib
make -s -C stream/ainr/dfn2 print-lib-path

依模型建立 grid 與 config，用 dfn2_stream_get_mem_size() 查詢 pool 大小與對齊，再配置 pool。以同一目標工具鏈建置並連結模型 archive 和 audiolib 的 libaudio_common.a。裝置 runtime 載入與 grid 相符的模型檔，負責每次 NPU 推論。

每 hop 呼叫

範例中的讀寫、run_accelerator 與 device_state_* 由呼叫端實作。裝置第一次使用或 generation 改變時，把 recurrent state 還原為模型的量化零值。推論已開始後回錯，也立刻清掉可能部分寫入的裝置 state。

DFN2Stream *ctx = dfn2_stream_init_from_erb_file(&cfg, erb_path, pool, bytes);
if (!ctx) return -1;
while (read_hop(pcm_in)) {
    DFN2HopIO io;
    if (dfn2_stream_pre_process(ctx, pcm_in, &io) != 1) return -1;
    int rc = 0;
    if (io.job_ready) {
        device_state_sync(io.state_generation);
        rc = run_accelerator(&io.inputs, &io.outputs);
        if (rc != 0) device_state_refill_zero();
    }
    if (dfn2_stream_post_process(ctx, rc, pcm_out) < 0) return -1;
    write_hop(pcm_out);
}

若由記憶體初始化，將 forward 表排成 [n_bins][n_erb]、inverse 表排成 [n_erb][n_bins]，並在 stream 存活期間保留兩者。使用 dfn2_stream_init_from_erb_file() 時，兩個指標留 NULL，載入器負責轉置檔案內的 inverse 表。full 與 mask-only 的 archive 各自建置，呼叫端的 DFN2_MASK_ONLY 要與 archive 相符，否則連結會失敗。

N=1 從 hop 0 起每拍都推論（暖機期間 core 丟棄 heads 並推進 generation）。N>1 沒有暖機拍：前 mask_lookahead + N - 1 拍 job_ready 恆 0，之後每 N 拍才回 1 一次；post_process() 不管該拍有無推論都要呼叫，從上一批算好的結果逐拍吐 PCM。post_process() 的回傳 1 代表當拍頻譜有效，PCM 還有一拍 OLA 延遲。full 出貨 grid 在 N=1、L=D=1 時 t=2 首次回 1、t=3 才對齊第一拍輸入；N>1 時收尾要多送 L+D+N 拍零 PCM（不是 N=1 的 L+D+1）才能把最後一批排完。對應的匯出選項與公式見 Multi-frame export。
