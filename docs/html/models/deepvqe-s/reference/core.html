每個 window 輸入由 graph 的 Slice 位移：conv 與 score window 取輸入的 frame 1..N−1（Slice axis 2，start 1，end N，step 1） 再把新一幀 Concat 在後面；attention ring 取輸入的 slot 0..D−2 再把新一幀 Concat 在前面。Concat 的結果就是 *_out，被丟掉的那一格（conv／score window 的 frame 0、ring 的 slot D−1）只讓輸入與輸出 shape 相同，graph 不讀它。 export_graph 對寫出的檔案呼叫 validate_inplace_state_contract（每對 state shape 相同且 rank 4、 每個 window 輸入恰有一個 Slice 消費者、沒有 state 輸出由 Slice 產生、metadata 帶 state_binding = in_place_same_address）。

形狀屬於應用端：函式庫只收 state_elements[id]，不知道形狀；測試 driver 帶一張 16 列的表， 由 test_c_descriptor_matches_the_built_graph 釘在匯出的 graph 上。頻率階梯 257→129→65→33→17 是 encoder 的 stride-2 halving， conv window = causal conv kernel 4 幀（3 幀過去加目前一幀）、alignment score conv 是 (5,3) 所以 window 是 5 幀。head 輸出 output = packed CCM taps [1,1,257,18]；末軸保持 [time][frequency][RI] 次序，與 deepvqe_process.h 的 taps[n_bins][3][3][2] 攤平後同一塊記憶體，不需 transpose 或 copy。

Descriptor（13 欄）：DeepVqePrepostDescriptor = layout_version／delay_depth／sample_rate／ fft_size／hop_size／spectrum_bins／time_order／ freq_taps／conv_window_frames／score_window_frames／ gru_layers／gru_hidden／state_tensor_count。 deepvqe_prepost_descriptor_default(&grid, &desc) 填外部欄位，_descriptor_validate(&grid, &desc) 把除 delay_depth 之外的外部欄位釘在 grid 與本 build 的常數上（delay_depth 是 export 期的部署參數，只檢查範圍）； conv_window_frames／score_window_frames／gru_layers／gru_hidden 四欄屬於模型內部，default 給 0、validate 不讀。 DEEPVQE_PREPOST_LAYOUT_VERSION = 4（mic/far 的名稱與元素數 2×n_bins 不隨 layout 變，state 是完整 window、h_gru 是 rank 4，版號是唯一能攔下舊板綁新圖的閘門；1–3 已退役），且刻意不與 ULCNET_MODEL_IO_LAYOUT_VERSION 共用：兩個模型的 boundary 各走各的，共用號碼會讓 一邊的 bump 看起來像另一邊的。D 範圍 DEEPVQE_PREPOST_MIN_D=1 … MAX_D=256，沒有預設值：應用端給匯出該模型時的 D（出貨 32 ＝ 這個 grid 上的 0.5 秒搜尋範圍，ceil(0.5 × 16000/256)）。

Exporter metadata：AIAEC/_streaming_export.py 的 _C_DESCRIPTORS 把 DeepVQE_S 映到 _deepvqe_c_descriptor()，它從剛建好的 graph 量這 13 欄（tap 軸、conv／score window 深度、GRU 形狀、兩個 ring 的 D 與 model 自報的 D 必須一致、state 數 = input 數 − signal input 數），再把 metadata['state_layout_version'] 與 metadata['c_descriptor'] 一起寫進 ONNX props 與旁邊的 JSON。 外部欄位（grid、time_order、freq_taps、state_tensor_count、layout）不符會在板端變成一次 descriptor_validate() 拒絕；四個內部欄位只記在 metadata，C 端不讀。

延遲與 warm-up

  • NN 演算法 lookahead = 0 hop；每個算子都是因果、reset 時 zero 左 context ≡ offline 左零 padding，無 warm-up 特例（無 CRUSE 的 T≥D caveat——delay softmax 每幀獨立）。
  • 實測 stream-vs-offline（seed 0/1、96 幀、CPU fp32）：enhanced 1.5e-6、ccm_taps 4.5e-7、delay 3.7e-9；tolerances 以 ~10x headroom 釘在 2e-5 / 5e-6 （test_streaming_deepvqe_s.py 檔頭）。唯一算術差源是 GRU batched-vs-stepped kernel 路徑。
  • Framing：應用端用 center=False、每 hop 一幀的 rolling 分析 （ac_stft_push_planar，center 0）；端到端演算法延遲仍是 256 samples（16 ms）， 但它來自 synthesis 的半窗 trim、不是分析排程。Python reference 的 StreamSTFT/StreamISTFT 仍是 centered 排程，兩條排程自第二個 hop 起位元相同 （centered 只在開頭多一幀 reflect 前綴）。

頻域 API

如何呼叫使用

  1. grid 是 run-time 值：填 DeepVqeGridSpec（sample_rate、n_fft、delay_depth 取自匯出該模型的設定，frames_per_call 為每次加速器呼叫批幾幀，範圍 [1, DEEPVQE_MODEL_MAX_FRAMES_PER_CALL]，逐幀配置填 1）→ deepvqe_grid_make(&grid, &spec) 回 DEEPVQE_GRID_OK 或第一個失敗的 DEEPVQE_GRID_ERR_*。D = alignment 搜尋深度，範圍 DEEPVQE_PREPOST_MIN_D(1)…MAX_D(256)，沒有預設值，且必須等於匯出該 ONNX 時的 D（export_onnx.py --max-delay-frames，未給則用 checkpoint 的 D；出貨 32 ＝ 16 kHz 上 0.5 秒）。
  2. framing 由應用端做：用 audiolib 建兩個 AcStft（mic、far）與一個 AcIstft，組態 ac_stft_config_default(&sc, grid.n_fft)（sqrt-Hann、center 0、spec_scale = ispec_scale = 1），合成端另設 sc.ola = AC_OLA_ACCUMULATE（deepvqe_prepost.h 檔頭；無首拍特例，見下方延遲表）。類別不持有 window、FftHandle 或 STFT 物件。
  3. 16 個 state 歸應用端（DeepVqeStateId 順序，形狀見 DeepVQE-S 頻域與模型契約 的 State 表，函式庫只收元素數）：浮點 host 配 16 塊 float buffer，把 16 組（指標，元素數）登錄進 cfg.state[]／cfg.state_elements[]——全登錄或全不登錄，init 與 reset 時清零，每次 frame_finish 整塊檢查有限，不計入 pool 大小與 hash；目標平台不登錄，由加速器持有，把每個 state 輸入與其 *_out 綁在同一塊加速器 buffer。
  4. deepvqe_prepost_config_defaults(&cfg, &grid)（grid 被複製）→ 登錄 state → deepvqe_prepost_get_mem_size(&cfg, &req)（req.alignment = 16）→ deepvqe_prepost_init_ex(pool, req.bytes, &cfg, &req)。D = 32 的 pool：16 kHz／512 為 35,504 B、48 kHz／1024 為 70,320 B（本機量測，不含應用端的 state 與 AcStft／AcIstft）。
  5. 按名稱綁定 graph 的 state 時用 deepvqe_prepost_state_name(id)／_state_name_out(id)；啟動時把 ONNX／JSON 內的 c_descriptor 讀成 DeepVqePrepostDescriptor，以 deepvqe_prepost_descriptor_validate(&grid, &meta) 檢查。
  6. 每個 hop（從 hop 0 起一次推論）：ac_stft_push_planar×2 → pre_process_freq(mic, far) 恆回 1 → frame_open（host 端做 power-law 壓縮 0.3，mic／far 是壓縮後的 planar [1,2,1,n_bins]；只有 taps 預填 NaN）→ 加速器 → frame_finish（失敗改 frame_bypass）→ post_process_freq → ac_istft_push_planar。
  7. 目標平台：每次 deepvqe_prepost_state_generation() 改變（reset 或被拒的 frame_finish），把加速器自己的 16 個 state 清成零（定點 state 埠兩端的 zero_point 須為 0，見整合入口的 State 一節）；新建實例的 generation 為 0，做法同 Align-ULCNet 頻域與模型契約 的目標平台片段。
  8. 重新開始：deepvqe_prepost_reset(p)（登錄的 state、CCM ring 歸零，generation +1），並自行 ac_stft_reset／ac_istft_reset；結束：_destroy（對 _init 實例是 no-op，登錄的 buffer 與 pool 歸應用端）。
#include <stdlib.h>
#include <string.h>
#include "audio_stft.h"
#include "DeepVQE_S/deepvqe_prepost.h"

extern int npu_run(const DeepVqePrepostInputs *in, DeepVqePrepostOutputs *out);

static void *block(size_t n) { return aligned_alloc(16, (n + 15u) / 16u * 16u); }

/* elems[id]：DeepVqeStateId 順序的 state 元素數（匯出圖的 shape 乘積，見 State 表）；
 * D 必須等於匯出該 ONNX 時的 --max-delay-frames。 */
int run_deepvqe(int D, const size_t elems[DEEPVQE_STATE_COUNT],
                const float *mic, const float *far, float *out, long hops)
{
    const DeepVqeGridSpec spec = { 16000, 512, D, 1 };   /* sample_rate, n_fft, delay_depth, frames_per_call */
    DeepVqeGrid grid;
    DeepVqePrepostConfig cfg;
    DeepVqePrepostMemReq req;
    AcStftConfig sc;
    int rc = -1;

    if (deepvqe_grid_make(&grid, &spec) != DEEPVQE_GRID_OK) return -1;
    if (deepvqe_prepost_config_defaults(&cfg, &grid) != 0) return -1;
    for (int id = 0; id < DEEPVQE_STATE_COUNT; ++id) {      /* 浮點 host：16 組 (指標, 元素數) 全登錄 */
        cfg.state[id] = calloc(elems[id], sizeof(float));
        cfg.state_elements[id] = elems[id];
    }

    ac_stft_config_default(&sc, grid.n_fft);   /* sqrt-Hann、center 0、spec_scale = ispec_scale = 1 */
    sc.ola = AC_OLA_ACCUMULATE;                 /* 合成用；分析忽略 */
    size_t an = ac_stft_get_mem_size(&sc), sy = ac_istft_get_mem_size(&sc);
    void *m0 = block(an), *m1 = block(an), *m2 = block(sy);
    AcStft *mic_stft = m0 ? ac_stft_init(m0, an, &sc) : NULL;
    AcStft *far_stft = m1 ? ac_stft_init(m1, an, &sc) : NULL;
    AcIstft *istft   = m2 ? ac_istft_init(m2, sy, &sc) : NULL;

    float *buf = calloc(6u * (size_t)grid.n_bins, sizeof(float));
    float *m_re = buf, *m_im = m_re + grid.n_bins, *f_re = m_im + grid.n_bins;
    float *f_im = f_re + grid.n_bins, *o_re = f_im + grid.n_bins, *o_im = o_re + grid.n_bins;
    void *pool = NULL;
    DeepVqePrepost *p = NULL;
    if (deepvqe_prepost_get_mem_size(&cfg, &req) == 0 && (pool = block(req.bytes)))
        p = deepvqe_prepost_init_ex(pool, (size_t)req.bytes, &cfg, &req);

    if (p && mic_stft && far_stft && istft && buf) {
        rc = 0;
        for (long h = 0; h < hops && rc == 0; ++h) {
            DeepVqePrepostInputs xin;
            DeepVqePrepostOutputs xout;
            float *dst = out + h * grid.hop;
            /* mic：原始麥克風 hop（前面沒有 linear AEC）；far：同一輸入 hop 的遠端參考 */
            ac_stft_push_planar(mic_stft, mic + h * grid.hop, m_re, m_im);   /* center 0：恆 1 幀 */
            ac_stft_push_planar(far_stft, far + h * grid.hop, f_re, f_im);
            if (deepvqe_prepost_pre_process_freq(p, m_re, m_im, f_re, f_im) != 1 ||
                deepvqe_prepost_frame_open(p, &xin, &xout) != 0) { rc = -1; break; }
            if (npu_run(&xin, &xout) != 0 || deepvqe_prepost_frame_finish(p) != 0)
                deepvqe_prepost_frame_bypass(p);                  /* fail-closed：當前增強頻譜歸零 */
            if (deepvqe_prepost_post_process_freq(p, o_re, o_im) != 0) { rc = -1; break; }
            if (ac_istft_push_planar(istft, o_re, o_im, dst) == 0)   /* 第一個 hop 無輸出 */
                memset(dst, 0, (size_t)grid.hop * sizeof(float));
        }
    }
    deepvqe_prepost_destroy(p);   /* _init 實例：no-op；登錄的 buffer 與 pool 歸應用端 */
    free(pool); free(buf); free(m0); free(m1); free(m2);
    for (int id = 0; id < DEEPVQE_STATE_COUNT; ++id) free(cfg.state[id]);
    return rc;
}

片語可在 -std=c11 -Wall -Wextra -Wpedantic -Werror 下編譯；接替身加速器（CCM 為單位核）在 16 kHz／512、D = 32 跑 40 hop，輸出等於 mic 延後一個 hop。npu_run 由目標平台提供。

錯誤處理速查

呼叫失敗回傳原因／處置
deepvqe_grid_makeDEEPVQE_GRID_ERR_*（grid 不動）_NULL(-1)、_SAMPLE_RATE(-2)、_N_FFT(-3，audiolib 建不出該 n_fft)、_DELAY_DEPTH(-4，D 超出 1…256)
config_defaults-1NULL 或無效 grid
get_mem_size-1，*req 不動同上，或 state 登錄不一致（有指標無元素數、元素數無指標、16 組沒有全設或全空）
init／init_exNULLpool 未對齊／太小、config 錯、expected 不符（陳舊 pool；hash 認 grid、D、layout 與 carve 版本）；被拒的呼叫不動 pool
pre_process_freq-1NULL、上一個 frame 尚未 frame_finish／frame_bypass
frame_open-1沒有開啟中的 frame
frame_finish-1任一 tap 或登錄 buffer 的任一元素（整塊，含較舊的幀）非有限：登錄的 state 全部歸零（沒登錄時只檢查 taps）、generation +1、CCM ring 不前進、frame 仍開；呼叫 frame_bypass 或重新 frame_open
frame_bypass-1（無 frame）成功時當前增強頻譜歸零，PCM 合成保留前拍 overlap（deepvqe_prepost_skip_policy_name() = "mute_fail_closed"）：CCM ring 與 state 維持原樣。想要優雅降級的呼叫端須自己在 pipeline 層放 canceller 並 cross-fade
post_process_freq-1NULL、frame 還開著；成功時 re／im 寫滿 n_bins 個值
