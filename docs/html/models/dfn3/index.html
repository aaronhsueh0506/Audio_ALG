DeepFilterNet3

概要

DFN3 的 C 類別 DFN3Prepost 與 DFN2 的類別同形（函式名把 dfn2 換成 dfn3，生命週期、交易式 frame 狀態機、bypass／generation 規則相同；兩者都只做頻域，grid、framing 與 recurrent state 都歸應用端），差別只在模型：低頻直接濾原始 noisy 頻譜、高頻乘 ERB gain、沒有 alpha head（DFN3PrepostOutputs 只有 erb_mask／coefs 與兩個 *_next）、延遲短一個 hop，且 DFN3GridSpec 沒有 frames_per_call（一次 invocation 一個 frame）。模型內容見 DeepFilterNet3 頻域與模型契約。

如何呼叫使用

  1. 應用端備齊（皆為借用或由應用端配置）：DFN3GridSpec（模型匯出時決定的值）→ dfn3_grid_make(&grid, &spec)，非 0 就是被拒，dfn3_grid_status_text() 給文字；framing 用 audiolib 的 AcStft／AcIstft：ac_stft_config_default(&sc, grid.n_fft)，只改 sc.spec_scale = grid.stft_scale 與 sc.ispec_scale = grid.stft_unscale（其餘預設：sqrt-Hann、center 0、hop = n_fft/2、AC_OLA_ACCUMULATE），函式庫不持有窗、FFT 或 STFT，尺度設錯偵測不到；ERB 矩陣 erb_fwd／erb_inv 兩個指標（由應用端載入並持有；export_erb_matrix.py --runtime-bins DIR 輸出 erb_fwd.bin（bin-major）／erb_inv.bin（band-major）兩個 raw 檔，版面等於函式庫要的）；float host 另備 h_gru（5 × 256 floats）與 df_convp_history（64 × 5 × 96 floats）兩塊 state buffer，板端不備。
  2. dfn3_prepost_config_defaults(&cfg, &grid) → 填 erb_fwd／erb_inv（float host 再填兩組 state 的指標與元素個數：兩組都設或四個值全為 NULL／0）→ dfn3_prepost_get_mem_size（alignment 16）→ dfn3_prepost_init_ex(pool, req.bytes, &cfg, &req)；host 工具可用 _create／_destroy（只釋放 _create 配置的記憶體，不碰註冊的 buffer 與 ERB 矩陣）。
  3. 每個 hop：ac_stft_push_planar → pre_process_freq（每拍回 1）→ frame_open → 加速器 → frame_finish，失敗或被拒就 frame_bypass → post_process_freq（valid 只是資訊，可傳 NULL）→ ac_istft_push_planar（每拍；零頻譜得零 hop）。前 M 拍（出貨 M=1：第 0 拍）是暖機幀：加速器照跑，heads 由 frame_finish／frame_bypass 丟棄、登錄 state 歸零、generation 加 1，回 0；M=0 沒有暖機幀。
  4. 板端（不註冊 state）：加速器自己保存定點 state，起始時填成量化後的 0；每次 dfn3_prepost_state_generation() 與上次看到的值不同（reset、每個暖機幀或被拒的 frame_finish），先把加速器 state 重填成量化後的 0 再跑（M 個暖機幀各重填一次）。generation 在 init 後是 1，永遠用「與上次比較」判斷。float host 註冊的 buffer 由函式庫在 init、reset 與被拒時歸零，不需要重填。
  5. 重新開始一段串流：dfn3_prepost_reset(p) 加應用端自己的 ac_stft_reset／ac_istft_reset。結尾：再餵零頻譜並照跑加速器，可把尾端排出（grid.output_delay 個只排出最後一個頻譜框，要輸出最後一個真實 hop 的 PCM 需再多 1 個，共 grid.output_delay + 1）（dfn3_prepost_pre_process_freq 的標頭註解）；若要精確處理有限長 clip 的尾端，模型 feature 需補訓練時的零 padding，而不是用零頻譜重算正規化後特徵。持續餵零音訊只是在延續 live stream。

完整 C 整合範例

加速器自行保存 state 時，每次推論前依 generation 回填量化零。若推論可能部分寫入後回錯，立即重新回填，再走當拍的 bypass。最後一個頻譜及 PCM 分別需要 output_delay 與 output_delay+1 拍排空。

推論呼叫範例

加速器擁有 state 時，每拍送入已分析的頻譜。下例的裝置同步、回填及推論由 adapter 提供。

DFN3PrepostInputs inputs;
DFN3PrepostOutputs outputs;
if (dfn3_prepost_pre_process_freq(p, re, im) != 1 ||
    dfn3_prepost_frame_open(p, &inputs, &outputs) != 0) return -1;
device_state_sync(dfn3_prepost_state_generation(p));
int rc = run_accelerator(&inputs, &outputs);
if (rc != 0) device_state_refill_zero();
if (rc != 0 || dfn3_prepost_frame_finish(p) != 0) {
    if (dfn3_prepost_frame_bypass(p) != 0) return -1;
}
if (dfn3_prepost_post_process_freq(p, out_re, out_im, &valid) != 0) return -1;
