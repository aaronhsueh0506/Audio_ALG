Audio_ALG

模型開發與部署

PCM SDK 負責窗函數、STFT／ISTFT 及模型前後處理，每 hop 交給呼叫端執行加速器。已經拿到頻譜的應用，可直接用 lib/ainr/ 或 lib/aiaec/ 內的 model core。

AINR

模型C 入口訊號
DeepFilterNet2PCM SDK、頻域 coreint16 語音 → 增強 PCM；full 或 mask-only。
DeepFilterNet3頻域 core原始低頻深濾波與高頻 ERB mask，在同一頻譜輸出。
GTCRN頻域 core單路複數頻譜 → ERB 特徵 → 複數 mask。
RNNoise-ERB頻域 core單路頻譜 → 三幀特徵窗 → ERB gains，對齊延遲頻譜。

AIAEC

模型C 入口訊號
Align-ULCNetPCM SDK、頻域 core線性 AEC 的 float 殘差與原始 far → 增強 PCM。
DeepVQE-SPCM SDK、頻域 core原始 mic 和 far PCM → 複數濾波 → 增強 PCM。
CAGCRNmask 合成 helper原始 mic 和 far。Python 串流與匯出，C 提供複數 mask 合成。
Align-CRUSEmask 合成 helper原始 mic 和 far。Python 串流與匯出，C 提供實數 mask 合成。

ONNX 張量邊界、state、匯出與 PTQ calibration

三個 PCM SDK 以主機和替身加速器驗證。目標板上的真實 graph、量化、cache／DMA 與每 hop 耗時，需在部署時另外核對。
