Align-ULCNet

輸入是線性 AEC 的 error hop 與原始 far 參考。使用 ulcnet_stream_pre_process_f32() 可把 AecResContext.formed_hop 直接交給 STFT。兩路都是滿幅約 1.0 的 float，輸出是 int16 PCM。原生 int16 輸入可改呼叫 ulcnet_stream_pre_process()。

建置與初始化

make -C stream/aiaec/ulcnet lib
make -s -C stream/aiaec/ulcnet print-lib-path

依模型建立 grid 與 config，用 ulcnet_stream_get_mem_size() 查詢 pool 大小與對齊，再配置 pool。以同一目標工具鏈建置並連結模型 archive 和 audiolib 的 libaudio_common.a。裝置 runtime 載入與 grid 相符的模型檔，負責每次 NPU 推論。

每 hop 呼叫

範例中的讀寫、run_accelerator 與 device_state_* 由呼叫端實作。裝置第一次使用或 generation 改變時，把 recurrent state 還原為模型的量化零值。推論已開始後回錯，也立刻清掉可能部分寫入的裝置 state。

UlcnetStream *ctx = ulcnet_stream_init(&cfg, pool, bytes);
if (!ctx) return -1;
while (read_aec_hop(&rctx, far_float, &delay)) {
    UlcnetHopIO io;
    int pre = ulcnet_stream_pre_process_f32(ctx, rctx.formed_hop, far_float, delay, &io);
    if (pre < 0) return -1;
    int rc = 0;
    if (pre == 1) {
        device_state_sync(io.state_generation);
        rc = run_accelerator(&io.inputs, &io.outputs);
        if (rc != 0) device_state_refill_zero();
    }
    if (ulcnet_stream_post_process(ctx, rc, pcm_out) < 0) return -1;
    write_hop(pcm_out);
}

UlcnetStreamDelay.changed 或 solid 從上一拍的假轉為真，會在分析前清除 STFT、ISTFT 與模型狀態，並安排一拍 reprime。該拍 pre 回 0，照常呼叫 post。Reprime 或推論失敗時，當拍線性誤差頻譜直接送入合成。init／reset 後第一個 ISTFT hop 的 PCM 填零。
