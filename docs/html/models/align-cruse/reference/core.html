延遲與 warm-up

  • NN 演算法 lookahead = 0 hop；framing 半窗 256 samples（16 ms）。
  • T ≥ D caveat（forward_stream docstring 明文）：offline 用最終 utterance 長度 T 做 arange(D) < T 的 observable mask，stream 無法預知 T，因此假設 T ≥ D。utterance ≥ 63 hops（1 s @16k）時每一幀（含前 63 幀）精確等價：實測 T=90 全幀 stream-vs-offline enhanced 4.9e-7 / mask 1.8e-7 / delay 3.3e-7（ATOL 釘 5e-6）。 整段 < 63 幀的短檔刻意發散：專屬測試 T=30 差 > 1e-3 （test_short_utterance_below_delay_window_differs）。
  • paper_global checkpoint 不可串流，必須以 causal_running 重訓。
  • startup 前 D 幀的 softmax 含未觀測（score=0）delay 候選——這是 offline 訓練語意 本身，非 streaming 造成（見 AIAEC/aiaec_common.py 的 GlobalDelayAttention）。

函式清單：公開 vs 內部

分類名稱
公開（Python）AIAEC.Align_CRUSE.inference.load_model、AlignCRUSE.create_stream_state、AlignCRUSE.forward_stream、AIAEC.aiaec_streaming.StreamSTFT／StreamISTFT、export_onnx.py／inference.py（含 calib）兩個命令列入口
公開（C，可用零件）aiaec_apply_real_mask（align_cruse_process.h）；audiolib ac_stft_*／ac_istft_*、ac_window_build
內部底線開頭的模組（_cli_common.py、_streaming_export.py、_streaming_calibration.py 等）是實作細節，不是命令列入口；aiaec_streaming.py 的 cell 類別（GlobalDelayAttentionCell 等）與 AlignCRUSE.forward（整段版）供測試與訓練使用
