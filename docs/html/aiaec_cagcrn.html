CAGCRN（end-to-end AEC+RES+NR，backup）

概要

Wang et al.（INTERSPEECH 2025-608）的重建。task（dataset_gen/model_views.py）= end_to_end_aec_res_nr_dereverb：輸入是未對齊的 microphone 與 far-end 複數頻譜（mic_postclip / far_render）；target 是 near_target。輸出是 bounded CRM（Tanh，[B,2,T,257]）乘在 mic 頻譜。 論文未公開原始碼、ERB 帶數、delay 上限、decoder 通道與 Mask 塊細節；本實作以 可微分 soft delay-window gate（raw_window 純量參數）取代不可微的整數 floor(D) 窗——與任何未公開作者實作 checkpoint 不相容。

參數量實測 54,963 trainable + 12,929 buffer（ERB merge/split 固定矩陣）； state_dict 總量約 0.068 M 值，對應論文 0.07 M class（test： test_published_size_classes_are_preserved_on_project_grid，釘 60k–80k）。 16k grid：ERB 保留 2 kHz 以下線性 65 bins + 高頻 32 帶 → compressed_bins = 97； max_delay_frames = 63；stream_output_delay = 0。

ONNX / NPU graph boundary（已交付： AIAEC/CAGCRN/export_onnx.py）： graph 內 = mag_ri_feature、ErbBandCodec.merge/split（matmul）、 四層殘差 causal encoder ×2（depthwise dilated conv，dilation 至 4）、CATA（mic 自注意 softmax + 對 delay 軸的 softmax，學到的 window gate 在推論期是 常數 log-bias，create_stream_state() 已預先算成 cata_gate_log）、 TFGRU ×2（頻率軸 bidirectional GRU 每幀獨立 + 時間軸 GRU，hidden 是 per-frequency-bin）、TFAG、mirror decoder（含 ConvTranspose2d）、Tanh mask。 graph 外（C 前後處理）= centered sqrt-Hann STFT/ISTFT 與 complex↔RI。 recurrent state 全為顯式 I/O tensor。

NPU 風險（readiness §3.4，四候選中 op 面最重）：CATA 的 q.unsqueeze(3)*delayed 逐幀仍是 [B,24,1,63,49]（≈74k 元素）broadcast； decoder 的 ConvTranspose2d 用動態 output_size，export 前必須固定。

API 用法

from AIAEC.CAGCRN.inference import load_model
from AIAEC.aiaec_streaming import StreamSTFT, StreamISTFT

model, grid = load_model("ckpt.pth", "cpu")
state = model.create_stream_state()   # 23 個 cell/常數（見 State 表）
mic_stft = StreamSTFT(grid.n_fft, grid.hop_len, window)
far_stft = StreamSTFT(grid.n_fft, grid.hop_len, window)
synth    = StreamISTFT(grid.n_fft, grid.hop_len, window)
for s in range(0, n, grid.hop_len):
    for m, f in zip(mic_stft.push(mic[:, s:s+256]), far_stft.push(far[:, s:s+256])):
        out = model.forward_stream(microphone=m.unsqueeze(1),
                                   far_end=f.unsqueeze(1), state=state)
        samples = synth.push(out.enhanced[:, 0])

STFT×2 / ISTFT 狀態——C struct（Python reference：host）

LayerNorm ×4 只作用在 channel 軸（無跨時間統計）；可學 delay window （raw_window）在推論期為常數，已在 create_stream_state() 內以 torch.no_grad() 預計算成 cata_gate_log。

延遲與 warm-up

  • NN 演算法 lookahead = 0 hop；zero-init ≡ offline 左零 padding， 無 warm-up 特例（CATA delay softmax 每幀獨立、無累積 state）。
  • 實測 stream-vs-offline（seeds 0/1、B=2、T=96）：enhanced/mask/delay/erb_mask 最差 5.3e-7（純 fp32 累加順序噪音）；TOL 以 ~10x headroom 釘 5e-6 （test_streaming_cagcrn.py 檔頭）。
  • Framing：center=True → 半窗 256 samples（16 ms）lookahead；端到端演算法延遲 256 samples。
