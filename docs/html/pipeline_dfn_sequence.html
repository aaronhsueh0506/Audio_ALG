DFN2 pipeline 流程時序圖(mono / 4ch)

概要

本頁是 pipeline_dfn_usage 的時序圖:初始化、穩態 hop(48 kHz host 與 8／16 kHz host 經 rate bridge)、4ch 的前半、失敗與 reset。圖中的箭頭標的是實際函式名,順序就是呼叫順序;「|」是物件的生命線,箭頭太短放不下的標籤寫在箭頭上一行。

1. 初始化(mono;4ch 把 Aec 換成 AudioPipeline4Ch,並多一個應用自建的 AecRes)

2. 穩態 hop:48 kHz host(stage 直接在 host 格點)

App(main.c)                 Aec                      DfnHop                   DfnResStage                model | NPU
  |                          |                          |                          |                          |
-- 每個 host hop(48 kHz host:mic / ref / out 各 512 個 float) ------------------------------------------------------------
  | aec_process_context(aec, mic, ref)                  |                          |                          |
  |------------------------->|                          |                          |                          |
  | se_frame_from_aec(aec, &f)                          |                          |                          |
  |------------------------->|                          |                          |                          |
  | 0;f.e = E、f.cn、f.g_res_ctx(借用到下一次 process / reset)                     |                          |
  |<-------------------------|                          |                          |                          |
  | sk_min_f32 + sk_capply_gain_f32 -> P = E*min(1, G_res);cng_on 時 aec_cng_fill  |                          |
  |-- dfn_hop_begin(&hop, f.e, P) --------------------->|                          |                          |
  |                          |                          | dfn_res_stage_begin(stage, E, P, &job)              |
  |                          |                          |------------------------->|                          |
  |                          |                          | 1 = job 已開 | 0 = 前兩個 warm-up hop(沒有模型幀)   |
  |                          |                          |<-------------------------|                          |
-- 路徑 A:dfn_hop_process = begin + 迴圈{ nn_begin; nn_end(dfn_res_stage_infer(job)) } + end -----------------------------
  |                          |                          | dfn_res_stage_infer(stage, &job)                    |
  |                          |                          |------------------------->|                          |
  |                          |                          |                          | model.infer(user, &job.inputs, &job.outputs)
  |                          |                          |                          |------------------------->|
  |                          |                          |                          | 0 = 每個輸出都寫滿 | 其他 = 失敗
  |                          |                          |                          |<-------------------------|
-- 路徑 B:phased,呼叫端自己跑加速器 --------------------------------------------------------------------------------------
  | dfn_hop_nn_begin(&hop, &job)  ->  1(job 借用到 nn_end)| 0(沒有幀)| < 0         |                          |
  |---------------------------------------------------->|                          |                          |
  |-- job.inputs -> 加速器 -> job.outputs(輸出預填 NaN,要寫滿) ---------------------------------------------->|
  |<- rc -----------------------------------------------------------------------------------------------------|
  |-- dfn_hop_nn_end(&hop, rc) ------------------------>|                          |                          |
  |                          |                          | dfn_res_stage_end(stage, rc, stage_out)             |
  |                          |                          |------------------------->|                          |
  |                          |                          |                          | rc != 0、輸出未寫或非有限 -> dfn2_prepost_frame_skip()(identity,時鐘照走)
-- 收尾(兩條路徑相同) ----------------------------------------------------------------------------------------------------
  |-- dfn_hop_end(&hop, out) -------------------------->|                          |                          |
  |                          |                          | 沒被取走的 job 走 identity;ac_istft_push(istft, stage_out, out) -> 剛好一個 hop
  | 0 | DFN_HOP_INVALID(-1)| DFN_HOP_SEQUENCE_ERROR(-2) |                          |                          |
  |<----------------------------------------------------|                          |                          |

48 kHz 時第 0 幀沒有右鄰居(graph 吃 [t-1, t, t+1]),dfn_res_stage_begin() 回 0 而不叫模型;前兩個 hop 輸出全零頻譜,之後第 p 個 hop 輸出「傳統鏈的 hop#(p-2)」,合計 3 hop = 1536 samples 的純延遲。

3. 穩態 hop:8／16 kHz host(經 DfnRateBridge)

App(main.c)               DfnHop                  DfnRateBridge               DfnResStage                model | NPU
  |                          |                          |                          |                          |
-- 每個 host hop(8 / 16 kHz host);前半同 48 kHz:aec_process_context -> se_frame_from_aec -> 形成 P -----------------------
  | dfn_hop_begin(&hop, E, P)|                          |                          |                          |
  |------------------------->|                          |                          |                          |
  |                          | dfn_rate_bridge_begin(bridge, E, P)                 |                          |
  |                          |------------------------->|                          |                          |
  |                          |                          | E、P 各自:ac_istft_push(原生 WOLA)-> audio_resampler 升頻(16 kHz x3 / 8 kHz x6)-> 48 kHz FIFO
-- 迴圈:每 hop 0..2 次(16 k/hop 128 為 0,1,1,1;16 k/hop 256 與 8 k/hop 128 為 1,2) ---------------------------------------
  | dfn_hop_nn_begin(&hop, &job)                        |                          |                          |
  |------------------------->|                          |                          |                          |
  |                          | dfn_rate_bridge_nn_begin(bridge, &job)              |                          |
  |                          |------------------------->|                          |                          |
  |                          |                          | FIFO 每滿 512:ac_stft_push x2(sqrt-Hann 1024/512)   |
  |                          |                          | dfn_res_stage_begin(E48, P48, &job)                 |
  |                          |                          |------------------------->|                          |
  |                          |                          | 1 | 0(warm-up 幀由 bridge 自己 finish)              |
  |                          |                          |<-------------------------|                          |
  |<- 1 = job 已開 | 0 = 本 hop 沒有幀 | -1 ------------|                          |                          |
  |-- job.inputs -> 加速器 -> job.outputs ------------------------------------------------------------------->|
  |<- rc -----------------------------------------------------------------------------------------------------|
  | dfn_hop_nn_end(&hop, rc) |                          |                          |                          |
  |------------------------->|                          |                          |                          |
  |                          | dfn_rate_bridge_nn_end(bridge, rc)                  |                          |
  |                          |------------------------->|                          |                          |
  |                          |                          | dfn_res_stage_end(rc, out48)                        |
  |                          |                          |------------------------->|                          |
  |                          |                          | ac_istft_push(synth48)-> 降頻 -> 原生 out FIFO      |
-- 收尾 ------------------------------------------------------------------------------------------------------------------
  | dfn_hop_end(&hop, out)   |                          |                          |                          |
  |------------------------->|                          |                          |                          |
  |                          | dfn_rate_bridge_finish(bridge, out)                 |                          |
  |                          |------------------------->|                          |                          |
  |                          |                          | 未取走 / 未關閉的幀走 identity;從 out FIFO(init 預填 prefill 個零)取剛好一個 native hop

各 host 格點的 prefill、added delay 與總延遲(16 k/256:128、672、800 samples = 50.0 ms 等)見 pipeline_dfn_mono 的「延遲與 warm-up」;一個 hop 內最多兩次推論,是板端算力預算該看的峰值。

4. 4ch 的前半(單元)與應用的 RES

  |------------------------->|                          |                          |                          |
  |                          | four_aec_front_process():共用 delay aligner + 4 條線性 AEC lane                |
  |                          |------------------------->|                          |                          |
  |                          | doa_step(srp, lane 頻譜, mask, vad_raw, vad_out) -> bf_process_with_weights(...)
  |                          |---------------------------------------------------->|                          |
  | OK;beam.spectrum / beam.weights、info.delay / doa_* / bf_adaptive              |                          |
  |<-------------------------|                          |                          |                          |
  | audio_pipeline_4ch_fuse(unit, &f)                   |                          |                          |
  |------------------------->|                          |                          |                          |

  |                          |------------------------->|                          |                          |
  | OK | SEQUENCE_ERROR(沒有本 hop 的 beam,什麼都沒改)| 其他拒絕:單元已整個 reset  |                          |

  | se_res_stage_gain(res, &f) -> aec_res_process()(應用自備的 AecRes,不在單元內)                              |

  |<---------------------------------------------------------------------------------------------------------|
  | process_front -> [呼叫端用 front.linear_spectra 算 mask / VAD] -> process_beam 是 process_with_activity 的拆開形式;產品自帶 VAD 時改呼叫 _with_activity(見 usage 頁)

5. 失敗與 reset

App(main.c)                前端                      DfnHop                 Stage | Bridge                  model
  |                          |                          |                          |                          |
-- 任何一步失敗:se_frame_from_aec != 0、g_res_ctx == NULL(mono)、audio_pipeline_4ch_* 回非 OK、se_res_stage_gain 回 NULL(4ch)、dfn_hop_* 回負值 --
  | aec_reset(aec)  |  audio_pipeline_4ch_reset(unit) + aec_res_reset(res)   |                          |                          |
  |------------------------->|                          |                          |                          |
  | rng = SE_CNG_RNG_SEED    |                          |                          |                          |
  |-- dfn_hop_reset(&hop) ----------------------------->|                          |                          |
  |                          |                          | dfn_rate_bridge_reset() | dfn_res_stage_reset() + ac_istft_reset() + 清空 stage_out
  |                          |                          |------------------------->|                          |
  |                          |                          |                          | model.reset(user)(有設才呼叫)
  |                          |                          |                          |------------------------->|
-- 不要 reset 的情形 -----------------------------------------------------------------------------------------------------
  | AEC delay 改變(frame.delay_changed / delay.changed):stage 與 bridge 不消費 far-end,輸入仍連續,不 reset    |
  | nn_end(rc != 0):該幀 identity,不是錯誤,也不 reset   |                          |                          |
