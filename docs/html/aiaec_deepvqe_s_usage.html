AIAEC DeepVQE-S：如何呼叫、流程時序圖、外部／內部參數

概要

DeepVQE-S 是端到端 AEC+RES+NR：輸入是原始麥克風與遠端參考（前面沒有 linear AEC，兩者取自同一個輸入 hop，類別不做內部 skew），輸出是 3×3 因果複數 convolving mask（CCM）taps，由 C 端套在 raw mic 的 3 幀頻譜 ring 上。C 端是 DeepVqePrepost 類別（deepvqe_prepost.h），建在 deepvqe_process.c 之上，只處理頻域：framing（AcStft／AcIstft）與 16 個 recurrent state 由應用端持有。grid 是 run-time 值 DeepVqeGrid（deepvqe_grid_make()；出貨模型 16 kHz／512／256）。模型內容、I/O 表、State 表見 aiaec_deepvqe_s。

與 Align-ULCNet 最大的行為差異：frame_bypass 是 fail-CLOSED（輸出靜音），因為 stream 0 就是原始 mic，放行等於把未消除的迴聲送回遠端。

如何呼叫使用

  1. grid 是 run-time 值：填 DeepVqeGridSpec（sample_rate、n_fft、delay_depth 取自匯出該模型的設定）→ deepvqe_grid_make(&grid, &spec) 回 DEEPVQE_GRID_OK 或第一個失敗的 DEEPVQE_GRID_ERR_*。D = alignment 搜尋深度，範圍 DEEPVQE_PREPOST_MIN_D(1)…MAX_D(256)，沒有預設值，且必須等於匯出該 ONNX 時的 D（export_onnx.py --max-delay-frames，未給則用 checkpoint 的 D；出貨 32 ＝ 16 kHz 上 0.5 秒）。
  2. framing 由應用端做：用 audiolib 建兩個 AcStft（mic、far）與一個 AcIstft，組態 ac_stft_config_default(&sc, grid.n_fft)（sqrt-Hann、center 0、spec_scale = ispec_scale = 1），合成端另設 sc.ola = AC_OLA_ENV_NORM（deepvqe_prepost.h 檔頭）。類別不持有 window、FftHandle 或 STFT 物件。
  3. 16 個 state 歸應用端（DeepVqeStateId 順序，形狀見 aiaec_deepvqe_s 的 State 表，函式庫只收元素數）：浮點 host 配 16 塊 float buffer，把 16 組（指標，元素數）登錄進 cfg.state[]／cfg.state_elements[]——全登錄或全不登錄，init 與 reset 時清零，每次 frame_finish 整塊檢查有限，不計入 pool 大小與 hash；目標平台不登錄，由加速器持有，把每個 state 輸入與其 *_out 綁在同一塊加速器 buffer。
  4. deepvqe_prepost_config_defaults(&cfg, &grid)（grid 被複製）→ 登錄 state → deepvqe_prepost_get_mem_size(&cfg, &req)（req.alignment = 16）→ deepvqe_prepost_init_ex(pool, req.bytes, &cfg, &req)。D = 32 的 pool：16 kHz／512 為 35,504 B、48 kHz／1024 為 70,320 B（本機量測，不含應用端的 state 與 AcStft／AcIstft）。
  5. 按名稱綁定 graph 的 state 時用 deepvqe_prepost_state_name(id)／_state_name_out(id)；啟動時把 ONNX／JSON 內的 c_descriptor 讀成 DeepVqePrepostDescriptor，以 deepvqe_prepost_descriptor_validate(&grid, &meta) 檢查。
  6. 每個 hop（從 hop 0 起一次推論）：ac_stft_push_planar×2 → pre_process_freq(mic, far) 恆回 1 → frame_open（host 端做 power-law 壓縮 0.3，mic／far 是壓縮後的 planar [1,2,1,n_bins]；只有 taps 預填 NaN）→ 加速器 → frame_finish（失敗改 frame_bypass）→ post_process_freq → ac_istft_push_planar。
  7. 目標平台：每次 deepvqe_prepost_state_generation() 改變（reset 或被拒的 frame_finish），把加速器自己的 16 個 state 重填成量化後的 0；新建實例的 generation 為 0，做法同 aiaec_align_ulcnet_usage 的目標平台片段。
  8. 重新開始：deepvqe_prepost_reset(p)（登錄的 state、CCM ring 歸零，generation +1），並自行 ac_stft_reset／ac_istft_reset；結束：_destroy（對 _init 實例是 no-op，登錄的 buffer 與 pool 歸應用端）。
#include <stdlib.h>
#include <string.h>
#include "audio_stft.h"
#include "DeepVQE_S/deepvqe_prepost.h"

extern int npu_run(const DeepVqePrepostInputs *in, DeepVqePrepostOutputs *out);

static void *block(size_t n) { return aligned_alloc(16, (n + 15u) / 16u * 16u); }

/* elems[id]：DeepVqeStateId 順序的 state 元素數（匯出圖的 shape 乘積，見 State 表）；
 * D 必須等於匯出該 ONNX 時的 --max-delay-frames。 */
int run_deepvqe(int D, const size_t elems[DEEPVQE_STATE_COUNT],
                const float *mic, const float *far, float *out, long hops)
{
    const DeepVqeGridSpec spec = { 16000, 512, D };
    DeepVqeGrid grid;
    DeepVqePrepostConfig cfg;
    DeepVqePrepostMemReq req;
    AcStftConfig sc;
    int rc = -1;

    if (deepvqe_grid_make(&grid, &spec) != DEEPVQE_GRID_OK) return -1;
    if (deepvqe_prepost_config_defaults(&cfg, &grid) != 0) return -1;
    for (int id = 0; id < DEEPVQE_STATE_COUNT; ++id) {      /* 浮點 host：16 組 (指標, 元素數) 全登錄 */
        cfg.state[id] = calloc(elems[id], sizeof(float));
        cfg.state_elements[id] = elems[id];
    }

    ac_stft_config_default(&sc, grid.n_fft);   /* sqrt-Hann、center 0、spec_scale = ispec_scale = 1 */
    sc.ola = AC_OLA_ENV_NORM;                  /* 合成用；分析忽略 */
    size_t an = ac_stft_get_mem_size(&sc), sy = ac_istft_get_mem_size(&sc);
    void *m0 = block(an), *m1 = block(an), *m2 = block(sy);
    AcStft *mic_stft = m0 ? ac_stft_init(m0, an, &sc) : NULL;
    AcStft *far_stft = m1 ? ac_stft_init(m1, an, &sc) : NULL;
    AcIstft *istft   = m2 ? ac_istft_init(m2, sy, &sc) : NULL;

    float *buf = calloc(6u * (size_t)grid.n_bins, sizeof(float));
    float *m_re = buf, *m_im = m_re + grid.n_bins, *f_re = m_im + grid.n_bins;
    float *f_im = f_re + grid.n_bins, *o_re = f_im + grid.n_bins, *o_im = o_re + grid.n_bins;
    void *pool = NULL;
    DeepVqePrepost *p = NULL;
    if (deepvqe_prepost_get_mem_size(&cfg, &req) == 0 && (pool = block(req.bytes)))
        p = deepvqe_prepost_init_ex(pool, (size_t)req.bytes, &cfg, &req);

    if (p && mic_stft && far_stft && istft && buf) {
        rc = 0;
        for (long h = 0; h < hops && rc == 0; ++h) {
            DeepVqePrepostInputs xin;
            DeepVqePrepostOutputs xout;
            float *dst = out + h * grid.hop;
            /* mic：原始麥克風 hop（前面沒有 linear AEC）；far：同一輸入 hop 的遠端參考 */
            ac_stft_push_planar(mic_stft, mic + h * grid.hop, m_re, m_im);   /* center 0：恆 1 幀 */
            ac_stft_push_planar(far_stft, far + h * grid.hop, f_re, f_im);
            if (deepvqe_prepost_pre_process_freq(p, m_re, m_im, f_re, f_im) != 1 ||
                deepvqe_prepost_frame_open(p, &xin, &xout) != 0) { rc = -1; break; }
            if (npu_run(&xin, &xout) != 0 || deepvqe_prepost_frame_finish(p) != 0)
                deepvqe_prepost_frame_bypass(p);                  /* fail-closed：此框靜音 */
            if (deepvqe_prepost_post_process_freq(p, o_re, o_im) != 0) { rc = -1; break; }
            if (ac_istft_push_planar(istft, o_re, o_im, dst) == 0)   /* 第一個 hop 無輸出 */
                memset(dst, 0, (size_t)grid.hop * sizeof(float));
        }
    }
    deepvqe_prepost_destroy(p);   /* _init 實例：no-op；登錄的 buffer 與 pool 歸應用端 */
    free(pool); free(buf); free(m0); free(m1); free(m2);
    for (int id = 0; id < DEEPVQE_STATE_COUNT; ++id) free(cfg.state[id]);
    return rc;
}

片語已在暫存副本以 -std=c11 -Wall -Wextra -Wpedantic -Werror 編譯，並以替身加速器（CCM 為單位核）在 16 kHz／512、D = 32 跑 40 hop：輸出等於 mic 延後一個 hop。npu_run 由目標平台提供。

錯誤處理速查

呼叫失敗回傳原因／處置
deepvqe_grid_makeDEEPVQE_GRID_ERR_*（grid 不動）_NULL(-1)、_SAMPLE_RATE(-2)、_N_FFT(-3，audiolib 建不出該 n_fft)、_DELAY_DEPTH(-4，D 超出 1…256)
config_defaults-1NULL 或無效 grid
get_mem_size-1，*req 不動同上，或 state 登錄不一致（有指標無元素數、元素數無指標、16 組沒有全設或全空）
init／init_exNULLpool 未對齊／太小、config 錯、expected 不符（陳舊 pool；hash 認 grid、D、layout 與 carve 版本）；被拒的呼叫不動 pool
pre_process_freq-1NULL、上一個 frame 尚未 frame_finish／frame_bypass
frame_open-1沒有開啟中的 frame
frame_finish-1任一 tap 或登錄 buffer 的任一元素（整塊，含較舊的幀）非有限：登錄的 state 全部歸零（沒登錄時只檢查 taps）、generation +1、CCM ring 不前進、frame 仍開；呼叫 frame_bypass 或重新 frame_open
frame_bypass-1（無 frame）成功＝靜音該框（deepvqe_prepost_skip_policy_name() = "mute_fail_closed"）：CCM ring 與 state 維持原樣。想要優雅降級的呼叫端須自己在 pipeline 層放 canceller 並 cross-fade
post_process_freq-1NULL、frame 還開著；成功時 re／im 寫滿 n_bins 個值

caller / audiolib              DeepVqePrepost (C)                  NPU runtime
  |                                  |                                  |
  |== init ==========================|==================================|
  | grid_make(&grid,&spec) --------->| -4: D 不在 1..256                |
  | config_defaults(&cfg,&grid) ---->| 浮點 host: cfg 填 16 組 state    |
  | get_mem_size(cfg,&req) --------->| 登錄不一致 -> -1                 |
  | init_ex(pool,bytes,cfg,&req) --->| 登錄的 state = 0, generation = 0 |
  | descriptor_validate(&grid,&meta)>| 與 graph 的 c_descriptor 比對    |
  | ------------------- 目標平台: fill 16 states with quantized 0 --->|
  |                                  |                                  |
  |== 每個 hop (含 hop 0) ============|==================================|
  | ac_stft_push_planar x2 (center 0)|                                  |
  | pre_process_freq(mic,far) ------>| 複製兩路頻譜                     |
  | <-------- 1 ----------------------|                                  |
  | frame_open(&in,&out) -------->| 壓縮 x*|x|^-0.7 -> mic/far;      |
  |                                  | taps = NaN; state_out == state in |
  | state_generation() ------------->| (變了 -> 重填量化零) ------------->|
  | -------------------------------------- run(in, out) ------------->| 讀完 16 個 state 輸入,
  | <---------------------------------------- rc --------------------| 再寫 taps 與 state_out
  | frame_finish() ----------------->| finite 檢查; taps 套到 raw mic    |
  |                                  | 的 3 幀 ring; 暫存增強頻譜        |
  | post_process_freq(re,im) ------->| 交出增強頻譜 (n_bins)            |
  | ac_istft_push_planar(re,im,out)  | hop 0: 0 樣本; 之後 256 樣本     |
  |                                  |                                  |
