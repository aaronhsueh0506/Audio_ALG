AIAEC DeepVQE-S：如何呼叫、流程時序圖、外部／內部參數

概要

DeepVQE-S 是端到端 AEC+RES+NR：輸入是原始麥克風與遠端參考（前面沒有 linear AEC，兩者取自同一個輸入 hop，類別不做內部 skew），輸出是 3×3 因果複數 convolving mask（CCM）taps，由 C 端套在 raw mic 的 3 幀頻譜 ring 上。C 端是 DeepVqePrepost 類別（deepvqe_prepost.h），組合 aiaec_process.c 與 deepvqe_process.c。grid 固定 16 kHz／512／256（AIAEC_SR／AIAEC_N_FFT／AIAEC_HOP，與 ULCNET_MODEL_IO_* 建置參數無關）。模型內容、I/O 表、State 表見 aiaec_deepvqe_s。

與 Align-ULCNet 最大的行為差異：frame_skip 是 fail-CLOSED（輸出靜音），因為 stream 0 就是原始 mic，放行等於把未消除的迴聲送回遠端。

如何呼叫使用

  1. 準備 512 點 FftHandle 與 sqrt-Hann 窗表（ac_window_build(w, 512)）；DEEPVQE_IO_TIME 兩者必填，DEEPVQE_IO_FREQ 可為 NULL。皆 borrowed。
  2. deepvqe_prepost_config_defaults(&cfg, io_mode, D)：D = alignment 搜尋深度，範圍 DEEPVQE_PREPOST_MIN_D(1)…MAX_D(256)，預設 DEEPVQE_PREPOST_DEFAULT_D(32)（16 kHz 上 0.5 秒）。D 必須等於匯出該 ONNX 時的 D（export_onnx.py --max-delay-frames，未給則用 checkpoint 的 D）。
  3. deepvqe_prepost_get_mem_size(&cfg, &req) → 配置 req.bytes、對齊 req.alignment(16) → deepvqe_prepost_init_ex(pool, req.bytes, &cfg, &req)。D = 32：DEEPVQE_IO_TIME 637,072 B、DEEPVQE_IO_FREQ 615,280 B（本機量測；16 個 state 張量共 579,776 B 是其中最大宗）。
  4. 把 graph 的 16 個 state 輸入／輸出綁定好：in.state[id] 與 out.state_out[id] 是同一個指標，id 依 DeepVqeStateId 順序；按名稱綁定時用 deepvqe_prepost_state_name(id)／_state_name_out(id)，形狀用 _state_shape(id, D, dims)。啟動時另以 deepvqe_prepost_descriptor_default() 與 ONNX／JSON 內的 c_descriptor 比對（_descriptor_validate()）。
  5. 每個 hop（從 hop 0 起一次推論）：pre_process(mic_hop, far_hop) 恆回 1 → frame_inputs（host 端做 power-law 壓縮 0.3，mic／far 是壓縮後的 planar [1,2,1,257]；只有 taps 預填 NaN）→ 加速器 → frame_commit（失敗改 frame_skip）→ post_process。
  6. 每次 deepvqe_prepost_state_generation() 改變（reset 或被拒的 commit），把加速器自己的 16 個 state 重填成量化後的 0。新建實例的 generation 為 0。
  7. 重新開始：deepvqe_prepost_reset(p)（16 個 state、CCM ring 歸零，framing 重置）；結束：_destroy（對 _init 實例是 no-op）。
#include <stdlib.h>
#include "DeepVQE_S/deepvqe_prepost.h"

extern int  npu_run(const DeepVqePrepostInputs *in, DeepVqePrepostOutputs *out);
extern void npu_fill_state_with_quantized_zero(void);

int run_deepvqe(FftHandle *fft512, const float *window512, int D,
                const float *mic, const float *far, float *out, long hops)
{
    DeepVqePrepostConfig cfg;
    DeepVqePrepostMemReq req;
    int rc = 0;

    if (deepvqe_prepost_config_defaults(&cfg, DEEPVQE_IO_TIME, D) != 0) return -1;
    cfg.fft = fft512;  cfg.window = window512;         /* window512 = ac_window_build(w, 512) */
    if (deepvqe_prepost_get_mem_size(&cfg, &req) != 0) return -1;
    size_t bytes = ((size_t)req.bytes + req.alignment - 1) / req.alignment * req.alignment;
    void *pool = aligned_alloc(req.alignment, bytes);
    DeepVqePrepost *p = pool ? deepvqe_prepost_init_ex(pool, (size_t)req.bytes, &cfg, &req) : NULL;
    if (!p) { free(pool); return -1; }

    uint32_t seen = deepvqe_prepost_state_generation(p);       /* 新實例為 0 */
    npu_fill_state_with_quantized_zero();
    for (long h = 0; h < hops && rc == 0; ++h) {
        DeepVqePrepostInputs xin;
        DeepVqePrepostOutputs xout;
        int written = 0;
        /* mic: 原始麥克風 hop (前面沒有 linear AEC); far: 同一輸入 hop 的遠端參考 */
        if (deepvqe_prepost_pre_process(p, mic + h * AIAEC_HOP, far + h * AIAEC_HOP) != 1 ||
            deepvqe_prepost_frame_inputs(p, &xin, &xout) != 0) { rc = -1; break; }
        if (deepvqe_prepost_state_generation(p) != seen) {
            npu_fill_state_with_quantized_zero();
            seen = deepvqe_prepost_state_generation(p);
        }
        if (npu_run(&xin, &xout) != 0 || deepvqe_prepost_frame_commit(p) != 0)
            deepvqe_prepost_frame_skip(p);                     /* fail-closed: 此框靜音 */
        if (deepvqe_prepost_post_process(p, out + h * AIAEC_HOP, &written) != 0) rc = -1;
    }
    deepvqe_prepost_destroy(p);
    free(pool);
    return rc;
}

片語已在暫存副本以 -std=c11 -Wall -Wextra -Wpedantic -Werror 編譯通過；npu_run／npu_fill_state_with_quantized_zero 由目標平台提供。頻域入口把 pre_process／post_process 換成 _pre_process_freq（未正規化 rfft、center = 0）／_post_process_freq，是串接 AEC 或 4ch 單元輸出頻譜的模式。

錯誤處理速查

呼叫失敗回傳原因／處置
config_defaults-1NULL、io_mode 未知、D 超出 1…256
get_mem_size-1，*req 不動同上，或 TIME 缺 fft／window
init／init_exNULLpool 未對齊／太小、config 錯、fft 大小不對、expected 不符（陳舊 pool）
pre_process*-1NULL、模式不符、上一個 frame 尚未 commit／skip
frame_inputs-1沒有開啟中的 frame
frame_commit-1任一 tap、h_gru 或各 window 的最新一幀非有限：16 個 state 全部歸零、generation +1、CCM ring 不前進、frame 仍開；呼叫 frame_skip 或重新 frame_inputs。較舊的幀不重查，殘留的非有限值會在之後某一幀進到 taps 被擋下
frame_skip-1（無 frame）成功＝靜音該框（deepvqe_prepost_skip_policy_name() = "mute_fail_closed"）：CCM ring 與 state 維持原樣，只有 framing 排程前進。想要優雅降級的呼叫端須自己在 pipeline 層放 canceller 並 cross-fade
post_process-1NULL、模式不符、frame 還開著；hop 0 為零且 *written = 0
