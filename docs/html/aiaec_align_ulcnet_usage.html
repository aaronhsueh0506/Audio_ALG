AIAEC Align-ULCNet：如何呼叫、流程時序圖、外部／內部參數

概要

Align-ULCNet 是接在 linear AEC 後面的 RES+NR post-filter：輸入是 linear AEC 的 error 與未對齊的 raw far（兩者取自同一個輸入 hop）。C 端有三個層次，整合者通常只用第一或第二個：

入口用途標頭
A. UlcnetPrepost 類別（建議）hop 進 hop 出（ULCNET_IO_TIME）或頻譜進頻譜出（ULCNET_IO_FREQ，串接 AEC 或 4ch 路徑的頻譜用）；framing、壓縮域前端、四個 state、mask 套用全在物件內ulcnet_prepost.h
B. UlcnetAcceleratorAdapter把加速器 graph 包成 UlcnetModel callback，交給 pipeline／sample stage（pipelines/ulcnet/ulcnet_nn_stage.c）驅動；內部就是一個 ULCNET_IO_FREQ 的類別實例ulcnet_accelerator_adapter.h
C. ulcnet_model_io_*只要 state 與 prepare／commit，不含 framing；類別就是由它組成ulcnet_model_io.h

模型內容、graph 邊界（layout 18）、I/O 表、State 表見 aiaec_align_ulcnet；far branch／PTQ／reprime 見 aiaec_align_ulcnet_detail。

如何呼叫使用

  1. grid 是編譯期參數：一個 build 只服務一組 grid，16 kHz／512（預設）或 48 kHz／1024，以 -DULCNET_MODEL_IO_SR／-DULCNET_MODEL_IO_N_FFT 選擇（pipelines/Makefile 以 ULCNET_GRID=16k|48k 傳入）；其他組合在 ulcnet_model_io.h 直接 #error。
  2. D（delay depth）必須等於匯出該 ONNX 時的 --max-delay-frames：C 端只檢查範圍 ULCNET_MODEL_IO_MIN_D(2)…MAX_D(64)，檢查不出與 graph 不符。D 不跨 grid 沿用（D 數的是 hop）。
  3. 準備 FftHandle（ULCNET_N_FFT 點）與 sqrt-Hann 窗表（ac_window_build(w, ULCNET_N_FFT)）；TIME 模式兩者必填，FREQ 可為 NULL。皆為 caller-owned、borrowed。
  4. ulcnet_prepost_config_defaults(&cfg, io_mode, D) → 填 fft／window → ulcnet_prepost_get_mem_size(&cfg, &req)（req.alignment = 16）→ ulcnet_prepost_init_ex(pool, req.bytes, &cfg, &req)；host 工具可用 _create／_destroy。
  5. 每個 hop（從 hop 0 起一次推論，沒有只暖機不推論的拍）：pre_process(err_hop, far_hop) 恆回 1 → frame_inputs → 加速器 → frame_commit（失敗改 frame_skip）→ post_process。
  6. 每次 ulcnet_prepost_state_generation() 改變（reset、被拒的 frame_commit），把加速器自己的 state 重填成量化後的 0。新建實例的 generation 為 0。
  7. 重新開始：ulcnet_prepost_reset(p)（清四個 state、framing，丟掉未結束的 frame；config 與 pool 不動）；結束：_destroy（對 _init 實例是 no-op）。
#include <stdlib.h>
#include "Align_ULCNet/ulcnet_prepost.h"

extern int  npu_run(const UlcnetModelIoInputs *in, UlcnetModelIoOutputs *out);
extern void npu_fill_state_with_quantized_zero(void);

/* D 必須等於匯出該 ONNX 時的 --max-delay-frames。fft/window 的 grid 與編譯期
 * ULCNET_MODEL_IO_SR / _N_FFT 一致; window = ac_window_build(window, ULCNET_N_FFT)。 */
int run_ulcnet(FftHandle *fft, const float *window, int D,
               const float *err, const float *far, float *out, long hops)
{
    UlcnetPrepostConfig cfg;
    UlcnetPrepostMemReq req;
    int rc = 0;

    if (ulcnet_prepost_config_defaults(&cfg, ULCNET_IO_TIME, D) != 0) return -1;
    cfg.fft = fft;  cfg.window = window;
    cfg.istft = istft;          /* ulcnet_framing_config(&sc, fft, window, 0) + ac_istft_init()，應用端持有 */
    if (ulcnet_prepost_get_mem_size(&cfg, &req) != 0) return -1;
    size_t bytes = ((size_t)req.bytes + req.alignment - 1) / req.alignment * req.alignment;
    void *pool = aligned_alloc(req.alignment, bytes);
    UlcnetPrepost *p = pool ? ulcnet_prepost_init_ex(pool, (size_t)req.bytes, &cfg, &req) : NULL;
    if (!p) { free(pool); return -1; }

    uint32_t seen = ulcnet_prepost_state_generation(p);        /* 新實例為 0 */
    npu_fill_state_with_quantized_zero();
    for (long h = 0; h < hops && rc == 0; ++h) {
        UlcnetModelIoInputs xin;
        UlcnetModelIoOutputs xout;
        int written = 0;
        /* err: linear AEC 的 error hop; far: 同一輸入 hop 的原始 far hop (未對齊) */
        if (ulcnet_prepost_pre_process(p, err + h * ULCNET_HOP, far + h * ULCNET_HOP) != 1 ||
            ulcnet_prepost_frame_inputs(p, &xin, &xout) != 0) { rc = -1; break; }
        if (ulcnet_prepost_state_generation(p) != seen) {
            npu_fill_state_with_quantized_zero();
            seen = ulcnet_prepost_state_generation(p);
        }
        if (npu_run(&xin, &xout) != 0 || ulcnet_prepost_frame_commit(p) != 0)
            ulcnet_prepost_frame_skip(p);                      /* error 頻譜原樣通過 */
        if (ulcnet_prepost_post_process(p, out + h * ULCNET_HOP, &written) != 0) rc = -1;
    }
    ulcnet_prepost_destroy(p);
    free(pool);
    return rc;
}

入口 B（交給 pipeline 的 callback 邊界）：

#include <stdlib.h>
#include "Align_ULCNet/ulcnet_accelerator_adapter.h"

/* 目標平台 runtime: 綁定 inputs 的八個張量與 outputs 的五個張量;
 * 每個 *_out 綁在同名 state 輸入的位址, 先讀完所有 state 輸入才寫輸出。成功回 0。 */
extern int run_graph(void *user, const UlcnetModelIoInputs *in, UlcnetModelIoOutputs *out);

/* 給 pipeline 用的 UlcnetModel (callback 邊界): adapter 內含 CPU 端的全部 state。
 * D 必須等於匯出該 ONNX 時的 --max-delay-frames; descriptor 只做範圍檢查。 */
UlcnetAcceleratorAdapter *make_adapter(int D, void *runtime, UlcnetModel *model)
{
    UlcnetModelIoDescriptor desc;
    size_t bytes = 0, align = 0;

    if (ulcnet_model_io_descriptor_default(D, &desc) != 0) return NULL;     /* D 超出 2..64 */
    /* 從 ONNX／JSON metadata 載入的 descriptor 用 ulcnet_model_io_descriptor_validate() 檢查 */
    if (ulcnet_accelerator_adapter_get_mem_size(&desc, &bytes, &align) != 0) return NULL;

    void *mem = aligned_alloc(align, (bytes + align - 1) / align * align);  /* 板端: 靜態 arena */
    if (!mem) return NULL;
    UlcnetAcceleratorAdapter *a =
        ulcnet_accelerator_adapter_init(mem, bytes, &desc, run_graph, runtime);
    if (!a) { free(mem); return NULL; }
    *model = ulcnet_accelerator_adapter_model(a);   /* 交給 pipeline; adapter 與 pool 須活得比 pipeline 久 */
    return a;
}

兩段片語已在暫存副本以 -std=c11 -Wall -Wextra -Wpedantic -Werror 編譯通過（16 kHz grid）；npu_run／run_graph／npu_fill_state_with_quantized_zero 由目標平台提供。UlcnetModel.infer 回非 0 或輸出非有限時，pipeline 會改走 identity（輸出 linear error）；io_descriptor 必須發布，且須比 pipeline 活得久（pipeline 只複製 struct）。

錯誤處理速查

呼叫失敗回傳原因／處置
config_defaults-1NULL、io_mode 未知、D 超出 2…64
get_mem_size-1，*req 不動同上，或 TIME 缺 fft／window、fft 的 bin 數不是 ULCNET_BINS、model_layout_version 非 0 又不等於 18
init／init_exNULLpool 未對齊／太小、config 錯、expected 與本 build 不符（陳舊 pool）
pre_process*-1NULL、模式不符、上一個 frame 尚未 commit／skip
frame_inputs-1沒有開啟中的 frame
frame_commit-1mask 或 state 有非有限值（或沒先 frame_inputs）：四個 state 全部歸零、generation +1、frame 仍開；呼叫 frame_skip 或重新 frame_inputs
frame_skip-1沒有開啟中的 frame；成功＝identity（error 頻譜原樣通過，state 維持加速器寫完的樣子，framing 照常前進）
post_process-1NULL、模式不符、frame 還開著；成功時 out_hop 恆寫滿，hop 0 為零且 *written = 0
