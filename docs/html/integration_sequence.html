index 串接範例 整合時序圖 串接範例細節 mono 4ch AEC API NR API audiolib API

整合時序圖 — 每個函式庫何時被誰呼叫

概要

4 聲道的線性 AEC 前端是 flow 層 mcab(四條 lane 與共用 estimator 由應用建立後以指標注入,mcab 不擁有它們),SRP-PHAT／BF 在 sample helper mcab_sample_beam。其餘 stage(4ch 的 RES 亦然;mono 的 RES 在 AEC 呼叫內)都是獨立函式庫,各有 *_get_mem_size() 與 *_init(),初始化、逐 hop 串接、錯誤後的 reset 順序都是整合者(應用)的責任,範例 main 就是參考寫法。本頁用時序圖把三件事畫在一起:建立(一次)、每 hop 的呼叫順序、被拒絕或換串流時的 reset。圖中的箭頭標的都是真實函式名;「借用」代表回傳的指標指向函式庫內部 buffer,只到下一次處理呼叫或 reset 之前有效,不可寫入。

責任誰擁有
pool 記憶體(16-byte 對齊的一塊或多塊)應用:每個函式庫先 *_get_mem_size()(0 = 設定無效),應用配置並 carve 成 16-byte 對齊的子區塊,*_init() 在上面建構;*_destroy() 不釋放 caller pool
格點與 config 的一致性應用:AEC、NR、合成都用同一個 grid.fft_size 導出 config(三者 n_freqs／hop 對不上不會被偵測,會在頻域靜默錯位)
輸入守衛(是否有限)mono:沒有(aec_process_context() 與 anr_process_gain() 不檢輸入);4ch:mcab_process_front() 拒非有限樣本。輸出守衛由應用做(skn_all_finite_f32();mono 的 main.c 本身不做,example_board_adapter.c 有做)
RES(殘留回音增益)mono:在 aec_process_context() 內算,經 aec_get_res_context() 的 ctx.res_gain 交出;4ch:mcab 與 helper 都不算(McabFrame.g_res_ctx 為 NULL),應用自己用 libaec 的 AecRes(aec_res_process())
reset 的範圍函式庫只 reset 自己;任何一步被拒,應用把所有 stage 與自己的 CNG 亂數狀態一起 reset(見第 4 節)

1. mono:Aec + AnrDenoiser + AcIstft

應用(main)                  Aec(lib/aec)            AnrDenoiser(lib/nr)     AcIstft(audiolib)
   │                              │                          │                       │
   │═ ① 建立(一次;此後 hop 路徑零 heap)═══════════════════════════════════════════
   │ derive_lane(sr,fft,preset,&grid,&aec_cfg)              main.c 內: 0=ok, -1=拒絕(格點);aec_resolve_signal_grid + aec_config_from_preset
   │ anr_config_for_mode_grid(sr, grid.fft_size, mode) -> nr_cfg      ac_stft_config_default(&syn_cfg, fft)
   │── aec_get_mem_size ───────►│  0=無效                  │                       │
   │── anr_get_mem_size ─────────────────────────────────►│  0=無效               │
   │── ac_istft_get_mem_size ───────────────────────────────────────────────────►│  0=無效
   │ pool = platform_alloc(Σ ALIGN16(各大小) + 暫存, 16)
   │── aec_init(pool,...) ─────►│  NULL=過小/未對齊/無效   │                       │
   │── anr_init(pool+a,...) ─────────────────────────────►│  NULL=同左            │
   │── ac_istft_init(pool+a+n,...) ─────────────────────────────────────────────►│  NULL=同左
   │ unity[k]=1; rng=CNG_RNG_SEED
   │
   │═ ② 每 hop(mic、ref 各 grid.hop_size floats,同 sample rate、同時鐘)═══════════
   │── aec_process_context(aec,mic,ref) ►│ 線性 AEC + delay 估計 + AEC 內部 RES 增益
   │── aec_get_res_context(aec,&ctx) ►│ 借用視圖 ctx: error_spec,r2,comfort_noise,res_gain
   │── mono_nr_gain: anr_process_gain(nr,ctx.error_spec,extra,NULL) ─►│ r2*PSD_SCALE_INV 折進噪聲底 → anr_get_gain → G_nr
   │ sk_min_f32(g_total, G_nr, ctx.res_gain, n)            ← 應用自己呼叫 audiolib kernel
   │ sk_capply_gain_f32(spec, ctx.error_spec, g_total, n)
   │ aec_cng_fill(&rng,spec,ctx.comfort_noise,ctx.res_gain,G_nr,CNG_NR_GAIN_FLOOR,n)   ← 選用(AecConfig.enable_cng)
   │── ac_istft_push(istft,spec,out) ───────────────────────────────────────────►│ iFFT + sqrt-Hann OLA → out[hop]
   │ skn_all_finite_f32(out,hop)                            ← 輸出守衛,應用自己做(example_board_adapter.c 有做)
   │
   │═ ③ 任一步被拒 / 輸出非有限 / 換串流 ══════════════════════════════════════════
   │── aec_reset ─────────────►│ ── anr_reset ───────────────►│ ── ac_istft_reset ──►│   rng=CNG_RNG_SEED
   │
   │═ ④ 結束 ══════════════════════════════════════════════════════════════════════
   │ anr_destroy(nr); aec_destroy(aec); platform_free(pool)          (destroy 不釋放 caller pool)

mono_nr_gain() 只在 use_r2、ctx.r2 非 NULL 且 ctx.usable_linear 非零時才把 r2/32768² 折進噪聲底,否則等於純降噪。--aec-only:只建 Aec,每 hop 一個呼叫 aec_process(aec,mic,ref,out)(直寫 out,0-hop lag)。逐 hop 的 swimlane 與延遲見 pipeline_mono。

2. 4ch:mcab flow(共用 delay、4 lane)+ sample helper(SRP-PHAT、BF)+ 應用的 RES

應用(main)       Mcab(flow)                         McabSampleBeam(helper)     AecRes(libaec)  AnrDenoiser  AcIstft
                 [共用 aligner + 注入的 4 lanes]    [SRP] [BF]
   │                       │
   │═ ① 建立 ═════════════════════════════════════════════════════════════════════
   │ cfg = mcab_default_config(sr);  bp = mcab_sample_beam_default_params()   之後可改 cfg / bp.geometry / bp.bf_*(見 4ch 參數頁)
   │ lane: mcab_lane_config(&cfg,&lane) → aec_get_mem_size → aec_init ×4;MATCHED: mcab_delay_estimator_config → delay_aec_get_mem_size → delay_aec_init
   │── mcab_get_mem_requirements(&cfg,&req) ►│ 0=ok, -1=無效;req.{bytes,alignment=16,layout_version,...}
   │ pool = platform_alloc(req.bytes, req.alignment)
   │── mcab_init_ex(pool,req.bytes,&cfg,&libs,&req) ►│ carve: 控制區, mic lane, aligned far, fuse 緩衝, 對齊環;8 點閘 + lane／estimator 驗證,
   │                       │  任何失敗一律靜默回 NULL(無診斷輸出)       (以上 = mcab_sample_flow_init)
   │── mcab_sample_beam_get_mem_size → mcab_sample_beam_init(mem,bytes,&cfg,&bp,flow) ►│ carve: self, srp, bf, bf_spectrum, bf_weights;NULL=拒絕
   │ RES / NR / 合成另開一塊 post pool(應用自己的 init):
   │   aec_config_from_preset(&res_cfg,preset,sr); res_cfg.fft_size = mcab_fft_size(flow)
   │── aec_res_get_mem_size → aec_res_init(post,...) ►│ 0 / NULL = 無效或 pool 過小;沒有 destroy
   │ anr_init、ac_istft_init(同 mono 的 ①)
   │
   │═ ② 每 hop(mics_interleaved[hop][4]、ref[hop])═══════════════════════════════
   │── mcab_sample_beam_process_front(b,mics,ref,&front) ►│ mcab_process_front: 共用 delay → aligned_ref
   │                       │   → 4 條 lane(lane 0 真 far-FFT,lane 1-3 借用)
   │   front.{delay, linear_spectra[4], formed_hop[4], aligned_ref}(借用)
   │ [應用: 由 front.linear_spectra 算 frequency_mask / vad_raw / vad_out]
   │── mcab_sample_beam_process_beam(b,&front,vad_raw,vad_out,mask,&beam,&info) ►│ doa_step → bf_process_with_weights
   │   beam.{spectrum, weights}(借用)        (一次做完前兩步: process_with_activity / process)
   │── mcab_sample_beam_fuse(b,&frame) ►│ mcab_fuse(weights,spectrum) → frame(E, R2, CN)
   │   frame.{e,y,x,r2,cn,far_hop,...}(借用;g_res_ctx 恆為 NULL)
   │── mcab_sample_res_input(&frame,&in); aec_res_process(res,&in) ►│ G_res(NULL = 被拒)
   │── mcab_sample_anr_gain(nr,&frame,extra,1) ───────────────────────────────►│ G_nr
   │ sk_min_f32 -> sk_capply_gain_f32 -> aec_cng_fill(僅 frame.cn 非 NULL)   (應用自己)
   │── ac_istft_push(istft,spec,out) ─────────────────────────────────────────────────────►│ out[hop]
   │
   │═ ③ 錯誤 / 換串流 ═════════════════════════════════════════════════════════════
   │── mcab_sample_beam_reset(b) ►│(flow: 4 lanes＋estimator;SRP, BF, fallback VAD)
   │── aec_res_reset(res) (preset 保留);  anr_reset(nr);  ac_istft_reset(istft);  rng=MCAB_SAMPLE_CNG_RNG_SEED   ← 應用自己的後級
   │
   │═ ④ 結束 ═══════════════════════════════════════════════════════════════════════
   │ anr_destroy(nr); mcab_sample_beam_destroy(b); mcab_destroy(flow); aec_destroy ×4; platform_free(post, flow 區塊, helper pool)
   │ (AecRes 沒有 destroy;mcab_destroy 不碰 lane 與 estimator,所以拆除順序是 helper → mcab → lane;mcab_sample_flow_destroy 含後兩步)

RES 強度在執行期用 aec_res_set_preset(res, preset, ramp_ms)(res 是應用自備的 AecRes),NR 用 anr_set_mode(nr, mode),兩者都在兩個 hop 之間呼叫;見 pipeline_4ch_detail。

3. 4ch:mcab + 外部 beamformer(產品自己的波束器,不用 helper)

波束器在別處時不需要 helper:mcab_fuse(p, weights, beamformed_error, frame) 就是外部權重的入口,RES 由應用自備 AecRes(aec_res_get_mem_size()／aec_res_init(),config 由 aec_config_from_preset() 在同一個 fft 上取得)。範例:mcab_external_static.c(權重為每個 bin 皆 1/4 的等權佔位)。

應用            Mcab(flow)                 外部 BF(產品自己的)        AecRes(應用自備)  AnrDenoiser  AcIstft
 │── mcab_process_front(p,mics,ref,&front) ►│ 共用 delay + 4 lanes
 │   front.linear_spectra[4] / formed_hop[4] / aligned_ref / delay(delay.changed 非零 ⇒ 外部 STFT/OLA 歷史須清)
 │── front.linear_spectra ─────────────────────────►│ weights Complex[4][n_freqs](channel-major, out=Σ w·x 無共軛)
 │── mcab_fuse(p,weights,beamformed_error|NULL,&frame) ►│ frame.g_res_ctx=NULL(mcab 不算增益)
 │── mcab_sample_res_input(&frame,&in); aec_res_process(res,&in) ►│ G_res
 │── mcab_sample_anr_gain(nr,&frame,extra,1) ──────────────────────────────────────►│ G_nr
 │   sk_min_f32 -> sk_capply_gain_f32 -> aec_cng_fill -> ac_istft_push ─────────────────────────────►│ out
 │── mcab_reset(p); aec_res_reset(res); anr_reset(nr); ac_istft_reset(istft); rng=MCAB_SAMPLE_CNG_RNG_SEED

4. 錯誤與 reset:誰重設什麼

呼叫回傳／情況函式庫自己做了什麼應用要做什麼
mcab_process_front()／mcab_sample_beam_process_front()INVALID_ARGUMENT(NULL 或非有限樣本)不動 adaptive state;非有限樣本時不再有 pending 的 front(helper 也不再有 pending beam;NULL 引數則維持原狀)修正輸入後重送;不需 reset
同上DSP_ERROR(lane 拒絕該 hop,或對齊環無法服務目前 delay)mcab 已 reset(lane＋estimator＋flow);helper 的 SRP、BF、fallback VAD 與 frame_index 不動reset 自己的後級(4ch:AecRes、NR、合成、rng)
mcab_sample_beam_process_beam()SEQUENCE_ERROR(沒有 pending front,或本 hop 的 beam 已跑);INVALID_ARGUMENT(NULL、flag 不是 0／1、他格點的 front)不改動修正呼叫順序
mcab_sample_beam_fuse()INVALID_ARGUMENT(NULL 或 flow 的 enable_post=0)、SEQUENCE_ERROR(本 hop 沒有 beam)不改動修正呼叫
同上其餘非 OK(含 mcab 因權重非有限回的 INVALID_ARGUMENT、lane far 頻譜不一致或頻譜非有限回的 DSP_ERROR)依 mcab_sample_beam.c:整個 helper reset(flow、SRP、BF、VAD、frame_index)後回傳reset 自己的後級(含 AecRes)
mcab_fuse()(直接用 mcab)INVALID_ARGUMENT(權重全零或非有限)front 保持可用修正權重後可重試同一 hop
同上SEQUENCE_ERROR(沒有 front);DSP_ERROR(lane far 頻譜不一致、頻譜非有限或投影溢位)前者不改動;後者 mcab 已 reset後者 reset 自己的後級(含 AecRes)
NR 增益(mono:mono_nr_gain();4ch:mcab_sample_anr_gain())／4ch 的 aec_res_process()回 NULLNR 該 hop 被拒;4ch 的 RES 缺輸入(mono 對應 ctx.res_gain 為 NULL)視為該 hop 被拒,所有 stage 一起 reset:mono CLI 把該 hop 輸出填 0 後繼續;4ch 範例 reset 後回 MCAB_DSP_ERROR 並結束該次執行
輸出非有限(skn_all_finite_f32() 為 0)——flow／helper／Aec 與後級一起 reset(範例 static_hop()／raw_post() 的寫法)
4ch 的後級物件(AecRes、AnrDenoiser、AcIstft)與 CNG 的亂數種子 MCAB_SAMPLE_CNG_RNG_SEED 都不在 mcab／helper 裡,mcab_sample_beam_reset() 與 mcab_reset() 不會動它們。mcab 的 reset 會呼叫被注入 lane 與 estimator 自己的 reset 函式,但不會 destroy 或重新 init 它們。mono 的 mono_aec_nr_res/main.c(同一份原始碼建出 aec_nr_pipeline_static 與 -DAEC_NR_POOL_SPLIT=1 的 aec_nr_pipeline)在 process_hop() 回 −1 時呼叫 rig_reset() 並把該 hop 輸出填 0;這支 CLI 本身不做輸出有限檢查,example_board_adapter.c 與 4ch 的 static_hop()／raw_post() 才有。

5. 接 NN 後級的 hop 骨架(摘要)

NN 後級把一個 hop 拆成四個呼叫,加速器夾在 nn_begin 與 nn_end 之間;細節與 fail-open 規則在 串接範例 第 5 節、pipeline_ulcnet_mono／pipeline_dfn_mono。

應用            Aec 或 4ch(mcab＋helper)  NN stage(範例碼)            NN runtime／加速器
 │── (Aec: aec_process_context + aec_get_res_context／aec_get_linear_context) 或 (4ch: mcab_sample_beam_process_front/beam[/fuse]) ►│
 │── ulcnet_nn_stage_begin_time / _begin_complex  (dfn: dfn_hop_begin) ►│ 分析 err／far
 │── ulcnet_nn_stage_nn_begin(stage,&job) ►│ 回 1=有一幀、0=本 hop 無模型幀
 │── board_run_npu(job.*) ───────────────────────────────────────────────►│ out 已預填 NaN,必須寫滿
 │── ulcnet_nn_stage_nn_end(stage,rc) ►│ rc≠0 或輸出非有限 ⇒ identity(fail-open)
 │── ulcnet_nn_stage_end(stage,out) ►│ ac_istft_push_planar → out[hop]
