3. 範例 CLI 旗標

兩個板端骨架(mono_aec_dfn_res、4ch_aec_bf_dfn_res)共用 pipelines/dfn/dfn_example_args.h 的旗標集(mono 由 dfn_example_parse_args() 解析;4ch 的 dfn_parse() 先以它取預設,再經 mcab_sample_driver.h 的 mcab_sample_scan_cli() 掃描),延遲旗標與所有數字都走 pipelines/common/example_cli.h 的嚴格解析(example_cli_parse_int／_float:空字串、前導空白、尾隨字元、超出範圍、inf／nan 皆拒,純十進位與前導 + 通過)。被拒的旗標結束碼為 2,-h 為 0。

旗標(範例 CLI)範例範圍／預設備註
--sample-ratemono、4chmono {8000|16000|48000};4ch {16000|48000};預設 16000host 的取樣率(不是模型的)。4ch 對 8000 在參數解析就拒絕(結束碼 2);整串必須是整數(16000Hz 被拒)

--delay-modemono、4chmatched(預設)|fixed|external
--delay-num-filtersmono、4ch1..5,預設 5;僅 matched其他模式給非 5 的值被拒;3x 這類非整數被拒
--fixed-delaymono、4ch≥ 0 的原生取樣率樣本數;僅 fixedfixed 模式必須給;12x 被拒
--erb-fwd FILE --erb-inv FILEmono、4ch兩個 raw 檔,成對給或都不給無標頭的 little-endian float32:--erb-fwd 前向 bin-major [n_bins][n_erb]、--erb-inv 反向 band-major [n_erb][n_bins],大小各必須剛好 n_bins×n_erb×4 B(export_erb_matrix.py --runtime-bins 的 erb_fwd.bin／erb_inv.bin)。板端 sample 讀的 grid 對應 ERB 矩陣檔是另一種檔:匯出器 erb_matrix.bin 的格式(int32 n_bins、int32 n_bands,後接前向與反向,兩者都是 bin-major),反向由 sample 在 init 轉成 band-major。缺值或只給一個結束碼 2;檔案不可讀或大小不符結束碼 1;都不給 = unit partition(fail-open smoke)
--atten-limmono、4ch有限 dB,預設 0 = 不限制12dB、inf、nan 被拒
--cngmono、4ch預設關開啟 comfort-noise fill;B 與 P 不再同相位(見 Mono · DFN2)
-h／--helpmono、4ch結束碼 0

4ch 範例:估計用 E、套用在 P(= B × G_res)

E = frame.e(McabFrame):beamformed 線性誤差頻譜(helper 的 beam.spectrum,經 mcab_fuse() 放進 frame),也就是 RES gain 據以估計的那個 pre-RES 頻譜,只送進網路做估計。B = frame.b:渲染基底,沒有任何貢獻 lane 的輸出防護觸發時就是 E 本身(同一個指標),觸發的 hop 上該 lane 的分量改帶其 capture。P = dfn_form() 的輸出:B * min(1, G_res) + comfort noise,才是三個 head 套用的對象。理由與 mono 相同(mono 的估計輸入與套用都建立在 aec_get_output_base() 的 base_spec 上):DFN2 是以未經處理的 noisy speech 訓練的,不能讓它看見 RES 挖出的頻譜洞;像語音的 far-end 殘留由 DFN 保留、留給 RES 處理,不像語音的兩級都壓。comfort-noise fill(--cng)是開關但預設關閉:關閉時 B 與 P 逐 bin 同相位(守衛未觸發的 hop 上 B 即 E),複數 deep-filter tap 不會相位錯配;開啟時 CNG 在 RES 挖掉的 bin 改變 P 的相位,estimate/apply 一致性在那裡不成立(dfn_res_stage.h 開頭)。開啟時它包在 P 裡、過同一張 mask,atten_lim_db 限制任何一個 bin 最多被壓多少。

Lookahead pair(M／D)與延遲

DFN2 有兩個互相獨立的 lookahead:mask_lookahead M(0..2)與 df_lookahead D(0..df_order−1 = 4,出貨 df_order 為 5),共 15 個合法 pair,M 與 D 之間沒有大小限制。pair 是模型合約的一部分(checkpoint 屬於一個 pair);匯出的 ONNX graph 與 pair 無關,pair 只決定 host 餵進去的視窗 [t-(2-M)..t+M] 與就緒條件(已推入 M+1 幀)。規則與匯出面見 DeepFilterNet2 頻域與模型契約 與 AINR/README.md「Lookahead pairs」。只有出貨的 1/1 有訓練好的 checkpoint,其他 pair 的音質未量測。下表的 L = M + D。

  • Python:Dfn2Stage 的 M、D 取自載入的模型(config.ini [model]),Dfn2RateBridge.added_delay 用同一條公式。

4ch 範例:fail-open 等值

Fail-open = 傳統鏈的等值(延後)。沒有模型、infer() 回非 0、或輸出有未寫/非有限值時,該幀走 dfn2_prepost_frame_bypass()(unit ERB mask 經 partition-of-unity 的 erb_inv 展開成 unit bin gain、zero taps、alpha 0),輸出即「手寫傳統鏈(conv_chain_mcab.h,降噪器關;餵 helper 的 beam 權重與 beamformed 頻譜)延後 L 個 hop」,comfort noise 一併保留。這是本範例的 backbone gate,48 kHz 由 C 測試在 CNG 關/開兩輪逐 byte 釘死;16 kHz 因為多了 resampler 往返,gate 改為「延後 added delay 後的通帶容差」。
