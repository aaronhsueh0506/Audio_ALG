1. 設定欄位分級

1.1 格點、delay 與 residual(AecConfig,n_mics = AEC_ARRAY_MICS;四條 lane 共用同一個決策)

欄位分級範圍／預設說明
n_mics外部陣列只接受 4;1 是單支4 = array instance,一次 aec_init_ex() 建出整條 flow
sample_rate外部16000 或 48000(沒有 8 k);預設為 array_sample_default_config(&cfg, sr) 或 aec_config_from_level() 的引數不可變;mic 與 ref 必須同率同時鐘
fft_size外部factory 填 rate 預設(16k→256、48k→1024);16k 另可 512;48k 僅 1024;0 被拒hop = fft/2。16k/512 的 hop 是 256(延遲加倍)。後級的 NR 與合成必須用同一個 cfg.fft_size
residual整合者專用STATE／ESTIMATE／FULL(預設 FULL);OFF 被拒STATE:只有 lane(不 carve 融合緩衝與增益級),aec_process_residual() 與 array_sample_beam_fuse() 回 AEC_ERR_MODE(NN 後級的設定檔);ESTIMATE:融合但無增益(res_gain 為 NULL);FULL:融合加唯一一個 G_res
delay_mode外部AEC_DELAY_MATCHED(預設)／FIXED／EXTERNAL_ALIGNED決定 array pool 佈局;MATCHED 時 pool 內 1 個共用 DelayAec + 1 條共用 aligned render delay line,其餘兩種 matcher count = 0(沒有 estimator)
delay_num_filters外部[1, 5],僅 MATCHED;其他模式必須為 5(預設 5)記憶體旋鈕(只影響 estimator,不影響 lane);可靠搜尋範圍隨 n 縮小(125／221／317／413／509 ms)
fixed_delay_samples外部僅 FIXED:0..120×sr(原生取樣點);其他模式必須 −1(預設 −1)FIXED 的量測系統延遲;同時決定參考環(fixed + hop)
capture_proxy_channel外部(進階)[0, 3];預設 0共用 matcher 讀哪一路 mic;與麥克風擺位有關。也是 backward-quarantine 判斷「仍在消除回音」的那條 lane
delay_backward_quarantine_enabled內部0／1;預設 0只隔離比現行 delay 更早的新估計,且僅在 capture_proxy_channel 那條 lane 仍在消除回音時;產品組態維持 OFF(研究開關)
delay_backward_quarantine_s內部[0, 3600] s;預設 1.0隔離窗長,init 時換算成 hop 數,到期即採用——延後一個窗,不是治癒;不是 pre-echo 誤鎖的解藥

1.2 幾何、DOA、BF、備援 VAD(ArraySampleBeamParams)

欄位分級範圍／預設說明
geometry外部ARRAY_SAMPLE_GEOMETRY_UCA(預設)／ULA／CUSTOM陣列描述;決定 SRP-PHAT steering
uca_radius_m外部> 0 且有限;預設 0.035 m僅 UCA。UCA 時 microphone_x_m／y_m 由它重新產生,直接改那兩個陣列無效
ula_spacing_m外部> 0 且有限;預設 0.035 m僅 ULA
microphone_x_m[4]／microphone_y_m[4]外部有限;僅 CUSTOM 時採用各麥克風座標(m)
bf_enable外部0／1;預設 10 = 旁路 BF(權重為 [1,0,0,0],只取 channel 0)
bf_fixed_mode／bf_fixed_doa_rad外部0／1,預設 0;弧度,有限,預設 0固定波束方向(產品已知聲源方位時);1 時 BF 不跟隨 DOA
num_angles外部(進階)[4, 3600];預設 72DOA 角度解析度(steering table 與運算量)
doa_low_freq_hz／doa_high_freq_hz外部(進階)low ∈ [0, Nyquist);high ∈ [0, Nyquist];解析後的 high(0 = min(7000, Nyquist))須 > low;預設 300／7000(0 = min(7000, Nyquist))SRP 使用的頻帶;與陣列幾何耦合(間距越大,高頻越容易 spatial aliasing)
bf_adapt_interval外部(進階)[1, ARRAY_SAMPLE_BEAM_MAX_ADAPT_INTERVAL = 1<<20];預設 1RLS 每 N 個 hop 更新一次(算量旋鈕);固定波束的 notebook 模式強制為 1。bf_lambda 依 hop×interval retime
auto_vad_threshold_dbfs／auto_vad_snr_ratio／auto_vad_hangover_frames外部(進階)有限;≥ 1.0;≥ 0;預設 −55 dBFS／3.0／8僅 array_sample_beam_process() 的備援 energy VAD 用;有產品 VAD 時走 process_with_activity(),這三項完全不讀(但仍被驗證)。hangover 與噪聲 EMA(0.999／0.95)依 hop retime
speed_of_sound_m_s內部有限且 > 0;預設 343物理常數;只有非空氣或需溫度補償時才需要動
doa_enable_smoothing／doa_switch_consecutive／doa_angle_tolerance_rad內部0／1,預設 1;> 0,預設 3;≥ 0 弧度,預設 10°DOA 平滑器:連續 N 次一致觀測才切換;單位是 hop 數,不隨 grid retime,與 doa_update_interval 聯合決定 DOA 反應時間
doa_update_interval內部> 0;預設 2SRP 只在 vad_raw 為真且 frame 計數整除時更新,其餘 hop 沿用上次 DOA
bf_lambda／bf_mu內部(0, 1],預設 0.995;≥ 0,預設 0.1RLS 遺忘因子(以 10 ms 更新為基準 retime;retime 後下溢為 0 則整組參數被拒)與步長;收斂關鍵,validator 範圍遠寬於安全範圍
bf_fixed_align_notebook內部0／1;預設 0固定波束時採用 notebook 風格的更新:強制每 hop 更新、停用 mask 凍結與 mu scaling;對照參考實作用

1.3 lane 參數與 level(AecConfig 的其餘欄位;array 沒有獨立的 lane config)

四條 lane 的 config 由 array 從這份 AecConfig 衍生:fft_size(格點)與其餘欄位照抄,delay_mode = EXTERNAL_ALIGNED(delay_num_filters = 5、fixed_delay_samples = -1)、單支(n_mics = 1)、不開 quarantine,殘餘階段為 ESTIMATE(array 為 STATE 時 STATE)。應用不建 lane、也不能注入 lane。aec_config_from_level() 填 level(AecConfig.level),sample_rate 不是 16000／48000 時 fft_size 為 0,aec_get_mem_requirements() 回 −1。AecConfig 只有 12 個公開欄位:濾波器長度(16 kHz 832、48 kHz 3072 taps)、共用 delay ring 的容量(與單聲道同式:estimator 可回報的最大延遲加 hop)、matched filter 的 duty-cycle(預設關,每 hop 分析)與所有門檻都是函式庫內部的調校(AecTuning),不是欄位。RES 與 NR 的設定:

項目分級範圍／預設說明
level(aec_config_from_level(&cfg, level, sample_rate) 寫入)外部AEC_LEVEL_* 0..3(範例用 BALANCED;全零的 AecConfig 是 MILD,不在 0..3 被拒)array 增益級地板的起點;執行期改用 aec_set_level(aec, level)。lane 自己的 level 沒有效果
其餘調校值(AecTuning,不是 AecConfig 欄位)內部由 (sample_rate, fft_size, n_mics, level) 決定整合者不能設;範例(4ch_static.c、4ch_raw.c、4ch_external_static.c、4ch/aec_bf_dfn_res/main.c)只設 n_mics、residual 與 delay 欄位
降噪器(AnrConfig)外部anr_config_for_level_grid(sr, cfg.fft_size, level)不屬於 array;NR 與合成的 fft_size 必須與 array 同一格點

項目值位置／為什麼不開放

duty-cycle 常數divisor 5;ERLE 崩 6 dB 的看門狗(DUTY_ERLE_COLLAPSE_DB);leak 0.001 dB/hop @10 ms 基準換算aec_array.c。回全速不是立即:被略過的 hop 不發佈新估計,delay 改變／信心流失只能在下一個排定的分析被看見,最壞多等一個 duty 週期(週期 0.5 s 時約 96 ms @16 kHz/256;函式庫的調校預設不啟用 duty-cycle);看門狗必須先讓 ERLE 峰值超過 6 dB 才會武裝(lane ERLE 壓在 6 dB 之下時永遠不武裝,re-lock 全由 1-in-K 取樣承擔)

6. 狀態碼與序列規則

AEC_*(AecStatus)值意義
OK0成功
ERR_ARG−1NULL、非有限輸入、flag 不是 0／1、權重全零或非有限、struct_size 過短
ERR_MODE−2STATE 的 array 呼叫 aec_process_residual()／aec_get_residual();增益函式用在非 FULL 的 array;aec_process() 用在 array
ERR_SEQUENCE−3沒有 linear frame 就 residual(FULL 同一 hop 的第二次 residual 亦然);helper:沒有 pending front 就 beam,或沒有本 hop 的 beam 就 fuse(不改動任何狀態)
ERR_DSP−4lane 拒絕該 hop、ring 無法服務目前 delay、far 頻譜不一致,或融合的結果非有限(有限但極大的權重使投影溢位):array 已 self-reset(lane＋estimator＋增益級)。helper 的 fuse() 回非 OK 且非 SEQUENCE／MODE 時(含 array 因權重或 beamformed 頻譜無效回的 AEC_ERR_ARG)會 reset 整個 helper(array、SRP、BF、VAD、frame_index)後回傳

每個非 OK 之後,應用要 reset 自己的後級(見 整合時序圖 第 4 節)。residual 沒有 token 要歸還:從不呼叫 residual 的應用(NN 後級,residual = STATE)不需要任何「放棄」呼叫,下一個 linear 直接接手。

7. array 輸出契約(AecArrayView 與 AecResidualView)

欄位內容擁有者／壽命
AecArrayView.delayAecDelayState:delay_samples／confidence／solid／changed(另有 estimator_calls／estimator_updates);changed 非零 = 新的可用 alignment generation 在這個 hop 開始(MATCHED 的首次取得,init 或 reset 之後;鎖定中值改變),外部 STFT／OLA 歷史須在產生本 hop 的 frame 之前清除。solid 在 MATCHED 首次取得後保持到 reset。FIXED 與 EXTERNAL_ALIGNED 不會設 changed值複製
AecArrayView.lane_error_spec[4]各 lane formed 頻譜 [n_freqs](音訊尺度),與時域 hop 同一次選擇,別名 lane 自己的 buffer借用;有效至下一次 aec_process_linear()／reset／destroy;reset 不清除,呼叫端必須在 reset 後停讀
AecArrayView.lane_formed_hop[4]各 lane 的 [hop] formed 時域 hop(供自己做 sqrt-Hann 分析的外部時域波束器)同上
AecArrayView.aligned_ref[hop] 本 hop 實際餵給四條 lane 的 delay-aligned far(ring 未滿時為 raw ref);給外部 NN 後級(Align-ULCNet far branch)用同上
AecResidualView(aec_get_residual() 填)error_spec=beamformed 誤差、near_spec=投影近端、far_spec=lane 0 的 far 頻譜、r2／comfort_noise=投影後的殘餘回音／舒適噪音 PSD、base_spec=渲染基底、res_gain(FULL)、far_hop、max_dt／max_saturation／all_converged／usable_linear(只計對權重有非零響應的 lane)、clock_drift、delay 旗標、guard_lanes、post_reset_serial;formed_hop／echo_spec 恆為 NULL借用;error_spec 在傳入 beamformed_error 時別名呼叫端的陣列,否則別名 array 內 buffer;有效至下一次 aec_process_linear()／reset／destroy;不得寫入

分析 seam 與渲染基底是兩個訊號。lib/aec 的 formed 序列與 error_spec 一律是被選中的線性殘差(沒有 capture 候選),輸出守衛不改動它們;外部 beamformer 與 array 的增益級(G_res)讀的就是這個分析 seam。輸出守衛只決定每條 lane 的渲染基底(AecArrayView.lane_base_spec、lane_guard_active),aec_process_residual() 以同一組權重把它們加成 AecResidualView.base_spec;範例鏈的降噪器在 base_spec 上估計,渲染 base_spec × gain(aec_apply_gain())。

執行期控制與診斷

array + 外部 beamformer 的呼叫範例

產品的波束器在別處時不需要 sample helper:aec_process_residual() 吃呼叫端的權重(和可選的 beamformed 頻譜)。RES 增益由 array 內唯一的增益級(residual = FULL)算,應用不需要另建;lane 與 estimator 在 array 的 pool 內,沒有要另外建或另外拆的東西。可執行版本:4ch_external_static.c(權重是每個 bin 皆 1/4 的等權佔位,要換成產品波束器的權重);參考鏈:tests/conv_chain_4ch.h。以下範例已在 -Wall -Wextra -Werror 下編譯並執行(platform_alloc()、stream_next4()、product_beamformer() 是你的平台／I/O／波束器佔位;範例省略了 platform_alloc() 回傳值的檢查與記憶體釋放):

AecConfig cfg;
aec_config_from_level(&cfg, AEC_LEVEL_BALANCED, 16000);   /* 之後只覆寫要改的欄位 */
cfg.n_mics = AEC_ARRAY_MICS;                              /* MATCHED, capture_proxy_channel = 0 */
cfg.residual = AEC_RESIDUAL_FULL;                         /* array 內唯一的增益級; STATE 則只有 lane */
AecMemReq req;
if (aec_get_mem_requirements(&cfg, &req) != 0) return -1;   /* -1 = 無效 */
Aec* a = aec_init_ex(platform_alloc((size_t)req.bytes, req.alignment), (size_t)req.bytes, &cfg, &req);
if (!a) return -1;                                        /* NULL = 拒絕, 無診斷輸出 */
int hop = aec_hop_size(a), nf = hop + 1;

/* array 沒有 NR 與合成: 應用自備, config 的 fft 取 cfg 的格點 */
AnrConfig nr_cfg = anr_config_for_level_grid(cfg.sample_rate, cfg.fft_size, ANR_LEVEL_BALANCED);
AcStftConfig syn_cfg;  ac_stft_config_default(&syn_cfg, cfg.fft_size);
size_t nr_b = anr_get_mem_size(&nr_cfg), syn_b = ac_istft_get_mem_size(&syn_cfg);
if (!nr_b || !syn_b) return -1;                           /* 0 = 無效 */
AnrDenoiser* nr = anr_init(platform_alloc(nr_b, 16), nr_b, &nr_cfg);
AcIstft* istft = ac_istft_init(platform_alloc(syn_b, 16), syn_b, &syn_cfg);
if (!nr || !istft) return -1;
Complex* weights = (Complex*)platform_alloc((size_t)4 * nf * sizeof(Complex), 16);
Complex* spec = (Complex*)platform_alloc((size_t)nf * sizeof(Complex), 16);
uint32_t handled = aec_post_reset_serial(a);              /* 已處理的 post_reset_serial */

const float *mics, *ref;  float out[512];
while (stream_next4(&mics, &ref, out)) {
    AecArrayView front = { .struct_size = sizeof(front) };
    AecResidualView v = { .struct_size = sizeof(v) };
    const float* g_nr = NULL;
    int rc = aec_process_linear(a, mics, ref);              /* 共用 delay + 4 條 lane */
    if (rc == AEC_OK) rc = aec_get_array(a, &front);
    if (rc == AEC_OK) {
        if (front.delay.changed) { /* 產品波束器若有 STFT/OLA 歷史, 先在這裡清除, 再算本 hop 的權重 */ }
        product_beamformer(&front, weights);                /* 用 front.lane_error_spec[4] 算 [4][n_freqs] 權重 */
        AecBeam beam = { weights, NULL };                   /* NULL: 由 weights 重建 beamformed 誤差 */
        rc = aec_process_residual(a, &beam);
        if (rc == AEC_OK) rc = aec_get_residual(a, &v);
    }
    if (rc == AEC_OK) g_nr = anr_process_gain(nr, v.base_spec);     /* NR 在 B 上估計; NULL = 被拒 */
    if (g_nr) {
        if (v.post_reset_serial != handled) { ac_istft_reset(istft); handled = v.post_reset_serial; }
        if (aec_apply_gain(a, g_nr, spec) != AEC_OK ||      /* P = v.base_spec * min(G_nr, G_res) */
            aec_apply_cng(a, g_nr, spec) != AEC_OK) g_nr = NULL;   /* 補 RES 切掉的 bin; 同一個 G_nr */
        else {
            ac_istft_push(istft, spec, out);
            if (!skn_all_finite_f32(out, (size_t)hop)) g_nr = NULL;
        }
    }
    if (!g_nr) {                                            /* AEC_ERR_ARG(權重)可修正重試; 其餘一起 reset */
        aec_reset(a);  anr_reset(nr);  ac_istft_reset(istft);
        handled = aec_post_reset_serial(a);  memset(out, 0, (size_t)hop * sizeof(float));
    }
}
anr_destroy(nr);
aec_destroy(a);                                             /* lane 與 estimator 隨 pool 一起; 不釋放任何記憶體 */
return 0;

逐階段耗時(診斷用)

typedef struct AecArrayTiming {
    uint32_t delay_us;       /* 共用 delay estimator                 */
    uint32_t frontend_us;    /* 四條 lane:進入主濾波器之前            */
    uint32_t linear_us;      /* 四條 lane:主自適應濾波器(含 far FFT) */
    uint32_t lane_res_us;    /* 四條 lane:殘餘階段                    */
    uint32_t fuse_us;        /* aec_process_residual():融合與增益     */
} AecArrayTiming;

void aec_array_get_timing(const Aec* a, AecArrayTiming* out);

最近一個 hop 每個階段的 wall-clock 成本(微秒,預設用 CLOCK_MONOTONIC)。純診斷:array 自己不回讀,也不影響處理。a 為 NULL 或已銷毀時整份記錄不動;out 不得為 NULL。欄位:delay_us(共用 estimator,不含 align_render() 的 ring-buffer 複製與 realign 掃描)、fuse_us(aec_process_residual() 的融合與增益),以及四條 lane 加總的 frontend_us／linear_us／lane_res_us。NR、CNG 與逆轉換的耗時由應用自己量,不在這個記錄內。aec_get_last_timing() 回報同一份記錄但沒有 fuse_us(res_us = lane_res_us)。

五個欄位由同一個旗標 AEC_STAGE_TIMING 管轄(預設 1;make PROFILE=0 經 PROFILE 轉發給 lib/aec 的建置,關閉後所有欄位恆為 0)。lane 內部的 delay_us 也一併加進上面的 delay_us,但它結構上恆為 0:四條 lane 都是 AEC_DELAY_EXTERNAL_ALIGNED,沒有自己的 ring 或 estimator。相加而不是丟棄,是為了讓日後改變 lane 模式時不會靜默漏掉那筆成本。

目標平台沒有 CLOCK_MONOTONIC 時。clock_gettime 是 POSIX 而非 C99。用 make EXTRA_CFLAGS='-DAEC_NOW_US=board_timer_us -include my_timer.h' 換掉時鐘(或 make PROFILE=0 關掉量測);巨集要是純識別字(FP policy 不允許 EXTRA_CFLAGS 出現括號),指向不收參數、回傳 uint32_t 微秒的函式。替代時鐘必須單調。指向常數函式是合法用法,所有欄位讀 0。

呼叫端若要呈現完整分解,linear 側的未歸屬餘額要自己用減法算:linear_total − (delay_us + frontend_us + linear_us + lane_res_us)(linear_total 是你自己量的 aec_process_linear() 整段耗時) 涵蓋輸入去交錯／有限值檢查、align_render()、realign 掃描與 lane 迴圈自己的餘額。

aec_process_linear() 在 NULL 引數、已銷毀 handle 與非有限樣本的檢查之後把前四個欄位清零,所以中途失敗的 hop(例如 lane 拒絕)對沒跑到的階段回報 0 而不是上一個 hop 的數字;fuse_us 只在 aec_process_residual() 通過引數、sequence 與權重檢查之後清零。因 NULL 引數、已銷毀 handle 或非有限樣本被直接拒絕的處理呼叫不動記錄。
