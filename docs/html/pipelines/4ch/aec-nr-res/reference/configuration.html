1. 設定欄位分級

1.1 格點與 delay(McabConfig,四條 lane 共用同一個決策)

欄位分級範圍／預設說明
sample_rate外部16000 或 48000(沒有 8 k);預設為 mcab_default_config(sr) 的引數不可變;mic 與 ref 必須同率同時鐘
fft_size外部0 = rate 預設(16k→256、48k→1024);16k 另可 512;48k 僅 1024hop = fft/2。16k/512 的 hop 是 256(延遲加倍)。後級的 NR 與合成必須用 mcab_fft_size(flow)
delay_mode外部AEC_DELAY_MATCHED(預設)／FIXED／EXTERNAL_ALIGNED決定 mcab pool 佈局與是否需要 estimator;MATCHED 時 1 個共用 DelayAec(McabLibs.delay)+ 1 條共用 aligned render delay line,其餘兩種 matcher count = 0(McabLibs.delay 必須是 NULL)
delay_num_filters外部[1, 5],僅 MATCHED;其他模式必須為 5(預設 5)記憶體旋鈕(只影響 estimator,不影響 mcab pool 與 lane);可靠搜尋範圍隨 n 縮小(125／221／317／413／509 ms)
fixed_delay_samples外部僅 FIXED:0..120×sr(原生取樣點);其他模式必須 −1(預設 −1)FIXED 的量測系統延遲;同時決定參考環(fixed + hop)
capture_proxy_channel外部(進階)[0, 3];預設 0共用 matcher 讀哪一路 mic;與麥克風擺位有關。也是 backward-quarantine 判斷「仍在消除回音」的那條 lane
max_delay_ms外部(進階)[0, 4096];預設 1024僅 MATCHED:決定共用 delay ring 的容量 = ceil(ms×sr/1000) + 2×hop + 1(16 kHz/hop 128 預設 = 16,641 samples)。是記憶體旋鈕,不是可擷取上限(可擷取範圍由 delay_num_filters 決定);設得太小時 ring 無法服務目前 delay,mcab_process_front() 回 DSP_ERROR
delay_est_period_s外部(進階)[0, 3600] s;預設 0.0(每 hop 分析)matched filter duty-cycle:估計 solid 且 0.3 s(DUTY_HOLD_S,固定)不變後,分析降為 1-in-K(K = round(period/hop) ÷ 5,最小 1);estimator 每 hop 照餵(只降分析不降音訊)。非 0 可能改變所選的 lag,是 opt-in 的算量旋鈕。同一個值由 mcab_apply_lane_contract() 蓋到 lane 的 AecConfig。見第 4 節
delay_backward_quarantine_enabled內部0／1;預設 0只隔離比現行 delay 更早的新估計,且僅在 capture_proxy_channel 那條 lane 仍在消除回音時;產品組態維持 OFF(研究開關)
delay_backward_quarantine_s內部[0, 3600] s;預設 1.0隔離窗長,init 時換算成 hop 數,到期即採用——延後一個窗,不是治癒;不是 pre-echo 誤鎖的解藥
enable_post整合者專用0／1;預設 11:lane 保留頻域 post context 並 carve fuse 緩衝,mcab_fuse()／mcab_sample_beam_fuse() 可用;0:只留線性 context(AEC_CONTEXT_LINEAR_ONLY),fuse 回 INVALID_ARGUMENT(NN 後級的設定檔)

1.2 幾何、DOA、BF、備援 VAD(McabSampleBeamParams)

欄位分級範圍／預設說明
geometry外部MCAB_SAMPLE_GEOMETRY_UCA(預設)／ULA／CUSTOM陣列描述;決定 SRP-PHAT steering
uca_radius_m外部> 0 且有限;預設 0.035 m僅 UCA。UCA 時 microphone_x_m／y_m 由它重新產生,直接改那兩個陣列無效
ula_spacing_m外部> 0 且有限;預設 0.035 m僅 ULA
microphone_x_m[4]／microphone_y_m[4]外部有限;僅 CUSTOM 時採用各麥克風座標(m)
bf_enable外部0／1;預設 10 = 旁路 BF(權重為 [1,0,0,0],只取 channel 0)
bf_fixed_mode／bf_fixed_doa_rad外部0／1,預設 0;弧度,有限,預設 0固定波束方向(產品已知聲源方位時);1 時 BF 不跟隨 DOA
num_angles外部(進階)[4, 3600];預設 72DOA 角度解析度(steering table 與運算量)
doa_low_freq_hz／doa_high_freq_hz外部(進階)low ∈ [0, Nyquist);high ∈ [0, Nyquist];解析後的 high(0 = min(7000, Nyquist))須 > low;預設 300／7000(0 = min(7000, Nyquist))SRP 使用的頻帶;與陣列幾何耦合(間距越大,高頻越容易 spatial aliasing)
bf_adapt_interval外部(進階)[1, MCAB_SAMPLE_BEAM_MAX_ADAPT_INTERVAL = 1<<20];預設 1RLS 每 N 個 hop 更新一次(算量旋鈕);固定波束的 notebook 模式強制為 1。bf_lambda 依 hop×interval retime
auto_vad_threshold_dbfs／auto_vad_snr_ratio／auto_vad_hangover_frames外部(進階)有限;≥ 1.0;≥ 0;預設 −55 dBFS／3.0／8僅 mcab_sample_beam_process() 的備援 energy VAD 用;有產品 VAD 時走 process_with_activity(),這三項完全不讀(但仍被驗證)。hangover 與噪聲 EMA(0.999／0.95)依 hop retime
speed_of_sound_m_s內部有限且 > 0;預設 343物理常數;只有非空氣或需溫度補償時才需要動
doa_enable_smoothing／doa_switch_consecutive／doa_angle_tolerance_rad內部0／1,預設 1;> 0,預設 3;≥ 0 弧度,預設 10°DOA 平滑器:連續 N 次一致觀測才切換;單位是 hop 數,不隨 grid retime,與 doa_update_interval 聯合決定 DOA 反應時間
doa_update_interval內部> 0;預設 2SRP 只在 vad_raw 為真且 frame 計數整除時更新,其餘 hop 沿用上次 DOA
bf_lambda／bf_mu內部(0, 1],預設 0.995;≥ 0,預設 0.1RLS 遺忘因子(以 10 ms 更新為基準 retime;retime 後下溢為 0 則整組參數被拒)與步長;收斂關鍵,validator 範圍遠寬於安全範圍
bf_fixed_align_notebook內部0／1;預設 0固定波束時採用 notebook 風格的更新:強制每 hop 更新、停用 mask 凍結與 mu scaling;對照參考實作用

1.3 lane 的 AecConfig 與 RES(libaec,應用層;不是 McabConfig 的欄位)

四條 lane 的 AecConfig 由應用組:aec_config_from_level()(或 mcab_lane_config() 的 balanced 預設)加 mcab_apply_lane_contract(&cfg, &lane)。契約蓋上 fft_size(flow 的格點)、delay_mode = EXTERNAL_ALIGNED(delay_num_filters = 5、fixed_delay_samples = -1、enable_delay_est = 0)、enable_res = 0、return_res_context = 1、spatial_linear_context(enable_post=1 為 AEC_CONTEXT_NO_GAIN,否則 LINEAR_ONLY)與 delay_est_period_s;filter_length(預設 52 ms,≥ 44.1 kHz 為 64 ms)與 level 的其餘值保持原樣、mcab 不檢查,sample_rate 不同的 lane 被拒(−1)。mcab 與 helper 沒有 enable_res／res_level,fuse() 讓 frame.g_res_ctx 為 NULL。要在 fuse 之後做 RES 的應用在自己的 init 建一個 AecRes:

項目分級範圍／預設說明
lane 的 filter_length外部(0, 4096] 樣本;aec_config_from_level() 填預設 52 ms(≥ 44.1 kHz 為 64 ms):16 kHz 832、48 kHz 3072每條 lane 的 PBFDKF 長度;調高 → 記憶體與運算上升(四條 lane 用同一份 config);超出範圍時 aec_get_mem_size() 回 0
aec_config_from_level(&cfg, level, sample_rate)(RES 用)外部AEC_LEVEL_*(範例用 BALANCED);sample_rate = flow 的 sample_rateRES 地板的起點;執行期改用 aec_res_set_level(res, level, ramp_ms)
RES 的 cfg.fft_size外部= mcab_fft_size(flow)必須與 flow 同一格點;aec_res_get_mem_size() 回 0 = config 無效,aec_res_init() 回 NULL = pool 過小／未對齊／無效
其餘 AecConfig 欄位內部level 建構函式的值整合者不改;範例(mcab_static.c、mcab_raw.c、mcab_external_static.c、4ch/aec_bf_dfn_res/main.c)都只設 fft_size

輸入範圍說明

4. 固定在程式內的常數(內部)

項目值位置／為什麼不開放
lane 的契約欄位EXTERNAL_ALIGNED、enable_res=0、return_res_context=1、spatial_linear_contextmcab_apply_lane_contract();lane 不走自己的殘留抑制器,level 對它的輸出沒有意義(mcab_lane_config() 預設取 AEC_LEVEL_BALANCED)
delay 接受條件估計 ≥ 0、solid、n_updates ≥ 3update_shared_delay()(mcab.c);首次取得對齊立即接受
delay 變更 admission(Path-B)移動 > 32 樣本,且在 16 樣本內再次被提出,候選 TTL 3 hopsmcab_internal.h 的 MCAB_DELAY_CHANGE_*;與 lib/aec 同一條規則
duty-cycle 常數divisor 5;ERLE 崩 6 dB 的看門狗(DUTY_ERLE_COLLAPSE_DB);leak 0.001 dB/hop @10 ms 基準換算mcab.c。回全速不是立即:被略過的 hop 不發佈新估計,delay 改變／信心流失只能在下一個排定的分析被看見,最壞多等一個 duty 週期(約 96 ms @ delay_est_period_s=0.5,16 kHz/256);看門狗必須先讓 ERLE 峰值超過 6 dB 才會武裝(lane ERLE 壓在 6 dB 之下時永遠不武裝,re-lock 全由 1-in-K 取樣承擔)
far-FFT 共用lane 0 真 far-FFT,lane 1–3 借用4 次 → 1 次(mcab_far_fft_real_compute_count() 逐呼叫 +1);同一 hop 內若 lane 的 realign 結果混合 warm／soft,該 hop 改為各 lane 自算,fuse 也跳過 far 頻譜一致性檢查
構造用的 hashbuild_flags_hashcarve token 字串的 FNV-1a,不含任何 sizeof;mcab 的 control block 只長大而 carve 結構不變時 hash 不動,只能靠 layout_version bump 攔截

6. 狀態碼與序列規則

MCAB_*(McabStatus)值意義
OK0成功
INVALID_ARGUMENT−1NULL、非有限輸入、flag 不是 0／1、權重全零或非有限、enable_post=0 時呼叫 fuse
SEQUENCE_ERROR−2沒有 front frame 就 fuse;helper:沒有 pending front 就 beam,或沒有本 hop 的 beam 就 fuse(不改動任何狀態)
DSP_ERROR−3lane 拒絕該 hop、ring 無法服務目前 delay、far 頻譜不一致,或 fuse 的結果非有限(beamformed 頻譜非有限、有限但極大的權重使投影溢位):mcab 已 self-reset(lane＋estimator＋flow)。helper 的 fuse() 回非 OK 且非 SEQUENCE_ERROR 時(含 mcab 因權重無效回的 INVALID_ARGUMENT)會 reset 整個 helper(flow、SRP、BF、VAD、frame_index)後回傳

每個非 OK 之後,應用要 reset 自己的後級(見 整合時序圖 第 4 節)。fuse 沒有 token 要歸還:從不呼叫 fuse 的應用(NN 後級,enable_post=0)不需要任何「放棄」呼叫,下一個 front 直接接手。

7. mcab 輸出契約(McabFront 與 McabFrame)

欄位內容擁有者／壽命
McabFront.delayMcabDelayState:delay_samples／confidence／solid／changed(另有 estimator_calls／estimator_updates);changed 非零 = 新的可用 alignment generation 在這個 hop 開始(MATCHED 的首次取得,init 或 reset 之後;鎖定中值改變),外部 STFT／OLA 歷史須在產生本 hop 的 frame 之前清除。solid 在 MATCHED 首次取得後保持到 reset。FIXED 與 EXTERNAL_ALIGNED 不會設 changed值複製
McabFront.linear_spectra[4]各 lane formed 頻譜 [n_freqs](音訊尺度),與時域 hop 同一次選擇,別名 lane 自己的 buffer借用;有效至下一次 mcab_process_front()／reset／destroy;reset 不清除,呼叫端必須在 reset 後停讀
McabFront.formed_hop[4]各 lane 的 [hop] formed 時域 hop(供自己做 sqrt-Hann 分析的外部時域波束器)同上
McabFront.aligned_ref[hop] 本 hop 實際餵給四條 lane 的 delay-aligned far(ring 未滿時為 raw ref);給外部 NN 後級(Align-ULCNet far branch)用同上
McabFrame(mcab_fuse() 填)e=beamformed 誤差、y=投影近端、x=lane 0 的 far 頻譜、r2／cn=投影後的殘餘回音／舒適噪音 PSD、far_hop、max_dt／max_sat／all_converged／usable_linear(只計對權重有非零響應的 lane)、clock_drift、delay 旗標;g_res_ctx 恆為 NULL(RES 增益由應用的 aec_res_process() 取得)借用;e 在傳入 beamformed_error 時別名呼叫端的陣列,否則別名 mcab 內 buffer;有效至下一次 mcab_process_front()／reset／destroy;不得寫入

分析 seam 與渲染基底是兩個訊號。四條 lane 都以 enable_res=0／return_res_context=1 建立。lib/aec 的 formed 序列與 error_spec 一律是被選中的線性殘差(沒有 capture 候選),輸出守衛不改動它們;外部 beamformer 與各估計器讀的就是這個分析 seam。輸出守衛只決定每條 lane 的渲染基底(McabFront.render_spectra、guard_active),mcab_fuse() 以同一組權重把它們加成 McabFrame.b;範例鏈渲染 b * gain。

執行期控制與診斷

mcab + 外部 beamformer + 自備 RES 的呼叫範例

產品的波束器在別處時不需要 sample helper:mcab_fuse() 吃呼叫端的權重(和可選的 beamformed 頻譜)。mcab 不算 RES 增益(frame.g_res_ctx 恆為 NULL),RES 由應用用 libaec 的 aec_res_get_mem_size()／aec_res_init() 建(沒有 destroy);aec_config_from_level() 與 mcab_static.c 用的是同一個建構函式,只要把 fft_size 設成 mcab 解析出的值。lane 與 estimator 由應用建立:四條必須是不同物件、新建的(或已 reset),DelayAec 結構本身要活到 mcab_destroy() 之後。可執行版本:mcab_external_static.c(權重是每個 bin 皆 1/4 的等權佔位,要換成產品波束器的權重);參考鏈:tests/conv_chain_mcab.h。以下範例已在 -Wall -Wextra -Werror 下做過語法檢查(platform_alloc()、stream_next4()、product_beamformer() 是你的平台／I/O／波束器佔位;範例省略了 platform_alloc() 回傳值的檢查與記憶體釋放):

McabConfig cfg = mcab_default_config(16000);              /* MATCHED, enable_post=1, capture_proxy_channel=0 */
McabLibs libs;  memset(&libs, 0, sizeof(libs));
AecConfig lane;  McabDelayEstimatorConfig dc;
if (mcab_lane_config(&cfg, &lane) != 0 || mcab_delay_estimator_config(&cfg, &dc) != 0) return -1;
size_t lane_b = aec_get_mem_size(&lane);                  /* 0 = 無效 */
for (int ch = 0; ch < MCAB_CHANNELS; ++ch) {              /* 四條不同的 lane, 物件歸你 */
    libs.lanes[ch] = aec_init(platform_alloc(lane_b, 16), lane_b, &lane);
    if (!libs.lanes[ch]) return -1;
}
DelayAec delay;                                           /* 結構本身也要活到 mcab_destroy() 之後 */
if (dc.required) {                                        /* 只有 MATCHED */
    size_t db = delay_aec_get_mem_size(dc.sample_rate, dc.hop_size, dc.num_filters);
    if (db == 0 || delay_aec_init(&delay, platform_alloc(db, 16), db, dc.sample_rate,
                                  dc.hop_size, dc.num_filters) != 0) return -1;
    libs.delay = &delay;
}
McabMemReq req;
if (mcab_get_mem_requirements(&cfg, &req) != 0) return -1;

if (!p) return -1;                                        /* NULL = 拒絕, 無診斷輸出 */
int nf = mcab_n_freqs(p), hop = mcab_hop_size(p);

/* mcab 沒有 RES: 應用自備一個 AecRes(libaec), config 用 aec_config_from_level、fft 取 mcab 的格點 */
AecConfig res_cfg;  aec_config_from_level(&res_cfg, AEC_LEVEL_BALANCED, cfg.sample_rate);
res_cfg.fft_size = mcab_fft_size(p);
size_t res_b = aec_res_get_mem_size(&res_cfg);            /* 0 = 無效 */

if (!res || !nr || !istft) return -1;
Complex* weights = (Complex*)platform_alloc((size_t)4 * nf * sizeof(Complex), 16);
float* total_gain = (float*)platform_alloc((size_t)nf * sizeof(float), 16);
float* extra_noise = (float*)platform_alloc((size_t)nf * sizeof(float), 16);
Complex* spec = (Complex*)platform_alloc((size_t)nf * sizeof(Complex), 16);
uint32_t rng = MCAB_SAMPLE_CNG_RNG_SEED;

const float *mics, *ref;  float out[512];
while (stream_next4(&mics, &ref, out)) {
    McabFront front;  McabFrame frame;
    int rc = mcab_process_front(p, mics, ref, &front);      /* 共用 delay + 4 條 lane */
    if (rc == MCAB_OK) {
        if (front.delay.changed) { /* 產品波束器若有 STFT/OLA 歷史, 先在這裡清除, 再算本 hop 的權重 */ }
        product_beamformer(&front, weights);                /* 用 front.linear_spectra[4] 算 [4][n_freqs] 權重 */
        rc = mcab_fuse(p, weights, NULL, &frame);           /* NULL: 由 weights 重建 beamformed 誤差 */
    }
    if (rc == MCAB_OK) {
        AecResInput rin;  mcab_sample_res_input(&frame, &rin);
        const float* g_res = aec_res_process(res, &rin);        /* frame.g_res_ctx 在 mcab 恆為 NULL */
        const float* g_nr = mcab_sample_anr_gain(nr, &frame, extra_noise, 1);
        if (!g_res || !g_nr) rc = MCAB_DSP_ERROR;
        else {
            sk_min_f32(total_gain, g_nr, g_res, frame.n_freqs);
            sk_capply_gain_f32(spec, frame.b, total_gain, frame.n_freqs);
            aec_cng_fill(&rng, spec, frame.cn, g_res, g_nr, MCAB_SAMPLE_CNG_NR_GAIN_FLOOR, frame.n_freqs);
            ac_istft_push(istft, spec, out);
            if (!skn_all_finite_f32(out, (size_t)hop)) rc = MCAB_DSP_ERROR;
        }
    }
    if (rc != MCAB_OK) {                                    /* INVALID_ARGUMENT(權重)可修正重試; 其餘一起 reset */
        mcab_reset(p);  aec_res_reset(res);  anr_reset(nr);  ac_istft_reset(istft);
        rng = MCAB_SAMPLE_CNG_RNG_SEED;  memset(out, 0, (size_t)hop * sizeof(float));
    }
}
anr_destroy(nr);
mcab_destroy(p);                                            /* 先 mcab, 再 aec_destroy(lane) ×4; 不釋放任何記憶體 */
for (int ch = 0; ch < MCAB_CHANNELS; ++ch) aec_destroy(libs.lanes[ch]);

本節最重要的一件事:對四條 lane 重新指定 level 是無效操作。四條 lane 都經 mcab_apply_lane_contract() 蓋上 enable_res = 0、return_res_context = 1 與 spatial_linear_context,因此沒有任何一條會走到自己的殘留抑制器;它們各自的地板什麼都不塑形。真正乘上本產品輸出、也真正決定 comfort noise 量的那個 gain,來自唯一一個共用的 post-beam 抑制器(應用自備的 AecRes,mcab 與 helper 都不擁有)——上面的 level setter 針對的就是它,這也是它存在、而不是要呼叫端自己對四條 lane 迴圈呼叫 aec_set_level() 的原因。同理 NR 也只有一個共用實例(對 beamform 後的訊號跑),不是每條 lane 一個。RES 與降噪器都由應用自己初始化與持有;Mcab 與 McabSampleBeam 都沒有 level setter 本身。這一點由 tests/test_mcab_sample_beam.c(應用自備 AecRes 的 level／ramp／split_floor 與 aec_res_reset() 後保留)與 tests/test_mcab_sample_post.c(test_nr_set_level:anr_set_level() 對每個 level)釘住,不是推測。

逐階段耗時(診斷用)

typedef struct McabLastTiming {
    uint32_t delay_us;       /* 共用 delay estimator                 */
    uint32_t frontend_us;    /* 四條 lane:進入主濾波器之前            */
    uint32_t linear_us;      /* 四條 lane:主自適應濾波器(含 far FFT) */
    uint32_t lane_res_us;    /* 四條 lane:AEC post block              */
    uint32_t fuse_us;        /* mcab_fuse()                           */
} McabLastTiming;

void mcab_get_last_timing(const Mcab* p, McabLastTiming* out);

最近一個 hop 每個階段的 wall-clock 成本(微秒,預設用 CLOCK_MONOTONIC)。純診斷:mcab 自己不回讀,也不影響處理。p 為 NULL 或已銷毀時把 out 清零而不是失敗;out 不得為 NULL。欄位:delay_us(update_shared_delay() 的共用 estimator,不含 align_render() 的 ring-buffer 複製與 realign 掃描)、fuse_us(mcab_fuse()),以及四條 lane 加總的 frontend_us／linear_us／lane_res_us。RES(應用自備的 AecRes)、NR、CNG 與逆轉換的耗時由應用自己量,不在這個記錄內。

frontend_us／linear_us／lane_res_us(以及下述 lane 內的 delay_us)由 aec_get_last_timing()(aec.h)逐 lane 讀出後相加(lane 的 steering_us 不在記錄內),受 -DAEC_STAGE_TIMING=1 這個另一半的旗標管轄——只建 mcab 那半(-DMCAB_STAGE_TIMING=1),這幾欄讀 0 而 delay_us／fuse_us 照常量測,是可讀的狀態而非壞掉;make PROFILE=1 同時開啟兩個旗標(AEC 那半經 PROFILE 轉發給 lib/aec 的建置)。應用自己建 lane 時,lane 數字是否有值取決於它連結的 libaec.a 是否以 AEC_STAGE_TIMING=1 建出。lane 內部的 delay_us 也一併加進上面的 delay_us,但它結構上恆為 0:四條 lane 都是 AEC_DELAY_EXTERNAL_ALIGNED,沒有自己的 ring 或 estimator。相加而不是丟棄,是為了讓日後改變 lane 模式時不會靜默漏掉那筆成本。

目標平台沒有 CLOCK_MONOTONIC 時。clock_gettime 是 POSIX 而非 C99。用 make PROFILE=1 EXTRA_CFLAGS='-DMCAB_NOW_US=board_timer_us -DAEC_NOW_US=board_timer_us -include my_timer.h' 換掉時鐘;巨集要是純識別字(FP policy 不允許 EXTRA_CFLAGS 出現括號),指向不收參數、回傳 uint32_t 微秒的函式。替代時鐘必須單調。這層與四條 lane 各有自己的覆寫點,刻意不共用。開著旗標但指向常數函式是合法用法,所有欄位讀 0。

呼叫端若要呈現完整分解,mcab 的未歸屬餘額要自己用減法算:front_total − (delay_us + frontend_us + linear_us + lane_res_us)(front_total 是你自己量的 mcab_process_front() 整段耗時) 涵蓋輸入去交錯／有限值檢查、align_render()、realign 掃描與 lane 迴圈自己的餘額。

mcab_process_front() 在 NULL 引數與已銷毀 handle 的檢查之後把前四個欄位(delay_us／frontend_us／linear_us／lane_res_us)清零,所以中途失敗的 hop(例如非有限輸入)對沒跑到的階段回報 0 而不是上一個 hop 的數字(test_stage_timing 檢查這四欄);fuse_us 只在 mcab_fuse() 清零。因 NULL 引數或已銷毀 handle 被直接拒絕的處理呼叫不動記錄。
