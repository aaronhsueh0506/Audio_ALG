Audio_ALG / 選擇 pipeline

四聲道 · AEC／NR／RES

概要

四聲道線性 AEC 是 libaec 的一個 Aec array instance(AecConfig.n_mics = AEC_ARRAY_MICS,aec.h 的「Array instance」一節),pipelines/4ch/ 另有 sample 層 helper:

  • array(Aec,libaec.a):一次 aec_get_mem_requirements() / aec_init_ex() 在同一塊 pool 內建出共用 DelayAec(MATCHED 才有)、對齊環、4 條 lane(各是 EXTERNAL_ALIGNED 的單支 AEC,config 由陣列衍生)、融合緩衝與唯一一個 residual 增益級(AecConfig.residual = AEC_RESIDUAL_FULL);應用不建 lane、也不建 estimator。每 hop aec_process_linear() + aec_get_array() 交出 AecArrayView,aec_process_residual(&AecBeam{weights, beamformed_error}) + aec_get_residual() 交出融合結果 AecResidualView(error_spec、base_spec、near_spec、r2、comfort_noise、res_gain)。residual 可選 STATE(只有 lane,給直接吃 BF 頻譜的 NN)、ESTIMATE(融合但無增益)或 FULL。
  • sample helper array_sample_beam(array_sample_beam.{h,c};範例碼,不在 archive):擁有 SRP-PHAT DOA 與 BF(audiolib/doa、audiolib/bf)及保守 energy-VAD fallback,把 doa_step() + bf_process_with_weights() 接在 aec_process_linear() 與 aec_process_residual() 之間,輸出 BF 後誤差頻譜與有效權重(ArraySampleBeamResult);array_sample_beam_fuse() 用同一次 BF 呼叫的頻譜與權重呼叫 aec_process_residual()。NR(array_sample_anr_gain())、aec_apply_gain() / aec_apply_cng() 與合成 AcIstft 由應用自己初始化並串接。

結構稽核值:aec_array_matched_filter_count() 在 MATCHED 時 1、其餘 delay_mode 為 0;aec_array_linear_aec_count() 恆 4。Lane 0 每 hop 跑真 far-FFT,lane 1–3 經 aec_process_linear_shared_far_from() 借用 lane 0 的 far 頻譜(4 次 far-FFT → 1 次,測試以 aec_far_fft_real_compute_count() 證明)。支援 16 kHz(fft 256 預設 / 512 明示)與 48 kHz(fft 1024)。

Descriptor 慣例(32-byte 固定 ABI、aec_init_ex() 閘)是 Aec(單支與 array 同一個 AecMemReq)與 DFN2 模型串流／bridge 的;AnrDenoiser、AcIstft 與 sample helper 只提供大小查詢。AEC_LAYOUT_VERSION = 5,descriptor_version 1,涵蓋整個 array pool(lane、estimator、融合與增益級都在內),SRP/BF 在 sample helper。欄位分級、固定常數、函式清單、狀態碼與輸出契約收在 四聲道 參數與診斷。

如何呼叫使用

呼叫順序(括號為失敗訊號):array_sample_default_config(&cfg, sr) 與 array_sample_beam_default_params() → 視需要改欄位 → 查大小(aec_get_mem_requirements() 為整個 array pool,array_sample_beam_get_mem_size() 查 helper;−1 = 無效)→ 配置 16-byte 對齊的 pool → aec_init_ex()(NULL = 拒絕,無診斷輸出)→ array_sample_beam_init()(NULL = 拒絕)→ NR／合成各自查大小與 init → 每 hop → 失敗時 reset → 先 helper、再 array 拆除。

array + helper(含 SRP/BF)+ NR + 合成

AecConfig cfg;
array_sample_default_config(&cfg, 16000);                       /* 建立前可改 cfg 欄位(見 pipeline_4ch_params) */
ArraySampleBeamParams bp = array_sample_beam_default_params();   /* 陣列幾何、SRP/BF 參數 */
AecMemReq req;  size_t beam_b;
if (aec_get_mem_requirements(&cfg, &req) != 0 ||                 /* -1 = 無效 */
    array_sample_beam_get_mem_size(&cfg, &bp, &beam_b) != 0) return -1;
size_t aec_b = ALIGN16((size_t)req.bytes);
void* aec_mem = platform_alloc(aec_b, req.alignment);
void* beam_mem = platform_alloc(beam_b, 16);
Aec* aec = aec_init_ex(aec_mem, aec_b, &cfg, &req);          /* 一個 Aec array:4 條 lane + 共用 DelayAec + 融合 + 增益級 */
if (!aec) return -1;                                             /* NULL = 拒絕, 無診斷輸出 */
ArraySampleBeam* b = array_sample_beam_init(beam_mem, beam_b, &cfg, &bp, aec);
if (!b) return -1;

/* NR、合成: 應用自己的 init, 另一塊 post pool, 格點取 cfg 的值 */
int fft = cfg.fft_size, hop = aec_hop_size(aec), nf = hop + 1;
AnrConfig nr_cfg = anr_config_for_level_grid(cfg.sample_rate, fft, ANR_LEVEL_BALANCED);
AcStftConfig syn_cfg;  ac_stft_config_default(&syn_cfg, fft);
size_t nr_b = anr_get_mem_size(&nr_cfg), syn_b = ac_istft_get_mem_size(&syn_cfg);
if (!nr_b || !syn_b) return -1;                              /* 0 = 無效 */
size_t vec = ALIGN16(nf * sizeof(float)), cvec = ALIGN16(nf * sizeof(Complex));
uint8_t* post = (uint8_t*)platform_alloc(ALIGN16(nr_b) + ALIGN16(syn_b) + vec + cvec, 16);
AnrDenoiser* nr = anr_init(post, nr_b, &nr_cfg);
AcIstft* istft = ac_istft_init(post + ALIGN16(nr_b), syn_b, &syn_cfg);
if (!nr || !istft) return -1;
float* extra_noise = (float*)(post + ALIGN16(nr_b) + ALIGN16(syn_b));
Complex* spec = (Complex*)(extra_noise + vec / sizeof(float));
uint32_t handled = 0;                                        /* 已處理的 v.post_reset_serial */

const float *mics, *ref;  float out[512];
while (stream_next4(&mics, &ref, out)) {
    ArraySampleBeamResult beam;  ArraySampleBeamInfo info;  AecResidualView v;
    const float* g_nr = NULL;
    int vad = product_vad(mics);                            /* 沒有產品 VAD 時改呼叫 array_sample_beam_process() (內建 energy VAD) */
    int rc = array_sample_beam_process_with_activity(b, mics, ref, vad, vad, NULL, &beam, &info);
    if (rc == AEC_OK) rc = array_sample_beam_fuse(b, &v);    /* aec_process_residual + aec_get_residual;STATE 的 array 回 AEC_ERR_MODE */
    if (rc == AEC_OK) g_nr = array_sample_anr_gain(nr, &v, extra_noise, 1);   /* NR 在 v.error_spec(E)上估計;NULL = 被拒 */
    if (g_nr) {
        if (array_sample_post_reset_due(&handled, &v))       /* 某條 lane 本 hop 硬重置:在 CNG 第一次抽樣之前清合成尾巴(種子由 array 自己重設) */
            ac_istft_reset(istft);
        if (aec_apply_gain(aec, g_nr, spec) != AEC_OK ||   /* P = v.base_spec * min(G_nr, G_res) */
            aec_apply_cng(aec, g_nr, spec) != AEC_OK) g_nr = NULL;   /* 補 RES 切掉的 bin;同一個 G_nr */
        else {
            ac_istft_push(istft, spec, out);                /* 一次 iFFT/OLA */
            if (!skn_all_finite_f32(out, (size_t)hop)) g_nr = NULL;
        }
    }
    if (!g_nr) {                                            /* 任一步被拒或輸出非有限: helper(含 array)與後級一起 reset */
        array_sample_beam_reset(b);  anr_reset(nr);  ac_istft_reset(istft);  handled = aec_post_reset_serial(aec);
        memset(out, 0, (size_t)hop * sizeof(float));
    }
}
anr_destroy(nr);
array_sample_beam_destroy(b);  aec_destroy(aec);                      /* 先 helper, 再 array; 都不釋放 caller 記憶體 */
platform_free(post);  platform_free(beam_mem);  platform_free(aec_mem);
return 0;

有 VAD 用 process_with_activity()(如上),沒有則 array_sample_beam_process()(內建 energy VAD)。要由 lane 頻譜算 mask／VAD 時拆成 array_sample_beam_process_front(b, mics, ref, &front) → 在 front.lane_error_spec 上算 mask → array_sample_beam_process_beam(b, &front, vad_raw, vad_out, mask, &beam, &info)。外部 NN 後級(如 ULCNet)用 cfg.residual = AEC_RESIDUAL_STATE、不呼叫 array_sample_beam_fuse(),把 beam.spectrum 拆成 re／im 平面交給 ulcnet_stream_pre_process_freq()(四聲道 · Align-ULCNet)。

只用 array + 自備 beamformer

產品的波束器在別處時不需要 helper:aec_process_linear() + aec_get_array() → 自己的 beamformer → aec_process_residual(a, &beam) + aec_get_residual() → 同樣的後級。完整、已語法檢查的範例在 四聲道 參數與診斷;可執行範例是 4ch_external_static.c。

換用別的後級(例如 DFN2)。array 只交出 AecResidualView(error_spec 是 pre-RES 誤差頻譜,base_spec 是渲染基底 B,輸出守衛未觸發時等於 E,comfort_noise／r2 是同一次投影的 PSD);神經後濾波用 aec_apply_gain(aec, NULL, P) 自己組 P = B · G_res (+ comfort noise)(B = base_spec;估計仍用 error_spec),現成消費者是 四聲道 · DFN2。

強度只有一處:array 唯一的增益級(aec_set_level(aec, level))與你擁有的降噪器(anr_set_level());helper 沒有 setter,四條 lane 自己的 level 是無效操作。呼叫表、ramp 與逐階段耗時診斷(aec_array_get_timing())見 四聲道 參數與診斷。

 ├─ array_sample_beam_process_front(b, mics, ref, &front)
 │    └─ aec_process_linear(aec, mics, ref) + aec_get_array(aec, &front)

 │         ├─ update_shared_delay(): delay_aec_accumulate_ex(proxy_ch, ref, run)
 │         │     eligible = est>=0 && solid && n_updates>=3 → aec_delay_admission_offer() → accepted_delay
 │         ├─ align_render(): 共用 delay ring → aligned_ref[hop]
 │         ├─ delay.changed → aec_apply_external_realign(lane 0..3, Δdelay)
 │         └─ 4 lanes: lane0 aec_process_linear(mic0, aligned_ref)

 │                     每條 lane 接著 aec_process_residual(NULL)(r2、comfort noise);bind_lane_view() → front.lane_error_spec / lane_formed_hop(借用 lane buffer)
 ├─ [可選: 由 front.lane_error_spec 算 mask / vad_raw / vad_out]
 ├─ array_sample_beam_process_beam(b, &front, vad_raw, vad_out, mask, &beam, &info)
 │    ├─ doa_step(srp, front.lane_error_spec, mask, vad_raw, vad_out)    SRP-PHAT
 │    └─ bf_process_with_weights(bf, front.lane_error_spec, doa_get_smooth(srp),
 │            vad_out?0:1, mask, bf_spectrum, bf_weights)              BF(RLS) → beam.spectrum / beam.weights
 ├─ array_sample_beam_fuse(b, &v)   (residual != STATE) → aec_process_residual(aec, &{bf_weights, bf_spectrum}) + aec_get_residual(aec, &v)

 │      ├─ fuse_contexts(): 用同一組 weights 投影 near / residual / comfort(結果非有限 → AEC_ERR_DSP)
 │            residual_vec[k] = sqrt(r2[k])·echo[k]/|echo[k]| (取 echo 相位,|residual_vec|² == max(r2,0))
 │            v.r2 = |Σ_ch w·residual_vec|²(coherent);v.comfort_noise = Σ_ch |w|²·cn
 │      └─ FULL: array 的增益級對融合後的頻譜算 G_res(v.res_gain)
 └─ array 之外(各 main 的逐 hop 區段, 例如 array_sample_unit.h 的 array_sample_stages_chain())
        array_sample_anr_gain(nr, &v, extra_noise, 1) → G_nr   (1 個 mono NR; NULL = 被拒)
        aec_apply_gain(aec, G_nr, spec)    (spec = v.base_spec × min(G_nr, G_res))
        aec_apply_cng(aec, G_nr, spec)     (sqrt(1-res²)·sqrt(cn/32768²)·max(nr, AEC_CNG_NR_GAIN_FLOOR=0.316) × 隨機相位;種子由 array 自己管)
        ac_istft_push(istft, spec, out)   (AcIstft: fft_inverse + sqrt-Hann OLA) → out[hop]

範例一律建 RES(array 的增益級);換用別的後級(例如 DFN2、ULCNet)就是換掉最後一個方塊裡的幾行,array 與 helper 不變。

延遲與 warm-up

  • 演算法延遲:1 hop(WOLA;實測 argmax 127 samples @hop=128 → 8 ms @16k 預設)。
  • delay acquisition:估計值要 solid 且 n_updates≥3 才被接受;開始新的可用 alignment generation 的那個 hop 回報 delay.changed=1——MATCHED 的首次 acquisition(init 或 reset 之後)與鎖定中值改變(移動 > 32 樣本且 16 樣本內再次被提出)才會;FIXED／EXTERNAL_ALIGNED 不設(見 aec.h 的 AecDelayState 契約),array 對四條 lane 做 aec_apply_external_realign()(濾波器依 delay 差位移,不重置);外部 beamformer 若自帶 STFT/OLA 狀態,應照 changed 清除。ring 未累積到 delay 樣本前 aligned_ref 為 raw ref。
  • SRP/BF warm-up:DOA 平滑值為 NaN(尚無可用 DOA)時 BF 旁路取 mic 0 且不適應;DOA smoother 需 doa_switch_consecutive=3 次一致觀測才切換;BF RLS 由 vad_out 凍結(vad_out=1 → 凍結適應)。
  • NR 噪聲底的最小值追蹤視窗是函式庫預設的 wall-clock 約 512 ms。
