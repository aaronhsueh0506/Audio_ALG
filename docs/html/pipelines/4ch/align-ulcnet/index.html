Audio_ALG / 選擇 pipeline

四聲道 · Align-ULCNet

概要

pipelines/4ch/alignulcnet/main.c:沿用四聲道線性 AEC array(Aec,AecConfig.n_mics = AEC_ARRAY_MICS:共用 delay + 4 AEC lanes,見 四聲道 · AEC／NR／RES)與 sample 層 helper ArraySampleBeam(SRP-PHAT + BF),array 以 residual = AEC_RESIDUAL_STATE 建立(ulcnet_example_unit_config(&grid):array_sample_default_config(&cfg, grid.sample_rate) 加 fft_size = grid.n_fft 與 residual = STATE)——每 hop 不呼叫 array_sample_beam_fuse()(回 AEC_ERR_MODE),後級(RES／NR／CNG／ISTFT)不使用,由 Align-ULCNet 模型串流的頻譜進出口(stream/aiaec/ulcnet/ulcnet_stream.{h,c} 的 ulcnet_stream_pre_process_freq()／ulcnet_stream_post_process_freq())完全取代;沒有 token,也不需要「放棄」呼叫,下一個 process_* 直接接手。此例透過 ulcnet_stream 的頻譜進出口串接:四條 lane 與共用 estimator 在 array 的 pool 內(範例用 aec_init_ex() 建),array 加 helper 是一塊 pool(aec_get_mem_requirements()、array_sample_beam_get_mem_size()),串流另一塊(ulcnet_stream_get_mem_size(),有自己的 descriptor UlcnetStreamMemReq 與 ULCNET_STREAM_LAYOUT_VERSION),再加應用端自己的 far AcStft／輸出 AcIstft 與頻譜平面一塊。串流只吃三樣東西:BF 後頻譜(beam.spectrum,拆成 re／im 平面)、同一次呼叫原始 far hop 的頻譜(應用端 ac_stft_push_planar() 得到)、info.delay.changed／info.delay.solid。格點是執行期值:UlcnetGridSpec 經 ulcnet_grid_make() 得 UlcnetGrid(16 kHz / 512 / hop 256 / 257 bins或48 kHz / 1024 / hop 512 / 513 bins),main.c 以 --sample-rate 16000|48000 從兩列的表選,同一個 binary 兩者都能跑;unit 與串流必須同一個 grid,main.c 在 init 後比對 aec_hop_size() 與 grid.hop／grid.n_bins。

直送路徑(direct path):BF 的輸出頻譜就是模型的 error 幀。bf_process_with_weights() 產出的 bf_spectrum 已經是「當前 hop 的 sqrt-Hann、50% overlap、一 hop 一幀」分析幀——各 lane 的 AEC 用同一張窗、同一個 overlap 分析,beamformer 只是逐 bin 加權——所以它不經過任何重建或再分析,直接拆成 err_re/err_im 交給模型。far 分支用同一個 hop 的原始 far 走同樣的一 hop 一幀 framing(應用端的 ac_stft_push()),沒有補償 buffer。

ONNX/NPU graph 邊界與 runtime 保存的 NN states 與 mono 變體完全相同(graph 內:reorient/attention/GRU/mask 組合, learned compute only;graph 外:STFT/WOLA/AEC/beamform/delay policy＋固定前後端(signed-pow 壓縮特徵/mask 乘法/逆冪, 封在 ulcnet_model_io_prepare()／_enhance_spectrum();graph 止於 complex_mask 1×1 Conv);runtime 保存 far K/V window、logit window、GRU h;四個 state 屬於應用端(板端在加速器裡、登錄 NULL;float host 登錄緩衝),每個 *_out 就地綁定到同名輸入的位址)——見 Mono · Align-ULCNet 的邊界表。VAD 由呼叫端交給 helper 的 array_sample_beam_process_with_activity()(板端骨架 main.c 以固定的 0／0 帶入;helper 另有 auto-VAD fallback 的 array_sample_beam_process(),本範例不用)。

API 用法

呼叫順序:ulcnet_grid_make()、array_sample_default_config(&cfg, grid.sample_rate) 改 fft_size 與 residual = AEC_RESIDUAL_STATE → aec_get_mem_requirements()、array_sample_beam_get_mem_size()、ulcnet_stream_get_mem_size()、ac_stft_get_mem_size()／ac_istft_get_mem_size() → ulcnet_model_io_descriptor_default() 與 ulcnet_model_io_descriptor_validate()(板端換成模型匯出的 descriptor) → aec_init_ex()、array_sample_beam_init(…, aec)、ulcnet_stream_init_ex()、ac_stft_init()、ac_istft_init() → 每 hop 一次 → destroy(array_sample_beam_destroy() 再 aec_destroy())。完整可編譯範例、流程時序圖與參數表收在 Align-ULCNet pipeline 呼叫與時序、Align-ULCNet pipeline 呼叫與時序 與 Align-ULCNet pipeline 參數與狀態。每 hop 的核心如下:

ArraySampleBeamResult beam;  ArraySampleBeamInfo info;    /* unit = ArraySampleBeam*;mics=[grid.hop][4], far/out=[grid.hop] */
UlcnetHopIO io;  int pre, ai_rc = -1, ok;
ok = array_sample_beam_process_with_activity(unit, mics, far, vad, vad, NULL, &beam, &info) == AEC_OK;
if (ok) {
    ac_stft_push_planar(far_stft, far, far_re, far_im);
    for (k = 0; k < grid.n_bins; ++k) { err_re[k] = beam.spectrum[k].r;  err_im[k] = beam.spectrum[k].i; }
    pre = ulcnet_stream_pre_process_freq(stream, err_re, err_im, far_re, far_im,
              (UlcnetStreamDelay){ info.delay.changed, info.delay.solid }, &io);
    if (pre == 1) ai_rc = run_accelerator(NULL, &io.inputs, &io.outputs);   /* 1 = 本 hop 有一幀;0 = reprime hop */
    ok = pre >= 0 && ulcnet_stream_post_process_freq(stream, ai_rc, out_re, out_im) == 1 &&
         ac_istft_push_planar(istft, out_re, out_im, out) == grid.hop;
}
if (!ok) {
    array_sample_beam_reset(unit);  ulcnet_stream_reset(stream);      /* 被拒: 一起 reset，連同應用端的 AcStft／AcIstft */
    ac_stft_reset(far_stft);  ac_istft_reset(istft);
}

推論夾在 pre_process_freq(回 1 並交出 UlcnetHopIO;0 = 本 hop 無模型幀;−1 = 契約錯誤,例如同一 hop 第二次呼叫)與 post_process_freq(ai_rc) 之間;ai_rc != 0、mask 沒寫滿或 mask／輸出有非有限值時該幀走 identity(fail-open)。reprime 計數在 pre_process_freq 遞減。

板端若有由同一 hop 的 lane 頻譜算出的 per-bin mask 與 VAD(例如 masker 讀 lane 0),helper 的 array_sample_beam_process_with_activity() 要在 lane 與 beamformer 之間讓出控制權:它就是 array_sample_beam_process_front() 加 array_sample_beam_process_beam(front, v, v, NULL)。

AecArrayView front;
array_sample_beam_process_front(unit, mics, far, &front);    /* = aec_process_linear() + aec_get_array():共用 aligner 與四條 lane;front.lane_error_spec[4] 唯讀 */
/* 呼叫端:由 front.lane_error_spec[0] 算 mask(n_freqs 個 int)、vad_raw、vad_out */
array_sample_beam_process_beam(unit, &front, vad_raw, vad_out, mask, &beam, &info);   /* SRP-PHAT、BF;mask 可為 NULL */
/* info: doa_raw/smooth/used(rad,NaN = 無)、bf_adaptive、delay */
ac_stft_push_planar(far_stft, far, far_re, far_im);          /* 再把 beam.spectrum 拆成 err_re／err_im */
pre = ulcnet_stream_pre_process_freq(stream, err_re, err_im, far_re, far_im,
          (UlcnetStreamDelay){ front.delay.changed, front.delay.solid }, &io);
/* 之後的推論、post_process_freq 與合成與上面相同 */

mask[f] 非 0:SRP 使用該 bin、BF 凍結該 bin 的適應;NULL = 全部 bin 給 SRP、都不凍結。vad_raw 決定 SRP 該 hop 是否分析,vad_out 進 DOA smoother 並凍結 BF 適應(須為 0／1)。front.lane_error_spec 有效至下一次 process_front()／process_with_activity()／reset()／destroy();沒有待處理的 front 時 process_beam() 回 AEC_ERR_SEQUENCE。DOA 與 BF 適應狀態在 ArraySampleBeamInfo(info);aec_array_get_timing() 回上一 hop 的各階段微秒數(需以 -DAEC_STAGE_TIMING=1 建置,否則為 0)。

  • 模型 descriptor:production far branch 固定為 caller 的 raw far。main.c 在建串流前以 ulcnet_model_io_descriptor_validate() 核對模型匯出的 descriptor(aligned、別的 grid、未知 layout 都 reject),並要求一幀一包(ulcnet_model_io_descriptor_frames() == 1)。runtime 不提供 far-mode setter。
  • 唯讀 accessor:array 的尺寸查詢(aec_hop_size(),n_freqs = hop + 1;aec_resolve_signal_grid())、aec_array_get_timing()。沒有 beam hop:直送路徑不重建時域 beam hop,helper 的輸出是 beam.spectrum 與 beam.weights(array_sample_beam.h)。

沒有執行期強度 setter,而且是刻意的。標準 4ch 範例有 aec_set_level() / anr_set_level(),作用在 array 的增益級與應用自建的 AnrDenoiser 上(見 四聲道 · AEC／NR／RES 的「執行期強度控制」表);本變體沒有這兩個物件,因為 array 是 residual = STATE 的 front-only 組態,不 carve 融合緩衝與增益級(要 RES 的應用改用 FULL,在 aec_process_residual() 之後取增益),塑形輸出的是 ULCNet 的 mask。要改強度,請重新訓練/更換模型,或改用有 DSP 後級的 pipeline_4ch。

唯一的延遲來源是應用端 ULCNet synthesis 的半窗疊加:每 hop 輸出 = 當幀合成窗前半 + 前一幀留下的後半,ac_istft_push_planar()（AC_OLA_ACCUMULATE）每 hop 都回一個完整 hop,hop#0 也是(前一幀為零歷史)。兩個分支都從當前 input hop 取幀,所以模型看到的 err/far 幀對永遠屬於同一個 input hop——直送路徑沒有 one-hop far 補償 buffer;test_raw_far_timestamp_after_fixed_delay_lock() 要求 far 脈衝落點的 offset 為 +0。

err 分支讀的是分析 seam。四條 lane 以殘餘階段 STATE 建立(只有線性半邊);各 lane 的 error_spec 一律是被選中的線性殘差,輸出守衛不改動它,BF 加權出來的 err 幀(beam.spectrum)就是這些殘差的加權和,沒有 capture 候選(殘差與 seam 的細節見 Mono · Align-ULCNet)。各 lane 的渲染基底(AecArrayView.lane_base_spec)不餵給模型;identity／fail-open 的 hop 輸出未經守衛的殘差。

Identity reprime(alignment 邊界,option A)

邊界處理只做模型 state 重啟(state generation 加一)與武裝 identity reprime,不動應用端的 framing:從邊界 hop 起的 ULCNET_STREAM_REPRIME_FRAMES(= 1)個發射幀走 identity 且沒有模型幀;reprime 期間再來一次邊界會重新武裝(不累加);ulcnet_stream_reset() 會把它歸零(應用端的 AcStft／AcIstft 要一起 reset)。常數 1 由 tests/test_4ch_ulcnet.c 的 test_reprime_straddle_derivation() 在無邊界對照跑中以脈衝標記量出(ERROR 路是上界、FAR 路是推導);兩個 grid 的實測表見 Align-ULCNet pipeline 參數與狀態。

State 表

Pool 切分(main.c,三塊各自對齊):unit pool = array(aec_init_ex():四條 lane、共用 estimator、對齊環與控制區,AEC_LAYOUT_VERSION = 3 描述整個 array pool)接 SRP/BF helper(array_sample_beam_init();SRP、BF、bf_spectrum、bf_weights),見 四聲道 · AEC／NR／RES;residual = STATE 所以不含融合緩衝與增益級。第二塊是 串流 pool(ulcnet_stream_get_mem_size():16 kHz 103,312 B、48 kHz 202,640 B;descriptor UlcnetStreamMemReq 由 ulcnet_stream_init_ex() 核對),第三塊是應用端的 framing pool(far AcStft、輸出 AcIstft 與六段 float 頻譜平面:16 kHz 49,920 B、48 kHz 98,048 B)。串流 pool 內是控制塊、FftHandle、PCM 進出口用的兩個 AcStft 與一個 AcIstft(頻譜進出口不呼叫它們)、UlcnetPrepost(特徵張量、mask 與增強頻譜暫存)與 scratch;error 幀直接取自 beam.spectrum,所以應用端沒有 error 分析物件。grid 是執行期值,跨 grid 的串流與 unit 不可互換:範例在 init 後比對 aec_hop_size() 與 grid.hop／grid.n_bins,不符即失敗(4ch/alignulcnet/main.c)。

頻譜一致性註記(直送路徑的已知取捨)

beam.spectrum(BF 輸出)是逐 bin 加權的頻譜,一般不對應任何時域訊號的 STFT(inconsistent spectrogram);模型看到的就是這個未經 WOLA 投影的頻譜。輸入端的差異在真實 4ch 錄音上的大小與頻帶分佈待量測;輸出端不受影響(WOLA∘STFT∘WOLA 等於 WOLA)。

延遲與 warm-up

  • 總附加演算法延遲 = 1 個 grid hop:16 kHz 為 256 samples / 16 ms,48 kHz 為 512 samples / 10.67 ms。組成只有 ULCNet synthesis 的半窗 trim;BF 頻譜與 far 分析都在同一個 hop 完成,不加延遲。
  • 測試佐證:鎖定後 raw far 脈衝落點 = 脈衝 + 1 hop。測試把模型每 hop 拿到的 far 頻譜自己合成後找脈衝。16 kHz:far[2085] → [2341](expected 2341,offset +0,peak 1.0000);48 kHz:far[4133] → [4645](offset +0,peak 1.0000)。identity E2E:out[hop p] 逐 byte 等於測試自己從「模型實際看到的頻譜」經 mask = 1 的 mask 算術後合成的累加參考(capture model,FIXED delay 0、無邊界;mask = 1 與原頻譜只差壓縮的捨入,2e-6 內;累加規則:每個 hop = 當幀 IFFT 乘合成窗的前半 + 前一幀留下的後半,hop 0 的前一幀為零歷史;identity 時 hop 0 的前半窗是零歷史所以接近零,mask 改變頻譜時 hop 0 不為零)。
  • delay change(front.delay.changed)或 FIXED 首次 delay solid:串流讓 state generation 加一並武裝 identity reprime,不動應用端的 buffer(前端自行 realign 四條 lane;應用端的 far 分析與 synthesis 連續跑)。跨界的 1 幀改走 identity 且不 step 模型(見上節)。changed 涵蓋 unlock 後同值重鎖(新的可用 alignment generation),因此 unlocked 期間累積的 recurrent state 會在重新套用前被 flush。
  • delay lock 不閘控模型:模型從第一個 hop 起照常步進並套用(far 恆為 caller 的 raw far);alignment 可用或改變時 reset state。
  • 錯誤處理:helper 或串流回負值(尺寸不符、front 回錯誤、序列錯誤),或應用端 ac_istft_push_planar() 吐出的樣本數不是整 hop → 整合者把 helper(連帶 array)、串流與應用端的 AcStft／AcIstft 一起 reset(ulc_process():array_sample_beam_reset()、ulcnet_stream_reset()、ac_stft_reset()、ac_istft_reset());1-hop 前導重新開始。
