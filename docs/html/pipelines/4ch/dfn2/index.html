Audio_ALG / 選擇 pipeline

四聲道 · DFN2

概要

pipelines/4ch/aec_bf_dfn_res/main.c:建在四麥克風 Aec array(aec.h,AecConfig.n_mics = AEC_ARRAY_MICS:共用 delay、四條線性 AEC lane、投影融合與唯一一個 RES 增益級)與 sample 層的 SRP-PHAT／BF helper(array_sample_beam.h)上的範例,把傳統鏈的 post-beam MMSE-LSA 換成 DeepFilterNet2。array 在 libaec.a 內,沒有獨立的 archive;一次 aec_get_mem_requirements() / aec_init_ex()(範例在一塊記憶體內建好)在同一塊 pool 內建出四條 lane、MATCHED 下共用的 DelayAec、融合緩衝與增益級,應用不建 lane、也不注入任何物件。範例另外建 dfn/dfn_hop.h 的 DfnHop(模型串流 DFN2Stream,16 kHz 時外加 rate bridge AinrBridge);DFN2 尾段由 dfn/dfn_hop_pool.h 算大小並切塊,main.c 加上 array、helper 與 P 緩衝。

每 hop 呼叫 array_sample_beam_process()(aec_process_linear() 加 helper 的 SRP-PHAT、BF 與 fallback VAD)與 array_sample_beam_fuse()(轉呼叫 aec_process_residual() 並以 aec_get_residual() 填 AecResidualView,res_gain 是 array 增益級的輸出),再以 aec_apply_gain(aec, NULL, post) 形成 P。範例自己擁有 P 緩衝、comfort-noise 開關與(48 kHz 時)ISTFT,在 dfn_form() 明寫 aec_apply_gain(選用 aec_apply_cng)形成 P,再把 E、P 交給 DfnHop,由它驅動模型串流層 stream/ainr/dfn2 的 dfn2_stream_pre_process_freq_dual()／dfn2_stream_post_process_freq()(記憶體模式;舊的 pipelines/dfn/dfn_res_stage.{h,c} 仍在封存檔內,範例不再呼叫,兩條路徑逐位元一致);array 不含 NR／合成,也不含 beamformer(自家 beamformer 的產品見 四聲道 · AEC／NR／RES)。中段的 DFN2 與 mono 是同一份程式碼,signal/timing 契約見 Mono · DFN2,本頁只寫四聲道特有的部分。

核心跑產品自己的取樣率(預設 16 kHz),只有 DFN2 模型在模型的取樣率(出貨 48 kHz)。--sample-rate 接受 16000 或 48000,沒有 8 kHz。48 kHz 時模型串流直接吃核心的頻譜;16 kHz 時範例改建一個 AinrBridge(stream/ainr/bridge/ainr_bridge.{h,c},本身不含模型)負責原生格點 ↔ 48 kHz 的來回,每個 native hop 進一個、出一個。四條 AEC lane、SRP-PHAT／BF、RES 與 CNG 一律留在產品取樣率,呼叫端不必在 API 之外先 resample。Bridge 的排程、prefill 與 added delay 與 mono 共用(Mono · DFN2)。

估計用 E、套用在 P(四聲道版本)

E = v.error_spec(AecResidualView,pre-RES 的 beamformed 線性誤差頻譜)只送進網路做估計;P = dfn_form() 組出的頻譜(B * G_res + comfort noise,B = v.base_spec 渲染基底,輸出守衛未觸發時等於 E)才是三個 head 套用的對象;理由與 mono 相同,comfort-noise fill(--cng 才開)預設關閉。

API 用法

呼叫順序:參數解析時以 dfn2_grid_make() 建出模型 grid,讀 ERB 矩陣(--erb-fwd／--erb-inv)、查大小、切塊、init(aec_init_ex() → array_sample_beam_init(…, aec) → dfn_hop_pool_build())→ 每 hop 一次 → dfn_cleanup()(helper、array destroy,再釋放 pool;DFN2 尾段沒有 destroy)。每個 hop:array_sample_beam_process()、array_sample_beam_fuse()(沒有本 hop 的 beam 回 AEC_ERR_SEQUENCE)、自寫的 P 形成(aec_apply_gain),再 dfn_hop_process() 一次收尾,或用 dfn_hop_begin → nn_begin／nn_end 迴圈 → dfn_hop_end 自己在中間跑加速器(DfnHop 的 phase 擋次序);每次 dfn_hop_end 寫出剛好一個核心 hop(16 k/256 為 128、16 k/512 為 256、48 k/1024 為 512)。範例、時序圖與參數表見 usage、sequence、params。每 hop 的核心:

ArraySampleBeamResult beam;  AecResidualView v;                    /* unit = ArraySampleBeam*, aec = array */
array_sample_beam_process(unit, mics_interleaved /* [hop][4] */, ref, &beam, NULL);   /* delay、4 lane、SRP-PHAT、BF */
array_sample_beam_fuse(unit, &v);                          /* = aec_process_residual(aec, &{beam.weights, beam.spectrum}) + aec_get_residual */
moved = array_sample_post_reset_due(&handled, &v);        /* v.post_reset_serial 變動:某條 lane 本 hop 硬重置 */
if (hop.bridge) { if (moved) ainr_bridge_reset_synthesis(hop.bridge); } /* 16 kHz:只清橋內原生合成的 OLA 尾巴 */
else {                                                      /* 48 kHz:每 hop 位移一格的 shift register(從 0 起) */
    reset_pending = (reset_pending << 1) | moved;
    if ((reset_pending >> dfn_hop_lookahead_frames(&grid)) & 1u) ac_istft_reset(hop.istft);   /* 只清呼叫端的合成 */
}                                                           /* comfort-noise 種子由 array 自己重設 */
aec_apply_gain(aec, NULL, post);                          /* P 必須在 dfn_hop_begin 之前形成:P = B * G_res，B = v.base_spec */
if (cng_on)                                                /* 預設關: B 與 P 要同相位 */
    aec_apply_cng(aec, NULL, post);

dfn_hop_process(&hop, v.error_spec, post, out);           /* (a) 一次完成:模型由 model.infer 執行(沒設就是 identity) */
/* (b) 或自己在中間跑加速器:dfn_hop_begin → while (dfn_hop_nn_begin() > 0) { 跑 NPU; dfn_hop_nn_end(rc) } → dfn_hop_end(&hop, out) */

pool plan、模型串流與 bridge 的 reject-first 清單(最容易踩到的是 erb_inv 必須是 partition of unity,由 dfn_hop_pool_build() 拒絕)見 DFN2 pipeline 參數與狀態。helper 的 process／fuse 回非 AEC_OK(array_sample_beam_fuse() 的 DSP 類拒絕已 reset helper 與 array)、aec_apply_gain() 回非 OK、dfn_hop_* 回負值,整合者都要把 helper(array_sample_beam_reset(),連帶 reset array 的 lane、estimator 與增益級)與 DfnHop 一起 reset(main.c 的 dfn_reset())。

訊號泳道圖

48 kHz 核心的泳道與 mono 完全相同:每 hop 一次推論(前 M 個 hop 沒有 job,模型不跑),模型串流前 L 個 hop 輸出全零頻譜,之後第 p 個 hop 輸出「傳統核心的 hop#(p-L)」(出貨 pair:M=1、L=2,合計 3 hop = 1536 samples);四聲道前級不加延遲。16 kHz 核心多了 bridge 的第二個時鐘:

E 與 P 一路都是兩個指標。AecResidualView.error_spec 與 dfn_form() 組出的 P 緩衝是分開的兩塊,dfn_hop_begin() 的 E／P 換成 model scale 後分別送進 dfn2_stream_pre_process_freq_dual() 的 est／app(見 Mono · DFN2 同名註)。

  • 16 kHz 不是逐位元等值:訊號走過兩顆 FIR resampler,測試用容差(0.35 fs 低通後閘 < 1e-3,現查 8.70e-06 / 8.91e-06),延遲本身由近端脈衝精確釘住。
  • Warm-up:開頭的輸出是全零(長度見上),DfnHop 寫滿零頻譜並無條件合成。前 M 幀沒有 job(模型不跑,state 與 generation 不動);48 kHz 其餘每 hop 恰好一次推論,16 kHz 照泳道圖排程。
  • AEC delay 改變不 reset 模型串流/bridge。front.delay.changed(AecArrayView.delay)仍回報給外部 far-end 消費者,但模型串流與 bridge 不消費 far-end,輸入在 delay 改變後仍然連續。只有整合者的 reset(dfn_hop_reset(),連帶 model.reset)才重置它們;array_sample_beam_fuse() 的 DSP 類拒絕只重置 helper 與 array,範例在任何失敗處再把 DfnHop 一起 reset。收尾 flush 再推 L+1 個全零 hop(16 kHz 推滿 added delay),那幾拍加速器也要照跑。
