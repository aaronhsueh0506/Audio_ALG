mono AEC(linear) → echo-aware NR → RES — Aec + 各 main 自寫的逐 hop 串接

概要

mono 沒有包起來的模組,也沒有 pipeline 函式庫(沒有 mono archive,也沒有共用的串接 header)。處理鏈由獨立的函式庫物件組成,各有自己的 mem_size 與 init,初始化與逐 hop 串接都是整合者(範例 main)的事:lib/aec 的 Aec(線性 AEC,連同它自己的 RES 增益,aec_process_context())→ aec_get_res_context()(填 AecResContext,RES 增益在 ctx.res_gain)→ anr_process_gain() 與 anr_get_gain()(echo-aware NR 增益;有可用的線性估計時 ctx.r2 先經 sk_scale_f32 摺進噪聲底)→ sk_min_f32(g_total=min(g_nr,g_res))→ sk_capply_gain_f32(頻譜套 gain)→ aec_cng_fill(CNG,有 RES 增益且設定允許時)→ ac_istft_push(irfft + sqrt-Hann OLA)。NR 的 AnrDenoiser 與合成的 AcIstft 是普通的函式庫物件,由 main 以 anr_get_mem_size()／anr_init()(anr_config_for_level_grid(),追蹤視窗 L 用函式庫預設)與 ac_istft_get_mem_size()／ac_istft_init() 自己 carve。沒有包起來的鏈物件、沒有 ABI、沒有 layout version、沒有 descriptor。mono_aec_nr_res/main.c 是這個組合的範例,同一份原始碼編成兩支執行檔:aec_nr_pipeline_static(一塊 caller pool,另有 --print-mem-size)與 aec_nr_pipeline(-DAEC_NR_POOL_SPLIT=1:AEC 一塊、後級一塊);pool-first 建構為板端路徑:init→destroy 之間零 heap。

如何呼叫使用

呼叫順序(每一步的失敗訊號都在括號內):

  1. aec_resolve_signal_grid(sr, fft_size, &grid)(fft_size 取 aec_default_fft_size(sr) 或你指定的值;回 1 = 有這組格點,0 = 沒有,grid 不被寫入),再 aec_config_from_level(&aec_cfg, level, sr) 並設接縫欄位(fft_size、delay_mode、enable_res=0、return_res_context=1,範例的 derive_lane())。filter_length 範圍外、不合法的 delay 組合(例如 delay_num_filters 超出 [1,5]、MATCHED 卻給 fixed_delay_samples)由下一步的 aec_get_mem_size() 回 0 擋下。
  2. 用同一個 grid.fft_size 導出 NR 與合成的 config:anr_config_for_level_grid()、ac_stft_config_default()。
  3. 各函式庫查大小:aec_get_mem_size()／anr_get_mem_size()／ac_istft_get_mem_size()(0 = config 無效)。每次 build、每次改 config 都重查,不快取。
  4. 配置 16-byte 對齊的 pool(各子區塊 ALIGN16 後加總,再加暫存向量),依序 carve。
  5. aec_init()／anr_init()／ac_istft_init()(NULL = pool 過小、未對齊或 config 無效)。
  6. 每 hop:mic、ref 各剛好 grid.hop_size 個 float(同 sample rate、同時鐘),呼叫沒有長度引數、不檢查。
  7. 任何一步被拒、(若你檢查)輸出非有限、或換串流:aec_reset()、anr_reset()、ac_istft_reset() 與 CNG 亂數狀態一起 reset(不重驗 alignment／size)。
  8. 結束:anr_destroy()、aec_destroy()(對 caller pool 不釋放記憶體),最後由應用釋放 pool。

最小 C 範例(識別字皆為現行 API;platform_alloc() 是你平台的對齊配置函式,stream_next() 是你的 I/O;CNG_NR_GAIN_FLOOR、CNG_RNG_SEED、PSD_SCALE_INV 是範例檔頭自己的 #define,值見 mono_aec_nr_res/main.c;已在 -Wall -Wextra -Werror 下編譯檢查。需要的 header:aec.h、aec_res.h、anr.h、audio_stft.h、utility/mem_align.h、utility/simd_kernels.h、utility/simd_kernel_nn.h):

const int sample_rate = 16000;
AecSignalGrid grid;  AecConfig aec_cfg;
if (!aec_resolve_signal_grid(sample_rate, aec_default_fft_size(sample_rate), &grid)) return -1;   /* 0 = 沒有這組格點 */
aec_config_from_level(&aec_cfg, AEC_LEVEL_BALANCED, sample_rate);
aec_cfg.fft_size = grid.fft_size;           aec_cfg.delay_mode = AEC_DELAY_MATCHED;
aec_cfg.delay_num_filters = DA_NUM_FILTERS; aec_cfg.fixed_delay_samples = -1;
aec_cfg.enable_delay_est = 1;               /* 舊式鏡像, 與 MATCHED 一致 */
aec_cfg.enable_res = 0;  aec_cfg.return_res_context = 1;               /* 接縫: 增益留在 context 裡 */

AnrConfig nr_cfg = anr_config_for_level_grid(sample_rate, grid.fft_size, ANR_LEVEL_BALANCED);
AcStftConfig syn_cfg;  ac_stft_config_default(&syn_cfg, grid.fft_size);
size_t aec_b = aec_get_mem_size(&aec_cfg);                         /* 各函式庫各自查大小, 0 = 無效 */
size_t nr_b  = anr_get_mem_size(&nr_cfg);
size_t syn_b = ac_istft_get_mem_size(&syn_cfg);
if (!aec_b || !nr_b || !syn_b) return -1;
size_t vec  = ALIGN16(grid.n_freqs * sizeof(float));
size_t cvec = ALIGN16(grid.n_freqs * sizeof(Complex));
size_t off_nr = ALIGN16(aec_b), off_syn = off_nr + ALIGN16(nr_b), off_buf = off_syn + ALIGN16(syn_b);
uint8_t* pool = platform_alloc(off_buf + 2 * vec + cvec, 16);      /* 一塊 16-byte 對齊的 pool */
if (!pool) return -1;
Aec*         aec   = aec_init(pool, aec_b, &aec_cfg);              /* NULL = pool 過小/未對齊/config 無效 */
AnrDenoiser* nr    = anr_init(pool + off_nr, nr_b, &nr_cfg);
AcIstft*     istft = ac_istft_init(pool + off_syn, syn_b, &syn_cfg);
if (!aec || !nr || !istft) { platform_free(pool); return -1; }
float* total_gain = (float*)(pool + off_buf);                      /* 之後兩個暫存向量 + 一個 spec */
float* extra_noise = (float*)(pool + off_buf + vec);
Complex* spec = (Complex*)(pool + off_buf + 2 * vec);
uint32_t rng = CNG_RNG_SEED;                                       /* 範例自己的 #define */

const float *mic, *ref;  float out[512];                           /* 每 hop 皆 grid.hop_size floats */
while (stream_next(&mic, &ref, out)) {
    AecResContext c;  const float* nr_gain = NULL;  const float* extra = NULL;
    aec_process_context(aec, mic, ref);
    aec_get_res_context(aec, &c);
    if (c.error_spec && c.res_gain) {                              /* RES 增益 = AEC 自己的 c.res_gain */
        if (c.r2 && c.usable_linear) {                             /* 殘餘回音功率折進 NR 噪聲底 */
            sk_scale_f32(extra_noise, c.r2, PSD_SCALE_INV, grid.n_freqs);
            extra = extra_noise;
        }
        if (anr_process_gain(nr, c.error_spec, extra, NULL) == 0)
            nr_gain = anr_get_gain(nr, NULL);
    }
    if (nr_gain) {
        sk_min_f32(total_gain, nr_gain, c.res_gain, grid.n_freqs);
        sk_capply_gain_f32(spec, c.error_spec, total_gain, grid.n_freqs);
        if (aec_cfg.enable_cng && c.comfort_noise)                 /* 有 RES 增益且設定允許時 */
            aec_cng_fill(&rng, spec, c.comfort_noise, c.res_gain, nr_gain, CNG_NR_GAIN_FLOOR, grid.n_freqs);
        ac_istft_push(istft, spec, out);
        if (skn_all_finite_f32(out, (size_t)grid.hop_size)) continue;   /* 輸出守衛由整合者自己做 */
    }
    aec_reset(aec);  anr_reset(nr);  ac_istft_reset(istft);  rng = CNG_RNG_SEED;   /* 被拒的 hop: 各 stage 一起 reset */
    memset(out, 0, (size_t)grid.hop_size * sizeof(float));
}
anr_destroy(nr);  aec_destroy(aec);                                /* 不釋放 caller pool */
platform_free(pool);

桌面便利路徑 aec_create()(呼叫端持有 Aec 結構,內部配置)。診斷用唯讀查詢:aec_debug_status()／anr_debug_status()(--debug 旗標每秒印一行)、aec_get_res_context()(DUMP_CTX)。--no-nr 時不建 AnrDenoiser、NR 增益讀 unity 全 1 向量;--no-res 時 RES 增益改讀 unity,且不跑 CNG。逐步的呼叫表、錯誤語意與 config 對照見 docs/integration_mono_zh_TW.md。

接進外部後級(aec_get_res_context)

aec_get_res_context(aec, &ctx)(aec.h)在 aec_process_context() 之後交出 AecResContext:error_spec=線性 AEC 誤差頻譜 E(audio scale)、near_spec=近端頻譜、far_spec=far 頻譜、echo_spec=回音估計、r2=殘餘回音 PSD、comfort_noise=comfort-noise PSD(r2／comfort_noise 為 int16² 尺度)、res_gain=AEC 自己的 G_res,另有 linear_hop／formed_hop 與 usable_linear、far_power 等控制量;全部是借用視圖,指向 AEC 的 per-hop buffer,到下一次處理呼叫或 reset 前有效。lane 必須帶 seam(enable_res=0、return_res_context=1,derive_lane() 這樣建),否則 error_spec 為 NULL。要在鏈上插自己的 stage,就照 mono_aec_nr_res/main.c 的 mono_form() 的順序明寫(pipelines/tests/test_readme_flow.c 編譯並執行這段;該測試與 mono_aec_nr_res/tests/test_mono_chain.c 都以手寫 oracle conv_chain_mono.h 逐位元比對)。沒有函式指標表:每個應用把自己的幾行寫出來。目前的消費者是 pipeline_dfn_mono(不建 NR,P 交給 DFN2 hop)。執行期強度控制(aec_set_level()／anr_set_level())與逐階段耗時診斷見 pipeline_mono_detail。

Descriptor 慣例:mono 沒有 descriptor 也沒有 layout version(Aec(RES 增益在它的 aec_process_context() 內算)、AnrDenoiser、AcIstft 只提供大小查詢,串接寫在各 main 裡),所以每次 build 都要重查大小;init 只擋下過小或未對齊的 pool 與無效 config。需要 descriptor 閘的出貨物件只有 4ch 的 flow 層 Mcab(McabMemReq,只涵蓋 mcab 自己的 pool)與 DFN2 的 stage／bridge。AecConfig 的 filter_length、delay_mode、delay_num_filters、fixed_delay_samples 是建立時欄位;兩支 CLI 都沒有 delay 相關旗標(delay_mode 固定 MATCHED、delay_num_filters 為 DA_NUM_FILTERS),要改只能由呼叫端直接寫 AecConfig 欄位(板端 adapter 或測試)。

ctx.error_spec 不保證每個 hop 都是誤差。mono lane 無條件以 enable_res=0 / return_res_context=1 建 AEC(derive_lane()),而 lib/aec 的 formed 選擇器只在這個 context-only 模式多開一個 capture 候選:上一個 hop 的濾波品質判定尚未認可線性估計、且被選中的殘差在這個 hop 的能量大於同一 hop 的 mic capture 時,formed 時域 hop 與 ctx.error_spec 一起改送 capture,既有的 30-sample crossfade 承接邊界。換句話說,濾波器在加訊號的 hop 上這條 seam 就是 mic;NR/RES 照常套在它上面。--aec-only 走 aec_process(),輸出仍是 raw 線性殘差,不受影響。

State 表

全部 cross-call state 都住在 caller 的 pool(aec_nr_pipeline_static 的一個 16-byte 對齊 block;host 只擁有 pool 記憶體本身)。carve 順序(main.c 的 pool_bytes()／rig_build())= Aec, nr(AnrDenoiser), istft(含 fft、窗、acc、time、spec 暫存), unity, total_gain, extra_noise, spec;-DAEC_NR_POOL_SPLIT=1 的 aec_nr_pipeline 是兩塊(Aec 一塊、其餘一塊),順序相同。RES 增益在 Aec 內,不另佔 pool(所以 --no-res 不改 pool 大小)。這些是普通的函式庫物件與緩衝,沒有 layout version。

FFT backend 只有 ne10(audiolib 的唯一後端;有 NEON 的目標走它的 NEON FFT,否則是 scalar C FFT;見 audio_common.html);下表是 ne10 在 16 kHz/256 的量測值(aec_nr_pipeline_static --print-mem-size),合計 423,728 B(Aec 364,416 B、合成 AcIstft(含 FftHandle)11,344 B、NR 45,344 B、增益／頻譜暫存 2,624 B)。其他格點同一指令加旗標:8 kHz/256 310,160 B、16 kHz/512 575,056 B、48 kHz/1024 1,354,256 B;--no-nr 378,384 B、--aec-only 364,416 B。

延遲與 warm-up

  • 演算法延遲:full chain = 1 hop(128 samples = 8 ms @16k 預設;16k-alt 16 ms、48k ~10.7 ms;16k/256 實測 128 samples)。--aec-only = 0 samples(overlap-save 線性路徑,實測)。
  • warm-up:hop#0 輸出僅含半窗 ramp(≈0);AEC 線性濾波器收斂與 delay acquisition 需要 far 活動;NR 噪聲底的最小值追蹤視窗是函式庫預設的 wall-clock 約 512 ms(L 依 hop 換算,16 kHz/256 為 64 hops)。
  • 重置:aec_reset()、anr_reset()、ac_istft_reset() 加上 CNG RNG 回 CNG_RNG_SEED,等同同 pool 重 init(不重驗 alignment/size);必須一起呼叫(範例的 rig_reset())。
  • 範例在同一個 processing call 內計算並套用當前 AEC context 與 NR gain;只有最後的 WOLA time-domain emission 形成 1 hop 延遲,與 pipelines/README.md 一致。
