AINR DeepFilterNet3：如何呼叫、流程時序圖、外部／內部參數

概要

DFN3 的 C 類別 DFN3Prepost 與 DFN2 的類別同形（函式名把 dfn2 換成 dfn3，生命週期、交易式 frame 狀態機、skip／generation 規則相同），差別只在模型：低頻直接濾原始 noisy 頻譜、高頻乘 ERB gain、沒有 alpha head（DFN3PrepostOutputs 只有 erb_mask／coefs 與兩個 *_next）、延遲短一個 hop。模型內容見 ainr_dfn3。

如何呼叫使用

  1. 借用物件：FftHandle（1024 點，TIME 必填）；合成用的 AcIstft（TIME 必填，應用端以 dfn3_framing_config() 建）；erb_fwd.bin／erb_inv.bin（export_erb_matrix.py --runtime-bins 產生，呼叫端載入，兩種模式都必填）。
  2. dfn3_prepost_config_defaults → 填欄位 → dfn3_prepost_get_mem_size（alignment 16）→ dfn3_prepost_init_ex(pool, req.bytes, &cfg, &req)；host 工具可用 _create／_destroy。
  3. 每個 frame：pre_process[_freq]（前 M 拍回 0，不可呼叫加速器；其後回 1。出貨 M=1：第 0 拍）→ frame_inputs → 加速器 → frame_commit，失敗或被拒就 frame_skip → post_process[_freq]。
  4. 每次 dfn3_prepost_state_generation() 改變（reset 或被拒的 commit），把加速器自己的定點 state 重填成量化後的 0。
  5. 結尾：持續餵零 hop 並照跑加速器可把尾端排出；若要精確處理有限長 clip 的尾端，模型 feature 需補訓練時的零 padding，而不是用零頻譜重算正規化後特徵（dfn3_prepost.h 檔頭）。持續餵零音訊只是在延續 live stream。
#include <stdlib.h>
#include "DeepFilterNet3/dfn3_prepost.h"

extern int  npu_run(const DFN3PrepostInputs *in, DFN3PrepostOutputs *out);
extern void npu_fill_state_with_quantized_zero(void);

/* 頻域入口 (DFN3_IO_FREQ): 輸入/輸出是 normalized=True 尺度的頻譜 (rfft x 1/32)。 */
int run_dfn3_freq(const float *erb_fwd, const float *erb_inv,
                  const float *const *spec_re, const float *const *spec_im,
                  float *const *out_re, float *const *out_im, long frames)
{
    DFN3PrepostConfig cfg;
    DFN3PrepostMemReq req;
    int rc = 0;

    if (dfn3_prepost_config_defaults(&cfg, DFN3_IO_FREQ) != 0) return -1;
    cfg.erb_fwd = erb_fwd;  cfg.erb_inv = erb_inv;     /* FREQ 不需要 fft / window */
    if (dfn3_prepost_get_mem_size(&cfg, &req) != 0) return -1;

    size_t bytes = ((size_t)req.bytes + req.alignment - 1) / req.alignment * req.alignment;
    void *pool = aligned_alloc(req.alignment, bytes);
    DFN3Prepost *p = pool ? dfn3_prepost_init_ex(pool, (size_t)req.bytes, &cfg, &req) : NULL;
    if (!p) { free(pool); return -1; }

    unsigned seen = dfn3_prepost_state_generation(p);
    npu_fill_state_with_quantized_zero();
    for (long t = 0; t < frames && rc == 0; ++t) {
        int calls = dfn3_prepost_pre_process_freq(p, spec_re[t], spec_im[t]);
        if (calls < 0) { rc = -1; break; }
        if (calls == 1) {
            DFN3PrepostInputs xin;
            DFN3PrepostOutputs xout;
            if (dfn3_prepost_frame_inputs(p, &xin, &xout) != 0) { rc = -1; break; }
            if (dfn3_prepost_state_generation(p) != seen) {
                npu_fill_state_with_quantized_zero();
                seen = dfn3_prepost_state_generation(p);
            }
            if (npu_run(&xin, &xout) != 0 || dfn3_prepost_frame_commit(p) != 0)
                dfn3_prepost_frame_skip(p);
        }
        int valid = 0;                                 /* 前 max(M, D) 框 valid = 0, 輸出補零（出貨：第 0 框） */
        if (dfn3_prepost_post_process_freq(p, out_re[t], out_im[t], &valid) != 0) rc = -1;
    }
    dfn3_prepost_destroy(p);
    free(pool);
    return rc;
}

片語（頻域入口）已在暫存副本以 -std=c11 -Wall -Wextra -Wpedantic -Werror 編譯通過。頻譜為 torch.stft(normalized=True) 尺度（rfft × 1/32）；TIME 入口改呼叫 dfn3_prepost_pre_process／_post_process，並提供 1024 點 FftHandle 與應用端的 AcIstft（cfg.istft）。錯誤處理（各函式回傳 -1 的條件、commit 被拒時 state 歸零且 frame 仍開）與 DFN2 相同，見 ainr_dfn2_usage 的速查表。

流程時序圖

caller                         DFN3Prepost (C)                     NPU runtime
  |                                  |                                  |
  | config_defaults / get_mem_size / init_ex  (generation = 1)          |
  | ------------------------------ fill state with quantized 0 ------->|
  |                                  |                                  |
  |== frame 0 ========================|==================================|
  | pre_process[_freq](x) ---------->| features, window [0,0,F0]        |
  | <-------- 0 ----------------------|  (不呼叫加速器)                  |
  | post_process[_freq] ------------>|                                  |
  | <-------- written = 0 / valid = 0|                                  |
  |                                  |                                  |
  |== frame t >= 1 ===================|==================================|
  | pre_process[_freq](x) ---------->| window [F(t-2),F(t-1),F(t)]      |
  | <-------- 1 ----------------------|                                  |
  | frame_inputs(&in,&out) -------->| erb_mask, coefs = NaN            |
  | state_generation() ------------->| (變了 -> 重填量化零) ------------->|
  | ---------------------------------------- run(in, out) ------------->| 讀 state 輸入後
  | <---------------------------------------- rc ----------------------| 寫 heads 與 *_next
  | frame_commit() ----------------->| finite 檢查 -> compose_stream      |
  |                                  |  低頻: 原始頻譜 DF; 高頻: 原始 x gain
  | post_process[_freq] ------------>| written = 512 (輸出頻譜屬於框 t-1)|
  |                                  |                                  |
  | commit == -1 -> frame_skip()     | state 歸零, generation+1; skip 走 identity
  | reset() ------------------------>| 清 state/ring/framing            |
