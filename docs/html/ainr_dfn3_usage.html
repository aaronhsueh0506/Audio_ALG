AINR DeepFilterNet3：如何呼叫、流程時序圖、外部／內部參數

概要

DFN3 的 C 類別 DFN3Prepost 與 DFN2 的類別同形（函式名把 dfn2 換成 dfn3，生命週期、交易式 frame 狀態機、bypass／generation 規則相同；兩者都只做頻域，grid、framing 與 recurrent state 都歸應用端），差別只在模型：低頻直接濾原始 noisy 頻譜、高頻乘 ERB gain、沒有 alpha head（DFN3PrepostOutputs 只有 erb_mask／coefs 與兩個 *_next）、延遲短一個 hop，且 DFN3GridSpec 沒有 frames_per_call（一次 invocation 一個 frame）。模型內容見 ainr_dfn3。

如何呼叫使用

  1. 應用端備齊（皆為借用或由應用端配置）：DFN3GridSpec（模型匯出時決定的值）→ dfn3_grid_make(&grid, &spec)，非 0 就是被拒，dfn3_grid_status_text() 給文字；framing 用 audiolib 的 AcStft／AcIstft：ac_stft_config_default(&sc, grid.n_fft)，只改 sc.spec_scale = grid.stft_scale 與 sc.ispec_scale = grid.stft_unscale（其餘預設：sqrt-Hann、center 0、hop = n_fft/2、AC_OLA_ACCUMULATE），函式庫不持有窗、FFT 或 STFT，尺度設錯偵測不到；ERB 矩陣 erb_fwd／erb_inv 兩個指標（由應用端載入並持有；export_erb_matrix.py --runtime-bins DIR 輸出 erb_fwd.bin（bin-major）／erb_inv.bin（band-major）兩個 raw 檔，版面等於函式庫要的）；float host 另備 h_gru（5 × 256 floats）與 df_convp_history（64 × 5 × 96 floats）兩塊 state buffer，板端不備。
  2. dfn3_prepost_config_defaults(&cfg, &grid) → 填 erb_fwd／erb_inv（float host 再填兩組 state 的指標與元素個數：兩組都設或四個值全為 NULL／0）→ dfn3_prepost_get_mem_size（alignment 16）→ dfn3_prepost_init_ex(pool, req.bytes, &cfg, &req)；host 工具可用 _create／_destroy（只釋放 _create 配置的記憶體，不碰註冊的 buffer 與 ERB 矩陣）。
  3. 每個 hop：ac_stft_push_planar → pre_process_freq（每拍回 1）→ frame_open → 加速器 → frame_finish，失敗或被拒就 frame_bypass → post_process_freq（valid 只是資訊，可傳 NULL）→ ac_istft_push_planar（每拍；零頻譜得零 hop）。前 M 拍（出貨 M=1：第 0 拍）是暖機幀：加速器照跑，heads 由 frame_finish／frame_bypass 丟棄、登錄 state 歸零、generation 加 1，回 0；M=0 沒有暖機幀。
  4. 板端（不註冊 state）：加速器自己保存定點 state，起始時填成量化後的 0；每次 dfn3_prepost_state_generation() 與上次看到的值不同（reset、每個暖機幀或被拒的 frame_finish），先把加速器 state 重填成量化後的 0 再跑（M 個暖機幀各重填一次）。generation 在 init 後是 1，永遠用「與上次比較」判斷。float host 註冊的 buffer 由函式庫在 init、reset 與被拒時歸零，不需要重填。
  5. 重新開始一段串流：dfn3_prepost_reset(p) 加應用端自己的 ac_stft_reset／ac_istft_reset。結尾：再餵零頻譜並照跑加速器，可把尾端排出（grid.output_delay 個只排出最後一個頻譜框，要輸出最後一個真實 hop 的 PCM 需再多 1 個，共 grid.output_delay + 1）（dfn3_prepost_pre_process_freq 的標頭註解）；若要精確處理有限長 clip 的尾端，模型 feature 需補訓練時的零 padding，而不是用零頻譜重算正規化後特徵。持續餵零音訊只是在延續 live stream。
#include <stdlib.h>
#include "audio_stft.h"
#include "DeepFilterNet3/dfn3_prepost.h"

/* 加速器：erb、spec 視窗與 h_gru、df_convp_history -> erb_mask、coefs；各 *_next 與其輸入同位址。 */
extern int npu_run(const DFN3PrepostInputs *in, DFN3PrepostOutputs *out);

static void *alloc16(size_t bytes) { return aligned_alloc(16, (bytes + 15) & ~(size_t)15); }

/* erb_fwd：bin-major [513][32]；erb_inv：band-major [32][513]。應用端載入，函式庫只借用。 */
int run_dfn3(const float *erb_fwd, const float *erb_inv, const float *in, float *out, long hops)
{
    const DFN3GridSpec spec = {          /* 出貨模型：config.ini [signal] [model] [feature] */
        .sample_rate = 48000, .n_fft = 1024, .n_erb = 32, .df_bins = 96, .df_order = 5,
        .mask_lookahead = 1, .df_lookahead = 1,
        .erb_norm_tau_sec = 1.0f, .erb_norm_init_lo_db = -60.0f, .erb_norm_init_hi_db = -90.0f,
        .erb_norm_scale_db = 40.0f, .spec_norm_tau_sec = 1.0f,
        .spec_norm_init_lo = 0.001f, .spec_norm_init_hi = 0.0001f,
    };
    DFN3Grid grid;
    if (dfn3_grid_make(&grid, &spec) != DFN3_GRID_OK) return -1;

    int rc = -1;
    const size_t nb = (size_t)grid.n_bins;
    float *gru = calloc((size_t)5 * 256, sizeof *gru);          /* h_gru [1,5,1,256]：匯出圖決定的形狀 */
    float *convp = calloc((size_t)64 * 5 * 96, sizeof *convp);  /* df_convp_history [1,64,5,96] */
    float *buf = malloc(sizeof *buf * 4 * nb);
    float *re = buf, *im = re + nb, *out_re = im + nb, *out_im = out_re + nb;
    void *stft_mem = NULL, *istft_mem = NULL, *pool = NULL;
    AcStft *stft = NULL;
    AcIstft *istft = NULL;
    DFN3Prepost *p = NULL;
    if (!gru || !convp || !buf) goto done;

    AcStftConfig sc;                     /* framing 是 audiolib 的，函式庫不持有窗、FFT 或 STFT */
    ac_stft_config_default(&sc, grid.n_fft);
    sc.spec_scale = grid.stft_scale;
    sc.ispec_scale = grid.stft_unscale;
    size_t stft_bytes = ac_stft_get_mem_size(&sc), istft_bytes = ac_istft_get_mem_size(&sc);
    stft_mem = alloc16(stft_bytes);
    istft_mem = alloc16(istft_bytes);
    if (!stft_mem || !istft_mem) goto done;
    stft = ac_stft_init(stft_mem, stft_bytes, &sc);
    istft = ac_istft_init(istft_mem, istft_bytes, &sc);
    if (!stft || !istft) goto done;

    DFN3PrepostConfig cfg;
    DFN3PrepostMemReq req;
    if (dfn3_prepost_config_defaults(&cfg, &grid) != 0) goto done;
    cfg.erb_fwd = erb_fwd;
    cfg.erb_inv = erb_inv;
    cfg.gru_hidden = gru;         cfg.gru_hidden_elements = (size_t)5 * 256;       /* float host：兩組都註冊， */
    cfg.df_convp_history = convp; cfg.df_convp_history_elements = (size_t)64 * 5 * 96;  /* 板端都不註冊 */
    if (dfn3_prepost_get_mem_size(&cfg, &req) != 0) goto done;
    pool = alloc16((size_t)req.bytes);
    p = pool ? dfn3_prepost_init_ex(pool, (size_t)req.bytes, &cfg, &req) : NULL;
    if (!p) goto done;

    rc = 0;
    for (long h = 0; h < hops && rc == 0; ++h) {
        float *hop_out = out + h * grid.hop;
        ac_stft_push_planar(stft, in + h * grid.hop, re, im);
        if (dfn3_prepost_pre_process_freq(p, re, im) != 1) { rc = -1; break; }   /* 每個 hop 回 1 */
        DFN3PrepostInputs xin;
        DFN3PrepostOutputs xout;
        if (dfn3_prepost_frame_open(p, &xin, &xout) != 0) { rc = -1; break; }
        /* 板端: dfn3_prepost_state_generation(p) 變了就先重填量化零 (reset、暖機幀、被拒的 commit) */
        if (npu_run(&xin, &xout) != 0 || dfn3_prepost_frame_finish(p) != 0)
            dfn3_prepost_frame_bypass(p);                      /* 此框原樣通過，時序不變 */
        if (dfn3_prepost_post_process_freq(p, out_re, out_im, NULL) != 0) { rc = -1; break; }
        ac_istft_push_planar(istft, out_re, out_im, hop_out);  /* 每個 hop；前 output_delay 個為零頻譜，得零 hop */
    }
done:
    free(pool); free(istft_mem); free(stft_mem); free(buf); free(convp); free(gru);
    return rc;
}

範例（float host）已在暫存副本以 -std=c11 -Wall -Wextra -Wpedantic -Werror 編譯通過，並以單位 mask 與 unit DF tap 的假加速器跑完整個迴圈（輸出等於輸入延遲 2 hops，40 個 hop 加 2 個全零 hop 排空；暖機幀之後下一次執行看到的 state 為零）；npu_run 由目標平台 runtime 提供。頻譜為 torch.stft(normalized=True) 尺度（出貨 grid：rfft × 1/32）。錯誤處理（各函式回傳 -1 的條件、frame_finish 被拒時 state 歸零且 frame 仍開）與 DFN2 相同，見 ainr_dfn2_usage 的速查表。

  |== frame 0 ========================|==================================|
  | ac_stft_push_planar(hop) -> re/im|                                  |
  | pre_process_freq(re,im) -------->| features, window [0,0,F0]        |
  | <-------- 1 (暖機幀) ---------------|                                  |
  | frame_open, run(in,out) ---------------------------------------->| 照跑, heads 不用
  | frame_finish() ----------------->| 丟棄 heads, state 歸零, generation+1 |
  | <-------- 0 ----------------------|  (板端下一拍重填量化零)          |
  | post_process_freq -------------->|                                  |
  | <-------- valid = 0 --------------|  (輸出頻譜為零; push 全零頻譜得零 hop) |
  |                                  |                                  |
  |== frame t >= 1 ===================|==================================|
  | ac_stft_push_planar, pre_process_freq ->| window [F(t-2),F(t-1),F(t)]|

  | frame_open(&in,&out) -------->| erb_mask, coefs = NaN            |
  | state_generation() ------------->| (變了 -> 板端重填量化零) --------->|
  | ---------------------------------------- run(in, out) ------------->| 讀 state 輸入後
