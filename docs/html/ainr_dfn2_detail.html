AINR DeepFilterNet2 細節 — 記憶體與所有權、加速器 callback 邊界、建置

概要

本頁收 ainr_dfn2 的 dfn2_prepost 類別中會把單頁撐過 30 KB 的細節:pool 大小與所有權、DFN2Model callback 邊界與 descriptor、libainr_prepost.a 的建置,以及 skip identity 所依賴的 partition-of-unity 檢查。API 用法、其餘 transaction 規則、頻譜尺度警告、block diagram、泳道圖、I/O 表、State 表、延遲與檔案清單仍留在原頁。

記憶體與所有權

io_modepool(get_mem_size)說明
DFN2_IO_TIME246,320 byteshop 進、hop 出;framing/window/OLA 由本類別做(pool 內一個 AcStft 與一個 AcIstft),transform 呼叫呼叫端的 FftHandle
DFN2_IO_FREQ219,536 bytes頻譜進、頻譜出,不做 transform,不 carve 任何 framing 物件;fft 可為 NULL
  • FREQ 比 TIME 小 26,784 bytes:DFN2State 不內嵌 analysis/window/synthesis 緩衝 與 scratch,TIME 的 AcStft（16,480 B,含窗表）與 AcIstft（12,384 B,借用窗表）只在 TIME carve;FREQ 多 carve 雙輸入的第二組 staging (app_re/app_im)。io_mode 是 pool 的身分,init-time 固定,由 _init_ex 檢查。
  • DFN2_PREPOST_CARVE_VERSION = 7(dfn2_prepost.h):carve 走訪順序的版本, 摺進 build_flags_hash,所以舊 carve 的 pool 會在 hash 被拒。 版本 4:遞迴 state 就是 DFN2ModelIOState 自己的陣列,別無其他;版本 5:DFN2State 另帶每個 ERB band 的非零 bin 範圍;版本 6:遞迴 state 是 5 列 h_gru 與 5 幀 pathway window(graph layout 8);版本 7:STFT／ISTFT 物件借用呼叫端的 FftHandle 與視窗表(pool 大小改變)。
  • 遞迴 state:只有就地綁定:兩個 state tensor(h_gru (1,5,1,256) 與 df_convp_history (1,64,5,96), 共 32,000 float = 128,000 bytes)各只有一份 buffer、位址固定;每個 state 的輸入與 *_out 輸出 shape 完全相同並綁到同一個位址, 下一次呼叫的輸入就是這次的輸出,沒有第二份 buffer 也沒有複製。runtime 必須先讀完所有 state 輸入、才寫同位址的輸出 (目標平台已確認 NPU 先讀完所有輸入再寫輸出)。DFN2PrepostOutputs 的 *_next 指標就是輸入的同一個位址。
  • ERB 特徵與 mask 展開只走矩陣的非零範圍:dfn2_set_erb_matrices() 依矩陣內容記下每個 bin／band 的非零區間 (DFN2State.erb_fwd_lo/hi、erb_inv_lo/hi,以及正向矩陣每個 band 的 bin 範圍 erb_fwd_k0/k1),出貨矩陣 16,416 格只有 995 格非零。被略過的項都是「有限值 × ±0」, 累加器從 +0 開始、加 ±0 不改變任何值(含 Inf/NaN),保留的項順序不變,所以結果與完整矩陣乘法逐位元相同; 某個 bin 的 power 或某個 band 的 gain 非有限時(x × 0 會是 NaN),只有那一列走完整範圍。 power 全有限時正向和依 erb_fwd_k0/k1 逐 band 算(相鄰四個 band 並行、暫存器累加,band 內仍是 bin 遞增順序,逐位元不變;每個 48 kHz frame 1.88→0.23 µs,Apple M4),任何 power 非有限時退回逐 bin 走法。 dfn2_state_init() 之後矩陣為 NULL、範圍為完整。就地改寫矩陣內容後必須再呼叫一次 set_erb_matrices; 回歸測試 AINR/tests/test_c_prepost.c 的 test_dfn_erb_spans_exact 逐位元比對稀疏與完整兩種算法(含溢位、NaN、非有限 mask、含 NaN 的矩陣)。
  • window 是借用的:cfg.window 非 NULL 時,分析與合成物件都借用它(須與物件同壽命、內容不變); NULL 時由分析物件在 pool 內自帶 sqrt-Hann 表、合成物件借用同一張。出貨路徑一律留 NULL。
  • FftHandle 與 ERB 矩陣是借用的,從不建立或銷毀。ERB 矩陣兩個模式都必填,fft 只有 TIME 需要。
  • 32-byte DFN2PrepostMemReq 七欄:descriptor_version(=1)、layout_version (DFN2_MODEL_IO_LAYOUT_VERSION)、io_mode、build_flags_hash (FNV-1a-32 蓋 grid + geometry + feature version + io_mode)、alignment(16)、reserved、bytes。

加速器 callback 邊界:DFN2Model

host 不擁有 runtime,只擁有四個指標;邊界放在 prepost 而非 dfn2_process.h,因為 dfn2_process.c 必須能單獨編給 parity build。

typedef struct DFN2Model {
    void *user;
    int (*infer)(void *user, const DFN2PrepostInputs *inputs,
                 DFN2PrepostOutputs *outputs);   /* 回 0 = 每個輸出都寫了 */
    void (*reset)(void *user);                   /* 可選;hosting stage reset 時呼叫 */
    const DFN2ModelIoDescriptor *io_descriptor;  /* NULL = 未發布 */
} DFN2Model;

int dfn2_model_run_frame(const DFN2Model *model, DFN2Prepost *p);

dfn2_model_run_frame() 把一個已開啟的 frame 走完:frame_inputs()(head 預填 NaN)→ infer() → frame_commit();infer() 回非 0 或 commit 被拒時改走 frame_skip(), 所以 framing 與 compose 兩個時鐘永遠恰好前進一次。有限性規則不在這裡重寫一份——那是 frame_commit() 的責任。回 1 = heads 已 commit、0 = 該幀被 skip、-1 = 契約錯誤(model/instance 為 NULL、 沒有 infer、或沒有開啟中的 frame)。與 AIAEC 的 identity 政策不同:被 skip 的幀仍然吐出兩拍前的 source frame ——identity 是在 cascade 內部套用的,時序從不改變。

有 infer 就必須發布 descriptor。DFN2ModelIoDescriptor是 18 個欄位的圖合約:layout_version、sample_rate、fft_size、hop_size、 spectrum_bins、erb_bands、df_bins、df_order、mask_lookahead、 df_lookahead、input_frames、encoder_gru_layers、erb_gru_layers、 df_gru_layers、gru_hidden、encoder_channels、df_pathway_window(=5)、 state_tensor_count(=2)。_descriptor_default() 填本 build 的值,_descriptor_validate() 逐欄位比對(不是 memcmp,padding 不得參與決定),不合即 -1。欄位全是編譯期常數(沒有 Align-ULCNet delay_depth 那種部署自由度),所以 validate(default())==0 恆真,它唯一的工作是擋掉對著另一個 layout 版本或另一組幾何匯出的圖——那正是 NaN 預填看不見的一類錯誤(抓得到「沒寫」,抓不到「形狀不對」)。

實際消費者:pipelines/dfn_res_stage.c。它在 get_mem_requirements() 就把 「有 infer 卻沒 descriptor」「descriptor 被 validate() 拒絕」「有 reset／descriptor 卻沒 infer」三種組合一併拒掉,再由 mono 與 4ch 兩支 DFN2 pipeline 使用;它們走的是雙輸入入口(估計用 pre-RES 頻譜、 套用在 post-RES 頻譜)。

建置

make -C AINR lib                 # 產出 libainr_prepost.a
make -C AINR -s print-lib-path   # 印出本組態的 archive 絕對路徑
  • archive 落在 build/simd<N>-<sig>/libainr_prepost.a(<sig> = 工具鏈/旗標的 cksum, 另有 config.manifest 擋碰撞)。不要自己拼路徑,用 print-lib-path。
  • 成員 = dfn2_process.o、dfn2_model_io.o、dfn2_prepost.o、 gtcrn_process.o。RNNoise-ERB 不在裡面(它有自己的 Makefile、沒有 archive)。 WERROR=1 會傳到 compiler 並進組態簽章。對應的 AIAEC archive 是 libaiaec_prepost.a。
  • 兩支 DFN2 pipeline不連這個 archive:pipelines/Makefile 直接把三個 DFN2 TU 編進 libaudio_pipeline_dfn.a／lib4aec_dfn_res.a。

skip identity 的 partition of unity 檢查

  • skip 是精確的 identity,不是近似:erb_inv 是 partition of unity (每個 bin 的 band 權重和為 1),unit band mask 展開後就是 unit bin gain,noisy 頻譜原樣穿過 cascade。 兩條匯出路徑都會擋:一般路徑查 inverse_unity_max_error(1e-6),--runtime-bins 在寫檔前呼叫 require_partition_of_unity()——照 df_common_expand_mask 的順序逐 band 以 float32 累加後逐位元比對 1.0f(export_erb_matrix.py)。C 側 host (pipelines/dfn_res_stage.c)在 get_mem_requirements() 再驗一次,所以載到一份 不是 partition of unity 的 erb_inv.bin 會被 init 擋下,而不是讓 identity 悄悄變成近似。
