AINR DeepFilterNet2：grid 由應用端於執行期給定

概要

DFN2 函式庫不持有任何 grid：取樣率、FFT 大小、ERB 帶數、deep filter 的 bin 數、兩個 EMA 係數、lookahead pair 都不是函式庫的常數，沒有 preset、沒有預設值。應用端用 dfn2_grid_make() 建一個 DFN2Grid，傳給它建立的每一個物件（framing、DFN2State、DFN2ModelIOState、model-I/O descriptor、DFN2Prepost）；同一個 binary 在編譯期容量（capacity）以內跑任何 grid。grid、訓練好的模型、它的 ERB 矩陣三者必須屬於同一組；出貨 checkpoint 的 grid 是 48 kHz、FFT 1024、32 個 ERB band、df_bins 96、lookahead 1／1。

(sample rate, FFT size) 對應 n_erb、df_bins 與 lookahead pair 的表是模型的性質，由應用端持有（板端 sample 有自己的表，見下）；函式庫只驗證應用端傳入的值。模型本身（cascade、I/O、State）見 ainr_dfn2，呼叫順序見 ainr_dfn2_usage。

本頁的大小為本機（64 位元主機、-ffp-contract=off）量測；非出貨 grid 的音質與板端行為待量測。DFN2 的 grid 與 pool 版號的詳細規則另見 AINR/DeepFilterNet2/README.md 的 "Choosing the grid"。

API 用法

  1. 應用端依模型的 config.ini（[signal] sr／n_fft、[model] n_erb／df_bins／mask_lookahead／df_lookahead）呼叫 dfn2_grid_make()；回傳 DFN2_GRID_OK（grid 已寫入）或第一個失敗的檢查（grid 不動）。dfn2_grid_status_text() 給 log 用的短字串。
  2. 把 &grid 交給 dfn2_framing_config()、dfn2_state_init()、dfn2_model_io_init()、dfn2_model_io_descriptor_default()／_validate()、dfn2_prepost_config_defaults()；DFN2PrepostConfig 按值持有一份，dfn2_prepost_grid(p) 回傳實例的那份。
  3. 每個收 grid 的入口先跑 dfn2_grid_validate()，無效的 grid 回 -1（dfn2_framing_config() 沒有回傳值，改把輸出組態清零：fft_size 為 0，ac_stft_get_mem_size()／ac_istft_get_mem_size() 回 0，框架物件拒絕它）；手改過的衍生欄位（hop、ring、scale）也會被擋（DFN2_GRID_ERR_INCONSISTENT）。
DFN2Grid grid;                 /* sample_rate n_fft n_erb df_bins mask_la df_la */
int status = dfn2_grid_make(&grid, 48000, 1024, 32, 96, 1, 1);
if (status != DFN2_GRID_OK) { fprintf(stderr, "%s\n", dfn2_grid_status_text(status)); return -1; }

AcStftConfig sc;
dfn2_framing_config(&sc, &grid, fft, NULL);              /* AcStft / AcIstft 的組態 */
DFN2PrepostConfig cfg;
dfn2_prepost_config_defaults(&cfg, DFN2_IO_TIME, &grid);  /* 按值複製 grid */
cfg.fft = fft;  cfg.istft = istft;  cfg.erb_fwd = erb_fwd;  cfg.erb_inv = erb_inv;
DFN2PrepostMemReq req;
dfn2_prepost_get_mem_size(&cfg, &req);                   /* 48 kHz 1/1：234,048 bytes */

給定量與推導量

六個給定值是訓練好的模型所固定的：sample_rate、n_fft、n_erb、df_bins、mask_lookahead、df_lookahead。其餘由公式推導（dfn2_grid.h）：

欄位公式
hop、n_binsn_fft／2、n_fft／2 + 1（組幀固定為 50 % overlap、sqrt-Hann、不補零，audiolib audio_stft.h）
stft_scale、stft_unscalefloat32 的 1／√n_fft 與 √n_fft（torch.stft(normalized=True) 的尺度與其反向；float32 的除法與開根號是正確捨入，各編譯器結果相同）。train.py 的 analysis_scale() = 2·hop／win²·√n_fft，win = n_fft、hop = n_fft／2 時恰為同一值，它作用在餵給正規化器的拷貝；頻譜進出 DFN2_IO_FREQ 的換算用 stft_scale／stft_unscale
erb_norm_alpha、spec_norm_alphadfn2_norm_alpha(sample_rate, hop, 1.0) = train.py 的 make_norm_alpha：exp(−(hop／sr)／tau) 取到小數第三位（若進位到 1.0 就多一位），tau = 1.0 s。hop 512 @ 48 kHz 得 0.989（0x3f7d2f1b）；hop 128 @ 16 kHz 與 hop 256 @ 32 kHz 的 hop／sr 都是 8 ms，得 0.992（0x3f7df3b6）。用了其他 tau 的模型，把這兩個欄位覆寫成 dfn2_norm_alpha() 算出的值；兩者須在 (0, 1)
df_history、ringDFN2_DF_ORDER − df_lookahead − 1 個過去 tap；ring 深度 max(DFN2_DF_ORDER, mask + df + 1)，mask-only 為 mask + 1

合法性規則與狀態碼

狀態碼規則
DFN2_GRID_ERR_NULL指標為 NULL
DFN2_GRID_ERR_SAMPLE_RATEsample_rate > 0，且它給出的 norm alpha（dfn2_norm_alpha(sample_rate, hop, 1.0)，float32）嚴格在 0 與 1 之間：取樣率低或高到 alpha 取整後到 0 或 1 的被拒絕，所以 dfn2_grid_make() 接受的 grid，dfn2_grid_validate() 一定接受
DFN2_GRID_ERR_N_FFT2 的次方，且在 [16, 8192]（audiolib 組幀範圍）

DFN2_GRID_ERR_DF_BINS[2, n_bins)；-DDFN2_MASK_ONLY 可到 n_bins（高於 deep filter 的 bin 保留 masked 頻譜，所以完整版至少留一個；df_bins = 1 會讓正規化器起點的 linspace 除以零）
DFN2_GRID_ERR_MASK_LOOKAHEAD[0, 2]
DFN2_GRID_ERR_DF_LOOKAHEAD[0, DFN2_DF_ORDER − 1]；mask-only 必須為 0（沒有 deep filter 可以 look ahead）
DFN2_GRID_ERR_CAPACITYn_fft、n_erb、df_bins 或 ring 超過下一節的容量
DFN2_GRID_ERR_INCONSISTENT（dfn2_grid_validate()）衍生欄位與 dfn2_grid_make() 推導的不同，或 alpha 不在 (0, 1)

n_erb 36、df_bins 100、n_fft 2048 或 2／4 這組 pair（ring 7）在預設容量下都回 DFN2_GRID_ERR_CAPACITY（本機以 dfn2_grid_status_text() 驗證）；n_erb 30 回 DFN2_GRID_ERR_N_ERB。

編譯期容量與仍在編譯期的東西

巨集預設意義
DFN2_MAX_N_FFT1024最大 n_fft（DFN2_MAX_N_BINS 隨之）
DFN2_MAX_N_ERB32最多的 ERB band 數
DFN2_MAX_DF_BINS96最多的 deep filter bin 數
DFN2_MAX_DF_RING5（mask-only 2）最深的 ring：M + D ≤ 4 的 pair（ring 5）；mask-only 到 mask 1
  • 超過容量的 grid 被 DFN2_GRID_ERR_CAPACITY 拒絕；要服務它，在每一個編譯單元用一個 -D 提高，例如 pair 2／4（ring 7）加 -DDFN2_MAX_DF_RING=7，mask-only 的 mask 2 加 -DDFN2_MAX_DF_RING=3（AINR/tests/dfn_pairs.py 的 defines() 替測試加上）。容量是上限，不是程式跑的那個 grid。
  • 仍在編譯期：DFN2_DF_ORDER（5，定義它是 #error）、上述容量、DFN2_MASK_ONLY、DFN2_FRAMES_PER_CALL、graph 幾何（DFN2_MODEL_*：GRU hidden 256、64 個 encoder channel、三個輸入 frame）、DFN2_FEATURE_VERSION，以及正規化器的起點（DFN2_ERB_NORM_INIT_LO_DB 等，libDF 的常數、與 grid 無關；用了其他起點的模型在建置參數定義，須加在每個單元；pool hash 讀的是 dfn2_process.c 編進去的值，即 dfn2_norm_starts[]，因為初始化 state 的是它）。
  • lookahead 是 grid 的欄位（ring 深度、graph 視窗、延遲、descriptor、pool hash 都由它決定），不再有編譯期的 pair 常數，也沒有連結期的 pair 符號。

連結符號與 pool 身分

  • 連結符號只有 variant 加容量：dfn2_process.c 定義 dfn2_variant_{full|mask_only}_n<MAX_N_FFT>_e<MAX_N_ERB>_d<MAX_DF_BINS>_r<MAX_DF_RING>（預設為 dfn2_variant_full_n1024_e32_d96_r5，mask-only 預設為 dfn2_variant_mask_only_n1024_e32_d96_r2），dfn2_model_io.c、dfn2_prepost.c 與任何執行 DFN2_REQUIRE_VARIANT_LINK() 的應用單元引用它。一部分單元帶 -DDFN2_MASK_ONLY、或容量不同的物件連結失敗；grid 與 pair 不在符號裡——一個 build 服務所有 grid，grid 或 pair 不符由執行期的 descriptor、pool hash 與 grid 檢查拒絕。容量值須是單純十進位整數。dfn2_frames_per_call<N> 是另一個連結符號。
  • 在 .c → .o 規則下，不同旗標（mask-only、容量、DFN2_FRAMES_PER_CALL）編出的物件同名：每組旗標用自己的物件資料夾，或在切換之間清除；殘留的舊物件會以 dfn2_variant_* 未定義而連結失敗。make -C AINR lib 本來就一組旗標一個資料夾。dfn 與 dfn-lite 兩個板端 sample 也是如此。
  • pool 身分：DFN2_PREPOST_CARVE_VERSION = 9（前一版 8）；build_flags_hash（FNV-1a-32）對每一個 grid 都折入整個 grid：sr、n_fft、hop、n_erb、df_bins、DF_ORDER、兩個 lookahead、兩個 alpha、五個正規化起點（取自 dfn2_process.c 匯出的 dfn2_norm_starts[]），加上 layout 與 carve 版號、graph 幾何、feature 版本、io_mode，N > 1 時再加 N。carve 8 時查到的 pool 大小或 DFN2PrepostMemReq 會被 dfn2_prepost_init_ex() 拒絕，請重新查詢。容量不在 hash 裡，它改變 bytes（_init_ex 比對）與連結符號。

所有 DFN2 板端 sample 的 ERB 矩陣都讀 /mnt/sd/dfn2_blobs/fb_<sr>_<n_erb>.bin（例如 fb_48000_32.bin；<sr> 是模型 grid 的取樣率，不是 host 的），一套部署檔共用。這個檔就是匯出器的 erb_matrix.bin（export_erb_matrix.py --output-dir DIR --format bin，--format all 也會寫）依 grid 改名：int32 n_bins、int32 n_bands、float32 erb_fb[n_bins*n_bands]、float32 erb_inv[n_bins*n_bands]，兩個矩陣都是 bin-major。它不是 --runtime-bins 寫的 erb_fwd.bin（bin-major）與 erb_inv.bin（band-major，函式庫要的版面）那一對；板端 sample 先核對標頭與 grid 的 n_bins、n_erb，再把 erb_inv 轉置成 band-major。板端實跑待量測。

  • 測試在建置時用自己的標頭選 grid，不經函式庫；pipeline 與範例 main 不用：AINR/tests/dfn2_test_grid.h 與 pipelines/dfn/tests/dfn_test_grid.h（-DDFN2_GRID_KHZ=16|32|48，或 -DDFN2_SR／-DDFN2_N_FFT／-DDFN2_N_ERB／-DDFN2_DF_BINS，加上 -DDFN2_MASK_LOOKAHEAD／-DDFN2_DF_LOOKAHEAD；dfn2_test_grid()／dfn_test_grid() 回傳 DFN2Grid）。它們提供測試自己的固定陣列用的 DFN2_* 大小巨集並掃 grid 與 pair；preset 預設的 pair 是 1／1，不是上表 16、32 kHz 的 0／0，所以它們證明程式在那個 grid 上跑得對，不是在驗上表的某一列。
  • pipeline 的 dfn_res_stage、dfn_rate_bridge、dfn_hop 沒有建置期的 grid：DfnResStageConfig.grid 由應用端給（dfn_res_stage_default_config(&grid)），stage 的尺度取 grid.stft_scale／stft_unscale（出貨 grid 為 2-5／25），延遲取 dfn_res_stage_lookahead_frames(&grid)。dfn_rate_bridge_default_config(sample_rate, &model_grid) 的 resolve() 在 stage 的 grid 不是 48000／1024 時回 -1：bridge 的重取樣倍率、每 hop 推論排程、prefill 校準與延遲算式都是為 48 kHz 模型寫的。兩支 DFN2 pipeline 與 dfn2_stage.py 只以出貨 grid 驗證；stage、bridge、hop 的 C 測試另在 16、32 kHz 的測試 grid 上跑（make test-dfn-grids）。

切 grid 的流程

  1. 訓練端：config.ini [signal] 的 sr／n_fft／win_len／hop_len 與 [model] 的 n_erb／df_bins／兩個 lookahead 改成該 grid（hop_len = n_fft／2；n_erb 為 4 的倍數）；alpha 與 analysis scale 由 train.py 推導，不是設定值。
  2. 匯出：export_onnx.py 與 export_erb_matrix.py。pipeline 範例讀 --runtime-bins DIR 的 erb_fwd.bin／erb_inv.bin（各 n_bins × n_erb 個 float32；48 kHz 是 513 × 32 = 65,664 bytes，16 kHz 是 129 × 24 = 12,384 bytes）；板端 sample 讀改名後的 erb_matrix.bin（上一節）。
  3. 應用端：用同一組值呼叫 dfn2_grid_make()，載入該 grid 的 model 與 ERB 矩陣。DFN2ModelIoDescriptor 的 grid 欄位（sample_rate、fft_size、hop_size、spectrum_bins、erb_bands、df_bins、兩個 lookahead）取自傳入的 grid，執行期擋掉對著另一組幾何匯出的圖。
