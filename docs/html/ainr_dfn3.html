DeepFilterNet3：raw 低頻 DF / 高頻 ERB split

概要

本機 DFN3 是 48 kHz 單路降噪模型，FFT/window/hop = 1024/1024/512，32 ERB bands、96 個低頻 DF bins、5 個複數 taps。低頻直接濾原始 noisy 頻譜，高頻乘 ERB gain；沒有 alpha 混合輸出。DFN2 的產品 pipeline 仍使用 DFN2，切換模型須另外整合與使用相容權重。

API 用法

完整呼叫順序（含錯誤處理與 reset）、流程時序圖、外部／內部參數表：ainr_dfn3_usage。

DFN3PrepostConfig cfg;
dfn3_prepost_config_defaults(&cfg, DFN3_IO_FREQ);
cfg.erb_fwd = fwd;  /* bin-major [513][32] */
cfg.erb_inv = inv;  /* band-major [32][513] */
/* get_mem_size -> caller block aligned to req.alignment -> init_ex */
int n = dfn3_prepost_pre_process_freq(p, re, im);
if (n == 1) {
    dfn3_prepost_frame_inputs(p, &inputs, &outputs);
    /* runtime: read state inputs before writing same-address state outputs */
    if (accelerator_run(&inputs, &outputs) != 0 ||
        dfn3_prepost_frame_commit(p) != 0)
        dfn3_prepost_frame_skip(p);
}
dfn3_prepost_post_process_freq(p, out_re, out_im, &valid);

FREQ 入口不做 transform，頻譜為 sqrt-Hann STFT 的 normalized=True 尺度（1/32）。TIME 入口使用相同生命週期，改呼叫 pre_process/post_process，並借入可用的 FFT handle。ERB 矩陣由 export_erb_matrix.py --runtime-bins 產生。每個 init/create 皆先查 fresh memory descriptor；process 不配置 heap。

DFN3_MODEL_IO_LAYOUT_VERSION = 9；DFN2 layout 8 不相容。get_mem_size 實測（本機）：DFN3_IO_TIME 246,256 bytes、DFN3_IO_FREQ 219,472 bytes；sizeof(DFN3State) = 67,344 bytes。單路 C descriptor 不能拿 batch-N graph 代替。init generation 為 1，reset 與被拒的 commit 會清零兩個 recurrent state 並增加 generation；runtime 必須同步重填自己的量化 state。

延遲與 warm-up

mask／DF lookahead 是 M／D 兩個獨立設定（M 0..2、D 0..4，15 個 pair，規則見 ainr_dfn2_detail），出貨為 1/1；兩條路平行，模型延遲 max(M, D) hops（DFN2 是相加），ring 深度 5 + max(M, D) − D。TIME identity 路徑再加 WOLA，總延遲 1 + max(M, D) hops；出貨 1/1 為 1024 samples = 2 hops = 21.33 ms（不含推論時間或外部排隊）。前 M 個 hop pre_process 回 0（出貨：第一 hop），其後每 hop 回 1；written = 0 的拍數是 max(M, D)；C 端以 -DDFN3_MASK_LOOKAHEAD／-DDFN3_DF_LOOKAHEAD 取 pair，須與 checkpoint 一致，只有 1/1 有訓練好的 checkpoint（其他 pair 音質未量測）。skip 使用 unit 高頻 gain 和 unit current DF tap，維持相同時序。有限 clip 的精確尾端應補模型 feature 的零 padding；持續餵零音訊只是在延續 live stream。
