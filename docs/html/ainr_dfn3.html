AINR DeepFilterNet3 (48 kHz 平行 band split)

概要

48 kHz 全頻帶降噪模型,保留作為 DFN2 cascade 的對照組。網路預測兩個 head (ERB mask、低頻 deep-filter 係數,無 learned alpha);合成是平行 band split: bins 0..95 完全由 DF(作用在未遮罩原譜)輸出,bins 96..512 用 ERB mask—— 與 DFN2 的「先 mask 再 DF 再 alpha blend」不同,也因此串流延遲只有 1 hop。 C 端 dfn3_process.c 對應 model.py 的 heads()/compose() 邊界。

項目值(以現行程式碼為準)
取樣率 / grid48000 Hz;FFT/win/hop = 1024/1024/512(DFN3_N_FFT/DFN3_HOP_LEN)

勿把 DFN3 band-split checkpoint 載入 DFN2(合約閘會擋)。細節見 README 與 UPSTREAM_ALIGNMENT。

API 用法

#include "DeepFilterNet3/dfn3_process.h"

DFN3State st;                       /* 85,224 bytes, 呼叫端配置 */
dfn3_state_init(&st);

for (each hop of 512 new samples) {
    dfn3_analysis(&st, frame512, spec_re, spec_im);        /* [513] */
    dfn3_compute_features(&st, spec_re, spec_im,
                          feat_erb /*[32]*/, feat_spec /*[192]*/);
    /* heads 對應 current-1 框; 第 0 拍 heads_valid=0 */
    int valid = dfn3_compose_stream(&st, spec_re, spec_im, heads_valid,
                                    erb_mask /*[32]*/, coefs /*[960]*/,
                                    /*atten_lim_db=*/0.0f,
                                    out_re, out_im, &out_frame_idx);
    if (valid == 1)                          /* out 屬於 current-1 框 */
        dfn3_synthesis(&st, out_re, out_im, out512);
}

frame-aligned 參考路徑為 dfn3_compose();與串流 API 混用前必須重新 dfn3_state_init()。Python 離線:inference.py --config config.ini --model ckpt.pt --input in.wav --output out.wav。

延遲與 warm-up

  • 演算法延遲(模型側)= 1 hop = 512 samples = 10.67 ms @48 kHz: 平行 band split 下 DF 未來 tap 讀 raw 頻譜,不等未來框的 mask, 總延遲 = max(mask_lookahead, df_lookahead) = 1(對照 DFN2 cascade 的 2 hops)。
  • STFT framing 結構延遲:win−hop = 512 samples = 10.67 ms。
  • Warm-up:dfn3_compose_stream() 第 1 次呼叫回 0(heads_valid=0); 第 2 次起輸出 current-1 框。右端 flush 由中介硬體以訓練同款 zero padding 續呼。
  • 正規化器 EMA warm-up:tau = 1.0 s(α=0.989)。
  • 對齊守衛:tests/test_c_prepost.c: test_dfn_stream_alignment() 同時覆蓋 DFN2/DFN3 的 output_frame_index 與逐 bin 3e-6 一致性。
