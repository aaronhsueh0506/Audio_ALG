DeepFilterNet3：raw 低頻 DF / 高頻 ERB split

概要

本機 DFN3 是 48 kHz 單路降噪模型（出貨 grid：FFT/hop = 1024/512，32 ERB bands、96 個低頻 DF bins、5 個複數 taps）。低頻直接濾原始 noisy 頻譜，高頻乘 ERB gain；沒有 alpha 混合輸出。函式庫只做頻域：grid 由應用端以 DFN3GridSpec 在執行期給定（dfn3_grid_make()），framing（AcStft/AcIstft）、ERB 矩陣與 recurrent state 都歸應用端。DFN2 的產品 pipeline 仍使用 DFN2，切換模型須另外整合與使用相容權重。

API 用法

完整呼叫順序（含錯誤處理與 reset）、流程時序圖、外部／內部參數表：ainr_dfn3_usage。

DFN3Grid grid;
DFN3PrepostConfig cfg;
DFN3PrepostMemReq req;
dfn3_grid_make(&grid, &spec);                /* spec：DFN3GridSpec，模型匯出時決定的值 */
dfn3_prepost_config_defaults(&cfg, &grid);   /* grid 被複製進 config */
cfg.erb_fwd = fwd;                           /* bin-major [513][32]，借用 */
cfg.erb_inv = inv;                           /* band-major [32][513]，借用 */
dfn3_prepost_get_mem_size(&cfg, &req);       /* float host 另在 cfg 註冊兩組 state；板端不註冊 */
DFN3Prepost *p = dfn3_prepost_init_ex(pool, req.bytes, &cfg, &req);   /* pool：16-byte 對齊 */

ac_stft_push_planar(stft, hop_in, re, im);   /* 每個 hop；spec_scale = grid.stft_scale */
if (dfn3_prepost_pre_process_freq(p, re, im) != 1) return -1;   /* 1 on every hop */
dfn3_prepost_frame_open(p, &inputs, &outputs);
/* runtime: read state inputs before writing same-address state outputs; reload quantized zero
 * when dfn3_prepost_state_generation(p) changed (a reset, a warm-up frame, a refused commit) */
if (accelerator_run(&inputs, &outputs) != 0 ||
    dfn3_prepost_frame_finish(p) != 0)
    dfn3_prepost_frame_bypass(p);
dfn3_prepost_post_process_freq(p, out_re, out_im, NULL);            /* valid: informational */
ac_istft_push_planar(istft, out_re, out_im, hop_out);   /* every hop; ispec_scale = grid.stft_unscale */

函式庫不做 transform：頻譜由應用端的 AcStft 產生（audiolib 預設的 sqrt-Hann、center 0、hop = n_fft/2，spec_scale = grid.stft_scale，出貨 grid 為 1/32，即 torch.stft(normalized=True) 尺度），AcIstft 用 AC_OLA_ACCUMULATE 與 ispec_scale = grid.stft_unscale；尺度或窗設錯，函式庫偵測不到。ERB 矩陣是兩個借用指標，由應用端載入並持有；export_erb_matrix.py --runtime-bins DIR 輸出 raw little-endian float32 的 erb_fwd.bin（bin-major）與 erb_inv.bin（band-major），版面等於函式庫要的。每個 init/create 皆先查 fresh memory descriptor；process 不配置 heap。

Block diagram

caller hop (n_fft/2 samples)
  -> ac_stft_push_planar (AcStft, spec_scale = grid.stft_scale) -> spectrum re/im [n_bins]
  -> dfn3_prepost_pre_process_freq -> features + [t-1,t,t+1] host window
  -> dfn3_prepost_frame_open -> stateless graph: erb_mask, df_coefs, next states
  -> dfn3_prepost_frame_finish -> dfn3_enhance_spectrum_stream
       low bins < df_bins（出貨 0..95）: DF(raw spectra)
       high bins >= df_bins（出貨 96..512）: raw target * ERB gain
       -> attenuation limit
  -> dfn3_prepost_post_process_freq -> enhanced spectrum (valid after output_delay frames)
  -> ac_istft_push_planar (AcIstft, ispec_scale = grid.stft_unscale) -> one hop

訊號泳道圖

current input frame     0             1                2

出貨 1/1（M = 1）：hop 0 是暖機幀，模型照跑、heads 丟棄、登錄 state 歸零，generation 加 1；零頻譜進 AC_OLA_ACCUMULATE 的 AcIstft 得零 hop。

DFN3_MODEL_IO_LAYOUT_VERSION = 9（DFN2 layout 8 不相容）、DFN3_PREPOST_CARVE_VERSION = 9。get_mem_size 實測（出貨 grid 48000/1024、1/1、64-bit 本機）：pool 90,384 bytes，其中 state block（dfn3_state_mem_size()）65,808、model_io block（dfn3_model_io_mem_size()）2,688；pool 不含 ERB 矩陣、註冊的 state 與應用端的 AcStft/AcIstft；sizeof(DFN3State) = 304 bytes（只有標頭）。ring 深度隨 pair 變，pool 也變：ring 6（1/0、2/1）102,416、ring 7（2/0）114,448。單路 C descriptor 不能拿 batch-N graph 代替。state generation 在 init 後為 1，reset、每個暖機幀與被拒的 frame_finish 各加 1（已註冊的 state 同時歸零）；板端 runtime 偵測到 generation 改變，須把自己的量化 state 重填成量化後的 0。

延遲與 warm-up

mask／DF lookahead 是 DFN3GridSpec 的兩個欄位 mask_lookahead（M，0..2）與 df_lookahead（D，0..df_order−1，order 5 時 0..4），15 個 pair（規則見 ainr_dfn2_detail），出貨為 1/1；函式庫沒有 pair 常數，也不在建置時選 pair，dfn3_grid_make() 只拒絕範圍外的 pair；與 checkpoint 不符的 pair 由 dfn3_model_io_descriptor_validate()（dfn3_model_run_frame() 內部會呼叫）與 dfn3_prepost_init_ex() 對照呼叫端事先保存的 DFN3PrepostMemReq（build_flags_hash）拒絕。兩條路平行，模型延遲 grid.output_delay = max(M, D) hops（DFN2 是相加），ring 深度 grid.ring = df_order + max(M, D) − D。經應用端 AcStft/AcIstft 的 identity 路徑再加一個 hop，總延遲 1 + max(M, D) hops；出貨 1/1 為 1024 samples = 2 hops = 21.33 ms（不含推論時間或外部排隊）。pre_process_freq 每 hop 回 1；前 M 個 hop 是暖機幀（出貨：第一 hop；heads 丟棄、state 歸零，首個真幀從零 state 開始，音訊不變，串流開頭多 M 次加速器呼叫，板端每個暖機幀後重載量化零）；D > M 時，其後幾次加速器照跑但還沒有輸出，heads 在 ring 裡等；valid = 0 的拍數是 max(M, D)，其間頻譜為零，合成端每 hop 無條件 push。frame_bypass 使用 unit 高頻 gain 和 unit current DF tap，維持相同時序。有限 clip 的精確尾端應補模型 feature 的零 padding；持續餵零音訊只是在延續 live stream。
