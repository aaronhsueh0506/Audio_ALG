AINR DeepFilterNet2：如何呼叫、流程時序圖、外部／內部參數

概要

本頁把整合者用得到的三件事集中在一處：呼叫順序（含錯誤處理）、流程時序圖、可調整與不建議開放的參數表。模型本身（cascade 結構、I/O 表、State 表、延遲）見 ainr_dfn2；pool 大小與 callback 邊界見 ainr_dfn2_detail。

入口適用標頭
A. DFN2Prepost 類別（建議）整合者只管音訊（或頻譜）與加速器張量；framing、特徵、遞迴 state、compose 全在物件內AINR/DeepFilterNet2/dfn2_prepost.h
B. DFN2Model callback由 hosting stage 擁有 runtime 的 DFN2Model（infer／reset／descriptor 四個指標）；dfn2_model_run_frame() 把 frame_inputs→infer→frame_commit／frame_skip 包成一次呼叫（pipelines/dfn_res_stage.c 持有 DFN2Model，自己依序呼叫這幾個函式）dfn2_prepost.h
C. 低階 API自帶 state struct、做 parity 對照；類別就是由這些函式組成，A 或 B 能滿足就不必直接呼叫dfn2_process.h、dfn2_model_io.h

如何呼叫使用

  1. 準備借用物件：FftHandle（fft_init 於 DFN2_N_FFT = 1024 點，fft_get_mem_size(1024) = 26,352 bytes，本機量測；TIME 模式必填，FREQ 可為 NULL）；erb_fwd.bin／erb_inv.bin 由呼叫端載入成 float 陣列（export_erb_matrix.py --runtime-bins 產生，各 513×32 個 float32 = 65,664 bytes；函式庫從不讀檔，也不複製）。
  2. dfn2_prepost_config_defaults(&cfg, io_mode) 後填 fft／erb_fwd／erb_inv（window 出貨留 NULL）。
  3. dfn2_prepost_get_mem_size(&cfg, &req)：req.bytes 是整個 pool，req.alignment = 16；DFN2_IO_TIME 246,320 bytes、DFN2_IO_FREQ 219,536 bytes（本機量測）。板端把 pool 放進靜態 arena，host 工具可改用 dfn2_prepost_create(&cfg)／_destroy()。
  4. dfn2_prepost_init_ex(pool, req.bytes, &cfg, &req)：起始即 reset，state_generation = 1。傳入查詢時的 req 可擋下「別的 build／io_mode 查出來的陳舊 pool 大小」。
  5. 加速器那份定點 state 在啟動時填成量化後的 0；之後每次 state_generation 變了就重填（見時序圖）。
  6. 每個 hop：pre_process → （回 1 才）frame_inputs → 加速器 → frame_commit（或 frame_skip）→ post_process。
  7. 串流結尾：再餵 2 個全零 hop 並照常跑加速器，才能把尾端排出（dfn2_prepost.h 檔頭）。
  8. 重新開始一段串流：dfn2_prepost_reset(p)，然後把加速器 state 重填量化零；結束：dfn2_prepost_destroy(p)（對 _init 實例是 no-op）。
#include <stdlib.h>
#include "DeepFilterNet2/dfn2_prepost.h"

/* 目標平台提供: 兩個 state 輸出綁在輸入的同一個位址, 先讀完所有 state 輸入才寫輸出 */
extern int  npu_run(const DFN2PrepostInputs *in, DFN2PrepostOutputs *out);
extern void npu_fill_state_with_quantized_zero(void);

/* erb_fwd / erb_inv: 呼叫端從 export_erb_matrix.py --runtime-bins 產生的 .bin 載入 (函式庫不讀檔)。
 * fft: fft_init(..., DFN2_N_FFT) 建好的 handle。回 0 成功, -1 失敗。 */
int run_dfn2(FftHandle *fft, const float *erb_fwd, const float *erb_inv,
             const float *in, float *out, long hops)
{
    DFN2PrepostConfig cfg;
    DFN2PrepostMemReq req;
    int rc = 0;

    if (dfn2_prepost_config_defaults(&cfg, DFN2_IO_TIME) != 0) return -1;
    cfg.fft = fft;  cfg.erb_fwd = erb_fwd;  cfg.erb_inv = erb_inv;
    cfg.atten_lim_db = 0.0f;                           /* 0 = 不限制衰減量 */
    if (dfn2_prepost_get_mem_size(&cfg, &req) != 0) return -1;

    /* 板端: 靜態 arena, 位址對齊 req.alignment (16)。此處用 heap 示意。 */
    size_t bytes = ((size_t)req.bytes + req.alignment - 1) / req.alignment * req.alignment;
    void *pool = aligned_alloc(req.alignment, bytes);
    DFN2Prepost *p = pool ? dfn2_prepost_init_ex(pool, (size_t)req.bytes, &cfg, &req) : NULL;
    if (!p) { free(pool); return -1; }

    unsigned seen = dfn2_prepost_state_generation(p);
    npu_fill_state_with_quantized_zero();              /* 加速器那份 state 起始為 0 */

    for (long h = 0; h < hops && rc == 0; ++h) {
        int calls = dfn2_prepost_pre_process(p, in + h * DFN2_HOP_LEN);
        if (calls < 0) { rc = -1; break; }
        if (calls == 1) {                              /* 第 0 拍回 0: 不可呼叫加速器 */
            DFN2PrepostInputs xin;
            DFN2PrepostOutputs xout;
            if (dfn2_prepost_frame_inputs(p, &xin, &xout) != 0) { rc = -1; break; }
            if (dfn2_prepost_state_generation(p) != seen) {  /* reset 或被拒的 commit 清了 state */
                npu_fill_state_with_quantized_zero();
                seen = dfn2_prepost_state_generation(p);
            }
            if (npu_run(&xin, &xout) != 0 || dfn2_prepost_frame_commit(p) != 0)
                dfn2_prepost_frame_skip(p);            /* identity, 時鐘照走 */
        }
        int written = 0;                               /* 前 2 拍 written = 0, out 補零 */
        if (dfn2_prepost_post_process(p, out + h * DFN2_HOP_LEN, &written) != 0) rc = -1;
    }
    dfn2_prepost_destroy(p);                           /* _init 實例為 no-op */
    free(pool);
    return rc;
}

以上片語已在暫存副本以 -std=c11 -Wall -Wextra -Wpedantic -Werror 編譯通過；npu_run／npu_fill_state_with_quantized_zero 由目標平台 runtime 提供。頻域入口把 pre_process／post_process 換成 _pre_process_freq／_post_process_freq（頻譜為 torch.stft(normalized=True) 尺度，見 ainr_dfn2 的尺度警告）；估計與套用分支來自不同頻譜時用 _pre_process_freq_dual。

錯誤處理速查

呼叫失敗回傳原因處置
get_mem_size-1，*req 不動NULL、未知 io_mode、缺 ERB 矩陣、atten_lim_db 非有限、TIME 缺 fft 或其 bin 數不是 513修正 config
init／init_exNULLconfig 同上；pool 為 NULL、未對齊 16、太小；expected 與本 build 的 descriptor 不符重新查大小、重新配置
pre_process*-1NULL 參數、io_mode 不符、上一個 frame 還開著（沒 commit 也沒 skip）先 frame_commit／frame_skip
frame_inputs-1沒有開啟中的 frame（例如第 0 拍 pre_process 回 0 之後）只在 pre_process 回 1 後呼叫
frame_commit-1三個 head 或兩個遞迴 state 有非有限值，或沒先 frame_inputs兩個遞迴 state 已歸零、state_generation +1、frame 仍開著：呼叫 frame_skip，或重新 frame_inputs 再跑一次加速器
frame_skip-1沒有開啟中的 frame—（成功即 identity，時鐘照走）
post_process*-1NULL、io_mode 不符、frame 還開著先關閉 frame
set_atten_lim／set_erb_matrices-1NULL、非有限值，或 frame 開著在 hop 之間呼叫

寫了一半但仍有限的加速器輸出偵測不到（三個 head 預填 NaN 只抓得到「沒寫」）；兩個 state 是就地覆寫，commit 失敗時前一份已不存在，所以只能歸零。

流程時序圖

lifeline：caller（應用）、DFN2Prepost（C，pool 內）、NPU（目標平台 runtime）。箭頭上是實際函式名。

caller                         DFN2Prepost (C)                     NPU runtime
  |                                  |                                  |
  |== init ==========================|==================================|
  | config_defaults(io_mode) ------->|                                  |
  | get_mem_size(cfg,&req) --------->| -1: config 不完整                |
  | init_ex(pool,bytes,cfg,&req) --->| reset, generation = 1            |
  | ---------------------------------- fill state with quantized 0 ---->|
  |                                  |                                  |
  |== hop 0 ==========================|==================================|
  | pre_process(in_hop) ------------>| STFT, features, push window      |
  | <-------- 0 (沒有右鄰居) ---------|                                  |
  | post_process(out,&written) ----->|                                  |
  | <-------- written = 0 (補零) -----|                                  |
  |                                  |                                  |
  |== hop n >= 1 (steady) ===========|==================================|
  | pre_process(in_hop) ------------>| features, window [t-1,t,t+1]     |
  | <-------- 1 ----------------------|                                  |
  | frame_inputs(&in,&out) -------->| heads = NaN, views into pool     |
  | state_generation() ------------->| (變了 -> 重填量化零) ------------->|
  | ---------------------------------------- run(in, out) ------------->| 先讀完 state 輸入,
  | <---------------------------------------- rc ----------------------| 再寫 heads 與 *_next
  | frame_commit() ----------------->| finite 檢查, compose, synthesis  |
  | <-------- 0 -----------------------|                                  |
  | post_process(out,&written) ----->| hop 1: written = 0               |
  | <-------- written = 512 (hop >= 2)|                                  |
  |                                  |                                  |
  |== 失敗路徑 =======================|==================================|
  | frame_commit() ----------------->| 非有限: state 歸零, generation+1 |
  | <-------- -1 ----------------------| frame 仍開著                     |
  | frame_skip() ------------------->| identity (unit mask, alpha 0)    |
  | (下一拍 state_generation 變了) ---------- fill quantized 0 ------->|
  |                                  |                                  |
  |== 設定與重置 =====================|==================================|
  | set_atten_lim(db) / set_erb_matrices(fwd,inv)  (hop 之間, frame 開著 -> -1)
  | reset() ------------------------>| 清 state/ring/framing, generation+1
  | destroy() ---------------------->| _create 配置的才釋放             |

內部：存在且可改，但不建議開放

下列都是 checkpoint／graph 契約的一部分：改任何一項都等於換一個模型，需重訓、重匯出，並讓 layout 版號或 feature 版本跟著變；開放給第三方只會得到「形狀合法但數值錯誤」的結果。
