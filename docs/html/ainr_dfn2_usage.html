AINR DeepFilterNet2：如何呼叫、流程時序圖、外部／內部參數

概要

本頁把整合者用得到的三件事集中在一處：呼叫順序（含錯誤處理）、流程時序圖、可調整與不建議開放的參數表。模型本身（cascade 結構、I/O 表、State 表、延遲）見 ainr_dfn2；pool 與所有權、callback 邊界見 ainr_dfn2_detail；grid 見 ainr_dfn2_grids。

入口適用標頭
A. DFN2Prepost 類別（建議）整合者只管頻譜與加速器張量；特徵、合成、遞迴 state 的檢查全在物件內；框化由應用端用 audiolib 的 AcStft／AcIstft 做lib/ainr/dfn2/dfn2_prepost.h
B. DFN2Model callback由 hosting stage 擁有 runtime 的 DFN2Model（infer／reset／descriptor 四個指標）；dfn2_model_run_frame() 把 frame_open→infer→frame_finish／frame_bypass 包成一次呼叫（pipelines/dfn/dfn_res_stage.c 持有 DFN2Model）dfn2_prepost.h
C. 低階 API自帶 state、做 parity 對照；類別就是由這些函式組成，A 或 B 能滿足就不必直接呼叫dfn2_process.h、dfn2_model_io.h

如何呼叫使用

  1. 建立 grid：把模型的值填成 DFN2GridSpec，dfn2_grid_make(&grid, &spec)（欄位見 ainr_dfn2_grids），回 DFN2_GRID_OK 才往下，同一個 grid 交給每個物件。
  2. 準備應用端的物件：ERB 矩陣由應用端載入並持有，erb_fwd（bin-major）、erb_inv（band-major），各 n_bins × n_erb 個 float32（48 kHz 為 65,664 bytes；函式庫不讀檔、不複製）；框化：ac_stft_config_default(&sc, grid.n_fft)，設 spec_scale = grid.stft_scale、ispec_scale = grid.stft_unscale，建 AcStft／AcIstft（大小見 ainr_dfn2_grids）；浮點 host 另備兩塊遞迴 state buffer。
  3. dfn2_prepost_config_defaults(&cfg, &grid) 後填 erb_fwd／erb_inv（必填）與 atten_lim_db；浮點 host 再登錄遞迴 state（gru_hidden／df_convp_history 與各自的 *_elements，出貨模型 1,280 與 30,720 個 float），板端四欄留 NULL／0，由加速器持有。
  4. dfn2_prepost_get_mem_size(&cfg, &req)：req.bytes 是整個 pool，req.alignment = 16；48 kHz 1/1 為 92,608 bytes（本機量測；不含應用端的 AcStft／AcIstft、ERB 矩陣與登錄的 state；其他 grid 見 ainr_dfn2_grids）。板端把 pool 放進靜態 arena，host 工具可改用 dfn2_prepost_create(&cfg)／_destroy()。
  5. dfn2_prepost_init_ex(pool, req.bytes, &cfg, &req)：起始即 reset，state_generation = 1。傳入查詢時的 req 可擋下「別的 build／grid 查出來的陳舊 pool 大小」。
  6. 每個 hop 同一條流程（frames_per_call N = 1）：ac_stft_push_planar → pre_process_freq（回 1）→ frame_open → 加速器 → frame_finish（或 frame_bypass）→ post_process_freq → ac_istft_push_planar；valid 只是資訊（可傳 NULL），AC_OLA_ACCUMULATE 下每 hop 都 push，零頻譜得零 hop。前 M 個 hop 是暖機幀：加速器照跑，heads 被丟棄、登錄 state 歸零、generation 加 1，所以首個真幀從零 state 開始，音訊不變；M = 0 沒有暖機幀，N > 1 維持舊流程（見 ainr_dfn2_detail）。
  7. 加速器那份定點 state 在啟動時填成量化後的 0，之後每次 state_generation 變了就重填（reset、每個暖機幀、被拒的 commit；M 個暖機幀各重填一次，串流開頭多 M 次加速器呼叫，見時序圖）。串流結尾：再餵全零 hop 並照常跑加速器才能排出尾端：M+D 個只排出最後一個頻譜框，PCM 要多 1 個（ISTFT 重疊），共 M+D+1 個（出貨 pair 3 個；identity 實跑確認）。
  8. 重新開始一段串流：dfn2_prepost_reset(p)，並 reset 自己的 AcStft／AcIstft，然後把加速器 state 重填量化零；結束：dfn2_prepost_destroy(p)（對 _init 實例是 no-op）。
#include <stdlib.h>
#include "audio_stft.h"
#include "DeepFilterNet2/dfn2_prepost.h"

/* 目標平台提供: 兩個 state 輸出綁在輸入的同一個位址, 先讀完所有 state 輸入才寫輸出 */
extern int  npu_run(const DFN2PrepostInputs *in, DFN2PrepostOutputs *out);
extern void npu_fill_state_with_quantized_zero(void);

static void *alloc16(size_t n) { return aligned_alloc(16, (n + 15u) & ~(size_t)15u); }

/* spec: 模型固定的值; erb_fwd / erb_inv: 應用端讀入的 ERB 矩陣 (函式庫不讀檔、不複製)。
 * 回 0 成功, -1 失敗。 */
int run_dfn2(const DFN2GridSpec *spec, const float *erb_fwd, const float *erb_inv,
             const float *in, float *out, long hops)
{
    DFN2Grid grid;
    AcStftConfig sc;
    DFN2PrepostConfig cfg;
    DFN2PrepostMemReq req;
    void *stft_mem, *istft_mem, *pool;
    float *spec_buf;
    AcStft *stft = NULL;
    AcIstft *istft = NULL;
    DFN2Prepost *p = NULL;
    int rc = -1;

    if (dfn2_grid_make(&grid, spec) != DFN2_GRID_OK) return -1;

    ac_stft_config_default(&sc, grid.n_fft);          /* sqrt-Hann、50% overlap、center 0 */
    sc.spec_scale = grid.stft_scale;                  /* 訓練時的 normalized=True */
    sc.ispec_scale = grid.stft_unscale;
    stft_mem = alloc16(ac_stft_get_mem_size(&sc));
    istft_mem = alloc16(ac_istft_get_mem_size(&sc));
    spec_buf = malloc(4 * (size_t)grid.n_bins * sizeof *spec_buf);
    if (!stft_mem || !istft_mem || !spec_buf) goto done;
    stft = ac_stft_init(stft_mem, ac_stft_get_mem_size(&sc), &sc);
    istft = ac_istft_init(istft_mem, ac_istft_get_mem_size(&sc), &sc);
    if (!stft || !istft) goto done;
    float *re = spec_buf, *im = re + grid.n_bins;
    float *out_re = im + grid.n_bins, *out_im = out_re + grid.n_bins;

    if (dfn2_prepost_config_defaults(&cfg, &grid) != 0) goto done;
    cfg.erb_fwd = erb_fwd;  cfg.erb_inv = erb_inv;
    cfg.atten_lim_db = 0.0f;                           /* 0 = 不限制衰減量 */
    /* 板端: 不登錄 state (NPU 持有)。浮點 host: cfg.gru_hidden／df_convp_history 與各自的元素數 */
    if (dfn2_prepost_get_mem_size(&cfg, &req) != 0) goto done;
    pool = alloc16((size_t)req.bytes);                 /* 板端: 靜態 arena, 16 bytes 對齊 */
    p = pool ? dfn2_prepost_init_ex(pool, (size_t)req.bytes, &cfg, &req) : NULL;
    if (!p) { free(pool); goto done; }

    unsigned seen = dfn2_prepost_state_generation(p);
    npu_fill_state_with_quantized_zero();              /* NPU 那份 state 起始為量化後的 0 */
    rc = 0;
    for (long h = 0; h < hops && rc == 0; ++h) {
        ac_stft_push_planar(stft, in + h * grid.hop, re, im);
        if (dfn2_prepost_pre_process_freq(p, re, im) != 1) { rc = -1; break; }   /* 每 hop 回 1 (N = 1) */
        DFN2PrepostInputs xin;
        DFN2PrepostOutputs xout;
        if (dfn2_prepost_frame_open(p, &xin, &xout) != 0) { rc = -1; break; }
        if (dfn2_prepost_state_generation(p) != seen) {   /* reset、暖機幀或被拒的 commit 清了 state */
            npu_fill_state_with_quantized_zero();
            seen = dfn2_prepost_state_generation(p);
        }
        if (npu_run(&xin, &xout) != 0 || dfn2_prepost_frame_finish(p) != 0)
            dfn2_prepost_frame_bypass(p);              /* 原頻譜直通, 時鐘照走 */
        if (dfn2_prepost_post_process_freq(p, out_re, out_im, NULL) != 0) { rc = -1; break; }   /* 前 M+D 拍為零頻譜 */
        ac_istft_push_planar(istft, out_re, out_im, out + h * grid.hop);   /* 每 hop 都 push */
    }
    free(pool);
done:
    free(spec_buf); free(istft_mem); free(stft_mem);
    return rc;
}

以上片語已在暫存副本以 -std=c11 -Wall -Wextra -Wpedantic -Werror 編譯通過，並以 unit mask、alpha 0 的替身加速器實跑（出貨 grid 與 pair 1/1），輸出等於輸入延遲 3 hops（40 個 hop 加 M+D+1 = 3 個全零 hop：加速器跑 43 次、state 重填 2 次，少推一個全零 hop 就排不完）。估計與套用分支來自不同頻譜時用 _pre_process_freq_dual。

錯誤處理速查

呼叫失敗回傳原因處置
get_mem_size-1，*req 不動NULL、缺 ERB 矩陣、atten_lim_db 非有限、state 登錄不合規則（指標配 0 個元素、元素數配 NULL、完整版只登錄 h_gru、mask-only 登錄 df_convp_history）、grid 無效修正 config
init／init_exNULLconfig 同上；pool 為 NULL、未對齊 16、太小；expected 與本 build 與 grid 的 descriptor 不符重新查大小、重新配置
pre_process_freq*-1（N=1 正常回 1）NULL 參數、上一個 frame 還開著（沒 finish 也沒 bypass）先 frame_finish／frame_bypass
frame_open-1沒有開啟中的 frame（例如 N>1 時 pre_process_freq 回 0 之後）只在 pre_process_freq 回 1 後呼叫
frame_finish-1三個 head 或登錄的遞迴 state 有非有限值，或沒先 frame_open登錄的 state 已歸零（未登錄時只有計數）、state_generation +1、frame 仍開著：呼叫 frame_bypass，或重新 frame_open 再跑一次加速器。暖機幀不檢查 heads，回 0（state 歸零、generation +1）
frame_bypass-1沒有開啟中的 frame—（成功即 identity，時鐘照走）
post_process_freq-1NULL、frame 還開著先關閉 frame
set_atten_lim／set_erb_matrices-1NULL、非有限值，或 frame 開著在 hop 之間呼叫

寫了一半但仍有限的加速器輸出偵測不到（三個 head 預填 NaN 只抓得到「沒寫」）；兩個 state 是就地覆寫，finish 失敗時前一份已不存在，所以只能歸零。

內部：存在且可改，但不建議開放

下列都是 checkpoint／graph 契約的一部分：改任何一項都等於換一個模型，需重訓、重匯出，並讓 layout 版號或 feature 版本跟著變；開放給第三方只會得到「形狀合法但數值錯誤」的結果。

名稱值位置不開放的原因
DFN2GridSpec 的模型欄位:sample_rate／n_fft／n_erb／df_bins／df_order／mask／df lookahead出貨 48000／1024／32／96／5／1／1(M 0..2、D 0..df_order−1,df_order=5 時 15 個 pair)dfn2_grid.h與 checkpoint 的 signal／model contract、ERB 矩陣尺寸、ring 與網路 head 的形狀綁定;改了需重訓。由應用端給定(板端 sample 的表),dfn2_grid_make() 驗證,函式庫沒有預設值,見 ainr_dfn2_grids
erb_norm_alpha／spec_norm_alpha、stft_scale／stft_unscale出貨 0.989／0.989(tau = 1.0 s)、1／32 與 32DFN2Grid 欄位由 sr、hop、tau 與 n_fft 推導(dfn2_norm_alpha(sr, hop, tau_sec));alpha 是 feature version 的一部分,須與 train.py 相同,tau 不同的模型改 spec 的 tau 欄位;scale 作用在餵給正規化器的拷貝,也是應用端 AcStft／AcIstft 的尺度
