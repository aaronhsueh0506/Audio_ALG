mono AEC → NR → RES — 參數與入口分級(外部／內部)

概要

mono 沒有包起來的模組,設定面由三個函式庫的 config 組成:Aec(AecConfig,由 aec_resolve_signal_grid() 與 aec_config_from_level() 導出,接縫欄位由範例的 derive_lane() 設)、AnrDenoiser(AnrConfig,由 anr_config_for_level_grid() 導出)、AcIstft(AcStftConfig)。本頁把「第三方可以調」與「存在、可調、但不建議開放」分開列。外部:描述部署環境(取樣率、格點、延遲模式、濾波長度)、模組開關,或單一取捨軸(level);有界、效果單調,錯值會被拒絕或只是效果變差。內部:時間常數、門檻、平滑係數、聯合調出來的操作點;單獨改一個沒有保證,甚至會讓收斂靜默失效。呼叫順序與時序圖見 pipeline_mono、整合時序圖。逐欄位的範圍與「調了會怎樣」在元件頁:AEC 參數頁、NR API。

「建立時」的欄位決定 pool 佈局,改了必須重新查大小並重新 *_init();*_init() 會複製 config,之後改手上那份無效。數字為 ne10、16 kHz/256 的本機實測(aec_nr_pipeline_static --print-mem-size 與以 derive_lane() 的 AecConfig + 各 *_get_mem_size() 直接查);換 backend、編譯選項或 submodule 即失效,一律現查。

1. 外部參數

1.1 建立時(AecConfig 與 level)

1.2 執行期(兩個 hop 之間呼叫、與 process 序列化、非 thread-safe)

呼叫範圍回傳／副作用
aec_set_level(aec, level, ramp_ms)ramp_ms ∈ [0, 60000];0 = 下一 hop 套用;> 0 以 dB 線性走過去0 或 −1(NULL、enum 外、ramp_ms 非有限／超出範圍;−1 時什麼都不寫);不是重啟,濾波器與 delay 鎖定繼續

2. 內部參數(存在、可調,不建議開放)

項目位置為什麼不開放
範例固定的 seam:enable_res=0、return_res_context=1mono_aec_nr_res/main.c 的 derive_lane() 一律設定;spatial_linear_context 保持 0(完整 context)這是整合拓樸不是調參:改掉它 ctx.error_spec 為 NULL 或失去 ctx.res_gain。mono 的 RES 增益由這個 lane 自己算,經 ctx.res_gain 交出
AecConfig 其餘 38 欄(共 56 欄;扣掉上列外部 10 欄〔含經 level 改動的 3 個地板欄位〕、進階 4 欄、seam 3 欄與 deprecated 的 enable_delay_est)aec.h以 10 ms 格點撰寫、建立時 retime 的時間欄位(warmup_frames、epc_hangover、ne_recent_*、filter_misadjustment_*);適應步進與模型不確定度(mu、delta、kalman_q_*、shadow_mu_*);偵測門檻;延遲獲取策略(delay_acquire_*、delay_est_init_s、max_delay_ms、delay_buffer_ms);double-talk 政策;保護性開關(enable_saturation、saturation_softclip_ref);預設關閉的實驗(live_observer_*、cng_n2_windowed_psd);衍生值 n_partitions。都是聯合調出來的,validator 只防崩壞不防音質崩壞
編譯期常數(不在 config 內)aec_balanced_config.h 的 AECB_*、SuppressionGainConfig、AecPostConfig、DA_*runtime 完全改不了,也不該提供接口
AnrConfig 其餘 33 欄(共 41 欄:外部為 sample_rate、fft_size 與 level 改的四個;frame_size／hop_size 是衍生值)anr_types.halpha_xi、alpha_s／d／p、L、delta_db、num_init_frames、scene_change_*、noise_gate_*、speech_protect_*、makeup_* 等為時間常數或聯合調過的門檻,以 10 ms／16 ms 為基準 retime;alpha_g 在增益路徑上不被讀取(alpha_attack／alpha_decay 才有作用)
AcStftConfig 其餘欄位audio_stft.h;範例用 ac_stft_config_default()center=0、ola=AC_OLA_ACCUMULATE、spec_scale=ispec_scale=1.0f、自帶 FFT 與 periodic sqrt-Hann 窗:與 AEC 的分析窗配對(50% overlap COLA),改了會破壞重建
範例常數mono_aec_nr_res/main.c 檔頭的 #defineCNG_NR_GAIN_FLOOR = 0.31622777f(−10 dB)、CNG_RNG_SEED = 0x9e3779b9、PSD_SCALE_INV = 1/32768²(int16² → audio power);範例碼可整份複製改寫,不是 ABI
建置旗標pipelines/Makefile-ffp-contract=off 是必要的;SIMD、NO_STDIO、PROFILE、WERROR、EXTRA_CFLAGS 屬建置者
