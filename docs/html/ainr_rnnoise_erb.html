AINR RNNoise-ERB (16 kHz ERB band-gain 模型)

概要

如何呼叫、流程時序圖、外部／內部參數表：ainr_rnnoise_erb_usage。

RNNoise v0.2 方向(Conv+GRU)的輕量 16 kHz 降噪模型:網路輸出 22 個實數 ERB band gain(sigmoid ∈ [0,1]),由 C 端經 partition-of-unity 反向三角矩陣展開為 257 個 bin gain 後,用 rnnoise_apply_gains() 乘在頻譜上。函式庫只做頻域:STFT／ISTFT 是 audiolib 的 AcStft／AcIstft,由應用端執行。出貨設定為純 ERB (use_complex_input=false):complex 分支程式仍在,但網路不建、也不吃 spec_input 的內容(ONNX 簽名仍保留該輸入以固定合約)。

項目值(以現行程式碼為準)
取樣率 / grid16000 Hz;FFT/win/hop = 512/512/256(RNNoiseGridSpec 的 sample_rate／n_fft,RNNoiseGrid.hop 由 rnnoise_grid_make() 推導)
頻譜 bins / ERB 帶257 / 22(RNNoiseGrid.n_bins／.n_bands,每帶 ≥ min_bins_per_band=2 bins greedy-forward 保證)
模型容量cond_size=64、gru_size=128、3 層 GRU;參數 321,110(以出貨 config 實際建構量測)
Lookaheadlookahead_frames=1:conv 3-tap 窗 [t−2,t−1,t] 的 gain 屬於 spectrum t−1(RNNoiseGrid.conv_delay = 2 − lookahead_frames = 1)
feature versionlog_erb_dfn_mean_cplx_unit_0_4k_v8(RNNOISE_FEATURE_VERSION;v8 = 以本專案 16 k 語料校準 EMA init)
正規化 EMAtau = 1.0 s → α = 0.984;ERB init −20/−45 dB、spec init 0.04/0.008、eps 1e-12(皆為 RNNoiseGridSpec 欄位)

公式推導與純 ERB 的表達力限制見 README.md;此頁不重複。

API 用法

注意:rnnoise_compute_features() 一次收一個 spectrum(AcStft 以 spec_scale = grid.stft_scale 產生,不是原始樣本窗); 且 lookahead=1 之下,應用端必須保存並延遲對應的 spectrum 再套 gain。完整生命週期(grid、framing、pool、state 註冊)見 ainr_rnnoise_erb_usage。

ac_stft_push_planar(stft, hop_in, re, im);                    /* 每個 hop；spec_scale = grid.stft_scale */
if (rnnoise_compute_features(st, re, im, erb, spec) == 1) {   /* 已累積 3 框 (oldest -> newest) */
    run_model(erb, spec, h1, h2, h3, band_gains);             /* h1..h3 就地更新 */
    if (rnnoise_frame_finish(st, band_gains) != 0)            /* 非有限：改用 unit gain */
        for (int b = 0; b < grid.n_bands; ++b) band_gains[b] = 1.0f;
    rnnoise_apply_atten_lim(st, band_gains, atten_lim_db);    /* 可選，<= 0 不作用 */
    rnnoise_expand_gains(st, band_gains, bin_gains);
    /* gain 屬於 spectrum t - grid.lookahead_frames：delayed_* 是應用端留下的那一框 */
    rnnoise_apply_gains(st, delayed_re, delayed_im, bin_gains);   /* 內含 x grid.stft_unscale */
    ac_istft_push_planar(istft, delayed_re, delayed_im, hop_out); /* ispec_scale 維持 1.0f */
}

Python 離線:inference.py --config config.ini --model output/rnnoise_best.pth --input in.wav --output out.wav (offline 以 F.pad(pad_left=2−LOOKAHEAD, pad_right=LOOKAHEAD) 一次過整段)。 ONNX 匯出:python export_onnx.py --config config.ini --model output/rnnoise_best.pth --output rnnoise.onnx。

延遲與 warm-up

  • 額外模型 lookahead = 1 hop = 256 samples = 16 ms(lookahead_frames=1: 3-tap conv 窗置中,gain 對應中間框 t−1;conv_delay = 2 − lookahead_frames = 1)。
  • OLA 重疊結構延遲:win−hop = 256 samples = 16 ms;單位增益時總落後 1 + lookahead_frames = 2 hops = 512 samples = 32 ms(README 的 framing 契約說明)。
  • Warm-up:rnnoise_compute_features() 前 2 框回 0(3-frame conv 窗未滿), 此期間無模型輸出、無音訊輸出。
  • EMA 正規化 warm-up:tau = 1.0 s(α=0.984,3·tau ≈ 187.5 框);v8 的 init 校準 (−20/−45 dB、0.04/0.008,量測自本專案 16 k 語料)把 3 秒片段殘留 init 成分壓到 ~4.9% (config.ini [feature] 有完整紀錄)。
  • C 特徵測試實證:stationary 輸入下 ERB mean 特徵收斂到 0、complex 特徵在 4096 框後 仍可觀測(test_rnnoise_features PASS 訊息原文)。
