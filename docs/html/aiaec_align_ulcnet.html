Align-ULCNet（linear AEC → RES+NR post-filter，paper reference）

概要

Shetu et al.（EUSIPCO 2025, arXiv:2410.13620）兩級混合式殘響/殘迴聲 + 噪音抑制器的重建。 task（dataset_gen/model_views.py 的 MODEL_TASKS）= linear_aec_postfilter_res_nr_dereverb：輸入是凍結 PBFDKF linear AEC 的 error（linear_error = mic_postclip − D_hat，不是 oracle residual）與 未對齊 far-end（far_render）；target 是共同的 near_target（去噪、去迴聲、early/dereverb 近端語音）。

16 kHz grid 512/512/256（257 bins）時 alignment 深度 D 固定 64（論文 Dmax）；其他 grid 用 SignalGrid.delay_frames(1.0)（48 kHz 1024/1024/512 → D=94）。參數量實測 672,441 trainable（16k grid；README 記 ~0.67 M，落在論文 0.69 M class）。stream_output_delay = 0。

ONNX / NPU graph boundary（export 腳本已交付：AIAEC/Align_ULCNet/export_streaming_onnx.py 匯出 stateless one-frame graph，K/V/logit/GRU state 全部顯式 I/O， boundary 標記為 stateless_one_frame_delta_state；D 由 checkpoint 的 max_delay_frames 決定並在 export 當下固定進 ONNX shape，見下方 D 覆寫段）：graph 內 = _signed_power（signed pow(0.3) 壓縮與逆冪解壓）、 atan2/cos/sin（壓縮域相位——對 0.3 次方後分量取角，板端不可用原始相位替代）、 ChannelSampledReorientation（C-SamFR reshape）、separable conv + ELU + MaxPool、 FrameDelayAttention（softmax over D）、FrequencyGRU （頻率軸 bidirectional GRU 32×2，逐幀、免 state）、兩個 2 層 128-unit 時間軸 GRU、FC + sigmoid + PReLU、stage-2 CNN complex mask。所有 recurrent state 是顯式 I/O tensor，由 runtime 逐次傳入/傳回。graph 外（C 前後處理）= PBFDKF linear AEC 與 delay 對齊（AEC C 端 seam）、centered sqrt-Hann STFT/ISTFT 與 complex↔RI 轉換 （C 實作 ulcnet_process.c；Python reference StreamSTFT/StreamISTFT）。

far_input_mode 契約：checkpoint contract 記錄 far_input_mode；欄位缺失（legacy）預設 raw_far 並由 load_model 印出；未知值在載入權重前即 ValueError （test：test_load_model_far_input_mode_default_present_and_rejected）。部署契約以 RAW_FAR 為預設、ALIGNED_FAR 為實驗性候選。同一個值由 export_streaming_onnx.py 寫進 ONNX/JSON metadata（far_input_mode 字串 + far_input_mode_c_value），C 端 UlcnetModelIoDescriptor.far_input_mode 與兩個 ULCNet pipeline（mono/4ch）各自的 far_input_mode config 欄位用同一份 ulcnet_far_input_mode_agrees() 做三方比對，metadata/descriptor/pipeline 三者不合即在 pipeline init 或 set_model() 時 reject——詳見 pipeline_ulcnet_mono「far_input_mode 部署契約」節。

API 用法

from AIAEC.Align_ULCNet.denoise import load_model
from AIAEC.aiaec_streaming import StreamSTFT, StreamISTFT

model, grid, linear_contract = load_model("ckpt.pth", "cpu")  # max_delay_frames=8 可覆寫 D
state = model.create_stream_state()          # {"align", "subband_gru0", "subband_gru1"}
stft_err = StreamSTFT(grid.n_fft, grid.hop_len, window)   # window = sqrt-Hann 512
stft_far = StreamSTFT(grid.n_fft, grid.hop_len, window)
istft    = StreamISTFT(grid.n_fft, grid.hop_len, window)
for s in range(0, n, grid.hop_len):                       # 每 hop 256 samples
    for e, f in zip(stft_err.push(err[:, s:s+256]), stft_far.push(far[:, s:s+256])):
        out = model.forward_stream(linear_error=e.unsqueeze(1),
                                   far_end=f.unsqueeze(1), state=state)
        samples = istft.push(out.enhanced[:, 0])          # 穩態每幀 256 samples
python3 AIAEC/Align_ULCNet/streaming.py checkpoint.pth mic.wav far.wav out.wav \
    [--verify] [--input-is-linear-error] [--max-delay-frames N] [--device cpu]

denoise.py 另提供 --stream（offline 評測改走 stream_forward_spec，與逐幀 forward_stream bit-identical——test： test_denoise_stream_path_equals_direct_forward_stream）。D 覆寫 （--max-delay-frames，denoise.py 與 streaming.py 皆有）：checkpoint contract 仍是 source of truth；權重 D-agnostic（D=64 checkpoint 可 strict-load 進 D=8）， 但輸出跨 D 不數值相同（fixture 實測 enhanced max-abs 差 8.9e-6）。

延遲與 warm-up

  • NN 演算法 lookahead = 0 hop；zero-init history ≡ offline 左零 padding， 從 reset 開始的 stream 與 whole-utterance forward 等價，無 warm-up 特例。 實測 stream-vs-offline 最差差異：enhanced 4.1e-8 / mask 1.2e-7 / magnitude_mask 6.0e-8 / delay 4.0e-7（test 檔頭記載；tolerances 以 ~10x headroom 釘在 5e-7 / 2e-6 / 1e-6 / 5e-6）。
  • Framing：center=True 契約 → 半窗 256 samples（16 ms）lookahead；C 端端到端演算法 延遲 = 256 samples（ulcnet_process.h 明文）。
  • C 前後處理 vs Python：float-ULP 級（實測 ~2e-5 絕對值，KISS f32 FFT vs torch double twiddles），非 bit-exact（test_ulcnet_process_c.py 檔頭）。
