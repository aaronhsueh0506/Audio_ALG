ONNX / NPU 邊界現況（AINR + AIAEC 全模型）

概要

「ONNX 邊界」= 匯出圖（NPU 跑的部分）裡有什麼、C 前後處理做什麼、 runtime 要替模型跨呼叫保存哪些顯式 states。現況（對照當前程式碼）：

  • 已有 C 前後處理：AINR 四個模型全部 （dfn2_process.c / dfn3_process.c / gtcrn_process.c / RNNoise-ERB process.c）+ AIAEC 的 Align-ULCNet（ulcnet_process.c）。
  • AIAEC C 邊界：Align-ULCNet 有完整 STFT/WOLA、model-state adapter 與 mono/4ch pipeline；Align-CRUSE/CAGCRN/GTCRN-AENR 共用 aiaec_process.c/h 的 mask composition，DeepVQE-S 有 CCM compose， DFN-AENR 有雙來源 feature state 與 DF compose。後五者尚未接成產品 application，也未接實際 NPU driver。
  • Stateless ONNX export：AINR 有 RNNoise-ERB、GTCRN、DFN2；AIAEC Align-ULCNet 使用專用 delta-state exporter，其餘五個使用共用 AIAEC/export_streaming_onnx.py。GRU/conv/K-V/attention state 皆為顯式 I/O；graph 不在加速器內保存 state。
  • PTQ calibration：AIAEC 六個候選共用 AIAEC/export_streaming_calibration.py（逐幀重放 WAV pair，錄下 每次 invocation 的輸入與 state）；AINR 側 DFN2 另有 AINR/DeepFilterNet2/export_calibration.py。 AIAEC/export_onnx.py + export_calibration.py 是 fixed-block 研究工具（每個 block 重置時間 state），不是部署邊界。

State layout version 與 calibration seam

兩件事跨 export/calibration/C 三方對齊，板端在信任任何一方之前要先比對：

項目現況依據
state_layout_version AINR 三個 exporter 都寫入，目前值皆 1，且與各自 C 標頭巨集 釘在一起（測試逐一比對）：DFN2_MODEL_IO_LAYOUT_VERSION、 GTCRN_MODEL_LAYOUT_VERSION、 RNNOISE_MODEL_IO_LAYOUT_VERSION。AIAEC 側只有 Align-ULCNet 有版本 （STATE_LAYOUT_VERSION=3 ↔ ULCNET_MODEL_IO_LAYOUT_VERSION 3u）。 共用 exporter 目前不寫這個 key，streaming calibration report 對其餘五個 模型寫 null——這是已知缺口，不是遺漏記錄 AINR/DeepFilterNet2/export_onnx.py:36、 AINR/GTCRN/export_onnx.py:37、 AINR/RNNoise-ERB/export_onnx.py:27、 AIAEC/Align_ULCNet/export_streaming_onnx.py:41、 AIAEC/export_streaming_calibration.py:246-249
Calibration 的 far seam Align-ULCNet 的 calibration 刻意使用訓練域的 linear_error + raw_far（calibration 階段不跑 matched filter）， production 則固定部署 aligned_far。report 兩個欄位分開記錄： calibration_far_input_mode 與 deployment_far_input_mode， 不宣稱兩條 seam 相同。其餘五個模型兩欄同為 model_native_far（calibration-only 標記） AIAEC/training_common.py:392,400、 AIAEC/export_calibration.py:48-61、 AIAEC/export_streaming_calibration.py:238-241
D（max_delay_frames） export artifact、calibration artifact 與 C descriptor 三者的 D 必須相同 ——D 決定 state tensor shape 與 host state RAM，但不改學到的權重 shape。 測試已交叉比對 calibration report 與 graph report 的 max_delay_frames/state_layout_version AIAEC/export_streaming_onnx.py:569-570、 AIAEC/export_streaming_calibration.py:242、 AIAEC/tests/test_export_streaming_calibration.py:135-136
Per-tensor precision marker 被 state_precision_policy 點名的 state tensor，在 calibration report 的 inputs 區塊不寫 min/max/ p001/p999，改帶一個 precision 標記。目前只有 Align-CRUSE 有兩筆：state_align_score_sum= float32_no_ptq、state_align_frame_index= int64_no_ptq。理由：無衰減 accumulator 的 range 只描述這次錄了多久， int64 幀計數的 float 百分位什麼都不描述——寫出來反而會引導 quantizer 去用它 AIAEC/export_streaming_onnx.py:93-107、 AIAEC/export_streaming_calibration.py:60-83

DFN-AENR48k 1024/512 （16k 變體 512/256, df_bins=64） 有：DeepFilterNet_AENR/dfn_aenr_process.c/h；error/far 各有獨立 EMA 特徵 state，另含 centered normalized STFT、DFN compose 與 WOLA export_streaming_onnx.py：輸入 4 組三幀 feature window + 全部 GRU/pathway state，輸出 mask/DF coefficients/alpha 與 next state。 error_spec/far_spec 是 DF feature，真頻譜叫 linear_error GRU 5×256、DF ring 5 幀、df_convp 4 幀 c0（96 KB）、EMA 共 256 floats （error/far 兩源各 32 ERB + 96 spec） lookahead 2 hops（mask 1 + DF 1 cascade；16k=32 ms、48k=21.3 ms）， 要 1 hop 須 df_lookahead=0 重訓；全 repo 唯一 normalized=True STFT； ≈310.6 MMAC/s @48k（GRU 佔 59%）。model-state 交接在 dfn_aenr_process.h 內（DFN_AENR_MODEL_IO_LAYOUT_VERSION=1）， 接口是雙輸入（error_hop+far_hop）；model-state commit 同樣是全有或全無的 finite-checked transaction

C model-io helper 的呼叫者現況（決定「有 C 程式碼」與 「已接進產品」不是同一件事）：只有 Align-ULCNet 的 ulcnet_model_io.c ← ulcnet_accelerator_adapter.c ← pipelines/{mono,4ch}_alignulcnet/main.c 這條鏈有 production caller。 AINR/GTCRN、AINR/RNNoise-ERB、 AINR/DeepFilterNet2/dfn2_model_io.c 與 AIAEC/DeepFilterNet_AENR/dfn_aenr_process.c 的 model-state 函式目前 只有測試呼叫；共用 aiaec_process.c/h 亦無 pipelines/ 呼叫者。這是整合缺口，不是權重或前後處理缺口。

Calibration 現況（六個 AIAEC 候選共用一支工具）： AIAEC/export_streaming_calibration.py 對六個模型都可跑，report schema = aiaec-stateless-stream-calibration-v1。逐模型差異只有三處—— Align-ULCNet 的 calibration_far_input_mode=raw_far ／ deployment_far_input_mode=aligned_far（其餘五個兩欄同為 model_native_far）；Align-CRUSE 需單一不中斷錄音（工具會拒絕 用重置片段拼出 --frames）且有兩筆 per-tensor precision marker； state_layout_version 目前只有 Align-ULCNet 有值，其餘五個是 null。
