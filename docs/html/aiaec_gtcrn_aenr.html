GTCRN-AENR（linear AEC → RES+NR，project variant）

概要

以審計過的 AINR/GTCRN（Xiaobin Rong et al., INTERSPEECH 2024）為骨幹的 project variant——不是作者的 AEC 論文/checkpoint，報告時必須標示 「GTCRN-AENR project variant」。task（dataset_gen/model_views.py）= linear_aec_postfilter_res_nr_dereverb：輸入是凍結 PBFDKF 的 linear_error（= mic_postclip − D_hat）與未對齊 far_end； target 是 near_target。唯一拓撲改動是第一個 conv：一路頻譜的 [mag,re,im]+SFE 是 9 通道，error+far 兩路 → en_convs[0] in_channels 9→18；其後 ERB、SFE、group temporal conv、TRA、兩個 DPGRNN、decoder、CRM 完全沿用。

Grid 鎖死 16 kHz / 512/512/256：以 48k grid 建構直接 ValueError（test：test_gtcrn_aenr_rejects_non_upstream_grid）。 參數量實測 24,389 trainable + 24,576 frozen ERB 參數（requires_grad=False）。 stream_output_delay = 0。

ONNX / NPU graph boundary（尚無 export 檔；boundary 由 streaming reference 固定）： graph 內 = _three_features（mag/re/im）、erb.bm/bs（ERB matmul）、 SFE、ConvBlock、GT block（depthwise dilated conv + TRA attention GRU + sigmoid gate）、DPGRNN（頻率軸 bidirectional intra GRU 每幀獨立 + 時間軸 inter GRU ×2）、decoder GT blocks（stride-1 depthwise ConvTranspose2d—— streaming/export 時以 _deconv_as_causal_conv 轉成 kernel 翻轉的等價因果 conv，權重轉換期恆等式）、CRM 套用（self.mask）。graph 外（C 前後處理）= PBFDKF linear AEC（AEC C seam）、centered sqrt-Hann STFT/ISTFT 與 complex↔RI。 recurrent state 全為顯式 I/O tensor。

上游已有 N=1 streaming 參考：AINR/gtcrn_github/stream/gtcrn_stream.py 的 cache layout（conv_cache (2,1,16,16,33) / tra_cache (2,3,1,1,16) / inter_cache (2,1,33,16)，合計 ≈70 KB fp32）；AENR 變體 layout 完全對應 （本頁 State 表實測 70.5 KB）。移植坑：AINR/GTCRN/model.py 的 GRNN zeros 初始 hidden 未帶 dtype，double()/fp16 路徑會 dtype mismatch。

API 用法

from AIAEC.GTCRN_AENR.denoise import load_model
from AIAEC.aiaec_streaming import StreamSTFT, StreamISTFT
from AIAEC.training_common import LinearAecEngine

model, grid, linear_contract = load_model("ckpt.pth", "cpu")
linear_aec = LinearAecEngine(n_lanes=1, sample_rate=grid.sr, contract=linear_contract)
error, _echo_estimate = linear_aec(mic, far, grid.sr)   # streaming.py 中整檔 offline
state = model.create_stream_state()      # 16 cells（見 State 表）
stft_err = StreamSTFT(grid.n_fft, grid.hop_len, window)
stft_far = StreamSTFT(grid.n_fft, grid.hop_len, window)
istft    = StreamISTFT(grid.n_fft, grid.hop_len, window)
for s in range(0, n, grid.hop_len):
    for e, f in zip(stft_err.push(error[:, s:s+256]), stft_far.push(far[:, s:s+256])):
        out = model.forward_stream(linear_error=e.unsqueeze(1),
                                   far_end=f.unsqueeze(1), state=state)
        samples = istft.push(out.enhanced[:, 0])

延遲與 warm-up

  • NN 演算法 lookahead = 0 hop；zero-init ≡ offline 左零 padding （F.pad 左補），無 warm-up 特例。
  • 實測 stream-vs-offline：96 隨機幀 max-abs 1.1e-6（enhanced/mask/erb_complex_mask）， TOL 釘 2e-5（test_streaming_gtcrn_aenr.py 檔頭：float 累加噪音，非 layout 錯）。
  • Framing：center=True → 半窗 256 samples（16 ms）lookahead；端到端演算法延遲 256 samples。
  • 運算量實測 ≈0.535 MMAC/frame ≈ 33.5 MMAC/s @16k（readiness §3.5）。
