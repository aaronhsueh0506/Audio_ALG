4ch 線性 AEC flow(mcab)+ BF helper + Align-ULCNet NN 後級(直送路徑)

概要

pipelines/ulcnet/4ch_alignulcnet/main.c:沿用四聲道線性 AEC flow mcab(共用 delay + 4 AEC lanes,見 pipeline_4ch)與 sample 層 helper McabSampleBeam(SRP-PHAT + BF),flow 以 enable_post = 0 建立(ulcnet_example_unit_config():mcab_default_config(ULCNET_SR) 加 fft_size = ULCNET_N_FFT)——每 hop 不呼叫 mcab_sample_beam_fuse()(回 MCAB_INVALID_ARGUMENT),後級(RES／NR／CNG／ISTFT)不使用,由範例 stage pipelines/ulcnet/ulcnet_nn_stage.{h,c} 完全取代;沒有 token,也不需要「放棄」呼叫,下一個 process_* 直接接手。沒有 ULCNet wrapper 函式庫,mcab 也不是函式庫而是 flow 層:lane 與共用 estimator 由應用建立(範例用 mcab_sample_flow.h)再以指標交給 mcab,flow 加 helper 是一塊 pool(mcab_sample_flow_get_mem_size()、mcab_sample_beam_get_mem_size()),stage 另一塊(ulcnet_nn_stage_mem_size(0));stage 是範例碼(沒有 ABI、沒有 layout version)。stage 只吃三樣東西:BF 後頻譜(beam.spectrum)、同一次呼叫的原始 far hop、info.delay.changed／info.delay.solid。每個 binary 服務一個編譯期格點:16 kHz / 512 / 256 / 257 bins或48 kHz / 1024 / 512 / 513 bins；runtime config 不符該 build 即 reject(ulcnet_example_unit_config() 的 grid 與 stage 的 ULCNET_BINS 必須一致,main.c 在 init 後比對 mcab_hop_size()／mcab_n_freqs())。

直送路徑(direct path):BF 的輸出頻譜就是模型的 error 幀。bf_process_with_weights() 產出的 bf_spectrum 已經是「當前 hop 的 sqrt-Hann、50% overlap、一 hop 一幀」分析幀——各 lane 的 AEC 用同一張窗、同一個 overlap 分析,beamformer 只是逐 bin 加權——所以它不經過任何重建或再分析,直接拆成 err_re/err_im 交給模型。far 分支用同一個 hop 的原始 far 走同樣的一 hop 一幀 framing(ac_stft_push_planar()),沒有補償 buffer。

ONNX/NPU graph 邊界與 runtime 保存的 NN states 與 mono 變體完全相同(graph 內:reorient/attention/GRU/mask 組合, learned compute only;graph 外:STFT/WOLA/AEC/beamform/delay policy＋固定前後端(signed-pow 壓縮特徵/mask 乘法/逆冪, 封在 model_io prepare/commit;graph 止於 complex_mask 1×1 Conv);runtime 保存 far K/V window、logit window、GRU h;四個 state 由 caller pool 保存,每個 *_out 就地綁定到同名輸入的位址)——見 pipeline_ulcnet_mono 的邊界表。VAD 由呼叫端交給 helper 的 mcab_sample_beam_process_with_activity()(板端骨架 main.c 以固定的 0／0 帶入;helper 另有 auto-VAD fallback 的 mcab_sample_beam_process(),本範例不用)。

API 用法

呼叫順序:mcab_default_config(ULCNET_SR) 改 fft_size 與 enable_post = 0 → mcab_get_mem_requirements()、mcab_sample_flow_get_mem_size()、mcab_sample_beam_get_mem_size()、ulcnet_nn_stage_mem_size(0)、ulcnet_accelerator_adapter_get_mem_size() → mcab_sample_flow_init()、mcab_sample_beam_init(…, flow)、ulcnet_nn_stage_init()、adapter init → ulcnet_nn_stage_set_model() → 每 hop 一次 → destroy(mcab_sample_beam_destroy() 再 mcab_sample_flow_destroy())。完整可編譯範例(含 phased 變體)、流程時序圖與參數表收在 pipeline_ulcnet_usage、pipeline_ulcnet_sequence 與 pipeline_ulcnet_params。每 hop 的核心如下:

McabSampleBeamResult beam;  McabSampleBeamInfo info;                        /* unit = McabSampleBeam*;mics=[ULCNET_HOP][4], far/out=[ULCNET_HOP] */
if (mcab_sample_beam_process_with_activity(unit, mics, far, vad, vad, NULL, &beam, &info) != MCAB_OK ||
    ulcnet_nn_stage_begin_complex(stage, beam.spectrum, far,
            (UlcnetNnDelay){ info.delay.changed, info.delay.solid }) != 0 ||
    ulcnet_nn_stage_process(stage, out) != 0) {       /* 或 nn_begin → NPU → nn_end(rc) → end */
    mcab_sample_beam_reset(unit);  ulcnet_nn_stage_reset(stage);     /* 被拒: 兩者一起 reset */
}

推論留給 NPU 時,同一個 hop 拆成 nn_begin(回 1 並交出 UlcnetNnJob;0 = 本 hop 無模型幀)、nn_end(rc)、end(out);rc != 0 或輸出有非有限 bin 時該幀走 identity(fail-open),序列錯誤回 ULCNET_NN_STAGE_SEQUENCE_ERROR。reprime 計數在 begin 遞減,所以與一次呼叫版本逐位元相同(test_phased_hop)。

板端若有由同一 hop 的 lane 頻譜算出的 per-bin mask 與 VAD(例如 masker 讀 lane 0),helper 的 mcab_sample_beam_process_with_activity() 要在 lane 與 beamformer 之間讓出控制權:它就是 mcab_sample_beam_process_front() 加 mcab_sample_beam_process_beam(front, v, v, NULL)。

McabFront front;
mcab_sample_beam_process_front(unit, mics, far, &front);          /* = mcab_process_front():共用 aligner 與四條 lane;front.linear_spectra[4] 唯讀 */
/* 呼叫端:由 front.linear_spectra[0] 算 mask(n_freqs 個 int)、vad_raw、vad_out */
mcab_sample_beam_process_beam(unit, &front, vad_raw, vad_out, mask, &beam, &info);   /* SRP-PHAT、BF;mask 可為 NULL */
/* info: doa_raw/smooth/used(rad,NaN = 無)、bf_adaptive、delay */
ulcnet_nn_stage_begin_complex(stage, beam.spectrum, far, (UlcnetNnDelay){ front.delay.changed, front.delay.solid });
/* 之後 nn_begin / nn_end / end 與上面相同 */

mask[f] 非 0:SRP 使用該 bin、BF 凍結該 bin 的適應;NULL = 全部 bin 給 SRP、都不凍結。vad_raw 決定 SRP 該 hop 是否分析,vad_out 進 DOA smoother 並凍結 BF 適應(須為 0／1)。front.linear_spectra 有效至下一次 process_front()／process_with_activity()／reset()／destroy();沒有待處理的 front 時 process_beam() 回 MCAB_SEQUENCE_ERROR。DOA 與 BF 適應狀態在 McabSampleBeamInfo(info);mcab_get_last_timing() 回上一 hop 的各階段微秒數(需以 -DMCAB_STAGE_TIMING=1／-DAEC_STAGE_TIMING=1 建置,否則為 0)。

  • ulcnet_nn_stage_set_model():struct by-value 複製;model->user 指向物由 caller 保活。會 infer 的 model 必須發布 descriptor(model->infer && !model->io_descriptor 直接 reject);production far branch 固定為 caller 的 raw far,因此非 NULL descriptor 必須通過 ulcnet_model_io_descriptor_validate()(aligned／未知 descriptor reject)。runtime 不提供 far-mode setter。
  • 唯讀 accessor:flow 的尺寸查詢(mcab_hop_size()／mcab_fft_size()／mcab_n_freqs()／mcab_sample_rate())、mcab_get_last_timing()。沒有 beam hop:直送路徑不重建時域 beam hop,helper 的輸出是 beam.spectrum 與 beam.weights(mcab_sample_beam.h)。

沒有執行期強度 setter,而且是刻意的。標準 4ch 範例有 aec_res_set_level() / anr_set_level(),作用在應用自建的 AecRes 與 AnrDenoiser 上(見 pipeline_4ch 的「執行期強度控制」表);本變體沒有這兩個物件,因為 flow 是 enable_post = 0 的 front-only 組態,不 carve fuse 緩衝(mcab 本身沒有 RES;要 RES 的應用改用 enable_post = 1,在 mcab_fuse() 之後自建 AecRes),塑形輸出的是 ULCNet 的 mask。要改強度,請重新訓練/更換模型,或改用有 DSP 後級的 pipeline_4ch。

Block diagram(每 hop 程式流)

主程式(ulcnet/4ch_alignulcnet/main.c 的 ulc_hop()):

   = mcab_sample_beam_process_front → mcab_sample_beam_process_beam
  ulcnet_nn_stage_begin_complex(stage, beam.spectrum, far, {info.delay.changed, info.delay.solid})
  ulcnet_nn_stage_process(stage, out) = [nn_begin → 模型 → nn_end] → end

 └─ mcab_process_front(flow, mics, far, &front)             共用 delay + 4 lanes(DSP 錯誤時 flow 已 reset)

   呼叫端(可選):mask、vad_raw、vad_out ← front.linear_spectra[0]

 │   (front.n_freqs 與 helper 格點不符 → MCAB_INVALID_ARGUMENT)

 └─ beam.spectrum = bf_spectrum(直接當 error 幀,無重建)

 ├─ if (delay.changed || FIXED 首次 solid):
 │        model.reset(user)                                  flush runtime K/V+logit+GRU

唯一的延遲來源是 ULCNet synthesis 的半窗 trim:幀 #0 的區塊落在被裁掉的半窗裡,所以 ac_istft_push_planar()（AC_OLA_ENV_NORM）在 hop#0 回 0 樣本(pipeline 補零),之後每 hop 一個完整 hop。兩個分支都從當前 input hop 取幀,所以模型看到的 err/far 幀對永遠屬於同一個 input hop——直送路徑沒有 one-hop far 補償 buffer;test_raw_far_timestamp_after_fixed_delay_lock() 要求 far 脈衝落點的 offset 為 +0。

err 分支讀的是分析 seam。四條 lane 以 context-only(enable_res=0 / return_res_context=1)建立;各 lane 的 error_spec 一律是被選中的線性殘差,輸出守衛不改動它,BF 加權出來的 err 幀(beam.spectrum)就是這些殘差的加權和,沒有 capture 候選(殘差與 seam 的細節見 pipeline_ulcnet_mono)。各 lane 的渲染基底(McabFront.render_spectra)不餵給模型;identity／fail-open 的 hop 輸出未經守衛的殘差。

Identity reprime(alignment 邊界,option A)

邊界處理只做 model->reset 與武裝 identity reprime,不清任何 C 側 buffer:從邊界 hop 起的 ULCNET_NN_STAGE_REPRIME_FRAMES(= 1)個發射幀走 identity 且完全不呼叫 infer;reprime 期間再來一次邊界會重新武裝(不累加);ulcnet_nn_stage_reset() 會把它歸零。常數 1 由 tests/test_4ch_ulcnet.c 的 test_reprime_straddle_derivation() 在無邊界對照跑中以脈衝標記量出(ERROR 路是上界、FAR 路是推導);兩個 grid 的實測表見 pipeline_ulcnet_detail。

頻譜一致性註記(直送路徑的已知取捨)

beam.spectrum(BF 輸出)是逐 bin 加權的頻譜,一般不對應任何時域訊號的 STFT(inconsistent spectrogram);模型看到的就是這個未經 WOLA 投影的頻譜。輸入端的這個差異在真實 4ch 錄音上的大小與頻帶分佈待量測;輸出端不受影響(WOLA∘STFT∘WOLA 等於 WOLA)。

延遲與 warm-up

  • 總附加演算法延遲 = 1 compiled-grid hop:16 kHz 為 256 samples / 16 ms,48 kHz 為 512 samples / 10.67 ms。組成只有 ULCNet synthesis 的半窗 trim;BF 頻譜與 far 分析都在同一個 hop 完成,不加延遲。
  • 測試佐證:鎖定後 raw far 脈衝落點 = 脈衝 + 1 hop。16 kHz:far[2085] → out[2341](expected 2341,offset +0,peak 1.0000);48 kHz:far[4133] → out[4645](offset +0,peak 1.0000)。identity E2E:hop#0 全零,之後 out[hop p] 逐 byte 等於測試自己從「模型實際看到的頻譜」合成的參考(capture model,FIXED delay 0、無邊界;混合規則:hop 0 零、hop p≥1 混 p−1 與 p 兩幀)。
  • delay change(front.delay.changed)或 FIXED 首次 delay solid:stage 呼叫 model->reset 並武裝 identity reprime,不清任何 buffer(前端自行 realign 四條 lane;stage 的 far 分析與 synthesis 連續跑)。跨界的 1 幀改走 identity 且不 step 模型(見上節)。changed 涵蓋 unlock 後同值重鎖(新的可用 alignment generation),因此 unlocked 期間累積的 recurrent state 會在重新套用前被 flush。
  • delay lock 不閘控模型:模型從第一個 hop 起照常步進並套用(far 恆為 caller 的 raw far);alignment 可用或改變時 reset state。
  • 錯誤處理:helper 或 stage 回負值(尺寸不符、front 回錯誤、synthesis 吐出非 0 且非整 hop 的樣本數)→ 整合者把 helper(連帶 flow)與 stage 一起 reset(ulc_process():mcab_sample_beam_reset() 加 ulcnet_nn_stage_reset());1-hop 前導重新開始。

pipeline_ulcnet_usage、pipeline_ulcnet_sequence、pipeline_ulcnet_params呼叫範例(init／每 hop／reset／destroy)、流程時序圖、外部／內部參數表與 public／internal 函式表
pipelines/4ch_aec_bf_nr_res/mcab.h / .c、mcab_sample_flow.h / .c、mcab_sample_beam.h / .c線性 AEC flow(MCAB_DESCRIPTOR_VERSION 1／MCAB_LAYOUT_VERSION 26;archive libaudio_pipeline_mcab.a 只含 mcab.o)與兩個 sample helper(lane／estimator 一次建置、SRP/BF),本頁的前級
pipelines/ulcnet/ulcnet_nn_stage.h / .c、pipelines/ulcnet/tests/test_ulcnet_nn_stage.c後級 stage(範例碼,沒有 ABI)與其 stage 層測試
AIAEC/Align_ULCNet/ulcnet_process.h / .cchain 實作 + UlcnetModel 邊界(兩變體共用);本 pipeline 用的是 ulcnet_framing_config()（center 0、一 hop 一幀的 AcStft 與 AC_OLA_ENV_NORM 的 AcIstft 設定）
pipelines/ulcnet/4ch_alignulcnet/tests/test_4ch_ulcnet.c(flow + helper 加 stage 的組合層)測試函式:identity E2E(1-hop timing、capture-model 自建參考)、counting model(每 hop 一次 infer、fail-open)、MATCHED 同值重鎖 reset、FIXED 首次對齊 reset、FIXED pre-lock seam 逐 byte 等於 raw far、example unit config／grid、create-vs-pool parity、DSP 錯誤後 helper(連帶 flow)與 stage 一起 reset 等於新建的一對(test_recovery_equals_fresh_pair)、far timestamp、UNLOCKED 仍套用、NaN/Inf、partial-write、identity-reprime straddle 推導(脈衝標記 / 無邊界對照跑;far 路是推導、error 路只是上界)、reprime 行為(delay change + FIXED fill)、raw-only descriptor gate、phased 序列(test_phased_hop:begin／nn／end 對一次呼叫版逐位元相同)。helper 層的拆分呼叫(front + beam(v, v, NULL) 對 process_with_activity 逐位元相同、mask 與 vad 確實影響 SRP／BF、序列與參數守衛:test_split_null_mask_equals_begin、test_split_mask_and_vad_reach_srp_bf、test_split_sequence_guards)在 4ch_aec_bf_nr_res/tests/test_mcab_sample_beam.c;flow 本身在 4ch_aec_bf_nr_res/tests/test_mcab.c
pipelines/ulcnet/4ch_alignulcnet/main.c板端 adapter 參考骨架(fail-open,accelerator run() 回 -1 佔位);收 --delay-mode/--delay-num-filters/--fixed-delay 並打印 resolved profile、unit pool bytes、stage pool bytes 與 adapter pool bytes;數字由 common/example_cli.h 的 example_cli_parse_int() 嚴格解析,3x、12x 等畸形值結束碼 2
pipelines/ulcnet/4ch_alignulcnet/Makefile應用入口(薄殼,測試與建置由 4ch_aec_bf_nr_res/Makefile 轉發:make -C pipelines/ulcnet/4ch_alignulcnet test);ulcnet_nn_stage.o 與 ULCNet pre/post 直接連結到應用。libaudio_pipeline_mcab.a 只含 mcab.o,不含 sample helper 與 ULCNet stage。grid 用 make ULCNET_GRID=16k|48k 選(只套到 ULCNet TU 並進 CFG_SIG),make test-grids 一次測兩個 grid。

板端骨架印 4ch_alignulcnet: fail-open board skeleton PASS,並打印 unit pool 2994640 bytes … + stage pool 36400 bytes(16 kHz, matched n=5)/unit pool 6304624 bytes … + stage pool 71728 bytes(48 kHz)與 accelerator adapter pool 75280 bytes(D=8, 16 kHz)/142864 bytes(48 kHz);reprime 的 ERROR 路在 48 kHz 比 FAR 路多 1 幀(AEC 濾波器尾音,見上節)。
