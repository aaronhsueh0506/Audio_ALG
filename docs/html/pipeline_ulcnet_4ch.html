audio_pipeline_4ch_ulcnet — 4ch 空間前級 + Align-ULCNet NN 後級(直送路徑)

概要

pipelines/4ch_alignulcnet/audio_pipeline_4ch_ulcnet.{h,c}:沿用四聲道空間前級(共用 delay + 4 AEC lanes + SRP-PHAT + GSC,見 pipeline_4ch),但核心的 post-beam RES/NR 路徑不使用——每個 pre frame 以 four_aec_nr_res_abandon_pre() 釋放,由 Align-ULCNet chain 完全取代 post 級。每個 binary 服務一個編譯期格點:16 kHz / 512 / 256 / 257 bins或48 kHz / 1024 / 512 / 513 bins；runtime config 不符該 build 即 reject(audio_pipeline_4ch_ulcnet.c:122-124)。

直送路徑(direct path):GSC 的輸出頻譜就是模型的 error 幀。gsc_process_with_weights() 產出的 gsc_spectrum 已經是「當前 hop 的 sqrt-Hann、50% overlap、一 hop 一幀」分析幀——各 lane 的 AEC 用同一張窗、同一個 overlap 分析,beamformer 只是逐 bin 加權——所以它不經過任何重建或再分析,直接拆成 err_re/err_im 交給模型(audio_pipeline_4ch_ulcnet.c:742-745)。far 分支用同一個 hop 的 far 源走同樣的一 hop 一幀 framing(ulcnet_analysis_push_frame(),:746-747),沒有補償 buffer。相對於舊的「beam WOLA 回時域再重新分析」路徑,每 hop 省下一次 IFFT 與一次 RFFT,並少一個 hop 的延遲。

ONNX/NPU graph 邊界與 runtime 保存的 NN states 與 mono 變體完全相同(graph 內:reorient/attention/GRU/mask 組合, learned compute only;graph 外:STFT/WOLA/AEC/beamform/delay policy＋固定前後端(signed-pow 壓縮特徵/逆冪, 封在 model_io prepare/commit);runtime 保存 far K/V ring、logit 史、GRU h)——見 pipeline_ulcnet_mono 的邊界表。VAD 僅提供外部版 process_with_activity()(auto-VAD fallback 留在標準 wrapper;auto_vad_* 欄位驗證但不使用)。

API 用法

AudioPipeline4ChConfig cfg = audio_pipeline_4ch_ulcnet_default_config();
/* sample rate/FFT 取自編譯期 ULCNET_SR/ULCNET_N_FFT */
AudioPipeline4ChUlcnetMemReq req;
audio_pipeline_4ch_ulcnet_get_mem_requirements(&cfg, &req);
void* pool = platform_alloc(req.bytes, req.alignment);
AudioPipeline4ChUlcnet* p = audio_pipeline_4ch_ulcnet_init_ex(pool, req.bytes, &cfg, &req);

UlcnetModel model = { my_user, my_infer, my_reset, &exported_descriptor };
audio_pipeline_4ch_ulcnet_set_model(p, &model);           /* NULL 可清除; 不觸發 reset */

while (stream) {   /* mics=[ULCNET_HOP][4], far/out=[ULCNET_HOP] */
    audio_pipeline_4ch_ulcnet_process_with_activity(p, mics, far, vad, out);
}
audio_pipeline_4ch_ulcnet_reset(p);    /* 也呼叫 model->reset; 不動 model 安裝 */
audio_pipeline_4ch_ulcnet_destroy(p);  /* 不釋放 caller pool */
  • set_model():struct by-value 複製;model->user 指向物由 caller 保活。會 infer 的 model 必須發布 descriptor(model->infer && !model->io_descriptor 直接 reject,:654);production far branch 固定為 aligned-far seam,因此非 NULL descriptor 必須通過 ulcnet_model_io_descriptor_validate()(raw/未知 descriptor reject)。runtime 不提供 far-mode setter。
  • 唯讀 accessor 只有四個尺寸查詢(_hop_size()／_fft_size()／_n_freqs()／_sample_rate())與 audio_pipeline_4ch_ulcnet_last_delay()。沒有 beam hop accessor:直送路徑不再重建時域 beam hop,舊的 _last_beamformed_error() 已隨 layout v17 一起從 C API 移除(audio_pipeline_4ch_ulcnet.h:219-222)。

沒有執行期強度 setter,而且是刻意的。標準 wrapper 有 audio_pipeline_4ch_set_aec_preset() / _set_nr_mode(),本變體 兩個都不提供——因為它沒有可以重新指定的強度面。本 wrapper 的核心是 core.enable_post = 0 的 pre-only 組態(validate_config() 拒絕任何其他值,:132-138),而 enable_post = 0 時核心根本不存在 post 級抑制器、也不存在 NR 實例;每個 pre frame 都以 four_aec_nr_res_abandon_pre() 釋放,塑形輸出的是 ULCNet 的 mask。核心那兩個 setter 在 pre-only 核心上本來就回 −1(見 pipeline_4ch 的「執行期強度控制」表),所以這一層不轉出它們。要改強度,請重新訓練/更換模型,或改用有 DSP 後級的 pipeline_4ch。

唯一的延遲來源是 ULCNet synthesis 的半窗 trim:幀 #0 的區塊落在被裁掉的半窗裡,所以 ulcnet_synthesis_push() 在 hop#0 回 0 樣本(pipeline 補零),之後每 hop 一個完整 hop。兩個分支都從當前 input hop 取幀,所以模型看到的 err/far 幀對永遠屬於同一個 input hop——舊版需要的 one-hop far 補償 buffer 在直送路徑下不存在,而且測試會抓:把 far 分支延一個 hop,far-timestamp 測試立刻偏 +1 hop 變紅。

err 分支不保證每個 hop 都是誤差。模型的 err 幀來自 GSC 對 pre.linear_spectra 的加權,而那四路是各 lane 的 formed 頻譜;四條 lane 都以 enable_res=0 / return_res_context=1 建立,而 lib/aec 的 formed 選擇器只在這個 context-only 模式多開一個 capture 候選:上一個 hop 的濾波品質判定尚未認可線性估計、且該 lane 被選中的殘差在這個 hop 的能量大於同一 hop 的 mic capture 時,該 lane 的時域 hop 與頻譜一起改送 capture(既有 30-sample crossfade 承接邊界)。這種 hop 上 beamform 出來的 err 幀混的是 mic 原樣,不是誤差。

Identity reprime(alignment 邊界,option A)

model->reset 清掉 runtime 的 K/V ring、logit 史與 GRU h,但 C 側 framing 狀態是連續跑的(核心 lane 的分析、本 wrapper 的 far 分析與 synthesis 都不清):邊界當下還在飛的分析窗仍跨在邊界上。在那種幀上 step 模型,等於用半舊的 err/far 幀對把剛清掉的 state 重建回去。

政策:從邊界 hop 起的 AUDIO_PIPELINE_4CH_ULCNET_REPRIME_FRAMES 個發射幀走 identity(誤差原樣)且完全不呼叫 infer——K/V、logit、GRU 都不前進;等到 err 與 far 兩路分析窗都只含切換後的 hop,才同時恢復 step 與 apply。reprime 期間再來一次邊界會重新武裝(不累加);audio_pipeline_4ch_ulcnet_reset() 會把它歸零(該路徑會 re-init 兩個 chain 結構,history 已清空)。compute 只會少 1 幀推論,不會加倍。

常數 = 1,而且是量出來的(audio_pipeline_4ch_ulcnet.h:153)。推導:兩個分支都從當前 input hop 取幀(hop T 的 GSC 頻譜、以及用 hop T 推入的 far 分析),而每個 50%-overlap 幀橫跨兩個 hop,所以只有邊界 hop T 發射的那一幀還蓋到切換前的 hop T−1,hop T+1 的幀已經只含切換後的兩個 hop。這與 mono wrapper 的 1 相同(mono 同樣兩路都從當前 hop 取幀)。測試 test_reprime_straddle_derivation() 用「切換前最後一個 input hop 正中央打一個單位脈衝、其餘全靜音」在一個完全沒有邊界的對照跑(FIXED delay 0)裡量,所以 reprime 邏輯不參與量自己;兩路分開標記。

頻譜一致性註記(直送路徑的已知取捨)

gsc_spectrum 是逐 bin 加權的頻譜,一般不對應任何時域訊號的 STFT(即所謂 inconsistent spectrogram);舊的 WOLA 來回一趟等於把它投影到一個 consistent 的頻譜上,直送路徑則不做這個投影,模型看到的是未投影的 GSC 頻譜。這個投影殘差是模型輸入端的差異:先前在真實 4ch 錄音上量過 round-trip residual 約 −30 dB complex(−33 dB magnitude),語音帶 750–4000 Hz 為 −36..−43 dB,該組錄音最差在 DC 約 −22 dB;合成場景(噪聲 far＋0.6× 回音＋近端單音)量到 −44 dB complex,最差落在 Nyquist(−16 dB)與 bin 126–130(約 −20 dB),DC 反而最好(−51 dB)——最差頻段是場景相關的,不能一概而論。輸出端則不受影響:identity model 下新舊兩版的輸出只差浮點雜訊(−137 dB,錯一個 hop 對齊後),因為 WOLA∘STFT∘WOLA 等於 WOLA。目前尚未做聽感 A/B,所以「模型對未投影頻譜的反應」只有這個量級佐證,沒有主觀驗證。

邊界行為也和 v16 不同:v16 在每個對齊邊界會清掉 beam WOLA 的 OLA 累加器(與 far 補償 buffer),等於在邊界 hop 送出一個半窗衰減的 hop(實測 out_old[T+1] ≈ window² × out_new[T],擬合殘差約 −50 dB);v17 沒有重建階段、不清任何 buffer,邊界 hop 完整送出。模型 stepping 也隨 REPRIME 2→1 改變:v16 在 T、T+1 兩幀不推論,v17 只在 T 那一幀不推論。

延遲與 warm-up

  • 總附加演算法延遲 = 1 compiled-grid hop:16 kHz 為 256 samples / 16 ms,48 kHz 為 512 samples / 10.67 ms(舊的直送前路徑是 2 hops)。組成只有 ULCNet synthesis 的半窗 trim;GSC 頻譜與 far 分析都在同一個 hop 完成,不加延遲。
  • 測試佐證:pre-acquisition seam 的 far 脈衝落點 = 脈衝 + 1 hop。16 kHz:far[2085] → out[2341](expected 2341,offset +0,peak 1.0000);48 kHz:far[4133] → out[4645](offset +0,peak 1.0000)。identity E2E:hop#0 全零,之後 out[hop p] 逐 byte 等於測試自己從「模型實際看到的頻譜」合成的參考(capture model,FIXED delay 0、無邊界;混合規則:hop 0 零、hop p≥1 混 p−1 與 p 兩幀)。
  • delay change(pre.delay.changed)或 FIXED 首次由 ring-fill raw far 轉為可用 aligned far:呼叫 model->reset 並武裝 identity reprime,不清任何 buffer(核心自行 reset 四條 lane;本層的 far 分析與 synthesis 連續跑)。跨界的 1 幀改走 identity 且不 step 模型(見上節)。changed 涵蓋 unlock 後同值重鎖(新的可用 alignment generation),因此 unlocked 期間累積的 recurrent state 會在重新套用前被 flush。
  • delay lock 不閘控模型:ring 尚無法供應該 offset 時 seam 整 hop 傳 raw far(FIXED 的 ring-fill 窗也是 raw,不是靜音),模型照常步進並套用;可供應後 reset state,再改用 aligned far。切換是整 hop 的,不會有半 raw 半 shifted 的 hop。
  • 錯誤處理:內部 DSP 錯誤(尺寸不符、abandon_pre 失敗、synthesis 吐出非 0 且非整 hop 的樣本數)→ wrapper 自我 reset 並回核心 status code(與標準 wrapper 同慣例);1-hop 前導重新開始。
