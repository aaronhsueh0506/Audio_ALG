NR C library(MMSE-LSA denoiser)— lib/nr/c_impl

概要

MmseLsaDenoiser(V3-2)是 OM-LSA 族降噪核心:Ephraim-Malah 1985 MMSE-LSA 增益 + Cohen&Berdugo 2001 MCRA 噪聲估計 + SPP。頻域 I/O:輸入/輸出都是 Complex[n_freqs] 頻譜,window / forward FFT / inverse FFT / OLA 全由呼叫端負責(mono pipeline 直接餵 AEC 的 ctx.error_spec,一次 FFT 走完 AEC+NR+RES 三級)。純 DSP、無 NN/NPU 成分;全部 state 收在 MmseLsaDenoiser C struct(caller pool 或 heap)。

mono pipeline(pipelines/audio_pipeline.c)實際使用的 seam 是 mmse_lsa_process_gain() + mmse_lsa_get_gain():算出每 bin 增益但不套用,並可把外部殘留回音 PSD R² 折進噪聲底(unified gain,ξ = S²/(N²+R²));MCRA 追蹤器只吃乾淨功率,R² 不污染噪聲估計。下游再取 g_total = min(G_nr, G_res)。

格點規則:frame = fft、hop = frame/2、無 zero-padding(mmse_lsa_validate_config() 強制)。常數重定時:大多數係數以 10 ms hop 為著作基準(mmse_lsa_retime_alpha/_frames),少數(alpha_xi、alpha_attack、L=32 與各 strength overlay)以 16 ms 為基準(*_ref(..., 0.016))——兩個著作格點並存是刻意的,詳見 mmse_lsa_types.h 各欄註解。

Strength modes(MmseLsaNrMode;g_min 為振幅 dB,/20 慣例):

另有正交的內容保留 overlay mmse_lsa_apply_stationary()(Wiener 下界 (ξ/(β+ξ))^p,p=2;只移除穩態噪聲底,保音樂/瞬態)。

API 用法

#include "mmse_lsa_denoiser.h"

/* mono pipeline 的實際組態:canonical 強度 preset + pipeline overlay */
MmseLsaConfig cfg = mmse_lsa_config_for_mode_grid(16000, 512, MMSE_LSA_NR_BALANCED);
cfg.broadband_threshold = 0.8f;                    /* AEC 殘差 pipeline 專屬 overlay */
cfg.L = mmse_lsa_retime_frames(150, 16000, cfg.hop_size);
cfg.alpha_decay = cfg.alpha_g;

size_t bytes = mmse_lsa_get_mem_size(&cfg);        /* 0 = config 無效 */
MmseLsaDenoiser* d = mmse_lsa_init(pool, bytes, &cfg);   /* 或 mmse_lsa_create(&cfg) */

for (每個 hop) {
    /* 呼叫端已有 E(f) = AecResContext.error_spec(或自行 window+FFT) */
    /* extra = ctx.r2[k] / 32768²(unified gain);純 NR 傳 NULL */
    mmse_lsa_process_gain(d, error_spec, extra_noise_psd, NULL);
    const float* g_nr = mmse_lsa_get_gain(d, NULL);   /* [g_min,1],下一次呼叫前有效 */
    /* pipeline:g_total[k] = min(g_nr[k], ctx.res_gain[k]);套用+IFFT+OLA 由呼叫端 */
}
mmse_lsa_destroy(d);   /* mmse_lsa_init 實例為 no-op */

獨立使用(不外接 RES)可改用 mmse_lsa_process(d, spec_in, spec_out):直接把增益套在頻譜上,可 in-place。查詢:mmse_lsa_get_spp/get_noise_psd/get_gain/is_initialized/debug_status。切換音訊流呼叫 mmse_lsa_reset()。

延遲與 warm-up

  • 演算法延遲 = 0 樣本:mmse_lsa_get_latency() 回 0。頻域增益同 hop 產出;框架延遲(window+FFT / IFFT+OLA,50% overlap 下為 1 hop)由呼叫端的 transform 負擔——mono pipeline 的端到端 1 hop 就來自這層(參見 aec.html 延遲表)。
  • Warm-up = num_init_frames(≈200 ms,格點重定時:16k/256=25 幀、16k/512=13 幀、48k=19 幀,實測):期間累積噪聲底、增益=1 直通(不抑制),滿幀後 mcra_init_noise() 完成初始化,mmse_lsa_is_initialized() 轉 true。
  • MCRA 最小值追蹤窗 L(balanced 實測 64/32/48 幀 ≈ 512 ms)決定噪聲底適應新環境的時間尺度;scene-change 偵測(hi-freq γ + 頻譜平坦度,broadband_threshold<1 時另有寬頻 reset)提供快速路徑。
