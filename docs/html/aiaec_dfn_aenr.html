DeepFilterNet-AENR（linear AEC → RES+NR，project variant）

概要

以本地 AINR/DeepFilterNet2 cascade/alpha graph 為骨幹的 project variant（非上游 DeepFilterNet AEC 模型）。task（dataset_gen/model_views.py）= linear_aec_postfilter_res_nr_dereverb：輸入是凍結 PBFDKF 的 linear_error 與未對齊 far-end；target 是 near_target。與其他候選不同， 公開 forward 收 5 個 tensor：linear_error（normalized 複數頻譜）+ error_erb / error_spec / far_erb / far_spec（extract_dfn2_features 產物）。命名陷阱：error_spec/far_spec 是 DF feature （[B,2,T,df_bins]），不是頻譜；真正的頻譜輸入叫 linear_error。 兩個 1×1 conditioner（erb_condition/spec_condition）融合 error/far 特徵，初始化為精確的 error-only pass-through（test： test_deepfilternet_conditioner_is_error_passthrough_at_init）。

Grid 預設：16k 512/512/256、df_bins=64；48k 1024/1024/512、 df_bins=96；n_erb=32、df_order=5。參數量實測：16k 預設 2,113,480、48k 預設 2,134,984 trainable。全 repo 唯一 normalized=True STFT（model_views.py 的 normalized_stft； streaming 時 StreamSTFT 幀乘 n_fft**-0.5，實證與 torch bit-equal，ISTFT 前 乘回 n_fft**0.5）。

stream_output_delay = 2 hops（16k = 32 ms、48k ≈ 21.3 ms）： mask_lookahead=1 與 df_lookahead=1 在 DFN2 cascade 中串聯 （compose 先 mask 後 DF，DF 的未來 tap 吃的是「已套 mask 的譜」）。要 1 hop 須 df_lookahead=0 並重訓。create_stream_state() 會驗證 mask_lookahead + df_lookahead == stream_output_delay，不符即拒絕。

ONNX / NPU graph boundary（尚無 export 檔；boundary 由 streaming reference 與 C twin AINR/DeepFilterNet2/dfn2_process.h（dfn2_compose_stream， 單輸入 DFN2 版骨架）固定）：graph 內 = 兩個 1×1 conditioner、 LookaheadConv2d（erb_conv0/df_conv0，lookahead 1 幀）、conv stack、 SqueezedGRU_S ×3（encoder/erb_dec/df_dec）、ERB mask head（sigmoid）、DF coefs head、 alpha head（sigmoid）。compose（ERB mask 套用、5-tap 複數 DF FIR、alpha blend、 post_filter）在 Python reference 中位於 forward_stream 內，部署契約由 dfn2_compose_stream 的 C ring 實作承接（DF ring 存的是已套 mask 的低頻譜； 高頻段必須同步延遲——dfn2_process.h 明文警告）。graph 外（C 前處理）= PBFDKF、normalized STFT×2、extract_dfn2_features 的兩條獨立 EMA normalization（error/far 各一，逐幀一階遞迴、固定常數初值——共用會被 model_views.py 拒絕）；（C 後處理）= 逆 scale + WOLA ISTFT。AENR 化尚需在 C 端加開 error/far 前處理 state 與兩個 conditioner（readiness §3.6）。無 lsnr head， 不能複製上游 per-frame stage skipping。

API 用法

from AIAEC.DeepFilterNet_AENR.denoise import load_model
from AINR.DeepFilterNet2.train import extract_dfn2_features, read_feature_config
from AIAEC.aiaec_streaming import StreamSTFT, StreamISTFT

model, grid, linear_contract = load_model("ckpt.pth", "cpu")
feature_cfg = read_feature_config(cfg_ini, grid.sr, grid.hop_len)
state = model.create_stream_state()
err_ema = far_ema = None                     # 兩條獨立 EMA state（不可共用）
scale, inv_scale = grid.n_fft ** -0.5, grid.n_fft ** 0.5
# 每個 StreamSTFT 幀（err_frame / far_frame）：
err_spec = (err_frame * scale).unsqueeze(-1)                 # (B, 257, 1)
_, error_erb, error_feat, err_ema = extract_dfn2_features(
    err_spec, model.erb_fb, model.df_bins,
    feature_cfg=feature_cfg, ema_state=err_ema)
_, far_erb, far_feat, far_ema = extract_dfn2_features(...)   # far 同理
out = model.forward_stream(linear_error=err_spec.transpose(1, 2),
                           error_erb=error_erb, error_spec=error_feat,
                           far_erb=far_erb, far_spec=far_feat, state=state)
for k in range(out.enhanced.shape[1]):       # 前 2 次呼叫 T=0，之後每次 1 幀
    samples = istft.push(out.enhanced[:, k] * inv_scale)
tail = model.flush_stream(state)             # 補最後 2 幀（offline 右零 padding 重演）
python3 AIAEC/DeepFilterNet_AENR/streaming.py checkpoint.pth mic.wav far.wav out.wav \
    [--config config.ini] [--verify] [--device cpu]

延遲與 warm-up

  • 演算法延遲 2 hops（mask 1 + DF 1 串聯；16k = 32 ms）+ centered framing 半窗 1 hop。前 2 次 forward_stream 回傳 T=0（shape-consistent 空輸出），之後每次 1 幀；flush_stream 必須呼叫——重演 offline 右零 padding 補出最後 2 幀 （test 斷言：per_call = [0,0,1,1,…]、tail_frames = 2）。
  • 實測 stream-vs-offline（T=90，fp32 CPU）：enhanced 3.4e-7、mask 6.0e-8、coefs 1.3e-7、alpha 6.0e-8；TOL 釘 1e-5（test_streaming_dfn_aenr.py 檔頭）。 feature 逐幀化（EMA 串接）≤1e-6（test_feature_extraction_streams_frame_by_frame）。
  • EMA normalization 為逐幀一階遞迴、固定常數初值（streaming-safe，非全段統計）； 16k/hop256 實測 norm alpha = 0.984（τ = 1 s），冷啟動 normalization 需數個 τ 收斂。現行 AIAEC call site 均 per-utterance cold start（ema_state=None）。
  • flush 帶 budget guard：2*(mask_lookahead+1) 次零幀內必須 drain 完，否則 RuntimeError。
