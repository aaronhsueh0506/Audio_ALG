Align-ULCNet pipeline 的參數表(外部／內部)

概要

分類準則同 pipeline_dfn_params:外部 = 第三方整合者可以調的;整合者專用 = 串接拓樸;內部 = 存在且可改、但不建議開放。範圍涵蓋 mono 與 4ch 兩個範例使用的設定面。出處是 Audio_ALG 內的 檔案:行號(行號隨原始碼移動,以符號為準)。

沒有執行期強度 setter,而且是刻意的:這條鏈沒有 RES、NR 實例，AEC 側只留線性半邊，塑形輸出的是 ULCNet 的 mask，所以「回音壓多深」是模型的性質。要改強度請重新訓練／更換模型，或改用有 DSP 後級的 pipeline_mono／pipeline_4ch。
