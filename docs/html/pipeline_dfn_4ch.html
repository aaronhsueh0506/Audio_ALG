4ch AEC → BF → RES → DeepFilterNet2 後級(flow + helper + dfn_hop)

概要

pipelines/dfn/4ch_aec_bf_dfn_res/main.c:建在四聲道 flow mcab(pipelines/4ch_aec_bf_nr_res/mcab.h:共用 delay、四條線性 AEC lane、投影融合)與 sample 層的 SRP-PHAT／BF helper(mcab_sample_beam.h)上的範例,把傳統鏈的 post-beam MMSE-LSA 換成 DeepFilterNet2。沒有 DFN wrapper 函式庫,mcab 也不是函式庫而是 flow 層:應用先建立 libaec 物件(四條 Aec lane 與 MATCHED 下共用的 DelayAec;範例經 mcab_sample_flow.h 在一塊記憶體內建好)再以指標交給 mcab,mcab 只擁有自己的 flow 狀態(delay admission、對齊 ring、fuse 緩衝)。範例另外建 libaec 的 AecRes(RES)與 dfn/dfn_hop.h(stage 或 rate bridge);各物件的 mem_size 由 main.c 加總並切塊。

每 hop 呼叫 mcab_sample_beam_process()(mcab_process_front() 加 helper 的 SRP-PHAT、BF 與 fallback VAD)與 mcab_sample_beam_fuse()(轉呼叫 mcab_fuse(),填 McabFrame,g_res_ctx 為 NULL),再以 mcab_sample_res_input(&frame, &in)(mcab_sample_post.h)加 aec_res_process(res, &in) 取 RES 增益。範例自己擁有 AecRes、增益暫存、comfort-noise 狀態與(48 kHz 時)ISTFT(在 DfnHop 的呼叫端物件裡),在 dfn_form() 明寫 sk_min_f32 → sk_capply_gain_f32 → aec_cng_fill 形成 P,再把 E、P 交給共用的 pipelines/dfn/dfn_res_stage.{h,c};mcab 不含 RES／NR／合成,也不含 beamformer。要接自家 beamformer 的產品改直接呼叫 mcab_process_front() 與 mcab_fuse(p, W, E, &frame)(W 是呼叫端的 Complex[4][n_freqs] 權重,E 是同一次 beamform 的頻譜或 NULL),同樣自備 AecRes(見 pipeline_4ch)。中段的 DFN2 與 mono 是同一份程式碼,signal/timing 契約見 pipeline_dfn_mono,本頁只寫四聲道特有的部分。

核心跑產品自己的取樣率(預設 16 kHz),只有 DFN2 stage 在 48 kHz。--sample-rate 接受 16000 或 48000,沒有 8 kHz。48 kHz 時 stage 直接吃核心的頻譜;16 kHz 時範例改建一個 DfnRateBridge(pipelines/dfn/dfn_rate_bridge.{h,c})負責原生格點 ↔ 48 kHz 的來回,每個 native hop 進一個、出一個。四條 AEC lane、SRP-PHAT／BF、RES 與 CNG 一律留在產品取樣率,呼叫端不必在 API 之外先 resample。Bridge 的排程、prefill 與 added delay 與 mono 共用(pipeline_dfn_mono)。

估計用 E、套用在 P(四聲道版本)

E = frame.e(McabFrame,pre-RES 的 beamformed 線性誤差頻譜)只送進網路做估計;P = dfn_form() 組出的頻譜(E * min(1, G_res) + comfort noise)才是三個 head 套用的對象;理由與 mono 相同,comfort-noise fill(--cng 才開)預設關閉。

API 用法

呼叫順序:查大小、切塊、init(mcab_sample_flow_init() → mcab_sample_beam_init(…, flow) → aec_res_init() → dfn_hop_pool_build())→ 每 hop 一次 → dfn_cleanup()(stage／bridge、helper、flow 依序 destroy)。每個 hop 先 mcab_sample_beam_process(),再 mcab_sample_beam_fuse() 填 McabFrame(借用視圖),aec_res_process() 取 RES 增益,自寫的 P 形成,再 dfn_hop_process() 一次收尾,或用 dfn_hop_begin → nn_begin／nn_end 迴圈 → dfn_hop_end 自己在中間跑加速器。沒有 token:helper 與 flow 用 phase 擋順序(沒有本 hop 的 beam 就 fuse 回 MCAB_SEQUENCE_ERROR),DfnHop 另有 phase 擋 begin／nn／end 的次序;每次 dfn_hop_end 寫出剛好一個核心 hop(16 k/256 為 128、16 k/512 為 256、48 k/1024 為 512)。範例、時序圖與參數表見 usage、sequence、params。每 hop 的核心:

McabSampleBeamResult beam;  McabFrame frame;  AecResInput in;   /* unit = McabSampleBeam* */
mcab_sample_beam_process(unit, mics_interleaved /* [hop][4] */, ref, &beam, NULL);   /* delay、4 lane、SRP-PHAT、BF */
mcab_sample_beam_fuse(unit, &frame);                      /* = mcab_fuse(flow, beam.weights, beam.spectrum, …);g_res_ctx 為 NULL */
mcab_sample_res_input(&frame, &in);                     /* frame 的 e／y／r2／cn／far_hop 等組成 libaec 的 RES 輸入 */
const float *g_res = aec_res_process(res, &in);          /* 應用自備的 AecRes(libaec);NULL = 被拒,走 reset */
sk_min_f32(gain, unity, g_res, n_freqs);                  /* P 必須在 dfn_hop_begin 之前形成 */
sk_capply_gain_f32(post, frame.e, gain, n_freqs);         /* P = E * min(1, G_res) */
if (cng_on && frame.cn)                                  /* 預設關: E 與 P 要同相位 */
    aec_cng_fill(&rng, post, frame.cn, g_res, unity, MCAB_SAMPLE_CNG_NR_GAIN_FLOOR, n_freqs);

dfn_hop_process(&hop, frame.e, post, out);                /* (a) 一次完成:模型由 model.infer 執行(沒設就是 identity) */
/* (b) 或自己在中間跑加速器:dfn_hop_begin → while (dfn_hop_nn_begin() > 0) { 跑 NPU; dfn_hop_nn_end(rc) } → dfn_hop_end(&hop, out) */

stage 與 bridge 的 reject-first 清單(最容易踩到的是 erb_inv 必須是 partition of unity)見 pipeline_dfn_detail。helper 的 process／fuse 回非 MCAB_OK(mcab_sample_beam_fuse() 的 DSP 類拒絕已 reset helper 與 flow)、aec_res_process() 回 NULL、stage 或 bridge 拒絕,整合者都要把 helper(mcab_sample_beam_reset(),連帶 reset flow 的 lane 與 estimator)、AecRes(aec_res_reset())、CNG RNG 與 DfnHop 一起 reset(main.c 的 dfn_reset())。

Block diagram(每 hop 程式流)

       → doa_step() SRP-PHAT → bf_process_with_weights() BF(RLS)→ beam.spectrum / beam.weights(helper 借用)
       (delay.changed 只回報給外部 far 消費者;序列閘由 helper 與 flow 的 phase 管)

mcab_sample_beam_fuse(unit, &frame)                 → McabFrame
 │     mcab_fuse(flow, beam.weights, beam.spectrum, &frame):用 BF 權重與頻譜做 coherent projection

P 的形成(main.c 的 dfn_form(),自寫):
 ├─ sk_min_f32(g_total, unity, g_res) → sk_capply_gain_f32(post, frame.e, g_total)
 └─ aec_cng_fill(&rng, post, frame.cn, g_res, unity, …)   (cng=1 時)
       post = P [n_freqs] Complex  (= E*min(1,G_res) + CNG)

dfn_hop_begin(&hop, E, P)                                    (phase 0 → 1)
 ├─【48 kHz】dfn_res_stage_begin(stage, E, P, &job)       ← 與 mono 同一份
 │      inputs_valid(E,P);A = E*0x1p-5f, B = P*0x1p-5f → pre_process_freq_dual()
 │      回 1 = job 已開(前 M 個 hop 回 0,出貨 M=1 即第 0 個 hop;輸出頻譜到第 L 個 hop 才有)
 └─【16 kHz】dfn_rate_bridge_begin(bridge, E, P)
        原生 AcIstft(E、P 各一個)→ 兩顆 audio_resampler 升到 48 kHz(×3)→ 48 kHz FIFO

while (dfn_hop_nn_begin(&hop, &job) > 0) {            (phase 1 → 2;每 hop 0..2 次)
    rc = run_npu(&job);          ← 呼叫端:DFN2PrepostInputs → 加速器 → DFN2PrepostOutputs
    dfn_hop_nn_end(&hop, rc);                          (phase 2 → 1)
}   【48 kHz】dfn_res_stage_end(stage, rc, stage_output):rc≠0／輸出未寫／非有限 → frame_skip() ← fail-open
    【16 kHz】bridge:48 kHz FIFO 每滿 512 開一個 job;nn_end 後 stage_end → 降頻 → 原生 out FIFO

dfn_hop_end(&hop, out)                                       (phase → 0)
 ├─【48 kHz】沒被取走的 job 走 identity;ac_istft_push(istft, stage_output, out)
 │       stage_output = valid ? Y*0x1p5f(frame t-L) : 全零
 └─【16 kHz】dfn_rate_bridge_finish(bridge, out):從 out FIFO(init 預填 prefill 個零)取剛好一個 native hop

dfn_hop_process(&hop, E, P, out) = 上面四個呼叫的序列,模型由 model.infer(經 dfn_res_stage_infer)執行
任一步失敗 → 整合者 reset(helper + AecRes + rng + hop)後重來(main.c 的 dfn_reset())

訊號泳道圖

48 kHz 核心的泳道與 mono 完全相同:每 hop 一次推論,前 M 幀沒有右鄰居所以不呼叫加速器,stage 前 L 個 hop 輸出全零頻譜,之後第 p 個 hop 的輸出就是「傳統核心的 hop#(p-L) 輸出」(出貨 pair:M=1、L=2,合計 3 hop = 1536 samples 純延遲);四聲道前級本身不加延遲。16 kHz 核心多了 bridge 的第二個時鐘:

延遲與 warm-up

  • 端到端演算法延遲 = 合成的 1 hop WOLA + DFN2 段的延遲(範例 main.c 以 hop 加 dfn_rate_bridge_added_delay_samples() 或 hop * (DFN_RES_STAGE_LOOKAHEAD_FRAMES + 1) 印出)。48 kHz 時 DFN2 段就是 L = M + D 個 hop 的模型 lookahead(DFN2_MASK_LOOKAHEAD + DFN2_DF_LOOKAHEAD,cascade 串聯相加而非取 max;出貨 pair 1/1 → 2);16 kHz 時是 bridge 的 added delay。下表是出貨 pair 的數字,其他 pair 的規則見 pipeline_dfn_detail。
核心格點hopprefillbridge added delay總演算法延遲
16 kHz / fft 256(預設)128128672(42.0 ms)800 samples = 50.0 ms
16 kHz / fft 51225685629(39.3 ms)885 samples = 55.3 ms
48 kHz / fft 1024512—(無 bridge)—1536 samples = 32.0 ms(3 hop)
  • added delay 的組成(prefill + 16 + (L+1)×512×sr/48000 + 16,整數除法;出貨 pair 為 1536×sr/48000)與 prefill 的 init 校正和 mono 相同,見 pipeline_dfn_mono;8 kHz 不在 mcab 的格點內,範例拒絕。
  • 16 kHz 不是逐位元等值:訊號走過兩顆 FIR resampler,測試用容差(0.35 fs 低通後閘 < 1e-3,現查 8.70e-06 / 8.91e-06),延遲本身由近端脈衝精確釘住。
  • Warm-up:開頭的輸出是全零(48 kHz 為 L 個 hop,16 kHz 為 added delay),stage 寫滿零頻譜,呼叫端無條件合成。前 M 幀不呼叫加速器(graph 視窗 [t-(2-M)..t+M],右鄰居還沒到);之後 48 kHz 每 hop 恰好一次推論,16 kHz 照泳道圖的排程。
  • AEC delay 改變不 reset stage/bridge。front.delay.changed 仍回報給外部 far-end 消費者,但 stage 與 bridge 都不消費 far-end,輸入在 delay 改變後仍然連續(前端自己對四條 lane 做 realign;dfn_res_stage.h 開頭)。只有整合者的 reset(dfn_hop_reset(),連帶 model.reset)才會這麼做;mcab_sample_beam_fuse() 的 DSP 類拒絕只重置 helper 與 flow(lane、estimator、SRP、BF),範例在任何失敗處再把 AecRes、CNG RNG 與 DfnHop 一起 reset。收尾 flush 再推 L 個全零 hop(16 kHz 推滿 added delay),那幾拍加速器也要照跑。
